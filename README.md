# ElondiaRPG — 埃隆迪亞大陸

以 UI 操作數值、行動與戰鬥的奇幻 RPG 網頁遊戲。規則與數值由遊戲引擎處理；每次行動、事件或戰鬥結束後，引擎輸出一份結構化報告，再交給 AI 寫成事件的詳細經過（AI 可以關閉，不設定也能玩）。整個世界——怪物、物品、NPC、任務、事件、世界書——都可以在遊戲裡修改，或做成「世界包」分享。

![埃隆迪亞大陸地圖](assets/map/elondia-map.webp)

## 遊玩

目前版本 v0.1.0（更新內容見 [CHANGELOG](CHANGELOG.md)）。

- 從 [Releases](https://github.com/yellow630914/ElondiaRPG/releases) 下載 zip，解開後用任何靜態網頁伺服器開啟（例如在資料夾裡執行 `npx serve` 或 `python -m http.server`）。**不能直接雙擊 `index.html`**：瀏覽器不允許從檔案載入模組。也可以照下面「自己建置」用 `pnpm dev` 執行。
- 存檔、世界與設定都存在你自己的瀏覽器裡（換瀏覽器或清除網站資料就不見了，記得用「💾 存讀檔」匯出備份）。
- 介面可以切換成簡體中文（「⚙️ 設定」右上角的「介面 / 界面」）；AI 寫的正文用哪一種，由「AI 的輸出語言」決定。見 [`docs/I18N.md`](docs/I18N.md)。
- 要 AI 寫敘事時，在「⚙️ 設定」填入自己的 API key：key 只存在這台瀏覽器，請求直接從瀏覽器送到你選的服務。除此之外遊戲不連任何外部伺服器（字型也隨遊戲打包）。

### 畫面

- **首頁**：繼續、開新遊戲、讀取存檔、🌍 世界管理、🧩 提示詞、設定與素材授權。
- **遊戲中**上方是「🗺️ 冒險」「🌍 世界」「🧩 提示詞」分頁，以及天數、所在地、金錢、待處理的事（🔔）、快速存讀檔、存讀檔、設定與回首頁。
- **冒險分頁**分成三欄：
  - 左：地圖（方向鍵或 WASD 移動）、隊伍卡、休息、主動行動與行動備註。
  - 中：工具列（隊伍、行囊、關係、冒險筆記、工藝）與冒險日誌；戰鬥時換成戰鬥畫面。
  - 右：所在設施的選單（酒館、商店、神殿、公會……各有自己的選單與對話框）、這裡的人、委託與旅行。
- 角色詳情（屬性、特質、紙娃娃換裝、刺青圖、角色設定、能力）從隊伍卡打開。

### AI 功能（都可以關閉）

- **AI 細節描述**：每次行動、事件或戰鬥結束後，請 AI 寫出經過（串流顯示）；關閉時顯示戰報與簡述，也可以複製提示詞自行使用。
- **AI 判定主動行動**：用文字描述主角要做的事，擲骰後由 AI 決定成敗並寫出經過，數值後果由程式夾在上限內；也讓 AI 設計各地居民、商店的交易清單與店名、談判方式。
- **服務**：Anthropic、OpenAI、Google Gemini，以及 OpenAI 相容格式（DeepSeek、阿里雲百煉、智譜、Moonshot、OpenRouter、Ollama……）。可以設定三個模型來源，再指定每個功能用哪一個（例如正文用寫作好的模型、判定用便宜的模型）；每則日誌顯示用掉的 token。見 [`docs/PROMPTS.md`](docs/PROMPTS.md)。
- **插圖**：替主角、夥伴與 NPC 生成形象圖（OpenAI、NovelAI、ComfyUI），可以先請語言模型把描述轉成標籤；也可以上傳自己的圖。見 [`docs/PORTRAITS.md`](docs/PORTRAITS.md)。

## 遊戲內容

**角色與成長**
- 6 種族（人類、精靈、矮人、魔族、貓魅族、玉璘族）、10 個戰鬥職業與普通人；五屬性、自由點數、出生地、外貌與背景（交給 AI 作為描寫依據）。
- 特質與缺陷（建角時挑選、升級或訓練取得）、建角裝備預算；升級分配屬性點、三選一學習能力（可以重抽）。
- 215 項技能、法術與戲法；刺青與誓約印記（11 個部位、28 種圖樣）。

**世界與探索**
- 6 個地區、26 個聚落、16 座地下城、44 個城鎮地標；城市與城鎮是固定的格子地圖，近郊與地下城（淺層、中層、深層、底層、深淵）隨機生成，有戰爭迷霧與光照。
- 旅行：依世界書的路程，一格一天的旅途地圖，出發時擲好事件（天候、檢定、選擇、戰鬥、洞窟與遺跡的臨時地圖、特殊任務的開頭），抵達時結算食宿；車資與路線依地區。
- 城鎮事件、地標的參訪與探索、特殊地圖（例如萊茵堡下水道、古蓄水池這類城鎮底下的地圖）。

**戰鬥**
- 逐回合：行動點、法術環、命中對迴避、幸運一擊、13 種傷害屬性、增益與減益；241 種怪物，地下城每層有層主。
- 戰鬥中可以用藥劑、投擲物與卷軸；戰後產生戰報、分配經驗；在地下城戰敗時，這趟撿到的東西怎麼處理可以在設定裡選。

**城鎮生活與經濟**
- 旅店、神殿、酒館、雜貨店、鐵匠鋪、裁縫店、珠寶店、魔法物品店、情報商、冒險者公會、娼館、市場；每間店每天一份交易清單，可以殺價、談長期折扣。
- 680 種物品；14 個裝備欄位（底材 × 材料、稀有度與附魔），委託打造或自己打造；鍊金、烹飪、工藝與配方（也可以自己發明配方）。
- 買房子、擺家具、在家休息與園藝；在各種設施打工。
- 貨幣統一為阿爾貝納發行的白鸛幣；聲望影響價格、王城與地標的進出；犯案被目擊會提高警戒，滿了會被通緝。

**夥伴與人際**
- 酒館雇傭（可以自訂出價與談判）、加入別人的隊伍、邀請認識的人；各地有固定與流動的 NPC，可以聊天、送禮、獻媚、偷竊、偷襲。
- 親密度、人際關係與冒險記憶，生成敘事時依參與人、地點與時間檢索後交給 AI；AI 可以提議更新關係描述，由玩家確認。
- 奴隸系統（公開與黑市的市場、契約印記；主角也可以是奴隸，有主人的事件與主人的家）。成人向內容可以在設定裡開關，關閉時相關場景改成一般的描寫。

**委託與任務**
- 冒險者公會 F～S 級：巡邏、討伐、採集、怪物掉落、層主與整層清除的委託，有期限；累積功績參加升級考核。
- 特殊任務：人工編寫的任務鏈，用劇情旗標串起劇情、判定、戰鬥、選擇，有固定的 NPC 與獨特的報酬；從公會、固定 NPC、旅途或情報商開始。
- 📒 冒險筆記：委託、特殊任務（目前的目標與經過）、情報。

**存檔**
- 多個存檔欄位、快速存檔／讀檔（F8 或 Ctrl+S／F9）、長休與抵達時自動存檔、讀檔前自動備份；存檔可以匯出成檔案（附上世界的自訂內容，可以選擇附上形象圖）。

## 自訂與世界生成

- **🌍 世界**：可以有好幾個世界，每個存檔記得自己用的世界。每個世界可以新增或修改怪物、物品、底材與材料、技能、狀態、特質、刺青與印記、地標、特殊地圖、商店、固定 NPC、特殊任務、旅途與城鎮事件；物品、底材與類別可以上傳圖示。內建項目都可以恢復預設。見 [`docs/CONTENT_EDITOR.md`](docs/CONTENT_EDITOR.md)。
- **🧩 提示詞**：文風、世界書（SillyTavern 格式，可以匯入匯出）、敘事與判定的規則都可以編輯，存成多組；世界可以綁定一組提示詞。
- **世界包**：一個檔案帶著世界的自訂內容與提示詞，「📥 匯入成新的世界」就能用，不會動到原版世界。
- **世界生成指南**（[`worldgen/`](worldgen/README.md)）：給 Agent 或玩家依序生成一整個世界的指南——每種內容的新增編輯指南、平衡性自檢方法、固定 NPC 與特殊任務的設計方法、填寫式的世界模板、世界書的寫回方式，以及檢查工具（`WORLD=<世界包> npx vitest run src/__tests__/worldCheck.spec.ts`）。
- **隨附的世界包「艾隆迪亞擴充」**（[`worldgen/worlds/elondia-plus/`](worldgen/worlds/elondia-plus/README.md)）：替各地補上 85 位固定 NPC（統治者、機構首長、地標與鄉間人物）、37 條特殊任務（大陸主線「龍影之兆」5 章、地區故事線、內建角色的任務線、地下城傳說）與對應的世界書條目。

## 自己建置

需要 Node.js 22.18 以上、Git 與 [pnpm](https://pnpm.io/)（11 版）。

```bash
git clone -b claude/admiring-tesla-zzw8ii https://github.com/yellow630914/ElondiaRPG.git
cd ElondiaRPG
pnpm install
pnpm dev               # 開發伺服器（預設 http://localhost:5173）
pnpm test:unit --run   # 測試
pnpm build             # 型別檢查 + 建置到 dist/（相對路徑，放在任何網頁伺服器的任何路徑底下都能用）
```

- 推送版本 tag（`v0.1.0` 這類）時，GitHub Actions 會跑測試、建置，建立 GitHub Release 並附上 zip（`.github/workflows/release.yml`）；平常推送不會觸發。
- `pnpm-workspace.yaml` 已經設定好不執行 `@google/genai` 與 `protobufjs` 的安裝腳本（兩者都不需要），所以 `pnpm install` 不會出現 `ERR_PNPM_IGNORED_BUILDS`。
- 也可以用 npm（`npm install`、`npm run dev`）。`.npmrc` 的 `legacy-peer-deps` 是為了避開 npm 10 在解析 vitest 選用依賴時的錯誤。
