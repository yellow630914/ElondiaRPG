# ElondiaRPG — 埃隆迪亞大陸

以 UI 操作數值、行動與戰鬥的奇幻 RPG 網頁遊戲。每次行動、事件或戰鬥結束後，遊戲引擎輸出一份結構化報告，再交給 AI 寫成事件的詳細經過。

![埃隆迪亞大陸地圖](assets/map/elondia-map.webp)

## 執行

需要 Node.js 22.18 以上、Git 與 [pnpm](https://pnpm.io/)。

```bash
git clone -b claude/admiring-tesla-zzw8ii https://github.com/yellow630914/ElondiaRPG.git
cd ElondiaRPG
pnpm install
pnpm dev               # 開發伺服器
pnpm test:unit --run   # 測試
pnpm build             # 型別檢查 + 建置到 dist/
```

開發伺服器啟動後，用瀏覽器打開終端機顯示的網址（預設 http://localhost:5173）。

畫面分成三欄：左邊是地圖、「👥 隊伍」與「💞 關係」視窗按鈕、主動行動、休息與行動備註；中間是冒險日誌（戰鬥時換成戰鬥畫面）；右邊是目前所在設施的選單、委託與旅行。設定在右上角。AI 提議更新人際關係描述時，右下角會跳出提醒。

**AI 細節描述**可以在「⚙️ 設定」或日誌上方開關：

- 開啟：每次行動、事件或戰鬥結束後，自動請 AI 寫出詳細經過。需要先在「設定」選擇 AI 服務並填入自己的 API key（Anthropic、OpenAI、Google Gemini，或 OpenRouter / DeepSeek / Ollama 等 OpenAI 相容格式）。可以設定三個模型來源，再指定每個功能用哪一個，例如正文用寫作好的模型、判定與各種清單用便宜的模型（見 [`docs/PROMPTS.md`](docs/PROMPTS.md)）。
- 關閉（預設）：不呼叫 AI，戰鬥直接顯示戰報，其他事件顯示簡述。

**AI 判定主動行動**（「設定」，預設關閉）：開啟時，主動行動擲骰後由 AI 決定結果並寫出經過，各地居民的名字與設定、商店的交易清單與談判方式也由 AI 設計；關閉時依規則判定與生成。

> - `pnpm-workspace.yaml` 已經設定好不執行 `@google/genai` 與 `protobufjs` 的安裝腳本（兩者都不需要），所以 `pnpm install` 不會出現 `ERR_PNPM_IGNORED_BUILDS`。
> - 也可以用 npm（`npm install`、`npm run dev`）。`.npmrc` 的 `legacy-peer-deps` 是為了避開 npm 10 在解析 vitest 選用依賴時的錯誤。

## 目前可以做什麼

- 建立角色：6 種族、10 職業、五屬性與自由點數；自選出生地（冒險的起點），自行填寫性別、外貌與背景（會交給 AI 作為描寫主角的依據）
- 走格子：城市與城鎮是固定的格子地圖（可在區塊間移動），近郊荒野與地下城四層是隨機生成、有戰爭迷霧
- 依世界書路程旅行：旅途是一條一格一天的單行道地圖，出發時擲好的事件放在格子上（天候與自動檢定、選擇事件、戰鬥、進入洞窟／遺跡／驛站的高階事件、特殊任務的開頭、主人的事件），抵達時結算食宿與乾糧（見 [`docs/TRAVEL_EVENTS.md`](docs/TRAVEL_EVENTS.md)）
- 旅店、神殿、雜貨店、酒館、冒險者公會，以及鐵匠鋪、裁縫店、珠寶店、魔法物品店、情報商都是地圖上的設施（小城鎮與村莊只有鐵匠鋪和裁縫店）
- 商店與交易：每間店每天一份交易清單（可由 AI 依商店類型生成），交易內容可以組合金錢、物品、好感度、情報甚至夥伴；一般交易直接計算，想殺價時才檢定
- 談判：委託報酬、打聽門路、長期折扣；選擇談判方式依規則檢定，自己描述做法則交給 AI 判定；結果可以是任務旗標或報酬
- 自訂內容：在「🛠️ 內容」頁籤新增或修改怪物（技能、掉落、出現地點）、物品（商店、寶箱、採集、事件、怪物掉落）、裝備的底材和材料、固定 NPC（出現的地方或固定的格子、劇情條件、屬性、技能、初始裝備）與特殊任務；內建項目可以恢復預設
- 行囊與裝備：11 個裝備欄位（底材 × 材料，稀有度與附魔）；裝備來自商店、地下城寶箱、敵對冒險者與人形怪物的掉落；在鐵匠鋪、裁縫店、珠寶店委託打造（自備秘銀礦石、龍皮之類的打造材料，AI 替成品取名與附魔）；戰鬥中可以用抗性與強化藥劑、投擲物與 20 多種卷軸
- 夥伴：酒館雇傭（可自訂出價與談判方式）、加入別人的隊伍、奴隸市場（公開與黑市，可殺價）、主角作為奴隸（可在建立角色時選擇；主人可挑選、自訂或無主；刻印檢定、出城要主人同意、主人突發事件（三選一或自己輸入回應）、在安全的地方談判或隨時逃離）、事件入隊與主動邀請；親密度 ≤ -20 的同伴會在休息時離隊；奴隸契約印記有不同的限制與副作用，也可以自訂名稱、描述與數值；主角對自己的奴隸行動有優勢
- 工作與娼館：在酒館、旅店、神殿、各種商店、公會、娼館工作換錢（可描述做法）；娼館可以消費、老鴇可以收留無主的奴隸，有主的奴隸經過時可能被推進去工作；成人向關閉時娼館顯示為按摩店
- D&D 短休（生命骰）與長休（旅店、安全房）
- 主動行動：用文字描述主角要做的事，先擲骰，再把骰值與完整資料（隊伍、屬性、裝備、技能、人際關係、記憶）交給 AI，由 AI 決定成敗（可能出乎預料）並直接寫出經過；數值後果由程式夾在上限內
- 公會委託：F 級在城內與近郊，E 級以上在冒險區域；材料委託（近郊與地下城的採集、怪物掉落，可以過量交付到 3 倍）與層主討伐，帶著委託進入時會補足採集點與戰鬥點
- 特殊任務：人工編寫的任務鏈，用劇情旗標串起多個任務點（劇情、判定、戰鬥、選擇），有固定的 NPC、任務同行的夥伴與獨特報酬；從公會、固定 NPC、旅途或情報商開始；在「🛠️ 內容」編輯（見 [`docs/STORY_QUESTS.md`](docs/STORY_QUESTS.md)）
- 情報商：賣附近近郊或地下城的事件點（盤踞的強敵、藏寶處、流浪商人）與特殊任務的消息
- 📒 冒險筆記：一般委託、特殊任務（目前的目標與經過）、情報
- 逐回合戰鬥：行動點、法術環、命中對迴避、幸運一擊、13 種傷害屬性加成、10 類 BUFF／DEBUFF，10 個職業共 150 項技能／法術／戲法
- 戰後產生戰報、分配經驗；升級時分配屬性點並三選一學習能力
- 人際關係（親密度、外貌、與主角及他人的關係）與冒險記憶（時間、地點、參與人、簡述），生成文本時依參與人、地點、時間檢索後交給 AI；AI 可以提議更新關係描述，由玩家確認；記憶超過 200 筆時自動合併舊的日常記憶
- AI 細節描述可開關：開啟時自動生成敘事（串流顯示），關閉時顯示戰報與事件簡述；也可以複製提示詞自行使用
- 角色名牌：🐱莉娜🏹（種族、依性別上色的名字、職業）；認識的人只在他平常待的地方出現
- 各地有固定的 NPC 名單（冒險者與普通人約各半，帶標籤：旅人、商人、平民、貴族、神官……），每人依活躍地點每天出現在不同的地點與地區；王都有貴族區與王城；人散落在地圖的格子上（店主在店裡），走到旁邊就能聊天、送禮、獻媚、偷竊，冒險者可以雇用或偷襲；名單會慢慢變動，近郊與地下城會遇到人（可能是認識的人，也可能是惡人：先擲潛行，再選擇避開、偷襲、蒙混、威嚇、付過路費或開戰）
- 犯案被目擊會提高衛兵警戒、降低聲望：警戒時出入城門要盤查，警戒滿了會被通緝（只能繳罰金通過）；聲望影響買賣價格，王城需要聲望才能進入
- 貨幣統一為阿爾貝納發行的白鸛幣
- 長休時可以和夥伴或同旅館的旅客互動；升級的能力三選一可以重抽（次數可在設定調整）；事件與委託可能給技能報酬
- 戰鬥中可以使用藥劑等道具；主動行動可以搭配法術或技能（花法術環或使用次數換檢定加值）；委託板每天更新
- 每則日誌顯示 AI 呼叫用掉的 token（輸入／輸出／讀到的快取），並分開列出每次呼叫的功能與來源（模型來源名稱、服務、模型）；日誌上方有本局總計與依來源的合計
- 🧩 提示詞頁籤：多個文風條目與其他提示詞（可開關、編輯、排序，選擇套用到敘事或判定）；世界書條目的常駐／觸發狀態、注入順序與編輯（也可以新增條目）；查看主角、隊伍、人際關係與記憶的注入結果；預覽下一次送出的完整提示詞；世界書（SillyTavern 格式）、文風與其他提示詞可以各自匯入匯出。提示詞依「不太變動的在前、常變動的在後」排列，以提高快取命中率
- 存讀檔：多個存檔欄位、快速存檔／讀檔（F8 或 Ctrl+S／F9）、長休與抵達目的地時自動存檔（保留 3 份）、讀檔前自動備份；存檔可以匯出成檔案或匯入，目前進度也一直自動存在瀏覽器
