# 戰鬥系統 v0.3

> 所有數值都在 `data/rules/`，改 JSON 就能調整平衡，不必動程式。本文件第 9 節的能力清單由 `data/rules/abilities.json` 產生。
> 記號：`mod(x) = floor((x − 10) / 2)`，即 DND 的屬性調整值。

| 力量 | 力量武器的命中與傷害、**生命值**、力量豁免 |
| 靈巧 | 靈巧武器的命中與傷害、**迴避**、**行動點**、**幸運一擊**、先攻 |

## 2. 三資源

### 生命值（等級、力量、信仰）

```
最大生命值 = 8 + 等級 × max(1, 4 + mod(力量) + mod(信仰))
```

例：力量 16、信仰 14 的 1 級角色 = 8 + 1 × (4 + 3 + 2) = 17；5 級 = 53。

### 行動點 AP（等級、靈巧、魅力）

```
行動點上限 = max(3, 3 + floor(等級 / 5) + floor((mod(靈巧) + mod(魅力)) / 2))
每回合回復 = 2 + floor(等級 / 6)
```

- 戰鬥開始時 AP 全滿。輪到自己時可以**連續行動**，直到 AP 用完或選擇「結束回合」。
- 沒用完的 AP **累積到下回合**（不超過上限）。這讓「這回合省一點，下回合放大招」成為選擇。
- 有些技能會**產生** AP：戰士的戰鬥節奏（命中 +2）、動作如潮（+4），武僧的調息（每回合 +1），遊蕩者的影步（+2），法師的時間暫停（+10）。

| 行動 | AP |
|---|---|
| 武器攻擊 | 2 |
| 防禦（迴避 +3 直到下回合） | 1 |
| 撤退（`1d20 + 熟練 + mod(靈巧)` ≥ 12，全隊脫離） | 2 |
| 技能 | 各自不同（0～5），見第 9 節 |
| 法術 | 依環數：1-2 環 2、3-5 環 3、6-8 環 4、9 環 5（部分法術例外） |
| 戲法 | 0，但每回合只能用一次 |

### 法術環（等級、智力、信仰）

- **全施法者**（法師、牧師、德魯伊、吟遊詩人）依等級查表；**半施法者**（聖騎士、遊俠）以 `ceil(等級 / 2)` 查表，最高 5 環；戰士、野蠻人、遊蕩者、武僧不施法。
- 表格以 DND 為基礎，但環數的解鎖等級**對齊世界書**：1-2 環 Lv1-4、3-4 環 Lv5-9、5-6 環 Lv10-14、7-8 環 Lv15-19、9 環 Lv20。

## 3. 命中與迴避

每次攻擊都是**雙方對擲**，而不是對固定的防禦值：

```
命中骰 = 1d20 + 熟練加值 + mod(能力屬性) + 命中修正 + 幸運骰
迴避骰 = 1d20（下限 = 1 + max(0, mod(靈巧))）+ floor(mod(靈巧) / 2) + 防具迴避 + 迴避修正 + 幸運骰
命中骰 ≥ 迴避骰 → 命中；命中骰的自然骰為 1 → 必定失手
```

**靈巧不只是加值，還提高迴避骰的下限。** 靈巧 18（+4）的角色迴避骰最低是 5，永遠不會擲出 1～4；同時固定 +2。所以高靈巧角色擲出高迴避值的機率更高，不只是平移數字。

- 防具在迴避與減傷之間取捨：布衣 +1 迴避／0 減傷、皮甲 +1／1、鍊甲與盾 -1／3、板甲 -3／4。
- 暈眩的目標無法迴避（迴避骰視為 0）。
- **優勢／劣勢**：擲兩次取高／取低，來源相互抵銷。

熟練加值 = `2 + floor((等級 − 1) / 4)`。

## 4. 幸運一擊

```
閾值 = max(16, 20 − floor((mod(靈巧) + mod(魅力)) / 3)) − 修正（最低 12）
命中骰的自然骰 ≥ 閾值 → 幸運一擊：必定命中，且傷害骰數量加倍
```

- 一般角色只有 20 才會幸運一擊；靈巧、魅力都很高的角色可以降到 16。
- 技能（精準架勢 -2、暗殺 -4、終結一擊 -3）、狀態（致命節奏 -3）與天賦（貓魅族 -1）可以再降低，最低到 12。

## 5. 豁免

部分技能與大多數範圍法術要求目標**豁免**，而不是擲命中：

```
DC = 8 + 熟練加值 + mod(施法或技能屬性)
豁免骰 = 1d20 + mod(豁免屬性) + 豁免修正 + 幸運骰
豁免骰 ≥ DC → 成功：傷害減半（或無效，依能力而定），且不會被附加狀態
```

## 6. 傷害屬性與加成

13 種傷害屬性分成 4 個群組：

| 群組 | 屬性 |
|---|---|
| 物理 | 鈍擊、穿刺、斬擊 |
| 元素 | 火焰、寒冰、閃電、雷鳴、酸蝕、毒素 |
| 神聖與暗影 | 神聖、暗影 |
| 奧術與心靈 | 奧術、心靈 |

**以 1 為基礎值，各來源加減累加：**

```
攻擊加成 = max(0, 1 + Σ 攻擊方對該屬性的加成)
受傷倍率 = max(0, 1 + Σ 防禦方對該屬性的加減)
最終傷害 = floor(擲骰傷害 × 技能倍率 × 攻擊加成 × 受傷倍率)
物理傷害再扣防具減傷，所有傷害再扣狀態減傷
```

- **來源**：裝備（`equipment.json` 的 `resist` / `offense`）、種族天賦、狀態（例如狂暴：物理 -0.5；天使化身：神聖攻擊 +0.5；印記：全部 +0.25）、怪物本身。
- 加成可以寫在**單一屬性**、**群組**或 **all** 上，三者疊加。例：骷髏士兵 `{ 穿刺: -0.5, 斬擊: -0.25, 鈍擊: +0.5, 毒素: -1, 神聖: +0.5 }`，所以用鎚子打骷髏是 ×1.5，用細劍只有 ×0.5。
- 標籤：倍率 0 為「免疫」、小於 1 為「抵抗」、大於 1 為「弱點」。戰鬥畫面會顯示敵人的抗性與弱點，戰報會記錄每次傷害的倍率。
- 板甲對閃電 +0.25：金屬導電。裝備因此不只是數值更高，而是會改變適合面對的敵人。

## 7. 技能、法術、戲法

| 類型 | 代價 | 學習 | 品質 |
|---|---|---|---|
| 技能 | 0～5 AP（部分會產生 AP） | 依解鎖等級 | 依解鎖等級：1-4 普通、5-8 優良、9-12 稀有、13-16 史詩、17-20 傳說 |
| 法術 | AP + 一個該環以上的法術環 | 擁有該環的法術環 | 依環數：1-2 普通、3-4 優良、5-6 稀有、7-8 史詩、9 傳說 |
| 戲法 | 0 AP，每回合一次 | 可學數量 = 2 + floor(等級 / 4) | 普通；傷害在 5、11、17 級各多一倍骰數 |

- **升級三選一**：每次升級從符合等級、環數與生命層級品質上限的能力中隨機給 3 個選項。
- **結算方式**：`attack` 對擲命中與迴避；`save` 由目標豁免；`auto` 必中（治療、BUFF、魔法飛彈、律令系）。
- **專注**：同一時間只能維持一個專注法術；施放新的會取消舊的。施法者受傷時進行信仰豁免，DC = `max(10, floor(傷害 / 2))`，失敗則專注中斷；倒下也會中斷。
- **每回合／每場戰鬥／每次休息**的使用次數限制寫在能力的 `uses`。

## 8. BUFF 與 DEBUFF 的運作方式

狀態定義在 `statuses.json`，持續時間以回合計，在**擁有者的回合開始時** -1。運作方式分成以下幾類：

| 機制 | 說明 | 例子 |
|---|---|---|
| 數值修正 | 命中、迴避、豁免、武器傷害、減傷、AP 回復、幸運一擊閾值 | 防禦（迴避 +3）、戰意（命中 +3、傷害 +4、AP +1）、加速（迴避 +2、AP +2） |
| 幸運骰 | 在指定擲骰（攻擊／迴避／豁免）額外擲一顆骰子，正的加、負的減 | 祝福 +1d4、激勵 +1d6、災禍 -1d4、削語 -1d6 |
| 優勢／劣勢 | 擲兩次取高／取低 | 野性直覺（迴避優勢）、恐懼（攻擊劣勢）、高等隱形（攻擊與迴避優勢） |
| 被攻擊時的優劣勢 | 攻擊這個目標的人擲兩次取高／取低 | 束縛、致盲、妖火、光導（攻擊者優勢），朦朧（攻擊者劣勢） |
| 傷害倍率 | 改變受傷倍率或攻擊加成 | 石膚（物理 ×0.5）、印記（受傷 ×1.25）、死亡印記（×1.5）、金剛（全部 ×0.75） |
| 減傷與護盾 | 固定減傷，或臨時生命值先吸收傷害 | 堅守（減傷 +3）、樹皮（減傷 +3）、援助術（臨時 HP 5）、野性變身 |
| 一次性防護 | 觸發一次就消失 | 閃避本能（下一次傷害減半）、偏轉（下一次物理傷害減去數值）、不倒（致命傷保留 1 HP） |
| 持續效果 | 回合開始時傷害、治療，或對隨機敵人發動攻擊 | 中毒、燃燒、靈體衛士、月華光束（持續傷害）；再生（持續治療）；靈體武器、召雷術（脈衝攻擊） |
| 命中附加 | 武器命中時附加傷害或狀態 | 毒刃（使目標中毒，3 次）、聖戰斗篷（+1d4 神聖） |
| 控制 | 改變能做的事 | 暈眩（跳過回合且無法迴避）、沉默（無法施法與戲法）、狂暴（無法施法）、嘲諷（只能攻擊施放者）、困惑（隨機攻擊任何人） |

帶 `charges` 的狀態（神導、激勵、削語、精準、光導……）在生效一次後扣一次，用完即消失。

## 8.1 仇恨值

敵人選目標時不是平均亂選，而是依仇恨值加權：每位隊員的權重 = 5 + 仇恨值，被選中的機率 = 權重 ÷ 全隊權重總和。仇恨值**不是絕對的**，再低也有機會被打，再高也不保證被盯上；只有「嘲諷」狀態會強制敵人只打嘲諷者。範圍攻擊、隨機目標（`random_enemies`）與困惑仍是隨機的。戰鬥畫面每位隊員下方顯示「🎯 仇恨・被盯上約 N%」。規則在 `combat.json` 的 `threat`。

**累積**（每次行動結算時，依結果累積，再乘上倍率）：

| 行為 | 仇恨 |
|---|---|
| 對敵人造成傷害 | 傷害量 × 1 |
| 治療隊友 | 治療量 × 0.6 |
| 對別人施加狀態（增益或減益） | 每個 +3 |
| 防禦 | +4 |
| 攻擊沒命中 | +1 |
| 使用道具 | +1 |
| 能力本身的 `threat` | 堅守 +20；機巧動作、影步 −10（減少時不乘倍率，最低 0） |

每回合結束，所有人的仇恨值 × 0.85。

**倍率** = 職業倍率 × (1 + 防具 + 武器 + 天賦與狀態的 `mods.threat`)；開戰時的仇恨 = 職業起始值 × 倍率。

| 職業 | 起始 | 倍率 | | 裝備 | 加減 | | 天賦／狀態 | 加減 |
|---|---|---|---|---|---|---|---|---|
| 戰士、野蠻人 | 8 | ×1.3 | | 板甲 | +25% | | 矮人【熔爐之軀】 | +10% |
| 聖騎士 | 6 | ×1.2 | | 鍊甲與盾 | +15% | | 魔族【荒原血脈】 | +10% |
| 武僧 | 4 | ×1.0 | | 皮甲、武僧袍 | ±0 | | 貓魅族【貓之反射】 | −15% |
| 牧師、德魯伊 | 3 | ×1.0 | | 布衣、無防具 | −10% | | 堅守（狀態） | +50% |
| 遊俠、吟遊詩人 | 2 | ×0.9 | | 巨斧、戰鎚 | +10% | | 隱匿（狀態） | −50% |
| 法師 | 1 | ×0.9 | | 細劍、短劍 | −5% | | | |
| 遊蕩者 | 1 | ×0.7 | | 匕首 | −10% | | | |
| 無法戰鬥 | 0 | ×0.5 | | 長弓 | −15% | | | |

資料欄位：職業 `classes.json` 的 `threat: { start, mult }`、裝備 `equipment.json` 的 `threat`、天賦與狀態的 `mods.threat`、能力 `abilities.json` 的 `threat`。

## 8.2 怪物的特徵與狀態

和人類 NPC 的標籤分開（`data/rules/monster_traits.json`）。開戰時每隻怪物擲 0～2 個特徵：第一個的機率 30%，之後每多一個再擲一次；冒險區域越深越容易（淺層 +5%、中層 +10%、深層 +15%、層主 +20%）。怪物資料的 `traits` 是一定帶著的特徵。特徵只改能力值與戰鬥行為，**不改掉落物**（掉落物在 `enemies.json` 每隻怪物單獨設定）。名字會加上特徵，例如「巨大・暴怒的灰狼」；戰鬥畫面以標籤顯示，滑過去可以看說明。

| 特徵 | 效果 | 行為 |
|---|---|---|
| 受傷 | 生命只剩六成、命中 −1、經驗 ×0.8 | 生命低於三成想逃 |
| 巨大 | 生命 ×1.5、傷害 +2、減傷 +1、迴避 −2、經驗 ×1.4 | |
| 敏捷 | 迴避 +2、命中 +1、行動點 +1、先攻 +3 | |
| 發情 | 傷害 +1、豁免 −1 | 比較不受仇恨牽引（focus ×0.5）。**只會出現在資料標明 `rut: true` 的怪物身上**；關閉成人向時顯示為「躁動」 |
| 暴怒 | 傷害 +3、命中 +1、迴避 −2 | 死盯仇恨最高的人（focus ×2），絕不逃跑 |
| 飢餓 | 命中 +1 | 專挑生命比例低的 |
| 狡猾 | 命中 +1 | 優先攻擊施法者，較不理會仇恨（focus ×0.4） |

| 年老 | 生命 ×0.8、命中 −1、豁免 +1 | |

互斥：巨大與年幼、年老與年幼、暴怒與怯懦。

## 8.3 敵人 AI

怪物與敵對的冒險者用同一套 AI：

- **選目標**：被嘲諷時只打嘲諷者；否則依仇恨加權，權重 = 5 + 仇恨 × focus（特徵決定），再依偏好調整：偏好虛弱者的 × (1 + 2 × 已損失的生命比例)，偏好施法者的對有法術環的人 ×2。
- **選行動**：替每個能用的技能打分數，武器攻擊是基準分 2，依分數的平方加權抽選（大致挑最好的，但保留一點不可預測）。
  - 治療：只在有同伴生命低於六成時使用，給最需要的人（分數 3～7，越危急越高）。
  - 淨化：有同伴身上有減益時。
  - 增益：身上已經有的不再上；前兩回合比較想先上；被嘲諷時不對自己上增益。
  - 單體攻擊技能 2.4、純減益 2（對方已經有就不用）。
  - 範圍與隨機目標：敵人越多分數越高（2 + 0.7 × 多出的人數），只剩一人時只有 1。
