# 夥伴、休息與奴隸契約 v0.1

> 狀態：本文件的內容都已實作。規則數值在 `data/rules/companions.json`、`data/rules/slavery.json`、`data/rules/actions.json`；程式在 `src/engine/companions.ts`、`party.ts`、`rest.ts`、`effects.ts`、`actions.ts`、`npcs.ts`。

## 1. 報酬／後果模板

事件、委託與主動行動的結果都用同一組「效果」描述，可以任意組合（`src/engine/effects.ts`）：

| 種類 | 說明 |
|---|---|
| `money` | 金錢（白鸛幣），負數為花費 |
| `item` | 物品；qty 負數為失去 |
| `affinity` | 某人的親密度增減 |
| `reputation` | 勢力聲望 |
| `xp` | 經驗值（全隊或指定成員） |
| `flag` | 劇情旗標 |
| `companion` | **新增夥伴**：`voluntary` 自願、`hired` 雇傭、`slave` 奴隸（可指定契約）。對象可以是已登場的 NPC，也可以是一份規格（名字、種族、職業、等級……），程式會生成並登錄 |
| `join_party` | 主角加入別人的隊伍（隊長、隊員，可附簽約金） |
| `leave` | 某人離隊 |
| `relationship_text` | 「與主角的關係」文字；預設是提議，玩家確認後才寫入 |
| `memory` | 新增一筆共同記憶 |
| `condition` | 非戰鬥狀態（奴隸印記、逃亡、受罰）的增減 |
| `hp` | 生命值增減（點數或比例） |
| `enslave_player` | 主角成為奴隸（主人、契約、主人的隊員） |
| `free` | 解除契約（主角或 NPC 奴隸） |
| `slot` | 法術環：`delta` 負數花掉（至少 `circle` 環，用最低的）、正數回復（不超過 `circle` 環） |
| `hit_dice` | 生命骰：`delta` 負數花掉、正數回復 |
| `ability` | **技能報酬**：學會新能力。可指定能力（id 或名稱，必須是目前可以學的，否則隨機挑一項）、給一次「N 選一」的學習機會（`choices`），或加上取得機率（`chance`）。記錄在報告的 `skills_gained`，來源為 `insight` |

例：委託報酬「80 白鸛＋傷藥 2 瓶＋委託人好感 +5＋獵戶自願入隊」

```json
[
  { "type": "money", "amount": 80 },
  { "type": "item", "name": "傷藥", "qty": 2 },
  { "type": "affinity", "npc": "gen_3", "delta": 5 },
  { "type": "companion", "npc": { "name": "獵戶托比", "race": "human", "class": "ranger", "level": 2 }, "mode": "voluntary" }
]
```

公會委託交付已經改用這個模板；`town_quests.json` 的範本可以加上 `rewards` 欄位給額外報酬。目前「夜間巡邏」「偵查商道」有 15% 機率領悟新能力，「討伐哥布林」有 20% 機率得到一次三選一的學習機會。主動行動與長休時的互動中，AI 判定為大成功時也可以給一項技能報酬（例如向高手請教）。隊伍滿了時，`companion` 不會出錯，而是在報告註明「想加入，但隊伍已滿」。

## 2. 新增夥伴的五種方式

每位夥伴都有「入隊方式」（`bond`）：雇傭、自願、奴隸、隊長（主角跟著的隊伍）、隊員（隊長帶來的人）。隊伍上限 4 人。

### 2.1 雇傭冒險者

- 可以雇用的是今天在城裡的冒險者：各地點有固定的名單（冒險者與普通人約各半），每個人依活躍地點決定今天在哪裡（見 docs/NPC_SYSTEM.md）。具名 NPC（`npcs.json`）也在名單上。可以在酒館的候選名單，或右側「這裡的人」直接雇用；普通人不能雇用。
- 每人有要價：(60 + 45 × 等級 + 10 × 等級²) ± 25%。
- **出價不低於要價**：直接成交。
- **出價低於要價**：主動行動（魅力為主），參考 DC = 10 + ⌈12 × (1 − 出價／要價)⌉ + 2 × max(0, 對方等級 − 主角等級)，夾在 5～30。出價的權重最大；出價 0 的 DC 約 22 以上，但仍可能免費雇到人。
  - 大成功／成功：以出價成交（大成功親密度 +5）
  - 部分成功：對方還價到兩者的中間
  - 失敗：今天不再談（親密度 −3）；大失敗：覺得被羞辱（−8）
- AI 判定開啟時，地點名單上的人（含候選冒險者）的名字、外貌、性格、背景由 AI 潤飾（種族、職業、等級、要價不變）。

### 2.2 加入別人的隊伍

- **主動**：在酒館「等待組隊」3 小時。機率 = 30% + 8% × mod(魅力) + 2% × 等級（最高 85%）。隊長等級為主角 +0～+2，可能帶 0～2 名隊員（不超過隊伍空位）；有機率付簽約金給主角（40 × 等級，魅力越高越多、機率越高）。
- **被動**：事件的 `join_party` 效果。
- 加入後，隊長與隊員不能被「請離」；主角自己的同伴仍留在隊伍裡。

### 2.3 買入奴隸

- 公開市場（在雜貨店格子）：萊茵堡、晨光城、阿爾貝納、血羽城堡（以物易物）、陰影之谷。
- 不公開的黑市：索里耶爾、阿爾貝納、灰港鎮、潮汐港。要先在酒館「打聽黑市」（魅力檢定 DC 14）；沒有黑市的城鎮成功了也找不到。精靈、玉璘族只在黑市出現。
- 價格依世界書「奴隸交易價格參考」：生命層級 1 的人類 8～80 金幣（800～8000 白鸛，依等級內插），魔族略高，精靈極貴；第 2、3 層依表；再乘職業、種族、市場倍率與 ±25% 浮動。
- 殺價、魅惑等主動行動（每人每天一次）：大成功 −30%、成功 −15%、部分成功 −5%、失敗不變、大失敗 +10%。
- 買下時選擇要刻上的契約印記：三種模板之一，或自訂（名稱、描述與各項數值，見第 4 節）；預設是奴隸身上原本的契約。
- 買下的奴隸**不會因親密度低而離隊**，也不能遣散。可以「解除契約」：變成自願同行，親密度 +15。
- 主角對自己的奴隸做任何主動行動（自由行動、交談、送禮……），奴隸那一方都是劣勢：實作上是主角擲兩次 d20 取高（報告與判定資料都會標示兩個骰值）。

### 2.4 主角作為奴隸

- 在奴隸市場「登記出售自己」（隊伍必須只剩主角）：等 6 小時，有買家的機率 = 30% + 7% × mod(魅力) + 3% × 等級（最高 85%）。主人等級比主角高 1～4，契約種類隨機（勞役 6：戰奴 3：魔導束縛 1）。主角拿到成交價 20% 的賣身錢。幾乎無法主動影響。
- 事件也可以用 `enslave_player` 讓主角成為奴隸；這時原本的同伴會與主角分開。
- **建立角色時以奴隸身分開始**：主人可以從生成的名單挑（貴族、旅人、祭司或惡人標籤的冒險者，可換一批）、自訂（名字、性別、種族、職業、等級、性格、外貌），或「無主」（印記還在，但沒有人牽著鏈子，行動與收入不受限制）；印記可以選模板或自訂。
- **刻印**：成為奴隸（出售自己或事件）後，在選好印記之前不能移動、休息或做其他事。先做一次刻印檢定（魅力，DC 12 + ⌊主人等級／2⌋），可以描述自己的態度與做法：

  | 結果 | 可以選的印記 |
  |---|---|
  | 大成功 | 任何模板，或自訂 |
  | 成功 | 主人打算的印記或更輕的 |
  | 部分成功 | 主人打算的印記 |
  | 失敗 | 重一級的印記 |
  | 大失敗 | 最重的魔導束縛，服從懲罰 +1 |

  AI 判定時可以用 `mark` 效果（名稱、描述）依主角的行為描寫印記的樣子；選模板時套用這段文字，數值仍依模板。
- 身為奴隸：主人是隊長；不能雇人、買奴隸、邀請、自己找隊伍；賺到的錢依契約「收益歸屬」部分或全部歸主人（報告的 `master_share_cc`）。
- **出城要主人同意**：在聚落裡要走出城門或出發旅行前，先在主動行動裡「請求主人同意出城」（魅力檢定，可以描述理由）。參考 DC = 印記的出城 DC + 服從懲罰 − ⌊主人親密度／20⌋，所以印記越重越難。部分成功以上當天在這座城可以自由進出；失敗則主人當天不准（明天再問），大失敗另受輕度懲罰，大成功主人親密度 +2。
- **主人的突發事件**：被主人帶著時，每走一步約 2%、每次旅行抵達時 35% 機率發生（至少間隔 6 小時）：差遣跑腿、炫耀奴隸、心情很差、賞賜、扛行李、考驗忠誠。事件發生後要先回應才能移動、休息或做其他行動：
  - **三選一**：每個事件有三種回應，例如心情很差時「低聲下氣地安撫（魅力 DC 13）」「默默承受」「頂嘴（魅力 DC 16）」。沒有檢定的直接套用結果；有檢定的依規則擲骰，成功與失敗各有效果。
  - **自己輸入**：描述自己的回應，走主動行動「回應主人」（`master_event`，預設魅力，參考 DC 13，可以搭配能力）。有 AI 時由 AI 決定結果與效果（親密度、生命值、金錢、物品、關係描述、旗標）；沒有 AI 時依成功程度：主人親密度 +3／+1／0／−2／−4（大失敗另扣 3 點生命值）。
  - 定義在 `data/rules/slavery.json` 的 `master_events`（`options`、`free_dc`、`free_outcomes`）。

### 2.5 事件入隊與主動邀請

- 事件報酬：`companion` 效果，可以是自願或奴隸。
- 主動邀請：對象要是認識的人、不在隊伍、親密度 ≥ 0、人在這座城鎮。參考 DC = 16 − ⌊親密度／10⌋ + 2 × max(0, 等級差)。部分成功是「再考慮一下」，失敗或部分成功後要等下次長休才能再邀請。

## 3. 離隊規則

每次**短休或長休**結束時檢查：

1. 親密度 ≤ −20 的同伴離隊（奴隸除外）。如果是主角跟著的隊長，整支隊伍丟下主角離開。
2. 主角打算離開別人的隊伍（在「隊伍」視窗選擇，下次休息時進行）：
   - **正式道別**：不需檢定，隊長與隊員親密度 −3。
   - **偷偷離開**：靈巧檢定，DC = 11 + ⌊隊長等級／2⌋；成功 −12、被撞見 −20。兩者都會離開，敘事焦點不同。
3. 逃亡奴隸：契約有「追蹤」時，有機率被主人找到（旅店 ×1.5）。找到後主人回到隊伍，主角受到嚴厲懲罰。

離隊的 NPC 角色資料（等級、經驗、能力）存回 NPC 登錄，之後再邀請或雇用時沿用。

### 3.1 主角是奴隸時

只能用主動行動（描述自己的做法）談判或逃離；對主人的檢定都受到契約的服從懲罰。談判只能在安全的地方（旅店、安全房、神殿）進行，逃離隨時都可以。

| | 談判（魅力為主） | 逃離（靈巧為主） |
|---|---|---|
| 參考 DC | 印記的談判 DC − ⌊主人親密度／20⌋ | 印記的逃離 DC |
| 大成功／成功 | 主人抹去契約，恢復自由（主人仍是隊長，之後可正常離隊） | 逃走，**契約仍在**，成為逃亡奴隸；印記反噬扣生命值（印記的反噬比例，大成功減半） |
| 部分成功 | 主人動搖，下次談判 DC −2 | 逃走但重傷（反噬加倍） |
| 失敗 | 輕度懲罰：生命值 −20%、受罰、主人親密度 −5 | 同左 |
| 大失敗 | 嚴厲懲罰：生命值 −40%、受罰、親密度 −10、服從懲罰 +1 | 同左 |

逃亡奴隸：公會不接委託、不能交付，神殿不治療，旅店價格加倍且更容易被找到。

## 4. 奴隸契約印記

每個奴隸身上的印記是一份獨立的條款（`ContractRef.terms`，型別 `MarkTerms`）：名稱、描述（純文字，交給 AI 判定與描寫）、收益歸主人、談判 DC、逃離 DC、出城 DC、逃亡時被找到的機率、逃離反噬、服從懲罰、副作用。沒有 `terms` 時沿用模板。三種模板：

| 契約 | 印記 | 功能 | 服從懲罰 | 收益歸主人 | 談判／逃離 DC | 出城 DC | 被找到機率 | 逃離反噬 |
|---|---|---|---|---|---|---|---|---|
| 勞役契約 | 頸側暗紅色荊棘紋 | 身分標示、服從、收益歸屬、追蹤 | −2 | 50% | 18／17 | 12 | 10% | 10% HP |
| 戰奴契約 | 頸後交叉雙劍烙印 | ＋距離束縛 | −3 | 100% | 20／19 | 14 | 20% | 30% HP |
| 魔導束縛契約 | 喉頭淡紫色法陣 | ＋魔力封印（戰鬥中只能施放 1 環法術） | −5 | 100% | 22／22 | 16 | 35% | 40% HP |

**自訂印記**（建立角色、買奴隸、刻印大成功時）：名稱最多 12 字、描述最多 160 字、副作用最多 4 項；數值夾在範圍內：收益 0～100%、談判與逃離 DC 8～30、出城 DC 5～25、被找到 0～60%、反噬 0～80%、服從懲罰 0～8。功能依數值推得：收益 > 0 有收益歸屬、被找到 > 0 有追蹤、反噬 ≥ 30% 有距離束縛；從魔導束縛模板改起時保留魔力封印。

主角的印記（含主人或「無主」）會完整放進判定資料與敘事資料，隊伍裡的奴隸也會列出印記。

非戰鬥狀態（`Character.status`）：奴隸契約印記、逃亡奴隸、受罰（下次長休前所有檢定 −2）。

## 5. 短休與長休（D&D 5e）

| | 短休 | 長休 |
|---|---|---|
| 時間 | 1 小時 | 8 小時（旅店住到隔天早上） |
| 地點 | 戰鬥以外幾乎都可以 | 旅店（付費）、地下城安全房（每人 1 份乾糧，每間一次） |
| 效果 | 每位隊員花生命骰回復生命值：每顆 = 生命骰 + mod(力量) + mod(信仰)，至少 1 | 生命值、法術環全滿；每次休息的能力重置；回復一半生命骰（至少 1）；解除「受罰」；清除邀請的冷卻 |
| 風險 | 荒野 15%、地下城 25% 被襲擊（安全房內不會） | — |
| 限制 | 生命骰用完就不能再回復 | 24 小時內只能一次（距上次長休結束至少 16 小時） |

生命骰：野蠻人 d12；戰士、聖騎士、遊俠 d10；遊蕩者、武僧、吟遊詩人、牧師、德魯伊 d8；法師 d6。總數 = 等級。

## 6. NPC 登錄

`GameState.npcs` 記錄所有登場過的 NPC（含各地點名單上的居民、其他隊伍、奴隸、事件角色；名單與活躍地點見 docs/NPC_SYSTEM.md）。具名 NPC 第一次離隊時也會複製進來。生成用的名字、外貌（多部位）與性格（多象限）素材在 `data/world/npc_traits.json`（見 docs/NPC_SYSTEM.md 第 15 節），性別與服裝在 `data/world/npc_pool.json`，種族比例依地區調整（南境多魔族、北境多矮人……）。

## 7. 性別、名牌與所在位置

- **性別**：NPC 有性別（男性、女性、偽娘、TS、扶她、未知），各有代表色；生成的 NPC 依權重決定性別，名字從對應的男名或女名挑選。主角的性別是自由填寫的文字，能對應到這幾種時也會上色。性別會寫進報告的角色快照與人際關係，交給 AI 參考。
- **名牌**：角色在畫面上一律顯示為「種族 emoji + 依性別上色的名字 + 職業 emoji」，例如 🐱莉娜🏹。滑鼠停在名牌上會顯示性別、種族與職業。
- **所在位置**：認識的人不會隨時隨地出現在主動行動的對象清單裡。隊友永遠在身邊；名單上的人依活躍地點，每天在某個地點的某個地區（一般區域、貴族區、王城、神殿、近郊），主角要在同一個地區才遇得到；店主、公會職員等職員固定待在自己的設施，知情人在酒館、在旅店認識的旅客在旅店。離隊的同伴回到該城鎮的酒館（在冒險區域離隊則回到最近的聚落）。邀請入隊也依同樣的規則。

## 8. 長休時的互動

長休時可以順便寫下想做的事（選填），長休結束後立刻進行一次主動行動「長休時的互動」（不另外花時間）：

| 對象 | 說明 |
|---|---|
| 全體夥伴 | 和大家一起度過；規則判定時每位隊友親密度 +3～-3 |
| 某位夥伴 | 單獨相處；DC 會因親密度降低 |
| 同旅館的旅客（只有旅店） | 可以認識一位新朋友（效果 `meet`）：登錄為 NPC、建立人際關係，之後在這間旅店找得到他 |
