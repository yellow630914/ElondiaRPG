# 內容之間的依賴關係與保護

> 上層：[CONTENT_EDITOR](CONTENT_EDITOR.md)。相關：[SAVES](SAVES.md)（讀檔時的清理）、[STORY_QUESTS](STORY_QUESTS.md)（檢查任務鏈）。
> 程式：`src/engine/usage.ts`（引用檢查）、`src/engine/mods.ts`（整理與套用）、`src/stores/content.ts`（刪除、改名）、`src/engine/state.ts` 的 `migrate`／`pruneAbilities`、`src/engine/story.ts` 的 `pruneStories`。

自訂內容（🛠️ 內容）可以新增、修改、刪除；存檔在內容改變之後還會繼續用。這份文件列出各種內容互相用到的地方，以及刪掉或改壞時的保護。

## 1. 依賴關係

箭頭表示「A 用到 B」（A → B）。

| 用到別人的（A） | 用到的（B） | 怎麼對應 |
|---|---|---|
| 怪物 | 能力、怪物特性、物品（掉落）、遭遇表（出現地點） | 能力 id、特性 id、物品名稱 |
| 物品 | 底材 × 材料（裝備）、材料（打造連結）、狀態（使用效果）、非戰鬥狀態（吃喝）、工具模板、其他物品（燃料、配方的材料、種子長出的作物） | id、物品名稱 |
| 制式裝備 | 底材 × 材料 | 自建的底材或材料自動產生，名稱由兩者組成 |
| 底材 | 武器、防具類型 | 內建底材共用武器類型（例：長劍） |
| 固定 NPC | 地點、聚落區塊（固定格子）、能力、底材 × 材料（裝備）、劇情旗標（出現條件、改變出沒） | id、旗標名稱 |
| 能力 | 職業、狀態 | 職業 id（含 `monster`）、狀態 id |
| 職業 | 能力（初始能力） | 能力 id |
| 特殊任務 | 固定 NPC（開頭、地點、敵人、友方、同行、效果）、怪物（戰鬥）、物品與裝備（效果、報酬）、能力（效果）、其他特殊任務（效果）、地點與設施、臨時地圖、劇情旗標 | id、物品名稱、旗標名稱 |
| 旅途事件、情報 | 怪物、特殊任務 | id |
| **存檔** | 以上幾乎全部：隊伍的能力與裝備、行囊（物品名稱）、登場過的 NPC、委託（怪物、物品）、情報、特殊任務的進度（任務點 id、旗標）、地圖格子（怪物、資源） | id、名稱 |

## 2. 刪除時的保護

**自建項目要沒有被用到才能刪**；編輯畫面上方列出用到的地方（🔗），刪除按鈕在有引用時停用。檢查的範圍：

| 刪除 | 會擋下刪除的引用 |
|---|---|
| 怪物 | 特殊任務的戰鬥任務點；目前存檔進行中的委託、有效的情報 |
| 物品 | 特殊任務的效果與報酬、其他物品的燃料、配方材料與種子的作物；目前存檔的行囊、身上的裝備、進行中的委託、房子裡的家具與苗圃上的作物（怪物的掉落會一起拿掉，不擋） |
| 底材、材料 | 玩家建立或修改過的物品（裝備組成、打造材料）、固定 NPC 的裝備、特殊任務的裝備獎勵；目前存檔身上的裝備與行囊 |
| 固定 NPC | 特殊任務的開頭、地點、敵人、友方、同行、效果；目前存檔的隊伍、奴隸契約的主人 |
| 特殊任務 | 其他特殊任務的「開始特殊任務」效果、內容是「特殊任務的消息」的情報物品；目前存檔正在進行 |
| 能力 | 職業的初始能力、怪物、固定 NPC、特殊任務的獎勵；目前存檔的角色與升級選項 |

**其他存檔**要等讀檔時才知道，所以讀檔（以及自訂內容改變之後）會清理：

- 不存在的能力從角色、升級選項與進行中的戰鬥拿掉。
- 不存在的特殊任務：進行中的算中斷，任務同行的夥伴離隊（不會一直佔著同行的名額）。
- 底材或材料不存在的裝備：留在身上或行囊裡，但**沒有效果、不能裝備**，說明顯示「已失效」（不會讓遊戲壞掉）。

## 3. 改名

- **自建物品改名**：怪物的掉落、特殊任務的效果與報酬、其他物品的配方材料與種子的作物、目前存檔的行囊、身上的裝備名稱、進行中的委託、房子裡的家具與作物一起改。其他存檔裡的會變成無法使用的雜物。其他物品的燃料（`tool.fuel`）目前**不會**跟著改（見 [KNOWN_ISSUES](KNOWN_ISSUES.md)）。
- 物品名稱不能有 `|`、`*`（打造指令用的分隔符號），不能和內建、自建、目前存檔裡 AI 生成或打造的物品同名。
- **底材、材料改名**：制式裝備的名稱跟著改；之後打造、寶箱、掉落的制式品如果目錄裡沒有同名同組成的物品，會另外登錄（仍然可以裝備）。

## 4. 修改的限制

- **內建底材**：欄位、材料類型、雙手不能改（存檔裡的裝備、職業起始武器、制式裝備都靠它們）；匯入的檔案也會被改回來。
- **內建材料**：類型與等級不能改（隨機裝備、起始裝備、NPC 配備依「類型 × 等級」找材料）。就算某一級的材料不見了，也會改用最接近的那一級，不會壞掉。
- **數字欄位留空**：用預設值（以前會變成 0 再被夾到最小值，例如價格變 1）。
- **乾糧**：雜貨店直接買乾糧的價格跟著目錄（不能低買高賣）。
- **特殊任務**：目前存檔已經完成的任務點 id 不能改（改了會被當成新的任務點，再觸發一次）；存檔正在進行時，編輯畫面提醒改旗標或解鎖條件可能讓任務卡住。
- **檢查任務鏈**另外提醒：開頭的城鎮沒有公會或情報商、任務點的地點沒有那種設施、效果裡的物品、裝備、角色、特殊任務不存在、要離開的角色不存在、開頭旗標和別的任務一樣（複製來的任務會互相觸發）。

## 5. 執行時的保護（舊存檔、匯入的檔案）

- 裝備的底材或材料不存在：數值、武器與防具類型略過，不會丟錯。
- 效果要加入的固定 NPC 不存在或已經在隊伍裡：略過（以前會讓任務點卡住）；只有入隊本身出錯時才在日誌註明。
- 效果的裝備底材或材料不存在：略過。
- 物品的打造連結指到不存在的材料：拿掉。
- 讀取保存的自訂內容時，自建的能力、底材與材料先登錄，物品、固定 NPC、任務裡用到它們的地方不會被誤刪。

- 已經生成的地圖上，遭遇格的怪物整組被刪掉：換成這個地方現在的遭遇（層主換成這一層現在的層主，強敵換成最強的一組再多一隻）；旅途上的遭遇換成這段路的遭遇。真的找不到才當成已清除（情報點會跟著結束）。

## 6. 脫困的方法

- **放棄一般委託**：冒險筆記的「一般委託」每一件都有「放棄」（公會聲望 -1）。目標怪物或物品被刪掉、委託永遠完成不了時可以用。
- **放棄特殊任務**：冒險筆記的「特殊任務」（原本就有）。
