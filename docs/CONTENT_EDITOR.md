# 自訂內容（🌍 世界頁籤）

> 上層：[GAME_DESIGN](GAME_DESIGN.md)。下層：[CONTENT_DEPENDENCIES](CONTENT_DEPENDENCIES.md)（內容之間的引用與刪除保護）。各種內容的遊戲規則：怪物 [MONSTERS](MONSTERS.md)／[COMBAT_SYSTEM](COMBAT_SYSTEM.md)、物品與裝備 [ITEMS](ITEMS.md)、特殊任務與固定 NPC 的劇情條件 [STORY_QUESTS](STORY_QUESTS.md)、NPC [NPC_SYSTEM](NPC_SYSTEM.md)。
> 程式在 `src/engine/mods.ts`（覆寫的整理與套用）、`src/stores/content.ts`（保存）、`src/components/ContentView.vue` 與 `src/components/content/`（編輯畫面）。

在首頁的「🌍 世界管理」（或遊戲中上方的「🌍 世界」）新增或修改怪物、物品、裝備底材、材料、技能、特質、固定 NPC 與特殊任務。

## 0. 世界

**世界**是一整套自訂內容，可以同時存有好幾個（`src/components/WorldBar.vue`）：

- **原版世界**：沒有任何自訂內容，不能修改。要自訂內容，先「＋ 新的世界」（從原版開始）或「📄 複製這個世界」。
- 可以改名、刪除、「📥 匯入成新的世界」；頁面底部的匯出、匯入、全部恢復預設作用在目前的世界。
- **世界包**（`src/engine/worldPackage.ts`，`type: elondia-world`）：一個檔案帶著一個世界的自訂內容與一組提示詞（文風、其他提示詞、世界書的修改與新增條目）。「📥 匯入成新的世界」認得世界包與內容檔：世界包另外建立一組提示詞並**綁定**到這個世界。「📦 匯出世界包」匯出目前世界的內容，加上綁定的提示詞組（沒有綁定時用目前用的那一組）。生成世界的流程見 [`worldgen/README.md`](../worldgen/README.md)。
- **綁定的提示詞組**：世界管理可以選一組提示詞綁定到目前的世界；切換到這個世界（開新遊戲、讀檔、繼續）時提示詞組跟著切換（那一組被刪掉時不動）。存在世界的 `promptSet`。
- **開新遊戲時選擇世界**，存檔記住它（`state.world`）。之後「繼續」或讀檔時自動切換到那個世界；**遊戲進行中不能切換世界**（可以修改它的內容，用這個世界的其他存檔也會受影響）。回到首頁才能切換。
- 存檔用的世界被刪掉時：存檔欄位與匯出的檔案附有當時的內容，讀取時還原成新的世界「名字（從存檔還原）」；沒有附內容（例如進行中的遊戲）時改用原版世界，畫面會提示。
- **匯入存檔**（見 [`SAVES.md`](SAVES.md) 第 3 節）：遊戲中只能匯入同一個世界的存檔；在首頁匯入、存檔的世界在這個瀏覽器不存在或內容不同時，用存檔附帶的內容建立新的世界（名稱用存檔世界的名字，同名時加 4 位數字；已經有內容相同的世界時沿用它；沒有記世界的舊檔用「匯入的世界」），不會改動目前的世界。匯出時記下世界的名字；原版世界的存檔不附自訂內容。
- 舊版只有一套自訂內容（localStorage 的 `elondia.content`）：第一次啟動新版時變成「我的世界」（沒有內容時從原版世界開始）。世界存在 localStorage 的 `elondia.worlds`。

- **內建項目**：可以修改，隨時「↩️ 恢復預設」；不能刪除，內建物品也不能改名（存檔與掉落表用名稱對應）。
- **自建項目**：可以修改；要沒有被其他內容或目前的存檔用到才能刪（編輯畫面列出用到的地方，見 [`CONTENT_DEPENDENCIES.md`](CONTENT_DEPENDENCIES.md)）；「📄 複製」以選取的項目為範本建立一份。
- 修改存在目前的世界（localStorage 的 `elondia.worlds`），用這個世界的存檔共用；頁面底部可以匯出、匯入（取代目前世界的內容）或全部恢復預設。
- 儲存後立刻生效。已經生成的地圖（地下城、近郊）與今天的商店清單要等下次重新生成才會反映。
- **篩選**：所有頁面都可以搜尋名稱、只看自建或修改過的項目。怪物另外可以依種類（野獸、人形、不死……）、等級（1-2、3-4……）與出現地點（城郊各地區、各座地下城，或沒有出現地點）篩選；物品可以依類別與取得方式（各種商店、寶箱、近郊或地下城採集、怪物掉落、事件獎勵、打造材料，或沒有取得方式）篩選。

## 1. 怪物

| 欄位 | 說明 |
|---|---|
| 基本 | 名稱、等級、種類、生命、行動點、迴避修正、物理減傷、經驗值、金錢範圍；圖示（上傳一張圖，只給這隻怪物；沒有時依種類與等級區間用內建的圖，見 [ITEMS](ITEMS.md) 8.1 節）；持有裝備（打倒時可能掉一件依等級生成的裝備）、可能擲到「發情」；給 AI 的描述 |
| 屬性與普通攻擊 | 五屬性；攻擊骰、傷害類型、攻擊屬性 |
| 抗性與攻擊加成 | 每種傷害屬性（或群組、全部）的倍率加減：-1 免疫、-0.5 減半、+0.5 弱點 |
| 技能 | 怪物技能、職業技能與戲法（怪物沒有法術環，不能用法術）；每個技能可以填「生命 ≤ X%」（1～99，`ability_hp_below`），生命降到那裡才能用，空白是隨時能用；固定特徵（巨大、年老……） |
| 掉落物 | 物品、機率、數量 |
| 出現地點 | 城郊（各地區）、各地下城的周邊／淺層／中層／深層、層主（取代原本的層主與護衛；可以另外選一種護衛與隻數 1～4，不選就是層主單獨出場）。每一組是遭遇表裡的一個選項，遭遇時從所有選項平均抽一個；權重是放幾組。內建怪物可以從內建的遭遇表移除（遭遇表不會被清空） |

刪掉自建怪物時，已經生成在地圖上的那種怪物會換成這個地方現在的遭遇（見 [CONTENT_DEPENDENCIES](CONTENT_DEPENDENCIES.md) 第 5 節）。

## 2. 物品

| 欄位 | 說明 |
|---|---|
| 基本 | 名稱（自建才能改）、類別、價格、描述、圖示（上傳一張圖；沒有時用底材或類別的圖，見 [ITEMS](ITEMS.md) 第 8 節）。材料的價格是商人的收購價 |
| 在哪裡出現 | 商店（雜貨店、神殿、酒館、鐵匠鋪、裁縫店、珠寶店、魔法物品店、情報商）與最低聚落規模；地下城寶箱各層的機率；近郊、地下城的資源格（採集）；事件（AI 判定主動行動時可以把它當成報酬，提示詞會列出這些物品）；怪物掉落 |
| 使用效果 | 消耗品、食物、卷軸：回復生命（骰子）、法術環、暫時生命、行動點、救起倒下的隊友、給隊友的狀態、解除狀態、投擲傷害、對敵人施加狀態（豁免屬性與 DC）、範圍、只能在戰鬥中使用；消耗品還可以當**書籍**，勾選讀完有機會學會的特質（`use.perks`，最多 6 個，種族特質不能選） |
| 裝備組成 | 裝備：底材、材料、稀有度、附魔（命中、傷害……、抗性、攻擊加成）；「依組成定價」；獨特物品的檢定加值；屬性加減（每項 ±3）；慾望指標的加減（每項 ±10，[LEWD_STATS](LEWD_STATS.md) 第 3 節）；「主人會強制裝備」與會用的主人身分（見 [ITEMS](ITEMS.md) 3.2 節）；獨特物品可以勾「也會出現在黑市」；任何物品可以勾「成人向」。有屬性加減或主人會強制裝備的不在商店上架 |
| 打造材料 | 材料：可以拿來打造哪些材料的裝備 |
| 鎖 | 雜物：白鐵、藍鋼、符文、黃金鎖（在裝備欄替拘束具上鎖，[LEWD_STATS](LEWD_STATS.md) 第 7 節） |

**類別圖示**：世界編輯器的「🖼️ 類別圖示」分頁可以替 8 種類別各上傳一張圖，取代內建的類別圖（沒有自己的圖、也不是裝備的物品用它）；換了立刻儲存，「全部恢復預設」換回內建的。存在世界內容的 `categoryIcons`。

上傳的圖會縮到 48×48 以內、存在世界裡（localStorage）。圖太多太大、世界存不進瀏覽器時，世界頁頂端會出現警告，這次的修改只在關掉頁面前有效。

**怪物掉落的設定存在怪物身上**：在物品這邊設定掉落，改的是那隻怪物的掉落物（和怪物編輯頁是同一份），所以物品「恢復預設」不會一起恢復掉落。

刪掉自建物品的限制見 [CONTENT_DEPENDENCIES](CONTENT_DEPENDENCIES.md) 第 2 節；其他存檔行囊裡已有的會變成無法使用的雜物，怪物也不再掉落。

## 3. 裝備底材與材料

- **底材**：名稱、欄位、材料類型、底價、仇恨、雙手、圖示（用這個底材的裝備都用這張圖，物品自己有圖時用物品的）；主手武器的傷害骰、傷害類型、攻擊屬性；上身防具的迴避、減傷與抗性；固定加成與「材料成長」（材料的加成依比例加到哪一項）。
- **材料**：名稱、類型、等級（1～5，決定打造的工錢與 DC）、加成、稀有度、建議等級、價格倍率、防具的額外迴避與減傷、抗性。圖示依類型與等級、顏色依稀有度自動決定，暫時不能上傳（[ITEMS](ITEMS.md) 8.1 節）。
- **束縛用**（飾品與護具的底材，武器、上身不行）：沒有任何加成，不能打造、沒有制式品，不會出現在寶箱、掉落、建角與 AI 生成的裝備裡，給「主人會強制裝備」的物品用（見 [ITEMS](ITEMS.md) 3.2 節）。內建底材不能改這一項。
- **服裝分類**（`outfit`：常規、二次元、成人向；武器不行）與**成人向**（`adult`）：服裝不進寶箱與掉落，裁縫店每天另外上架；成人向的標記給篩選用（見 [ITEMS](ITEMS.md) 第 2 節）。
- **曝露度**（上身、下身、內衣；0～3，空著依服裝分類）與**拘束**（束縛用的底材：雙面效應的種類與程度 1～3），見 [LEWD_STATS](LEWD_STATS.md) 第 3、7 節。
- 自建的底材或材料會自動產生「底材 × 同類材料」的制式裝備（第 5 級材料不在商店販售，第 3 級要城市、第 4 級要王都）。
- 修改內建底材或材料時，制式裝備的價格跟著重新計算；改名只影響之後新打造或生成的裝備，目錄裡的制式裝備沿用原本的名稱。
- 內建底材的武器與防具數值是共用的：同一種武器（例如長劍，也是戰士的起始武器）會一起改。

## 3.5 技能

技能、法術與戲法（`data/rules/abilities.json`）。頁籤在「固定 NPC」之前，可以依種類與職業（包括「怪物」）篩選。

- **基本**：名稱、種類（技能依等級學、法術依環數學並花法術環、戲法不花行動點）、解鎖等級或環數、行動點（法術不寫時依環數）、屬性（或依職業的施法屬性）、額外仇恨、誰可以學（各職業與怪物；怪物不能用法術）。圖示依種類（外框）與屬性（中間的圖與顏色）自動決定，暫時不能上傳（[ITEMS](ITEMS.md) 8.1 節）。
- **目標與判定**：目標（一名敵人、所有敵人、隨機敵人數次、隊友、自己……）、判定方式（命中骰對迴避、目標豁免、必中）、豁免屬性與成功時的效果、命中修正、優勢、幸運一擊門檻、攻擊次數、傷害倍率。
- **傷害**：一段或多段（武器傷害或骰子、傷害類型、加屬性調整值、每幾級多一組骰子）。
- **治療與護盾**、**狀態**（給誰、什麼時候、能不能豁免；「什麼時候」沒寫時依判定方式：命中骰是命中時、豁免是豁免失敗時、必中是一定。攻擊或豁免型的技能選「一定」給目標時，沒命中也會套上）、**次數**（每回合、每場戰鬥、每次長休）、獲得行動點、專注、淨化（移除目標的所有負面狀態）、回復法術環、斬殺。治療、護盾、淨化、回復法術環與斬殺只在判定方式是「必中」時顯示；其他判定方式的技能寫了這些，整理時會拿掉。
- **慾望戰鬥**（成人向，[COMBAT_SYSTEM](COMBAT_SYSTEM.md) 第 8.5 節）：增減目標的慾望、消耗自己的慾望、自己的慾望至少多少才能用、給目標行動點、戰後曝露名聲、慾望在隊友之間移動（分出去或吸過來）、引爆（倍率、傷害類型或治療、慾望至少多少）；狀態那一列可以加「目標的慾望 ≥ N% 才套用」。魅惑傷害在「傷害」選屬性「魅惑」。
- **刪除**：只有自建、而且沒有被用到的技能可以刪。編輯畫面會列出用到的地方：職業的初始能力、怪物、固定 NPC、特殊任務的獎勵，以及目前存檔的角色。被移除的技能（匯入、全部恢復預設）會從存檔的角色身上拿掉。
- 自建的技能存在 `ContentMods.abilities`，套用時最先處理（怪物與固定 NPC 會用到）。

## 3.55 狀態

戰鬥中的 BUFF／DEBUFF（`data/rules/statuses.json`，運作方式見 [COMBAT_SYSTEM](COMBAT_SYSTEM.md) 第 8 節）。頁籤「🌀 狀態」在「技能」之後，可以篩選增益或減益；清單上自建的在最前面，每一項旁邊有效果的簡述（`describeStatus`，戰鬥畫面滑過狀態也看得到）。

- **基本**：名稱、種類（增益，或減益；減益會被「淨化」移除）、生效幾次後消失（`charges`）。持續回合不在這裡設，由施加的技能或物品決定。
- **數值修正**：命中、迴避、豁免、武器傷害、減傷、行動點回復、幸運一擊閾值、仇恨倍率（負的就是減益）。
- **擲骰**：幸運骰（例如 `1d4`、`-1d4`）與作用的擲骰（攻擊、迴避、豁免）、優勢、劣勢、被攻擊時對方優勢或劣勢。
- **傷害倍率**：受到的、造成的（依傷害類型或群組，-0.25 = ×0.75）。
- **持續效果**：每回合的持續傷害、持續治療、對隨機敵人攻擊（可以加施放者的屬性調整值）。
- **武器命中時**：附加傷害，或使目標得到另一個狀態（不能是自己）。
- **控制與特殊**：暈眩、沉默、無法施法、嘲諷、困惑；致命傷保留 1 HP、下一次傷害減半、下一次物理傷害減去數值。
- **慾望戰鬥**（成人向）：受到的慾望倍率、生命傷害轉成慾望的比例、被侍奉（代受）的轉換比例、每回合增加的慾望、慾望上限倍率、依慾望的修正（慾望每 10% 某項 +N，最多多少）、慾望不會消退、不會高潮、淨化拿不掉。
- 狀態要由技能（技能編輯器的「狀態」）或物品（使用效果）施加才會出現在戰鬥裡。
- **刪除**：只有自建、而且沒有被用到的狀態可以刪。用到的地方：技能、其他狀態的命中附加、物品（使用時得到、解除、對目標施加）、目前存檔進行中的戰鬥。被移除的狀態會從進行中的戰鬥拿掉。
- 自建的狀態存在 `ContentMods.statuses`（舊的自訂內容沒有這一欄，讀取時補上），套用時最先處理（技能、物品、其他狀態都會用到）。

## 3.6 特質

特質（`data/rules/perks.json`，見 [`PERKS.md`](PERKS.md)）。頁籤在「狀態」之後；清單上自建的在最前面，種族特質排最後並標「種族」。

- **基本**：名稱、描述（空白時依效果產生）、**缺陷**（勾了才能有負的檢定加值與戰鬥修正；種族特質不能是缺陷）、**稀有度**（只決定圖示的顏色；不選時依強度）。畫面上顯示強度（`perkPower`，缺陷是負的）。圖示依正面或缺陷與強度自動決定，暫時不能上傳（[ITEMS](ITEMS.md) 8.1 節）。
- **效果**（最多 6 個）：檢定加值（加值與篩選：屬性、情境、主動行動、對象的標籤，同一欄是「或」、不同欄是「且」）、戰鬥修正（命中、迴避、豁免、傷害、減傷、行動點回復、幸運一擊、仇恨倍率）、抗性、增傷。數值範圍見 PERKS 第 4.4 節；抗性可以是弱點；**只有缺陷可以有負的檢定加值與戰鬥修正**（不是缺陷時，負值在存檔時拿掉）。
- **條件與互斥**：只有哪些種族、職業可以學；要先有哪些特質（流派的進階特質）；和哪些特質互斥。
- **慾望流派**（成人向，[LEWD_STATS](LEWD_STATS.md) 第 6 節）：屬於哪個流派，與慾望效果（慾望上限、受到的慾望、轉換、引爆、回血、指標成長的倍率，以及生命低於一半、主人在隊伍裡、有上鎖的拘束具時的戰鬥修正）。
- **訓練**：可以在哪些設施學、學費、時數、檢定屬性與 DC（缺陷：在哪裡花錢克服）。
- **NPC**：抽到的權重（0＝不會抽到）、更容易抽到的標籤與職業。
- **種族特質**：只能改名稱、描述與效果；種族固定、不能刪除，條件、互斥、訓練、NPC 這幾欄不顯示。複製種族特質會變成一般的自建特質。
- **刪除**：只有自建、而且沒有被用到的特質可以刪。編輯畫面列出用到的地方：固定 NPC 的特質清單、特殊任務的 `perk`／`lose_perk` 效果、書籍、其他特質的互斥，以及目前存檔的角色（身上的特質與學特質的機會）、登場過的人。
- 自建的特質存在 `ContentMods.perks`，套用時在能力之後、材料與物品之前（書籍、固定 NPC、任務會用到）。被移除的特質（匯入、全部恢復預設）會從存檔的角色身上拿掉。

## 3.7 刺青

頁籤「🖋️ 刺青」在「特質」之後，可以篩選普通刺青、誓約印記、奴隸印記與印記設定（見 [TATTOOS](TATTOOS.md)）。角色身上的刺青與印記是刺上時存的一份，**改模板只影響之後刺的**。

- **刺青圖樣**（`tattoos.json` 的 `templates`）：名稱、種類（普通刺青／誓約印記）、外觀、建議的部位；誓約印記另外填屬性的加減，要合規則（有加有減、加總為 0、每項 ±3、最多 3 項），不合規則不能存。
- **奴隸印記**（`slavery.json` 的 `contracts`）：名稱、外觀、部位、副作用與數值。範圍比玩家自訂印記寬：談判與逃離 DC 5～35、出城 DC 5～30、被找到 0～80%、反噬 0～90%、服從懲罰 0～10，可以有魔力封印（最多施放幾環）。功能依數值推得。新的印記要加進「印記設定」才會出現在刻印檢定、市場或老鴇身上（特殊任務的「主角淪為奴隸」可以直接指定）。
- **印記設定**（`roles`、`market_contracts`、`marking.severity`、`self_sale.contract_weights`）：預設的印記、老鴇刻的印記、刻印檢定的輕重順序、公開市場／黑市／自賣的權重（0～100，可以有小數，存到兩位，依比例抽）。只有一筆，可以恢復預設；匯入時沒寫的欄位用原版的設定。
- **刪除**：只有自建、而且沒有被用到的可以刪。刺青圖樣：特殊任務的 `tattoo` 效果、主人的事件；奴隸印記：印記設定（用途、輕重順序、權重）、特殊任務的「主角淪為奴隸」。角色身上的刺青與印記存的是自己的一份，不擋刪除。
- 存在 `ContentMods.tattoos`、`marks`、`markRules`（`markRules.rules` 一筆），套用時在狀態之後、能力之前（事件與特殊任務會用到）。

## 3.8 商店

頁籤「🏪 商店」列出每一種店（`data/rules/shops.json` 的 `types`）與自建的店（`shopMods.ts`）。內建的店**只能修改一部分**，名稱、目錄的類型、收購價與特殊功能（神殿治療、酒館招募、情報、刺青）都由程式決定，不能改；位置只能移動、不能刪除。

- **外觀**：emoji（地圖格子與地點卡片上的圖示）、描述（站在店裡時顯示）。
- **AI 特別商品**：關掉後第一次進店不再請 AI 設計「今日特別商品」，只有依目錄生成的平常商品（見 [TRADE](TRADE.md)）。
- **店主**：生成店主的稱呼與標籤（標籤決定 AI 怎麼描寫他）。指定固定 NPC 擔任店主在固定 NPC 的表單上（§4「擔任店主」），這裡只列出目前是誰。
- **交易清單**：目錄上架的物品類型（`catalog_tag`）不能改；可以另外加**固定清單**（`fixed`，最多 20 項）：每天一定上架的物品與份數，價格空白照目錄價（材料照這種店的加成），寫了就用這個價格（仍乘上聚落的物價）。和目錄重複的以固定清單為準。獨特物品、有屬性加減的裝備、主人強制裝備的東西不能放（和商店平常的規則一樣）。
- **收購的類別**（`buys`）：勾選這種店收購哪些類別的物品。
- **工作**（`work.json` 的 `jobs`，依格子）：DC（5～30）、時薪（0～100 白鸛）與描述；檢定的屬性不能改。流浪商人沒有打工。
- **受訓**：勾選哪些特質可以在這種店受訓。存在各特質的受訓地點（`train.cells`）上，和「特質」頁是同一份資料：拿掉某個特質最後一個地點，它就不能受訓；加回去時沿用內建的價格、時數與檢定。恢復這家店的預設不會改回受訓清單。流浪商人不能受訓。
- **位置**（內建）：列出這種店在每個聚落的格子，可以搬到**同一個聚落**的一格空地（道路，可以換區塊），也可以搬回原地。原本的格子變成道路。
- **自建的商店**（「＋ 新增商店」，或以選取的店「📄 複製」，複製不帶走專屬功能與位置）：id 是 `shop_` 開頭，地圖格子的種類就是這個 id。每一項都可以改：店名、圖示、描述、AI 特別商品、店主、**平常上架**（照某種內建店的目錄抽選，或只賣固定清單）、固定清單、收購類別、**打工**（可以不開放；檢定屬性、DC、時薪、描述）、受訓、**委託打造**（接哪些材料類型：金屬、木材、皮革、布料、珠寶；店主的工藝等級照一般店主）與**位置**（選聚落與區塊，在小地圖上點一格空地；可以擺好幾個地方，最多 20 處，每個聚落的店各自有店主與庫存）。沒有專屬功能（治療、招募、情報、刺青、娼館）。固定 NPC 可以擔任自建商店的店主。
- **位置的規則**（`computePlacements`）：先拿掉內建商店移走的格子，再擺上移過去的內建商店與自建的商店；目標要是空地（道路），同一格只能擺一家。存的時候擺不上去就不存；世界套用時擺不上去的略過（內建的留在原地）。聚落的地圖每次由資料建立，**舊存檔讀進來也會照新的位置**；站在被搬走的格子上的人變成站在道路上。
- 存在 `ContentMods.shops`：內建的只存跟內建不同的欄位（含 `moves`），可以恢復預設、不能刪除；自建的存整份（`custom: true`、`places`），沒有固定 NPC 擔任店主時可以刪除，刪除時在這裡受訓的特質一起拿掉這個地點。固定清單用到的物品不能刪，自建物品改名時一起改。

## 3.9 地標

頁籤「🏛️ 地標」列出城鎮的特色地標（[LANDMARKS](LANDMARKS.md)）。每一項都可以改：名稱、圖示、說明、AI 的氛圍、類型（最多 4 種）、位置，以及開放條件、參訪、場景、探索、打工與受訓（第 5、6 節；受訓存在特質上，恢復預設不會改回）。

- **內建的地標**：位置只能在同一個聚落裡移動（可以換區塊），不能刪除，可以恢復預設（位置也回到原處）。和內建一樣的不另外存。
- **自建的地標**（「＋ 新增地標」，或「📄 複製」）：id 是 `lm_` 開頭，擺在任何聚落的一格空地（道路）。沒有被用到時可以刪除：特殊任務的任務點、待在這裡的固定 NPC 都會擋。
- 位置要是空地（道路），而且不能是待售的空地（[HOMES](HOMES.md) 第 1 節）；商店與地標不能擺在同一格，存的時候檢查。匯入的世界包擺錯格子時，地標照樣登錄、但地圖上不出現，並列進匯入的問題。
- 存在 `ContentMods.landmarks`（整份），套用時在商店之前。

## 3.95 特殊地圖

頁籤「🗺️ 特殊地圖」列出特殊地圖（[SPECIAL_MAPS](SPECIAL_MAPS.md)）。

- **基本**：名稱、所屬地點、給 AI 的描述、光線、陷阱與寶箱比照地下城的哪一層、會不會刷新。
- **版面**：固定地圖用畫筆畫格子（牆、道路、水、出口、安全房、遭遇、強敵、BOSS、資源、寶箱、陷阱；每一格 BOSS 在下方「BOSS 格」各自指定怪物與名字），點或拖曳；「📍 入口」設定被傳送進來時站的位置。隨機地圖只設大小與挖幾步。
- **額外的隨機內容**（最少～最多）、**遭遇表**（選填，一組最多 4 種怪物）、**採集物**（選填）。
- **商店**（固定地圖）：選店種或自建的店，在地圖上點一格。
- **通道**（固定地圖）：在地圖上選這一頭的格子，另一頭選城鎮區塊的一格牆或水（小地圖上點），或別張固定特殊地圖的一格；可以寫要有／不能有的劇情旗標。不合規則的通道儲存時會被拿掉，並提示拿掉幾個。
- **特殊任務的任務點**：任務點的「在哪裡」選「特殊地圖裡的任務點」，再選地圖；固定地圖會顯示小地圖，點一格把 ⭐ 指定在那裡（空地或畫好的遭遇、資源、寶箱、陷阱；入口與通道端點點不了），「改回隨機」取消。隨機地圖只能隨機放。
- 內建的地圖不能刪、可以恢復預設；自建的（id 是 `sm_` 開頭）沒有被用到時可以刪：特殊任務的任務點與傳送、其他地圖的通道、待在這裡的固定 NPC 都會擋。複製時不帶走通道。
- 存在 `ContentMods.specialMaps`（整份），套用時在商店之後、固定 NPC 與特殊任務之前。改了版面或內容的設定，存檔裡的這張地圖重新生成。

## 3.97 事件

頁籤「🎲 事件」列出旅途事件（🧭、高階 ✨）、城鎮事件（🏘️）與地下城事件（⚠️，[ADULT_EVENTS](ADULT_EVENTS.md)），最下面是「⚙️ 事件設定」（[TRAVEL_EVENTS](TRAVEL_EVENTS.md)）。

- **基本**：標題、在哪裡（旅途上／城鎮的設施上）、種類（檢定：走到時直接擲骰揭曉；選擇：玩家選一個選項）、等級（旅途才有：普通或高階）、分類（人情、麻煩、機會、傳聞與異象、買賣）、描述。
- **出現的地方**：旅途事件勾路段；城鎮事件勾設施（含自建的商店）、聚落規模、地點；地下城事件勾觸發點（陷阱、寶箱、採集、安全房長休）、層、地區、地下城；每一項沒勾時不限。城鎮與地下城事件可以另訂幾天後才會再出現。
- **內容**：內容標籤（成人向、主角非自願……）、只給這些體型的主角、親密場景的描述；選項可以設定一定、成功或失敗時進入親密場景。
- **劇情條件**：要有／不能有的劇情旗標。
- **檢定與選項**：檢定的屬性與 DC，成功與失敗的結果；選項最多 5 個，每個可以有自己的檢定。高階的檢定事件成功後接著出現選項（例如要不要進洞窟）。
- **結果**：和特殊任務的結果相同（文字、旗標、效果、進入臨時地圖、傳送到特殊地圖、改去別的地點），但沒有任務同行、完成或失敗；效果沒有「主角淪為奴隸」，改去別的地點只能選聚落（不能直接進地下城）。匯入的事件寫了這兩種，整理時拿掉。
- **事件設定**：旅途各種路段每天發生事件的機率、事件種類的權重；城鎮事件走上設施時的機率、兩次事件的冷卻、同一事件多久不重複、最近出現過的分類降低多少權重；地下城事件四種觸發點的機率、冷卻與不重複的天數。
- 內建的事件可以改、恢復預設，不能刪；自建的事件（`mod_event_` 開頭）隨時可以刪，存檔裡等待中的這個事件會作廢。
- 存在 `ContentMods.travelEvents`（整份）與 `eventRules.rules`，套用時在物品、特殊地圖、商店之後（最後）。

## 3.98 主奴與娼館

頁籤「⛓️ 主奴與娼館」編輯共用**主人事件格式**的事件（`slavery.json`；程式 `masterEventMods.ts`），依事件庫篩選：

| 事件庫 | 資料 | 現在 |
|---|---|---|
| 主人的突發事件 | `master_events.events` | 37 件，被主人帶著時發生（[COMPANIONS](COMPANIONS.md) 2.4 節） |
| 調教事件 | `owner_events.events` | 空的，S5 才會發生 |
| 娼館打工事件 | `brothel_events.work` | 空的，S5 才會發生 |
| 娼館受訓事件 | `brothel_events.train` | 空的，S5 才會發生 |

- **基本**：事件庫（內建的不能換）、權重、花的時間、自己回應的參考 DC、成人向（「主角非自願」關掉時不發生）、描述（`{master}` 換成主人的名字）、親密場景。
- **條件**：主人的親密度範圍、主人有／沒有的身分標籤；主人的突發事件另外有：在家裡或外面、經過娼館時（機率）、離家逾期的「主人要回家」、主角身上還有空位（刺青）、主人有會強制裝備的東西。
- **掛的技能**（`teaches`，色情技能）：效果「學會事件庫的技能」（`ability_pool`）從同一個事件庫所有事件掛的技能裡抽一個還沒學的。調教事件另外有課程與「成功幾次保證學會」，娼館的事件有要求的頭牌等級（S5 用）。
- **回應**（最多 4 個）：名稱、要不要檢定（屬性、DC）、**屈服或抵抗**（`stance`：順從高的人屈服加值、抵抗減值，[LEWD_STATS](LEWD_STATS.md) 第 8 節）、進入親密場景（一定、成功或失敗時）、花的時間；沒有檢定時是結果與效果，有檢定時是成功與失敗各自的文字與效果，加上不論成敗都套用的效果。
- **效果**可以用：金錢、物品、經驗值（寫給主角時只給主角）、親密度（可以選「主人」）、記憶、非戰鬥狀態、生命值（比例或點數）、刺青、慾望指標、學會能力、學會事件庫的技能（都學過時的替代效果）、嚴加看管、延長離家期限、帶回主人的家、強制裝備、旗標。
- 內建的事件可以改、恢復預設，不能刪；自建的（`mod_mevent_` 開頭）隨時可以刪，等待回應中的這個事件會作廢（事件視窗顯示「略過」）。和內建一樣的不另外存。
- 存在 `ContentMods.masterEvents`（整份，帶 `pool`；舊的自訂內容沒有這一欄），套用時在旅途事件之後。

## 4. 固定 NPC

內建的具名角色（`data/world/npcs.json`）和自建的角色都是**固定 NPC**：在所屬地點的名單上，不會因為名單變動消失、搬走或被新的人取代（名單變動只動生成的居民）。特殊任務用角色的 id 指定他們。

- **基本**：名字、性別、種族、身分（冒險者或普通人）、職業或職業描述、等級、雇傭要價、勢力、出身、性格、外貌、背景、標籤。可以勾「成人向角色」（不佔名單名額）；「成人向外貌」是私密部位、性徵等細節，接在外貌後面交給 AI 與形象圖。勢力是下拉選單（地理資料的勢力）；出身與職業描述是可以輸入的下拉選單：出身先列這個種族的血統、部族與氏族，職業描述先列這個人的標籤的職業，也可以自己寫。
- **小隊**（`squad`，寫在隊長身上）：勾「帶著一支小隊」，填隊名、每天同行的機率，從固定 NPC 挑 1–3 名隊員（已經在別隊的人不在選單裡），可以設小隊成立的條件（旗標、好感）。隊員那邊的表單只顯示「是誰的小隊的隊員」。規則見 [NPC_SYSTEM](NPC_SYSTEM.md) 第 3.1 節；刪除隊員前要先把他從小隊移除。
- **不受雇用**（冒險者才有，`unhireable`）：統治者、機構首長這類不會跟著冒險者走的人。不出現在雇用候選與酒館名單，也不能談雇用；特殊任務的「任務同行」不受影響。
- **不可偷襲**（冒險者才有，`no_attack`）、**不可偷竊**（`no_steal`）：一國之主這類身邊戒備森嚴的人。「這裡的人」的偷襲、偷竊按鈕停用，AI 判定時也知道刺殺、偷竊不會得手；要和他交手只能透過特殊任務的戰鬥。
- **出現的地方**：所屬地點，加上兩種方式擇一：
  - **活躍地點**：每天依權重決定在哪個地點的哪個地區，和生成的居民一樣。
  - **固定在聚落的一格**：選區塊，在小地圖上點一格。
  - **固定在特殊地圖的一格**：選一張固定的特殊地圖（[SPECIAL_MAPS](SPECIAL_MAPS.md)），點一格走得到的格子。
  - **待在地標**：選所屬地點的一個地標（[LANDMARKS](LANDMARKS.md)），站在地標那一格，地標搬家時跟著走。
- **劇情條件**：只在某些劇情旗標成立時出現，或某些旗標成立時不出現（見 [`STORY_QUESTS.md`](STORY_QUESTS.md)）。旗標不成立時角色不在任何地圖上，也不能雇用；特殊任務把他列為「在場的友方」時例外。
- **依劇情旗標改變出沒**（`stages`）：一組一組「這些旗標成立（而且那些不成立）時，改成這個所屬地點與出現的方式」。由上往下用第一組成立的設定，都不成立時用上面的預設。例：A 因為某個事件從索里耶爾搬到萊茵堡，就加一組「🚩`a_moved` 成立時：所屬萊茵堡、活躍地點萊茵堡城區」，事件的結果設定 🚩`a_moved`。是同一個角色，親密度、關係、記憶、等級與裝備都延續；旗標被清除時回到預設。沒有填任何旗標的一組儲存時會被移除。還可以改變**身分**：名字、性格、背景、標籤（例如皇子登基成為國王；有寫的取代預設，條件不再成立時換回來，人際關係與隊伍裡的名字一起改）。 每一組可以再限定時段（只在白天或只在夜裡，`hours`），例如只在夜裡營業的俱樂部：其他時候照下一組或原本的設定。
- **能力值、技能與裝備**：預設依職業、種族與等級生成；可以自訂屬性（最終值）、指定會的技能、指定每個欄位的初始裝備（底材 × 材料，可以指定稀有度）。表單上有照目前設定建立的角色預覽。
- **特質**：預設依 id 固定地抽；可以指定（空的清單＝沒有特質），「恢復隨機」回到依 id 抽。見 [`PERKS.md`](PERKS.md)。
- **慾望指標**（成人向，`lewd`）：淫亂、敏感、忍耐、順從，各 0～100；空著的依標籤與 id 固定地擲（灰字顯示擲出來的值）。見 [`LEWD_STATS.md`](LEWD_STATS.md)。

- 已經登場過的角色會複製進存檔，之後出現的條件與固定的格子會跟著這裡改，其他資料（等級、裝備、經歷）以存檔裡的為準。
- **擔任店主**（`keeper`）：選一種店（雜貨店、神殿、酒館、鐵匠鋪、裁縫店、珠寶店、魔法物品店、情報商，或自建的商店），他就取代所屬地點那間店自動生成的店主：交易、交涉、親密度折扣、委託打造（工藝等級看他）都找他，平常待在店裡。他在隊伍裡、死亡、劇情旗標不符或被搬到別的地點時，換回生成的店主（`trade.ts` 的 `fixedKeeper`）。同一間店有好幾位時用第一位。驛站與娼館的老鴇不受影響。
- **從遊戲中加入**：人際關係清單上，遊戲中生成的人有「📌 存成固定 NPC」：把他目前的樣子（名字、性別、種族、職業、等級、性格、外貌、背景、標籤、出沒的地方、屬性、技能、特質、裝備）存進目前的世界，**沿用同一個 id**，目前存檔的親密度、關係與記憶都接得上，存檔裡的紀錄不再算生成的（名單變動不會換掉他）。生成的店主會存成擔任那間店的店主。原版世界不能修改，要先建立自己的世界、用那個世界開始遊戲（`promoteNpc.ts`）。
- **任務同行**：特殊任務可以讓固定 NPC 暫時入隊（夥伴類型「任務同行」）。不佔隊伍名額（最多 2 人，`companions.json` 的 `guest_max`），不能遣散，休息時也不會因為親密度太低離開，由任務的進展讓他離隊。

## 5. 套用的方式

覆寫存成一份 `ContentMods`：內建項目存整份修改後的資料，自建項目存整份資料並標上 `custom`。`applyContent` 先把遊戲資料還原成內建的樣子（模組載入時的快照），再依序套上能力、特質、材料、底材、產生的制式裝備（並重新定價）、物品（寶箱與採集表）、怪物、出現地點、固定 NPC 與特殊任務。每次修改都重新套用一次；開啟遊戲時在讀檔之前先套用。

儲存與匯入時每一項都會整理：數值夾在合理範圍，不存在的技能、狀態、傷害屬性、遭遇表會被拿掉。同一個世界裡新增的項目互相引用時都認得（例如互斥的新特質、城鎮事件指定新商店、特殊地圖用新怪物與新物品、商店固定清單放新底材或材料產生的制式裝備），匯入與之後重新開遊戲時都一樣。套用時出錯的項目略過，並在頁面上方列出原因；地標、商店擺不上去的格子也列在這裡。
