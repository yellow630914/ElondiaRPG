# 自訂內容（🛠️ 內容頁籤）

> 狀態：已實作。程式在 `src/engine/mods.ts`（覆寫的整理與套用）、`src/stores/content.ts`（保存）、`src/components/ContentView.vue` 與 `src/components/content/`（編輯畫面）。

在首頁的「🌍 世界管理」（或遊戲中上方的「🛠️ 內容」）新增或修改怪物、物品、裝備底材、材料、技能、固定 NPC 與特殊任務。

## 0. 世界

**世界**是一整套自訂內容，可以同時存有好幾個（`src/components/WorldBar.vue`）：

- **原版世界**：沒有任何自訂內容，不能修改。要自訂內容，先「＋ 新的世界」（從原版開始）或「📄 複製這個世界」。
- 可以改名、刪除、匯入內容檔「📥 匯入成新的世界」；頁面底部的匯出、匯入、全部恢復預設作用在目前的世界。
- **開新遊戲時選擇世界**，存檔記住它（`state.world`）。之後「繼續」或讀檔時自動切換到那個世界；**遊戲進行中不能切換世界**（可以修改它的內容，用這個世界的其他存檔也會受影響）。回到首頁才能切換。
- 存檔用的世界被刪掉時：存檔欄位與匯出的檔案附有當時的內容，讀取時還原成新的世界「名字（從存檔還原）」；沒有附內容（例如進行中的遊戲）時改用原版世界，畫面會提示。
- 舊版只有一套自訂內容（localStorage 的 `elondia.content`）：第一次啟動新版時變成「我的世界」（沒有內容時從原版世界開始）。世界存在 localStorage 的 `elondia.worlds`。

- **內建項目**：可以修改，隨時「↩️ 恢復預設」；不能刪除，內建物品也不能改名（存檔與掉落表用名稱對應）。
- **自建項目**：可以修改；要沒有被其他內容或目前的存檔用到才能刪（編輯畫面列出用到的地方，見 [`CONTENT_DEPENDENCIES.md`](CONTENT_DEPENDENCIES.md)）；「📄 複製」以選取的項目為範本建立一份。
- 修改存在目前的世界（localStorage 的 `elondia.worlds`），用這個世界的存檔共用；頁面底部可以匯出、匯入（取代目前世界的內容）或全部恢復預設。
- 儲存後立刻生效。已經生成的地圖（地下城、近郊）與今天的商店清單要等下次重新生成才會反映。
- **篩選**：所有頁面都可以搜尋名稱、只看自建或修改過的項目。怪物另外可以依種類（野獸、人形、不死……）、等級（1-2、3-4……）與出現地點（城郊各地區、各座地下城，或沒有出現地點）篩選；物品可以依類別與取得方式（各種商店、寶箱、近郊或地下城採集、怪物掉落、事件獎勵、打造材料，或沒有取得方式）篩選。

## 1. 怪物

| 欄位 | 說明 |
|---|---|
| 基本 | 名稱、等級、種類、生命、行動點、迴避修正、物理減傷、經驗值、金錢範圍；持有裝備（打倒時可能掉一件依等級生成的裝備）、可能擲到「發情」；給 AI 的描述 |
| 屬性與普通攻擊 | 五屬性；攻擊骰、傷害類型、攻擊屬性 |
| 抗性與攻擊加成 | 每種傷害屬性（或群組、全部）的倍率加減：-1 免疫、-0.5 減半、+0.5 弱點 |
| 技能 | 怪物技能、職業技能與戲法（怪物沒有法術環，不能用法術）；固定特徵（巨大、年老……） |
| 掉落物 | 物品、機率、數量 |
| 出現地點 | 城郊（各地區）、各地下城的周邊／淺層／中層／深層、層主（取代原本的層主）。每一組是遭遇表裡的一個選項，遭遇時從所有選項平均抽一個；權重是放幾組。內建怪物可以從內建的遭遇表移除（遭遇表不會被清空） |

刪掉自建怪物時，已經生成在地圖上的那種怪物會消失（格子視為已清除）。

## 2. 物品

| 欄位 | 說明 |
|---|---|
| 基本 | 名稱（自建才能改）、類別、價格、描述。材料的價格是商人的收購價 |
| 在哪裡出現 | 商店（雜貨店、神殿、酒館、鐵匠鋪、裁縫店、珠寶店、魔法物品店、情報商）與最低聚落規模；地下城寶箱各層的機率；近郊、地下城的資源格（採集）；事件（AI 判定主動行動時可以把它當成報酬，提示詞會列出這些物品）；怪物掉落 |
| 使用效果 | 消耗品、食物、卷軸：回復生命（骰子）、法術環、暫時生命、行動點、救起倒下的隊友、給隊友的狀態、解除狀態、投擲傷害、對敵人施加狀態（豁免屬性與 DC）、範圍、只能在戰鬥中使用 |
| 裝備組成 | 裝備：底材、材料、稀有度、附魔（命中、傷害……、抗性、攻擊加成）；「依組成定價」 |
| 打造材料 | 材料：可以拿來打造哪些材料的裝備 |

**怪物掉落的設定存在怪物身上**：在物品這邊設定掉落，改的是那隻怪物的掉落物（和怪物編輯頁是同一份），所以物品「恢復預設」不會一起恢復掉落。

刪掉自建物品時，行囊裡已有的會變成無法使用的雜物，怪物也不再掉落。

## 3. 裝備底材與材料

- **底材**：名稱、欄位、材料類型、底價、仇恨、雙手；主手武器的傷害骰、傷害類型、攻擊屬性；上身防具的迴避、減傷與抗性；固定加成與「材料成長」（材料的加成依比例加到哪一項）。
- **材料**：名稱、類型、等級（1～5，決定打造的工錢與 DC）、加成、稀有度、建議等級、價格倍率、防具的額外迴避與減傷、抗性。
- 自建的底材或材料會自動產生「底材 × 同類材料」的制式裝備（第 5 級材料不在商店販售，第 3 級要城市、第 4 級要王都）。
- 修改內建底材或材料時，制式裝備的價格跟著重新計算；改名只影響之後新打造或生成的裝備，目錄裡的制式裝備沿用原本的名稱。
- 內建底材的武器與防具數值是共用的：同一種武器（例如長劍，也是戰士的起始武器）會一起改。

## 3.5 技能

技能、法術與戲法（`data/rules/abilities.json`）。頁籤在「固定 NPC」之前，可以依種類與職業（包括「怪物」）篩選。

- **基本**：名稱、種類（技能依等級學、法術依環數學並花法術環、戲法不花行動點）、解鎖等級或環數、行動點（法術不寫時依環數）、屬性（或依職業的施法屬性）、額外仇恨、誰可以學（各職業與怪物；怪物不能用法術）。
- **目標與判定**：目標（一名敵人、所有敵人、隨機敵人數次、隊友、自己……）、判定方式（命中骰對迴避、目標豁免、必中）、豁免屬性與成功時的效果、命中修正、優勢、幸運一擊門檻、攻擊次數、傷害倍率。
- **傷害**：一段或多段（武器傷害或骰子、傷害類型、加屬性調整值、每幾級多一組骰子）。
- **治療與護盾**、**狀態**（給誰、什麼時候、能不能豁免）、**次數**（每回合、每場戰鬥、每次長休）、獲得行動點、專注、淨化、回復法術環、斬殺。
- **刪除**：只有自建、而且沒有被用到的技能可以刪。編輯畫面會列出用到的地方：職業的初始能力、怪物、固定 NPC、特殊任務的獎勵，以及目前存檔的角色。被移除的技能（匯入、全部恢復預設）會從存檔的角色身上拿掉。
- 自建的技能存在 `ContentMods.abilities`，套用時最先處理（怪物與固定 NPC 會用到）。

## 4. 固定 NPC

內建的具名角色（`data/world/npcs.json`）和自建的角色都是**固定 NPC**：在所屬地點的名單上，不會因為名單變動消失、搬走或被新的人取代（名單變動只動生成的居民）。特殊任務用角色的 id 指定他們。

- **基本**：名字、性別、種族、身分（冒險者或普通人）、職業或職業描述、等級、雇傭要價、勢力、出身、性格、外貌、背景、標籤。
- **出現的地方**：所屬地點，加上兩種方式擇一：
  - **活躍地點**：每天依權重決定在哪個地點的哪個地區，和生成的居民一樣。
  - **固定在聚落的一格**：選區塊，在小地圖上點一格。
- **劇情條件**：只在某些劇情旗標成立時出現，或某些旗標成立時不出現（見 [`STORY_QUESTS.md`](STORY_QUESTS.md)）。旗標不成立時角色不在任何地圖上，也不能雇用；特殊任務把他列為「在場的友方」時例外。
- **依劇情旗標改變出沒**（`stages`）：一組一組「這些旗標成立（而且那些不成立）時，改成這個所屬地點與出現的方式」。由上往下用第一組成立的設定，都不成立時用上面的預設。例：A 因為某個事件從索里耶爾搬到萊茵堡，就加一組「🚩`a_moved` 成立時：所屬萊茵堡、活躍地點萊茵堡城區」，事件的結果設定 🚩`a_moved`。是同一個角色，親密度、關係、記憶、等級與裝備都延續；旗標被清除時回到預設。沒有填任何旗標的一組儲存時會被移除。
- **能力值、技能與裝備**：預設依職業、種族與等級生成；可以自訂屬性（最終值）、指定會的技能、指定每個欄位的初始裝備（底材 × 材料，可以指定稀有度）。表單上有照目前設定建立的角色預覽。
- 已經登場過的角色會複製進存檔，之後出現的條件與固定的格子會跟著這裡改，其他資料（等級、裝備、經歷）以存檔裡的為準。
- **任務同行**：特殊任務可以讓固定 NPC 暫時入隊（夥伴類型「任務同行」）。不佔隊伍名額（最多 2 人，`companions.json` 的 `guest_max`），不能遣散，休息時也不會因為親密度太低離開，由任務的進展讓他離隊。

## 5. 套用的方式

覆寫存成一份 `ContentMods`：內建項目存整份修改後的資料，自建項目存整份資料並標上 `custom`。`applyContent` 先把遊戲資料還原成內建的樣子（模組載入時的快照），再依序套上材料、底材、產生的制式裝備、物品（寶箱與採集表）、怪物與出現地點。每次修改都重新套用一次；開啟遊戲時在讀檔之前先套用。

儲存與匯入時每一項都會整理：數值夾在合理範圍，不存在的技能、狀態、傷害屬性、遭遇表會被拿掉。套用時出錯的項目略過，並在頁面上方列出原因。
