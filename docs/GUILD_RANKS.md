# 冒險者公會的階級

程式：`src/engine/guild.ts`；資料：`data/rules/progression.json` 的 `guild_ranks`、`guild_merit`。

主角的階級由公會評定：累積**功績**，功績與等級都夠了，公會發**晉升考核**，通過才升階。隊友（NPC）的階級仍依等級換算（`guildRankFor`）。

## 1. 階級

| 階級 | 等級下限 | 需要的功績（累積） |
|---|---|---|
| F 實習級 | 1 | 0 |
| E 新手級 | 3 | 6 |
| D 普通級 | 5 | 20 |
| C 中堅級 | 7 | 45 |
| B 資深級 | 9 | 90 |
| A 精英級 | 11 | 160 |
| S 傳奇級 | 13 | 260 |

- 只能接同級或更低的委託；組隊（2 人以上）時可接高一級。晉升考核本來就是下一階的委託，不受這條限制。
- 功績累積、升階後不歸零。

## 2. 功績

| 來源 | 功績 |
|---|---|
| 交付委託 | 依委託階級：F 1、E 2、D 3、C 5、B 8、A 12、S 18 |
| 打倒地下城的層主（層主格的戰鬥獲勝） | 2 |
| 完成特殊任務 | 5（任務資料的 `merit` 可以覆蓋，內容頁籤的「完成時的公會功績」） |

功績寫在報告的 `changes.merit`（AI 會看到），升階寫在 `changes.rank_up`。

## 3. 晉升考核

- 功績與等級都達到下一階的要求時，在公會的委託板發出考核（`flags.exam`）；委託板每天更新也不會撤下它。
- 內容：討伐階級相符的層主（層主的等級換算成階級，和目標階級差 1 以內，近的地下城優先）；找不到時改成清剿階級最接近的地下城 `exam_clears`（3）次。
- 報酬：下一階報酬範圍的下限。考核本身不給功績。
- 交付時升階。放棄考核（公會聲望 -1）之後回公會會再發一次。
- 公會的畫面上方顯示目前的階級、功績與下一階的條件；隊伍視窗的主角標籤是公會階級。

## 4. 舊存檔

存檔格式 2（見 [SAVES.md](SAVES.md) 第 5 節）：沿用原本由等級換算出來的階級，功績從 0 開始。
