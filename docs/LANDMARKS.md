# 城鎮的特色地標

> 上層：[GAME_DESIGN](GAME_DESIGN.md)。依賴：[WORLD](WORLD.md)（聚落地圖）。被依賴：[STORY_QUESTS](STORY_QUESTS.md)（任務點）、[NPC_SYSTEM](NPC_SYSTEM.md)（固定 NPC、生成居民的分布）、[CONTENT_EDITOR](CONTENT_EDITOR.md)（地標頁籤）。
> 資料在 `data/world/landmarks.json`（類型與地標）。程式：`src/engine/landmarks.ts`（遊戲中的功能）、`src/engine/landmarkMods.ts`（內容編輯器）、`src/engine/grid.ts`（擺上地圖）。

## 1. 地標是什麼

聚落地圖上的一格，代表那座城的特色建築（騎士學院、聖環主殿、舊石橋……）。**格子的種類就是地標的 id**（`lm_` 開頭），所以所有用「格子種類」指定地方的系統都可以直接指定地標。一個地標只在一處。

- 內建 61 個：世界書各區域條目的「特色建築」32 個，加上世界書沒寫到的聚落由本專案補寫 12 個（月輝之母、生命之泉、七潮議會廳、深潮席渡口、海靈祠、渡口燈塔、花崗岩城牆、風錘、變異藥沼、森語之環、浮石觀星台、長老石廳）；再加上故事線解鎖的特殊區域 6 個、打工線委託人的地標 9 個（黃金骰子賭場、克勞澤伯爵府、怪人之塔、朝聖者澡堂、珍珠澡堂、熔岩溫泉旅館、下城區的按摩店、河畔的畫室、侍寢見習館），以及緋夢樂園的售票亭（[LUST_PARK](LUST_PARK.md)）與月下拍賣會（第 6 節）。後面這 17 個都是成人向的場所。
- 每個地標：名稱、圖示、說明（地點面板顯示）、**氛圍**（站在這裡行動時交給 AI）、**類型**（最多 4 種）、位置（區塊 key 與座標，要是道路，不能是待售的空地）。
- 擺法：建立聚落區塊時疊在道路上（`grid.ts` 的 `buildBlock`，在商店的位置之後）；不改 `maps.json`，所以舊存檔讀進來也看得到。地標可以走過去，不會擋路。

## 2. 類型

| 類型 | id | 聚到這裡的居民 |
|---|---|---|
| 聖地 | `holy` | 一般人、神官與主教（很高）、好人 |
| 學院 | `academy` | 一般人、冒險者、貴族 |
| 官府・議會 | `official` | 貴族、皇族 |
| 軍事・校場 | `military` | 冒險者 |
| 市集・交易 | `market` | 一般人、商人、旅人、惡人 |
| 工坊 | `workshop` | 一般人 |
| 碼頭・渡口 | `harbor` | 旅人、商人 |
| 古蹟 | `monument` | 一般人、冒險者、旅人 |
| 自然 | `nature` | 一般人 |
| 陰森之地 | `haunted` | 惡人 |

權重在 `landmarks.json` 的 `types[].npc`（`commoner`、`adventurer`，`tags` 是帶這些標籤的人）；一個地標有好幾種類型時取最高的（`population.ts` 的 `landmarkWeight`）。

## 3. 用途

| 用途 | 說明 |
|---|---|
| 特殊任務的任務點 | `at.where = cell`、`at.cell = 地標 id`（地標要在 `at.location` 那個聚落）；編輯器的設施清單會列出這個地點的地標 |
| 固定 NPC 的站點 | 出現的方式選「待在地標」（`NpcDef.landmark`）：站在地標那一格，地標搬家時跟著走；依劇情旗標搬走時看那一組的設定 |
| 生成居民的分布 | 依類型（第 2 節） |
| AI 的場景 | 站在地標上做主動行動時，場景加上「・地標名稱（氛圍）」（`withLandmark`） |
| 公會委託 | 第 4 節 |
| 參訪、探索、打工、受訓、開放條件 | 第 5 節 |
| 場景（解鎖的特殊區域） | 第 6 節 |

## 4. 公會委託的標的

`town_quests.json` 的範本可以寫 `landmark`（地標類型的清單）。委託板更新時，城裡有符合類型的地標，這種範本才會進候選（還沒出現的地標與成人向的場所不算）；選中時從符合的地標隨機挑一個：

- 委託記住地標（`Quest.landmark`），標題與場景的 `{landmark}` 換成地標的名字；
- 執行地點就是那個地標（`town.ts` 的 `questSpot`）；地標被刪掉時改回範本的設施（沒有寫時是公會）。

| 範本 | 類型 | 種類 |
|---|---|---|
| 清除{landmark}地下的巨鼠 | 古蹟、陰森、工坊、碼頭 | 戰鬥（巨鼠 ×3） |
| 在{landmark}守夜 | 聖地、古蹟、官府 | 巡邏 DC 11（可能遇到盜賊） |
| 調查{landmark}夜裡的怪聲 | 陰森、古蹟、聖地 | 尋找 DC 12（可能遇到墓鼠群與食屍鬼；有機會學到能力） |
| 替{landmark}的學者找齊資料 | 學院 | 尋找 DC 12（有機會學到能力） |
| 在{landmark}幫忙卸貨 | 碼頭、市集 | 送貨 |
| 揪出在{landmark}出沒的扒手 | 市集 | 尋找 DC 12（可能遇到盜賊） |
| 替{landmark}搬運礦石與燃料 | 工坊 | 送貨 |
| 維持{landmark}儀式的秩序 | 聖地、官府 | 巡邏 DC 10 |
| 在{landmark}擔任陪練對手 | 軍事 | 巡邏 DC 12（有機會學到能力） |
| 在{landmark}一帶採集藥草 | 自然 | 採集 DC 10（藥草 ×2） |

報酬照 F 級（30～50 白鸛）。每座城一次發的城內委託從 3 個增加到 4 個，讓一般的委託不會因為多了地標委託而變少。

## 5. 地標的功能

每個地標可以有下面幾種功能（都可以在內容編輯器設定），站在地標上時地點面板會列出來。

| 功能 | 說明 |
|---|---|
| **開放條件**（`open`） | 只在白天（6～18 時）或只在夜裡；劇情旗標成立（而且那些不成立）時；這裡的勢力至少要有多少聲望；官方場所（逃亡奴隸不能用）。不開放時不能參訪、探索、打工與受訓（公會委託照樣可以做）。勾了「條件不成立時不顯示」（`hidden`），旗標的條件成立之前地圖上是普通的道路（例如完成任務才開幕的店、秘密俱樂部）；勾了「成人向的場所」（`adult`），不當公會委託的地點 |
| **參訪**（`visit`） | 不用檢定：付錢（`money_cc`）、花時間（`hours`），得到效果；隔幾天才能再來（`cooldown_days`，預設每天一次）。例如晨曦聖殿「在祭壇前祈禱」得到祝福 |
| **探索**（`explore`） | 主動行動 `explore`：照設定的屬性與 DC 檢定，成功（含大成功）得到 `effects`，大成功另外得到 `critical`；隔幾天才能再試（預設 7 天，失敗也算）。AI 判定與寫經過時知道地標的氛圍 |
| **打工**（`work`） | 和設施的工作一樣（[WORK](WORK.md)），名稱是「地標名稱的雜務」 |
| **受訓** | 寫在特質的受訓地點（`perks.json` 的 `train.cells`）；地標的編輯表單可以直接勾選 |

參訪與探索的效果可以用：金錢、物品、裝備、經驗值、聲望、親密度、記憶、學會能力、生命值、特質的機會、非戰鬥狀態、刺青（不能讓主角淪為奴隸、開始特殊任務或讓人入隊）；最多 6 個。存檔記錄每個地標上次參訪、探索是第幾天（`GameState.landmarks`）。

## 6. 場景

地標可以有幾個**場景**（`scenes`，最多 8 個）：條件成立時出現在地點面板的固定場景，例如故事線解鎖的特殊區域。程式：`landmarks.ts` 的 `scenesHere`、`sceneBlocked`、`playLandmarkScene`；欄位見 [worldgen/guides/landmarks](../worldgen/guides/landmarks.md) 2.3 節。

- **出現的條件**：內容標籤（設定關掉的不出現）、主角的形象（`pc_body`：男性形象、女性形象、中性；設定打開「陽剛體型也能遇到『只給陰柔、中性』的成人內容」時，不含男性形象的限定也給男性形象，見 [ADULT_EVENTS](ADULT_EVENTS.md)「陽剛體型」）、劇情旗標（`requires`）；一定在場的固定 NPC 死了或被抓走時也不出現。勾了「條件成立前不顯示」、只有場景的地標（沒有參訪、探索、打工）一個場景都不出現時，地標本身也不出現（地圖上是普通的道路）；沒勾的在還有接得到或進行中的特殊任務要用到時照常出現（例如打工線委託人的地標：任務點在那裡，完成之後才有場景），都沒有時也不出現。
- **在場的人**（`cast`）：寫了旗標的人，旗標成立才在場；有人不在場時接上代替的人（`extras`，例如「其他不知名的魅魔」）。經過裡的 `{cast}` 換成在場的人，在場的每個人加 `affinity` 好感。
- **冷卻**：預設每 3 天一次，同一個地標的場景共用；勾了自己算冷卻（`own_cooldown`）的另外算（例如女僕咖啡廳前廳的喝茶，每天一次）。存檔記在 `GameState.landmarks[id].scene`、`.scenes[場景名稱]`。
- **內部**（`interior`）：地標可以指定一張同一個聚落的固定特殊地圖當內部。地標格變成入口（地點面板的「走進…」，地標不開放時不能進），從地圖的出口離開時回到地標格。寫了格子（`spot`）的場景只在內部的那一格出現，地圖上畫一顆心、格子名稱用 `spot_name`；沒寫格子的場景還是在外面的地標格上。
- **拍賣會**（`auction`，成人向）：地標的面板多了今晚的拍品、出價與寄賣（[LEWD_STATS](LEWD_STATS.md) 第 26 節）；目前是阿爾貝納的「月下拍賣會」。
- **限定穿著**（`wear`）：物品名稱或裝備底材，主角沒穿上時按鈕停用並說明（和特殊任務的任務點一樣，見 [STORY_QUESTS](STORY_QUESTS.md)）。
- **結果**：付錢、花時間、得到效果；報告交給 AI 寫經過，標了成人向的場景帶上 `narration.adult_scene`，照成人場景規則詳細描寫。

內建的特殊區域（都是成人向的場所、條件成立前不顯示；設計見 `worldgen/design/elondia-storylines.md` 第 3.3 節）：

內建的六個特殊區域都有內部（安全的室內，見 [SPECIAL_MAPS](SPECIAL_MAPS.md)）。在場的角色也站在裡面（固定 NPC 依劇情旗標的出沒，`fixed` 在內部地圖的一格）：咖啡廳開張後米米、伊芙、漣（回到陸地時）待在各自的小房間；人妻下午茶會之後三位夫人白天在沙龍；黑檀之夜、魅魔的宴會廳、三重奏的後台只在夜裡有人（阿雅；卡珊卓與成為戀人的雙子女僕、露西菈、諾艾爾；史黛拉、諾瓦、波姆），白天她們回到原本的地方。每個場景在一個房間裡：例如咖啡廳的前廳座位、米米和伊芙的小房間、漣的浴室、最大的小房間；榮譽洞的牆分成服務的一側與被服務的一側。

**打工線的場景**：十二條打工線（祭品儀式除外）完成之後，委託人所在的地標多一到兩個可以重複的場景，回去上工賺錢（預設每 3 天一次，見 [ADULT_EVENTS](ADULT_EVENTS.md) 第 8 節）。這些地標沒有勾「條件成立前不顯示」，線還沒完成、而且主角接得到或正在做那條線時照樣在地圖上（任務點在那裡）；接不到的主角（男性形象而且沒打開「陽剛體型也能遇到」的設定、關掉男性對象、等級或公會階級不夠）看不到。資料在 `worldgen/scripts/elondia/work26.py` 的 `SCENES`。
