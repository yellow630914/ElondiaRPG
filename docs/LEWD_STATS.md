# 慾望指標、流派與雙面效應（成人向）

> 上層：[GAME_DESIGN](GAME_DESIGN.md)。依賴：[COMBAT_SYSTEM](COMBAT_SYSTEM.md) 第 8.5 節（慾望戰鬥）、[ITEMS](ITEMS.md)（服裝的底材）、[COMPANIONS](COMPANIONS.md)（奴隸契約）、[WORK](WORK.md)（娼館）。被依賴：[PERKS](PERKS.md)（流派特質）、[ITEMS](ITEMS.md)（拘束具與鎖）、[EFFECTS](EFFECTS.md)（`lewd` 效果）、[STORY_QUESTS](STORY_QUESTS.md)（`stats` 條件）、[ACTIONS](ACTIONS.md)（情境修正、AI 判定的效果）、[TRAVEL_EVENTS](TRAVEL_EVENTS.md) 第 6 節（城鎮事件）、[PROMPTS](PROMPTS.md)（給 AI 的資料）。
> 資料：`data/rules/lewd.json`（分段、預設、成長量、服裝的預設、流派、雙面效應、鎖、主人工具人）；底材的曝露度、真空與拘束在 `gear.json` 的 `bases`（`exposure`、`vacuum`、`bind`、`bind_kind`）；流派特質在 `perks.json`（`school`、`lust`）。程式：`src/engine/lewd.ts`（指標）、`src/engine/schools.ts`（流派、雙面效應、鎖）、`src/engine/masterTool.ts`（主人工具人）。還沒做的構想：[點子庫 I24](plan/ideas/dev-discussion.md#i24)。

每個角色有四項長期指標，加上依地區記的曝露名聲，合計五項。它們隨經歷慢慢改變，影響慾望戰鬥與 AI 的描寫。角色詳情的「屬性與戰鬥」頁左欄、五維屬性底下顯示目前的值、分段與裝備的加減。

| 指標 | id | 存在哪裡 | 是什麼 |
|---|---|---|---|
| 淫亂 | `lewdness` | `Character.lewd` | 對性的渴求與開放 |
| 敏感 | `sensitivity` | `Character.lewd` | 身體對刺激的反應 |
| 忍耐 | `endurance` | `Character.lewd` | 承受刺激與拘束的能力 |
| 順從 | `submission` | `Character.lewd` | 服從的習慣；不是契約的 `obedience`（那是主人加的暫時檢定懲罰） |
| 曝露名聲 | `exposure` | `state.exposure[角色 id][地區]` | 在這個地區被多少人看過、傳得多開（只有主角與夥伴） |

- 基本值的範圍 0～100。主角與舊存檔沒有記錄時用 `defaults`（淫亂 10、敏感 50、忍耐 10、順從 10）。
- **有效值** = 基本值（含泌乳，夾在 0～100）+ 身上裝備的加減（第 3 節），最低 0、最高 100 + 全身合計上限（200）。**只有裝備能把有效值推過 100**；成長改的是基本值，照舊到 100 為止。條件、AI、畫面都看有效值。
- **效力**（`lewdPower`、`lewdPowerOf`）：戰鬥、檢定、身價這些機制用的值。100 以內和有效值一樣；超過 100 的部分邊際遞減：100 + 80 ×（1 − 100 ÷ 有效值）（80 是 `lewd.json` 的 `gear.over_scale`）。有效值 120 → 113、150 → 127、200 → 140（以前上限 100 的 1.4 倍），再怎麼堆也到不了 180。角色詳情在有效值超過 100 時寫「效力 N」。

## 2. 戰鬥（慾望戰鬥開著時）

開戰時換算成戰鬥單位的 `lustMods`（`combat.ts` 的 `initLust`；數值在 `lewd.json` 的 `combat`）。下面的「指標」都是效力（超過 100 的部分遞減，見開頭）：


| 指標 | 效果 |
|---|---|
| 忍耐 | 慾望上限 + 忍耐 / 2 |
| 敏感 | 受到的慾望 × (0.75 + 敏感 / 200)：敏感 0 是 ×0.75、50 是 ×1、100 是 ×1.25 |
| 淫亂 | 每 20 點，開戰帶上限 5% 的慾望；每回合的消退 × (1 − 淫亂 / 200)；60 以上自己增加的慾望 ×1.25 |
| 順從 | 有「傷害轉成慾望」的狀態時，轉換的比例每 20 點 +5% |
| 曝露名聲 | 在這個地區每 20 點，造成的魅惑傷害 +1 |
| 信仰 | （屬性）每 1 點調整值，魅惑的受傷倍率 −0.05（調整值是負的反而 +） |

開戰帶的慾望（淫亂、發情）最多到上限減 1，不會一開打就高潮。種族特質：精靈的魅惑 ×0.9、貓魅族 ×1.15（`perks.json` 的種族特質）。

## 3. 服裝與裝備

- **加減**：物品的 `gear.lewd`（例如 `{ "lewdness": 5 }`），加上底材的預設：**成人向服裝**每件淫亂 +5、**束縛用的底材**每件順從 +5、忍耐 +3（`lewd.json` 的 `gear`）。每件每項 ±20（`item_cap`，連同底材的預設一起算），全身每項合計 ±100（`total_cap`；2026-11 之前是每件 ±10、全身 ±20）。放在哪一格都照算，**拘束具放在額外飾品欄**也一樣（第 7.1 節）。物品說明會寫出來（例如「兔女郎裝・淫亂 +5・曝露度 2」）。
- **曝露度 0～3**：底材的 `exposure`；沒寫時成人向服裝是 2，其他是 0。只算上身、下身與看得到的內衣（`exposureLevel`）：
  - 上身穿著就看上身那件；沒穿上身時看內衣，只穿內衣至少算 2；什麼都沒穿是 3。
  - 下身看下身那件；沒有時上身那件也算遮住；再沒有才看內褲；什麼都沒穿是 3。
  - 頭飾、鞋子、腿飾、飾品不算。
  - 寫了曝露度的底材：短裙、旗袍、魔法少女服、水手服、皮緊身衣 1；比基尼鎧甲、舞孃紗衣、超短裙、開胸晚禮服 2；逆兔女郎裝、透視薄紗睡衣、乳貼、開檔內褲、開胸胸罩、無襠皮褲、微比基尼、吊帶泳衣 3。
- **真空**（`vacuumSides`）：外衣底下沒穿內衣或內褲，而外面那件會走光時，那一側曝露度 +1（最多 3）。
  - 「會走光」：外衣本身曝露度 1 以上，或底材的 `vacuum` 寫了那一側（`top` 上身、`bottom` 下身）。內建寫了的：百褶裙、長裙、連身裙、禮服、女僕裝、護士服、哥德蘿莉塔洋裝（下身），襯衫、荷葉邊上衣（上身），浴衣（兩邊）。鎧甲、長褲、長袍這類曝露度 0 又沒寫的不受影響。
  - 上身沒穿內衣只算陰柔、中性的體型；下身看遮住下身的那件（沒穿下身時是上身那件，只限連身類，例如連身裙、旗袍；底材勾了 `top_only`「上衣類」的襯衫、荷葉邊上衣、水手服、果實馬甲不遮下身，沒穿下身時看內褲，沒穿就是光著）；內褲欄被種族改名的（人馬族的「後蹄」）下身不算真空。
  - 例：水手服＋短裙都沒穿內衣褲 → 2；連身裙沒穿內褲 → 1；比基尼鎧甲沒穿內衣 → 3。
  - 角色詳情的曝露度後面寫「真空 +1：沒穿內褲」；紙娃娃空著的內衣、內褲欄寫「真空・沒穿內褲」。交給 AI 的角色資料只寫會走光的那一側（「沒穿內衣」「沒穿內褲」），生圖也是（no bra、no panties）。
- 內容編輯器的底材可以設曝露度、拘束，物品可以設慾望指標的加減與鎖（[CONTENT_EDITOR](CONTENT_EDITOR.md)）。

## 4. 怎麼漲、怎麼降

**事件**（`lewd.json` 的 `growth`；記在報告的 `changes.lewd`，日誌會寫出來）

| 來源 | 變化 |
|---|---|
| 親密場景（報告帶 `adult_scene`） | 場景的主角淫亂 +1，記下日子；派奴隸去娼館時記在奴隸身上（`narration.adult_actor`） |
| 戰鬥中高潮 | 每次淫亂 +1、敏感 +1；高潮過還撐到打贏，忍耐 +1 |
| 寬衣（能力的 `exposure`） | 戰後在這一帶的曝露名聲 +1 |
| 娼館打工（接客的人） | 淫亂 +2、曝露名聲 +2 |
| 主人加重服從懲罰（`obedience` +1） | 順從 +1 |
| 主人事件選了一定進入親密場景的回應（屈服） | 順從 +1 |
| 事件、任務的 `lewd` 效果、AI 判定 | 照效果 |

**每天**（`lewd.json` 的 `daily`；跨日時結算，只看隊伍裡的人，不寫進報告）

- 曝露名聲：每個地區每天淡掉 1；人在聚落裡（城市、城鎮、村落、港口、哨站、要塞）時，加上身上的曝露度 × 2。
- 穿著成人向服裝：淫亂 +1。人在聚落裡真空：淫亂 +1（`daily.vacuum`）。穿著束縛用的底材：忍耐 +1。身上有被主人鎖上的裝備：順從 +1。
- 沒有奴隸契約的日子：每 3 天順從 −1。
- 超過 7 天沒有親密場景：淫亂每天 −1，降到預設為止。
- 超過 7 天（`daily.sensitivity_idle_days`）沒有親密場景、**也沒在戰鬥中高潮**：敏感每天 −1，降到預設（50）為止。戰鬥中高潮會記下日子（`LewdStats.lastClimax`）。
- 四種下跌每次幾點照存檔規則（`exposureDecay`、`submissionDecay`、`lewdnessDecay`、`sensitivityDecay`，0～10 的整數，預設 1；[SAVES](SAVES.md) 第 7 節）：頻率不變（曝露名聲每天、順從每 3 天、淫亂與敏感每天），只改每次跌幾點；0 是不會跌。
- 走格子、旅途、開寶箱這類不產生報告的時間推進也會結算（`state.ts` 的 `advanceTime`）；一次最多結算 30 天。

### 4.1 主動降低：神殿的淨身與冥想道具

自然回落只會降到預設值；想降得更低、或想降忍耐、這一帶的曝露名聲，可以去神殿（資料由 `worldgen/scripts/elondia/purify50.py` 產生）：

- **淨身**（神殿選單的「淨身」，`purify.ts`；數值在 `lewd.json` 的 `purify`）：選一位隊員、一項指標（淫亂、敏感、忍耐、順從、這一帶的曝露名聲），一次降 1～5 點。預設值以上每點 40 白鸛，降到預設值以下的部分每點 ×2（曝露名聲的預設是 0）；花 2 小時，每人每天一次。逃亡中、育幼院欠費、戰鬥中不行。
- **冥想道具**（神殿賣，`use.lewd`；用了花一個小時，降不下去時不會用掉）：

  | 道具 | 價格 | 效果 |
  |---|---|---|
  | 清心香 | 150 | 敏感 −2 |
  | 淨念香 | 150 | 淫亂 −2 |
  | 自持經 | 180 | 順從 −2 |
  | 隱名符 | 120 | 這一帶的曝露名聲 −5 |

  內容編輯器的物品「使用效果」可以寫冥想的增減（每項 −20～+20，[CONTENT_EDITOR](CONTENT_EDITOR.md) 第 3 節）。
- **其他**：卸下加敏感的裝備、泌乳結束（有效值 −5）；禁慾派進階「清心寡慾」讓淫亂與敏感漲得慢一半。

## 5. 其他的連動

- **泌乳**（內容篩選「泌乳」打開時）：敏感的有效值 +5，在聚落裡胸前真空或曝露時曝露名聲每天多 +1，戰鬥中（修了流派）慾望上限與受到的慾望 +10%。見 [FAMILY](FAMILY.md) 第 10 節。
- **效果** `lewd`：`{ "type": "lewd", "stat": "submission", "delta": 5, "target": "pc" }`，曝露名聲記在目前的地區（[EFFECTS](EFFECTS.md)）。
- **條件** `stats`：`{ "stats": { "exposure": { "min": 40 } } }`，看主角的有效值，曝露名聲看目前的地區（`storyFlags.ts` 的 `condMet`）。
- **AI 判定**：可能進入親密場景的行動（自由行動、主人的要求、打工、光顧娼婦、特殊任務、戰敗事件、獻媚、誘惑、嘗試脫縛）多一種效果 `lewd`，每人每項一次、±3（`actions.json` 的 `caps.lewd`）。
- **主動行動的情境修正**（`actions.ts` 的 `lewdModifiers`）：淫亂淫蕩以上獻媚、誘惑 +1（淫亂 +2）；曝露名聲在這一帶遠近馳名以上時，對貴族、皇族、神官、主教唬騙 −1（人盡皆知 −2）。
- **城鎮事件**：成人向的城鎮事件，權重與機率 × (1 + 主角在這個地區的曝露名聲 / 100)；其他事件的機率不變（[TRAVEL_EVENTS](TRAVEL_EVENTS.md) 第 6 節）。
- **NPC**：依 id 固定地擲（不影響其他生成），標籤決定範圍（娼婦淫亂 50～80、奴隸順從 40～80、貴族與神官淫亂 0～20……，`lewd.json` 的 `npc_tags`）；固定 NPC 可以在內容編輯器指定（`NpcDef.lewd`，空著的照擲）。
- **給 AI**：只在成人向的日誌與判定送出。敘事：主角設定後面附上主角與隊友的分段（「淫亂：開放；敏感：敏感；…；曝露名聲：在這一帶小有名氣」）；判定：主角資料附上數值與分段，隊友各一行。

## 6. 慾望流派

流派說的是角色走哪一條修行路線（借用 I13 世界書的流派），做成特質：帶來被動的慾望效果，並讓拘束具的雙面效應生效（第 7 節）。

- **流派就是特質**：每個流派一個入門特質（`perks.json`，分類「慾望流派」）。色情技能不分流派，誰都能從技能書學，不用入門。
- **進階**：要先有入門特質（特質的 `requires.perks`）。
- **怎麼學**：在設施受訓（娼館、神殿、酒館、裁縫店、魔法物品店、情報商、地標「魅魔的宴會廳」……，見下表）、向流派的**老師**受訓、讀**秘法書**（第 6.1 節），也可以在建立角色時選入門特質。流派特質**不進升級的三選一**；NPC 只有娼妓、奴隸另外有機會帶入門特質（第 23 節），一般的特質抽選抽不到。
- **不限流派數量**；縱欲派與禁慾派互斥。流派只決定戰鬥方式，不影響順從。
- **慾望效果**（特質的 `lust`）：開戰時換算（`combat.ts` 的 `initLust`），慾望戰鬥關閉時不生效。抗性、增傷這類一般效果照特質的規則一直生效。
- **隸從派的認主**：有主人（奴隸契約上有主人；主角的奴隸夥伴的主人是主角）時全效，沒有主人時一半效果（戰鬥修正向下取整）。主人和自己同一邊上場時才有「奴之誓」的戰鬥修正。

## 7. 雙面效應與鎖

拘束具（底材有 `bind` 1～3 與 `bind_kind`；物品可以寫自己的 `bind` 蓋過底材的程度，種類照底材）**平常是負面效果，戰鬥中反轉成增益**。穿不穿完全由玩家決定；主人強制戴上的照奴隸的規則，事件鎖上的見第 27 節。

- **平常**：相關的檢定減值（`lewd.json` 的 `two_face.kinds`：限制行走影響靈巧與旅途、潛行；束縛雙手影響力量、靈巧、開鎖與陷阱；遮住視線影響智力、陷阱、開鎖、潛行與旅途；封住嘴巴影響魅力與談判；持續刺激影響智力、信仰與談判；全身拘束影響所有檢定）。程度越重扣越多；每 40 點忍耐減輕 1。和其他情境修正一起列出（「拘束【單手套】-3」）。
- **戰鬥中**：**修了任何流派、而且這件鎖上了**才有增益；沒修流派的人只吃平常的減值。慾望戰鬥關閉時沒有增益。

| 拘束 | 程度 1 | 程度 2 | 程度 3 |
|---|---|---|---|
| 限制行走 | 先攻 +2 | 先攻 +4 | 先攻 +5、行動點回復 +1 |
| 束縛雙手 | 減傷 +1 | 減傷 +2 | 減傷 +3；免疫繳械 |
| 遮住視線 | 迴避 +1 | 迴避 +2 | 迴避 +3；免疫致盲 |
| 封住嘴巴 | 豁免 +1 | 豁免、減傷 +1 | 豁免 +2、減傷 +1；免疫嘲諷 |
| 持續刺激 | 豁免 +1 | 行動點回復 +1 | 行動點回復 +1、豁免 +1 |
| 全身拘束 | 豁免 +1 | 命中、迴避、豁免 +1 | 命中、迴避、豁免、減傷、傷害 +1 |

- **倍率**：鎖的倍率 × 流派契合，每件**無條件捨去**（行動點回復 1 × 1.56 還是 1）。拘束具（含口枷）配束縛派或刑罰派、調教道具（持續刺激）配肉體派 ×1.2；認主中的隸從派（有主人）不論種類 ×1.4。
- **畫面上看得到的地方**：
  - 物品說明（行囊、商店、拍賣、打造、紙娃娃的標籤）裡的「限制行走 2」這一段有虛線：滑鼠移上去、用鍵盤聚焦或點一下，顯示平常受影響的檢定與減值、戰鬥中的增益、程度 3 的免疫、自帶的鎖（`bindRulesMods.ts` 的 `bindDetail`；元件 `EffectLine.vue`、`BindTip.vue`）。紙娃娃欄位的滑鼠提示也列出同樣的內容。
  - 紙娃娃下方的「**戰鬥中解放**」：拘束具、淫服、寄生物、懷孕的雙面效應在戰鬥中的增益合計（`combatRelease.ts`），寫成「套上上限後的值（實際加總）」，例如「減傷 +3（+7）」——括號裡是還沒套上全身上限的加總，兩個一樣時不寫括號；另外列出造成的慾望、免疫、懷孕後期有隊友倒下時的加成。沒修流派、慾望戰鬥關閉時寫原因。
- **全身上限**（2026-11）：所有拘束具的增益加總後封頂，上限是存檔規則（慾望戰鬥分組）：命中、迴避、豁免、傷害、減傷每一項最多 +3（`bindCapStat`）、行動點回復 +1（`bindCapAp`）、先攻 +5（`bindCapInit`）。以前沒有上限、每件四捨五入，十幾件疊起來會有減傷 +12、行動點回復 +8～12，只修一個流派入門的遊蕩者 Lv16 輸出約是一般的 3 倍（平衡模擬見 2026-11-11 的報告）。程式在 `schools.ts` 的 `twoFaceCombat`。
- **鎖**：在裝備欄選中拘束具，用行囊裡的鎖「上鎖」；自己鎖的隨時可以「打開鎖」或直接卸下，鎖放回行囊。主人強制戴上的拘束具用主人的鎖（依身分：惡人藍鋼、貴族符文、皇族黃金，其他白鐵），契約解除時主人把鎖帶走。
- **自帶的鎖**（物品的 `gear.lock`，例如囚徒的符文枷、獵奴人的鎖鏈）：戴上就算鎖上，雙面效應用這個等級；不能另外上鎖、也打不開（不會變成行囊裡的鎖），自己可以直接卸下。
- **繩縛之力**（束縛派進階）看的是「身上有上鎖的拘束具」。
- **口枷**戴在頭部，和眼罩、頭套搶同一格；要一起戴，其中一件放進額外飾品欄。
- **哪裡拿**：主要在地下街的**成人用品店**（第 7.1 節），每天上架 8～12 件；原本的店只留基礎款（`shops.json` 的 `restraints`：裁縫店 1～2、鐵匠鋪與珠寶店 0～1，魔法物品店不再賣），不和幾百件衣物一起抽；有些要城市以上或魅氣濃度 3 以上。另外有地下城寶箱（淺層程度 1、中層程度 2、深層以下程度 3 與獨特的）、園區寶箱、拍賣會、淫鬥場的稀有獎品、怪物掉落、主人強制，以及陷阱鎖（第 27 節）。資料由 `worldgen/scripts/elondia/lust_s9.py` 產生（2026-10-29 之前的拘束具是手寫的）。
- **額外飾品欄**（[ITEMS](ITEMS.md) 第 2 節）：任何部位的拘束具都可以戴在這一格，原本的部位留給一般裝備；只想戴一件的人不用犧牲原本的裝備，想戴整套的照舊要佔用一般的欄位。
- **內容編輯器**：底材頁的「拘束」（種類與程度）、物品頁的「拘束程度」（蓋過底材的），以及裝備底材清單最後的「⚙️ 雙面效應設定」——各種拘束的名稱、程度 1～3 的減值、受影響的檢定（屬性與情境，符合任一組就算）、戰鬥增益（先攻、命中、迴避、豁免、傷害、減傷、行動點回復）、免疫的狀態，忍耐每幾點減輕 1、流派契合與隸從派有主人的倍率，四種鎖的名稱與倍率。存在世界的自訂內容，可以恢復預設（[CONTENT_EDITOR](CONTENT_EDITOR.md) 第 3 節）。

## 8. 主角當奴隸：主人是工具人

系統上主人只是讓隸從派生效的條件，主角保有主導權；敘事上主人仍然主導（`masterTool.ts`，數值在 `lewd.json` 的 `master_tool`）。

- **和主人的親密度 60 以上**時，契約面板多兩個選項，不用擲骰、不用付錢：
  - **請主人解除契約**：直接恢復自由（和談判成功一樣）。
  - **換主人**：從這一區認識、親密度 40 以上、不是奴隸也沒有敵意、不是不受雇用的人（`unhireable`）裡選一位，契約與條款轉給他（和事件的 `change_master` 一樣，新主人以隊長身分入隊）。
- 報告註明「這是主角開口提的，但要寫成主人自己的決定」，AI 寫成主人准許、主人安排或把主角轉讓出去。
- 親密度不夠時照現有的規則（談判、逃離、投靠新主人）。
- **順從**：每 25 點，逃離與談判解約的 DC +1（契約面板的條款會寫「順從 +N」）。
- **主人事件的屈服與抵抗**：回應有 `stance` 時（屈服 `submit`、抵抗 `resist`），順從每 20 點，屈服的檢定 +1、抵抗 -1（事件視窗的回應會寫「順從・抵抗 -2」）。內建的主人事件裡，頂嘴、拒絕、掙扎、拖延、偷懶、求救這類回應標成抵抗，安撫、表忠心、硬扛、陪笑這類標成屈服。

## 9. 調教（主角對自己的奴隸）

奴隸的角色詳情（主角的奴隸、在隊伍裡）有「調教」：選一個課程，從 `slavery.json` 的 `owner_events` 抽一件同課程的事件（主人事件格式，[CONTENT_EDITOR](CONTENT_EDITOR.md) 3.98 節），主角從三種做法裡選一個、**自己擲檢定**（`ownerTraining.ts`；數值在 `lewd.json` 的 `training`）。

- **修正**：奴隸的順從每 10 點 +1；和奴隸的親密度低於 0 時 −2。事件視窗會列出來。
- **成功**（沒有檢定的做法一定算成功）：套用課程的指標（下表）；同一課程成功 3 次，保證學會這個課程事件掛的一個還沒學的技能，進度歸零。做法寫了「學會掛的技能」的，成功時另外學會事件掛的一個。
- **失敗**：照事件的效果；親密度低於 −20 時反彈：親密度再 −3，記一段怨恨的冒險記憶，有 30% 的機率趁機逃走（第 19 節）。在自己家裡、擺了調教家具時檢定有加值（第 19 節）。
- 事件的效果、指標、技能都記在奴隸身上；效果的「主人／對方」是奴隸（親密度）。成人向的場景交給成人場景的寫手，指標記在奴隸身上。

## 10. 娼館

`brothelLife.ts`；數值在 `lewd.json` 的 `brothel`，事件在 `slavery.json` 的 `brothel_events`（主人事件格式：`{actor}` 是接客或受訓的人，`{master}` 與效果的「主人／對方」是老鴇）。

- **頭牌等級**：每個人在每座城的娼館各自累積（`state.brothelRank`）：接客一次 +1、遇到打工事件 +2。0、5、15、30、60 次是見習、熟手、紅牌、頭牌、花魁。時薪每級 +15%；受訓每級便宜 10%；打工與受訓的事件可以要求頭牌等級（`rank_min`）。工作面板會寫出目前的等級。

## 12. 魅氣濃度

`charm.ts`；數值在 `lewd.json` 的 `charm`。每個聚落有一個魅氣濃度 1～4（清淨、尋常、放縱、淫靡），地區預設（`regions`：古樹森林 1，中央平原、北境群山、東海群島、西部荒野 2，南境枯萎荒原 4），個別地點覆蓋（`locations`：索里耶爾 1；阿爾貝納、潮汐港、沿海渡口、灰港鎮 3）。地圖面板的地點旁邊顯示「魅氣・淫靡」這類標籤。地下城與園區照所屬地區。

- **曝露名聲**：在聚落裡穿著曝露的服裝每天累積的量乘上 `exposure_mult`（清淨 ×0.5、尋常 ×1、放縱 ×1.5、淫靡 ×2）。
- **傳到相鄰地區**：每天一次，某個地區的曝露名聲讓有路直接相連的其他地區慢慢追上它的 30%（`spread.ratio`，每天 +1；還沒追到目標的地區當天不淡掉）。
- **怪物發情**：近郊與地下城的怪物擲到「發情」特徵的權重乘上 `rut_mult`（清淨 ×0.5～淫靡 ×2；只對資料標了 `rut` 的怪物）。
- **照規矩戴上拘束具進城**：濃度 4 的城門（`gate.min`）多一個選項，玩家自己選了才會：衛兵替主角戴上一件拘束具（`gate.item`，腕鐐）、用白鐵鎖鎖上，**當天出入城門不用盤查**（衛兵警戒時也一樣）。戲內是當地的規矩，戲外是玩家的選擇；鎖算主角自己的，之後可以自己打開，拘束具和鎖都歸主角（修了流派的人可以順便拿雙面效應）。內容篩選關掉「主角非自願」時沒有這個選項。通緝中也可以戴，但通緝時城門照樣不放行（要先繳罰金解除通緝）。
- **給 AI 的風氣**：成人向的判定與敘事多一句這一帶的風氣（`ai`），同樣的服裝在不同城鎮得到不同的反應。
- 濃度決定哪裡有淫鬥場、淫市的貨、拍賣會、訂做淫服；城鎮事件可以用 `charm` 條件（第 27 節），魅氣濃的城鎮有 20 件專屬的成人向事件（[ADULT_EVENTS](ADULT_EVENTS.md) 9.1 節）。

## 16. 鑰匙與脫縛

自己鎖的拘束具隨時可以打開（第 7 節）；這一節是**別人鎖在身上、自己打不開的**——主人強制戴上的（契約還在時）與陷阱鎖住的（第 27 節）。寄生裝備不算（要馴服或解咒）。規則在 `lewd.json` 的 `unbind`，資料由 `worldgen/scripts/elondia/lust_s8.py` 產生，程式在 `restraints.ts`。

- **嘗試脫縛**（主動行動 `unbind`，在裝備欄選中那件拘束具）：靈巧檢定，DC = 10 + 鎖（白鐵 0、藍鋼 +2、符文 +4、黃金 +6）+ 拘束程度 × 1 − 忍耐 / 20。雙手被綁的減值照雙面效應算在檢定上。
  - 成功：鎖被弄壞，拘束具不再是別人鎖上的，可以自己卸下。部分成功：鬆動了一點。
  - 主人看得到（還沒逃走的奴隸，或逃亡奴隸的主人就在附近）時，失敗輕度懲罰、大失敗嚴厲懲罰；大失敗越掙越緊，順從 +1。
- **鑰匙**（物品的 `key`）：白鐵、藍鋼、符文、黃金鑰匙，打開同等級以下的鎖，用一次就沒了，鎖歸自己（放進行囊）。不在商店賣；擊敗人形的敵人（持有裝備的怪物、敵對冒險者）時有 10% 搜到一把，依敵人等級（1 級白鐵、6 級藍鋼、11 級符文、16 級黃金）。
- **戰鬥中的拘束**（狀態的 `struggle`）：束縛、膠膜、吞入。行動「掙脫」（自己）或「撕開」（隊友，被膠膜黏住、被吞進去的人自己動不了），花 1 行動點；1d20 + 熟練 + 力量、靈巧較高的調整值，DC = 10 + 施加者等級 / 2 + 狀態的加減（吞入 +2），自己雙手被綁 +2。成功就拿掉那個狀態。
  - 淫物的噴膠改成**膠膜**（不能行動 2 回合）、食人花的吞入改成**吞入**（不能行動 2 回合、受到的慾望 +25%），隊友都可以撕開。
- 內容編輯器：物品頁的「鑰匙」、狀態頁的「戰鬥中的拘束」。

## 25. 成人向服裝與拘束具的委託打造

規則在 `lewd.json` 的 `outfit_commission`，程式在 `craft.ts`（`craftShopFor`、`commissionHere`、`outfitLewdBonus`）。2026-11 之前是裁縫店的「訂做淫服」（另外收費、要魅氣 3），現在改成一般的委託打造。

- 可以另外選一項慾望指標（淫亂、敏感、忍耐、順從），不另外收費；加成依材料等級：第 1 級 +4、第 2 級 +6、第 3 級 +8、第 4 級以上 +10（`bonus_by_tier`）。打造目標多一個 `!lewd=<指標>`。
- **自己動手打造**成人向服裝與拘束具也可以加一項慾望指標：加成 =（委託的加成 + `self_extra_by_tier`）× 做的人自己那一項的基本值 ÷ 100（四捨五入；`craft.ts` 的 `selfLewdBonus`）。`self_extra_by_tier` 是材料第 1、2 級 +1、第 3 級以上 +2，所以指標 100 的人自己做是 +5、+7、+10、+12，比委託（+4、+6、+8、+10）多一點。例：皮革（第 1 級）、順從 50 的人自己做 → (4 + 1) × 0.5 → 順從 +3。打造面板選了成人向服裝或拘束具時多一個「慾望指標」下拉選單。
- **畫面**：成人用品店的「淫服・拘束具訂製」（`components/adult/OutfitAtelier.vue`）：上方切換淫服／拘束具 → 部位（分類按鈕）→ 款式（淫服寫曝露愛心，拘束具寫拘束種類與程度；加上數值）→ 材料（文字卡，店主手藝不夠的上鎖）→ 慾望指標 → 訂單（數值、檢定、材料、稀有度、工錢）。邊框是紅線藤蔓、針與左下角的淫紋，邊緣有粉色呼吸光（`components/adult/AdultDeco.vue`、`deco.ts`；系統要求減少動態效果時不動）。一般的「委託打造」不在成人用品店出現。

## 26. 拍賣會

規則在 `lewd.json` 的 `auction`，程式在 `auction.ts`；地標「月下拍賣會」在阿爾貝納的地下街「聯邦市集的地下」（地標的 `auction`，內容編輯器的地標頁可以勾；在酒館打聽到地下街才進得去，見 [SPECIAL_MAPS](SPECIAL_MAPS.md) 第 9 節）。

- **拍品**：每天 3 件，從 `pool` 依權重抽（四件只在拍賣會出現的淫具、色情技能書、打工線的技能書、黃金鑰匙、黃金鎖、魅魔的香精，以及獨特拘束具「夢魔的眼紗」「聖女的貞潔鎖」與淫服「緋夢夫人的晚禮服」）；同一天、同一個地方固定（依存檔的種子，不動遊戲的亂數）。

- **寄賣**：成人向的物品與色情技能書（獨特裝備和商店一樣不收），照當天的行情（物品價格的 0.8～1.6 倍）賣掉，扣 10% 手續費。
- **被盯上**：得標後有 50% 被盯上（劇情旗標 `auction_watched`）：之後走到城門、旅店、酒館、商店時可能遇到城鎮事件「拍賣會上被盯上」（嚇走、甩掉、破財消災；處理完旗標就拿掉）。

## 27. 陷阱鎖與事件條件

**陷阱鎖**：事件、任務的效果 `restrain`（`{ "type": "restrain", "item": "單手套", "lock": "blue" }`，鎖沒寫是白鐵）把一件拘束具戴到主角身上、鎖住。程式在 `forcedGear.ts` 的 `restrainPc`，鎖的記號是 `EquippedGear.locked = trap:<物品>`。

- 戴在原本的部位（空的優先），都被鎖住時放額外飾品欄；原本的裝備收進行囊。不是拘束具、沒有地方戴、內容篩選關掉「主角非自願」時不生效。
- **不用契約也拿不下來**，離開地下城也還鎖著；解除契約不影響。雙面效應照算（鎖是事件寫的等級），每天也照「被鎖上的拘束具」成長順從（`daily.locked`）。
- 解開：嘗試脫縛、用鑰匙（第 16 節；身邊沒有主人，失敗沒有懲罰，大失敗照樣順從 +1），或在**鐵匠鋪剪鎖**（裝備欄的「請鐵匠剪鎖」，`unbind.cut`：白鐵 50、藍鋼 200、符文 800、黃金 3000 白鸛；鎖被剪壞不歸自己）。主人的鎖不能剪。解開之後拘束具歸主角。
- 裝備欄標「陷阱的〇〇鎖」，卸下的提示寫要怎麼解開。

**事件條件**（`StoryCond`；城鎮、地下城、旅途事件、特殊任務、固定 NPC 都能用，內容編輯器條件欄位的「成人向的條件」）：

- `stats`：主角的慾望指標範圍（已經有，現在編輯器也能設）。
- `charm`：所在地的魅氣濃度範圍（1～4，第 12 節），例如 `{ "min": 3 }`。
- `pc_tags`：主角至少有其中一個身分標籤（[NPC_SYSTEM](NPC_SYSTEM.md) 4.1 節）。
- `wearing`：主角身上戴著什麼——`bind`（任何拘束具）、`locked`（別人鎖上的：主人鎖上的、陷阱鎖住的；寄生裝備不算）、`adult_outfit`（成人向服裝）、`mark`（奴隸印記）寫 `true` 要有、`false` 要沒有；`bind_kind` 要戴著這一種拘束具。
