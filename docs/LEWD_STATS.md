# 慾望指標（成人向）

> 上層：[GAME_DESIGN](GAME_DESIGN.md)。依賴：[COMBAT_SYSTEM](COMBAT_SYSTEM.md) 第 8.5 節（慾望戰鬥）、[ITEMS](ITEMS.md)（服裝的底材）、[COMPANIONS](COMPANIONS.md)（奴隸契約）、[WORK](WORK.md)（娼館）。被依賴：[EFFECTS](EFFECTS.md)（`lewd` 效果）、[STORY_QUESTS](STORY_QUESTS.md)（`stats` 條件）、[ACTIONS](ACTIONS.md)（情境修正、AI 判定的效果）、[TRAVEL_EVENTS](TRAVEL_EVENTS.md) 第 6 節（城鎮事件）、[PROMPTS](PROMPTS.md)（給 AI 的資料）。
> 資料：`data/rules/lewd.json`（分段、預設、成長量、服裝的預設）；底材的曝露度在 `gear.json` 的 `bases`（`exposure`）。程式：`src/engine/lewd.ts`。計畫：[慾望戰鬥實作計畫](plan/LUST_COMBAT_PLAN.md) 第 5、6 節。

每個角色有四項長期指標，加上依地區記的曝露名聲，合計五項。它們隨經歷慢慢改變，影響慾望戰鬥與 AI 的描寫。角色詳情的「屬性與戰鬥」頁最下面顯示目前的值、分段與裝備的加減。

| 指標 | id | 存在哪裡 | 是什麼 |
|---|---|---|---|
| 淫亂 | `lewdness` | `Character.lewd` | 對性的渴求與開放 |
| 敏感 | `sensitivity` | `Character.lewd` | 身體對刺激的反應 |
| 忍耐 | `endurance` | `Character.lewd` | 承受刺激與拘束的能力 |
| 順從 | `submission` | `Character.lewd` | 服從的習慣；不是契約的 `obedience`（那是主人加的暫時檢定懲罰） |
| 曝露名聲 | `exposure` | `state.exposure[角色 id][地區]` | 在這個地區被多少人看過、傳得多開（只有主角與夥伴） |

- 範圍 0～100。主角與舊存檔沒有記錄時用 `defaults`（淫亂 10、敏感 50、忍耐 10、順從 10）。
- **有效值** = 基本值 + 身上裝備的加減（第 3 節）。戰鬥、條件、AI 都看有效值；成長改的是基本值。

## 1. 分段

每 20 一段：

| 數值 | 淫亂 | 敏感 | 忍耐 | 順從 | 順從（有奴隸契約時） | 曝露名聲 |
|---|---|---|---|---|---|---|
| 0～19 | 純情 | 遲鈍 | 初萌 | 生疏 | 恨與反抗 | 沒人知道 |
| 20～39 | 好奇 | 略鈍 | 漸成 | 配合 | 懲罰與絕望 | 有些傳聞 |
| 40～59 | 開放 | 正常 | 精熟 | 習慣 | 麻木與認命 | 小有名氣 |
| 60～79 | 淫蕩 | 敏感 | 入微 | 忠誠 | 依賴與習慣 | 遠近馳名 |
| 80～100 | 淫亂 | 極敏 | 隨心 | 奉獻 | 真心臣服 | 人盡皆知 |

## 2. 戰鬥（慾望戰鬥開著時）

開戰時換算成戰鬥單位的 `lustMods`（`combat.ts` 的 `initLust`；數值在 `lewd.json` 的 `combat`）：

| 指標 | 效果 |
|---|---|
| 忍耐 | 慾望上限 + 忍耐 / 2 |
| 敏感 | 受到的慾望 × (0.75 + 敏感 / 200)：敏感 0 是 ×0.75、50 是 ×1、100 是 ×1.25 |
| 淫亂 | 每 20 點，開戰帶上限 5% 的慾望；每回合的消退 × (1 − 淫亂 / 200)；60 以上自己增加的慾望 ×1.25 |
| 順從 | 有「傷害轉成慾望」的狀態時，轉換的比例每 20 點 +5% |
| 曝露名聲 | 在這個地區每 20 點，造成的魅惑傷害 +1 |
| 信仰 | （屬性）每 1 點調整值，魅惑的受傷倍率 −0.05（調整值是負的反而 +） |

開戰帶的慾望（淫亂、發情）最多到上限減 1，不會一開打就高潮。種族特質：精靈的魅惑 ×0.9、貓魅族 ×1.15（`perks.json` 的種族特質）。

## 3. 服裝與裝備

- **加減**：物品的 `gear.lewd`（例如 `{ "lewdness": 5 }`），加上底材的預設：**成人向服裝**每件淫亂 +5、**束縛用的底材**每件順從 +5、忍耐 +3（`lewd.json` 的 `gear`）。每件每項 ±10，全身每項合計 ±20。物品說明會寫出來（例如「兔女郎裝・淫亂 +5・曝露度 2」）。
- **曝露度 0～3**：底材的 `exposure`；沒寫時成人向服裝是 2，其他是 0。只算上身、下身與看得到的內衣（`exposureLevel`）：
  - 上身穿著就看上身那件；沒穿上身時看內衣，只穿內衣至少算 2；什麼都沒穿是 3。
  - 下身看下身那件；沒有時上身那件也算遮住；再沒有才看內褲；什麼都沒穿是 3。
  - 頭飾、鞋子、腿飾、飾品不算。
  - 寫了曝露度的底材：短裙、旗袍、魔法少女裝、水手服、皮衣 1；比基尼鎧甲 2；逆兔女郎裝、透視薄紗睡衣、乳貼、開檔內褲 3。
- 內容編輯器的底材有曝露度、物品有慾望指標的加減（整理時保留）；表單還沒有這兩個欄位。

## 4. 怎麼漲、怎麼降

**事件**（`lewd.json` 的 `growth`；記在報告的 `changes.lewd`，日誌會寫出來）

| 來源 | 變化 |
|---|---|
| 親密場景（報告帶 `adult_scene`） | 場景的主角淫亂 +1，記下日子；派奴隸去娼館時記在奴隸身上（`narration.adult_actor`） |
| 戰鬥中高潮 | 每次淫亂 +1、敏感 +1；高潮過還撐到打贏，忍耐 +1 |
| 寬衣（能力的 `exposure`） | 戰後在這一帶的曝露名聲 +1 |
| 娼館打工（接客的人） | 淫亂 +2、曝露名聲 +2 |
| 主人加重服從懲罰（`obedience` +1） | 順從 +1 |
| 主人事件選了一定進入親密場景的回應（屈服） | 順從 +1 |
| 事件、任務的 `lewd` 效果、AI 判定 | 照效果 |

**每天**（`lewd.json` 的 `daily`；跨日時結算，只看隊伍裡的人，不寫進報告）

- 曝露名聲：每個地區每天淡掉 1；人在聚落裡（城市、城鎮、村落、港口、哨站、要塞）時，加上身上的曝露度 × 2。
- 穿著成人向服裝：淫亂 +1。穿著束縛用的底材：忍耐 +1。身上有被主人鎖上的裝備：順從 +1。
- 沒有奴隸契約的日子：每 3 天順從 −1。
- 超過 7 天沒有親密場景：淫亂每天 −1，降到預設為止。
- 走格子、旅途、開寶箱這類不產生報告的時間推進也會結算（`state.ts` 的 `advanceTime`）；一次最多結算 30 天。

## 5. 其他的連動

- **效果** `lewd`：`{ "type": "lewd", "stat": "submission", "delta": 5, "target": "pc" }`，曝露名聲記在目前的地區（[EFFECTS](EFFECTS.md)）。
- **條件** `stats`：`{ "stats": { "exposure": { "min": 40 } } }`，看主角的有效值，曝露名聲看目前的地區（`storyFlags.ts` 的 `condMet`）。
- **AI 判定**：可能進入親密場景的行動（自由行動、主人的要求、打工、光顧娼婦、特殊任務、戰敗事件、獻媚）多一種效果 `lewd`，每人每項一次、±3（`actions.json` 的 `caps.lewd`）。
- **主動行動的情境修正**：淫亂淫蕩以上獻媚 +1（淫亂 +2）；曝露名聲在這一帶遠近馳名以上時，對貴族、皇族、神官、主教唬騙 −1（人盡皆知 −2）。
- **城鎮事件**：成人向的城鎮事件，權重與機率 × (1 + 主角在這個地區的曝露名聲 / 100)；其他事件的機率不變（[TRAVEL_EVENTS](TRAVEL_EVENTS.md) 第 6 節）。
- **NPC**：依 id 固定地擲（不影響其他生成），標籤決定範圍（娼婦淫亂 50～80、奴隸順從 40～80、貴族與神官淫亂 0～20……，`lewd.json` 的 `npc_tags`）；固定 NPC 可以在內容編輯器指定（`NpcDef.lewd`，空著的照擲）。
- **給 AI**：只在成人向的日誌與判定送出。敘事：主角設定後面附上主角與隊友的分段（「淫亂：開放；敏感：敏感；…；曝露名聲：在這一帶小有名氣」）；判定：主角資料附上數值與分段，隊友各一行。
