# 手機版畫面

> 上層：[文件地圖](README.md)。程式：`src/components/mobile/`（`mobile.ts` 判斷寬度與返回鍵、`MobileGame.vue` 冒險頁、`BottomSheet.vue` 半屏面板、`SwipeTabs.vue` 滑動分頁）、`App.vue`、`AppDialog.vue`、`CombatView.vue`、`ContentView.vue`。
> 樣稿：`docs/mockups/mobile.html`（探索）、`docs/mockups/mobile-combat.html`（戰鬥）。還沒做的部分見 [ROADMAP](plan/ROADMAP.md) R10。

螢幕寬度 **720px 以下**（手機直拿）時換成這套版面；電腦與平板照舊。面板元件和電腦版共用，只換外框與排列。不支援手機橫拿。

## 1. 冒險頁

```
┌────────────────────┐
│ 狀態列：時間 地點 金錢 🔔 │  只看不按（待處理的鈴鐺除外）
├────────────────────┤
│ 地圖（可收成一條）        │
├────────────────────┤
│ 冒險日誌                │  最下面是等待判定的行動
│ 🎲 主動行動：想做什麼…     │  點了展開
├────────────────────┤
│ [ 進入○○ ] 情境按鈕       │  站在設施上、或旅途中才出現
├────────────────────┤
│ 地圖│隊伍│休息│這裡│更多   │  底部分頁列
└────────────────────┘
```

要按的放下面（拇指好按），上面只放資訊。`App.vue` 在手機的冒險頁不畫電腦版的上方列與三欄，換成 `MobileGame`；對話框照舊由 `App.vue` 管。

### 1.1 地圖與日誌：探索、閱讀兩種狀態

| 狀態 | 地圖 | 日誌 | 什麼時候 |
|---|---|---|---|
| 探索 | 大，好點 | 剩下的空間 | 點地圖那一條，或底部「地圖」 |
| 閱讀 | 縮成一條（地名、所在設施、展開鈕） | 整頁 | AI 寫了一段經過時自動切過來 |

- 文字框拿到焦點（鍵盤打開）時地圖收起，情境按鈕與底部分頁列也藏起來；鍵盤收起時，中間有新的經過就維持閱讀狀態，沒有就放回原本的狀態。
- 只能點相鄰的格子，一次走一步；點到其他格子不會動，相鄰的格子閃一下提示能走哪裡。不做「點遠處自動走」，也不放大地圖（最寬 13 格時每格約 28px）。
- 換地圖＝走到出口格（出城、進地下城、下一層）。
- 旅途中，地圖面板本來就把路畫成一天一格，當作進度條；情境按鈕是「往前走」（`RoadPanel` 在手機上不畫自己的按鈕）。

### 1.2 情境按鈕

站在 `floor`、`wall`、`water`、`road` 以外的格子（或特殊任務點、房子裡）時，底部列上方出現「進入／查看○○」，點了從下面滑出地點面板（`PlacePanel`）。設施的「購買」「出售」打開交易頁。

### 1.3 主動行動

和電腦版一樣在日誌底部（[ACTIONS](ACTIONS.md)），平常收成一行「🎲 主動行動：想做什麼…」，點了才展開。擲完骰的行動顯示在日誌最下面。「這裡的人」的「主動行動」把那個人加進對象並展開這一行。

### 1.4 底部分頁列

| 按鈕 | 內容 | 提醒 |
|---|---|---|
| 地圖 | 切換探索、閱讀 | — |
| 隊伍 | 全螢幕頁面：隊伍｜行囊 | 有人可以升級 |
| 休息 | 半屏：短休、長休、生命骰 | — |
| 這裡 | 半屏：這裡的人、行動備註，以及進行中的事（談判中的長期折扣、特殊任務的進度、進行中的委託、這裡可以接的特殊任務） | 身邊的人數 |
| 更多 | 半屏：關係、筆記、工藝、契約（有契約時）、存讀檔、快存、快讀、設定、語言、提示詞、世界、首頁 | 底下項目的提醒加總 |

進行中的事在電腦版是右欄的地點面板下半部；手機上放進「這裡」，走在街上也看得到（`PlacePanel` 的 `part`：`place`／`ongoing`）。談判的對話框掛在 `MobileGame`，從哪裡開始都打得開。

## 2. 半屏面板與全螢幕頁面

| 種類 | 用在 | 關閉 |
|---|---|---|
| 半屏面板（`BottomSheet`） | 這裡、休息、地點、更多 | 往下拉、點外面、右上 × |
| 全螢幕頁面（`AppDialog` 在手機上） | 隊伍、角色詳情、交易、事件、關係、筆記、工藝、契約、存讀檔、設定、世界編輯器的表單 | 左上角「←返回」 |

- 頁面裡再開頁面（隊伍 → 角色詳情），返回回到上一頁；從半屏面板打開的頁面，返回後面板還在，捲動位置也留著。
- 必須回應的事件頁沒有返回鈕，選了選項才關；按返回鍵只提示「先選一個選項」。
- **返回鍵**（Android 返回鍵、iPhone 邊緣右滑、瀏覽器上一頁）和「←返回」一樣，先關最上層的頁面，再關半屏面板（`mobile.ts` 的層級堆疊：每打開一層 `history.pushState` 一筆，`popstate` 時關掉最上層；用畫面上的按鈕關掉時把那一筆退回去）。冒險頁最底下另外墊一筆：沒有面板時按返回先提示「再按一次返回鍵離開遊戲」，兩秒內再按才離開（`guardExit`）。

## 3. 滑動分頁（`SwipeTabs`）

隊伍（隊伍｜行囊）、角色詳情、交易（店裡的商品｜你的行囊）可以左右滑換分頁：

- 分頁並排在一條軌道上，內容和分頁底線跟著手指移動；放開時拉過四分之一寬、或甩得夠快就換頁，不然彈回。只畫目前與相鄰的分頁（看過的保留）。
- 移動 8px 後判斷方向：橫的才接手，直的交給上下捲動；從輸入框、選單、分頁列開始的不算。第一頁、最後一頁拉得動但有阻力，放開彈回。
- 軌道的位移用每一頁自己的寬度算（`translateX(-i × (100% + 間距))`），分頁之間留 32px 間距。
- 分頁列一打開就捲到目前的分頁（升級時直接開在角色詳情的「能力」）。
- 電腦版：交易視窗依序畫出所有分頁（左右兩欄），其他只畫目前的分頁，外觀和原本一樣。

手機上行囊與商店的物品列改成名稱一排、按鈕一排；行囊與交易的欄位用 `minmax(0, 1fr)`，窄螢幕（375px）不會被搜尋列撐開。

## 4. 戰鬥畫面

- 戰鬥中不顯示狀態列與底部分頁列；上方一條「戰鬥・場景｜第 N 回合｜⋯」，「⋯」放戰鬥紀錄、隊伍、設定。
- **我方在上、敵人在下**（敵人貼近行動區，選目標時拇指好點），各自兩欄小卡：名字、等級、生命條、慾望條、我方的行動點、最多兩個狀態（其餘「+N」）。名字放不下時來回捲動（`v-marquee`），A、B 看得到；減少動態效果時照舊截斷。
- 戰鬥紀錄只露最新兩行，夾在敵我之間；點了從下面滑出完整紀錄。
- 行動區在最下面：目前行動的人與行動點、「結束回合」；武器攻擊、防禦、撤退一排；技能依類型分頁（技能、法術、戲法、色情、道具，只列有東西的分頁）。
- 選目標：能選的卡片發亮並捲進畫面，行動區換成目標按鈕（可以橫向捲動），「取消」固定在右邊。
- **長按**（0.45 秒，手指移動超過 10px 取消）技能或卡片打開詳情：武器屬性、法術環、仇恨、抗性、特性、專注、幸運門檻這些在手機上不畫在卡片上，搬到詳情裡。點到不能用的技能時說出原因（不設 `disabled`）。

## 5. 其他頁面

- **世界編輯器**：平常只有清單；點了項目，編輯表單變成全螢幕頁面，返回鍵與「返回清單」回到清單，捲動位置留著（[CONTENT_EDITOR](CONTENT_EDITOR.md)）。
- **提示詞、世界頁**：背景圖上蓋一層暗色（`.m-dim`），說明文字不會壓在亮的地方。
- **開新遊戲**：上方列的標題縮小、右邊的按鈕只留圖示，擠成一排。
- **設定**：功能分配表每列改成「名稱＋來源」一排、說明換到下一排。
- 工藝的技能表可以橫向捲動；其他全螢幕頁面本來就是單欄。
