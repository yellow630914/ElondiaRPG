# 特質（被動）

> 上層：[GAME_DESIGN](GAME_DESIGN.md)。依賴：[COMBAT_SYSTEM](COMBAT_SYSTEM.md)（戰鬥修正和裝備一起算）、[ACTIONS](ACTIONS.md)（受訓、爭取特質是主動行動）、[EFFECTS](EFFECTS.md)（`perk`、`lose_perk`）。被依賴：幾乎所有檢定（第 1 節的表）、[STORY_QUESTS](STORY_QUESTS.md)、[ITEMS](ITEMS.md)（書籍）、[CONTENT_EDITOR](CONTENT_EDITOR.md)（特質頁籤、固定 NPC 的特質、書籍）、[CONTENT_DEPENDENCIES](CONTENT_DEPENDENCIES.md)（刪除保護）。
> 資料：`data/rules/perks.json`；程式：`src/engine/perks.ts`（查詢、檢定修正、戰鬥修正、強度、取得與失去、NPC）、`src/engine/perkActions.ts`（受訓、爭取特質、從機會選一個）。
> 畫面：建立角色的「🌟 特質」（`PerkPicker`、`PerkBuilder`）、事件視窗的「🌟 有機會學會特質」（`events/PerkOfferPanel`）、設施上的「🎓 受訓」（`TrainPanel`）、隊伍視窗的「🌟 特質」。

特質是角色身上**一直生效**的能力：讓某些檢定更容易、在戰鬥中更強或更耐打。主角、隊友、NPC 都有。種族天賦也是特質（**種族特質**，第 3.1 節），依種族自動擁有。**缺陷**是只有壞處的特質（第 3.2 節）。

## 1. 被動效果怎麼生效

所有檢定都透過同一個函式 `checkModifiers(角色, 情境)`（`perks.ts`）取得情境修正：**非戰鬥狀態**（受罰、微醺、放鬆……）、**特質**、主角的**身分標籤**（`pcTags.ts`）、身上**獨特物品**的檢定加值（可以疊加，見 [ITEMS](ITEMS.md) 3.1 節）、**寄生物**與已馴服的**印記**、拘束具與淫服的**雙面效應**（`schools.ts` 的 `bindModifiers`、`outfitModifiers`，見 [LEWD_STATS](LEWD_STATS.md)）。主動行動另外加上慾望指標的修正（`actions.ts` 的 `lewdModifiers`）。每一條都會列在判定資料或日誌裡（例如「特質【識途老馬】+2」「缺陷【路痴】-2」）。

| 情境（context） | 檢定 | 程式 |
|---|---|---|
| action | 主動行動（包括受訓、爭取特質），可以再用 kinds 限定種類；地下城事件、寄生物事件、城鎮事件的檢定、娼館的獻媚也算這一種 | `actions.ts` 的 `prepareAction`、`dungeonEvents.ts`、`parasiteEvents.ts`、`road.ts`、`brothelLife.ts` |
| negotiation | 談判（委託報酬、交易條件）的選項 | `negotiation.ts` |
| master_event | 回應主人的要求（三選一） | `slavery.ts` |
| gate | 城門盤查、說服王城的衛兵 | `security.ts`、`companions.ts`（`palace_gate`） |
| trap | 察覺陷阱（隊伍裡靈巧最高的人） | `grid.ts` |
| lock | 開鎖（負責開鎖的人） | `grid.ts` |
| travel | 旅行途中的危險：旅途事件的檢定除了 `road` 也算這個情境（同一個條件兩個都寫只算一次，`road.ts` 的 `roll`） | 旅途事件 |
| road | 旅途上的事件（隊伍裡最擅長的人；城鎮事件改用 action） | `road.ts` |
| quest | 執行一般委託 | `town.ts` |
| retreat | 撤出地下城（帶路的人） | `expedition.ts` |
| stealth | 潛行：避開敵意的冒險者、偷偷離開別人的隊伍 | `encounters.ts`、`rest.ts` |
| initiative | 戰鬥先攻 | `combat.ts` |
| save | 戰鬥中的豁免（依屬性）、專注 | `combat.ts` |

- 誰擲骰就用誰的特質：派奴隸去工作時用奴隸的，帶路撤退時用帶路的人的。
- 加值可以限定**檢定分類**（skills：說服、欺瞞、威嚇、交易、魅惑、潛行、巧手、察覺、求生、工藝、勞動、侍奉、脫逃），每種行動、情境屬於哪一類見 [ACTIONS](ACTIONS.md) 2.1 節；自由行動的分類由 AI 判定時選。
- 加值可以限定**對象的標籤**（vs_tags），例如「對貴族、皇族的檢定 +1」：主動行動看行動的對象（多個對象時看主要對象），談判看談判的對方，主人事件看主人。
- **戰鬥**：特質的 `combat`（命中、迴避、豁免、傷害、減傷、行動點回復、幸運一擊、仇恨）、`resist`（受到的傷害倍率）、`offense`（造成的傷害倍率）和防具、裝備一起算（`gearAffinities`；種族特質也從這裡算，不再另外讀 `attributes.json`）。
- **不受影響的**：戰敗事件的「敵人起意」（那是對主角不利的擲骰，也刻意不加熟練加值）、只看機率不擲骰的（等待組隊、出售自己、逃亡被找到）。
- 非戰鬥狀態影響上面所有用 `checkModifiers` 的檢定（例如受罰的 −2）。
- AI 判定時，主角資料會列出特質，並註明「已算進情境修正，不要重複加值」；寫正文的主角設定、NPC 的身分說明也會列出特質，缺陷標明「缺陷」。

## 2. 資料格式

```jsonc
{ "id": "silver_tongue", "name": "能言善道", "desc": "魅力檢定 +1；殺價、交涉價格與談判再 +1。",
  "effects": [
    { "check": { "skills": ["persuade"] }, "bonus": 2 },     // 檢定分類（ACTIONS 2.1 節）
    { "check": { "attrs": ["cha"] }, "bonus": 1 },
    { "check": { "kinds": ["haggle", "bargain"] }, "bonus": 1 },
    { "check": { "contexts": ["negotiation"] }, "bonus": 1 },
    { "combat": { "hit": 1 } }, { "resist": { "fire": -0.25 } }
  ],
  "requires": { "races": [], "classes": [], "perks": [] },   // 只有這些種族或職業可以學；perks：要先有這些特質（不寫＝都可以）
  "exclusive": [],                               // 互斥的特質
  "train": { "cells": ["tavern"], "price_cc": 300, "hours": 8, "attr": "cha", "dc": 12 },   // 可以在哪裡受訓
  "npc": { "weight": 2, "tags": ["merchant"], "classes": ["bard"] },                         // NPC 抽到的權重
  "flaw": false,                                 // 缺陷：效果是負的（見 3.2 節）
  "race": "elf",                                 // 種族特質：這個種族自動擁有（見 3.1 節）
  "rarity": "rare",                              // 選填：只決定圖示的顏色；不寫時依強度（見 ITEMS 8.1 節）
  "category": "social",                          // 選填：分類，建角時依分類折疊（見 4.1 節）；不寫時依效果推斷
  "camp": true                                   // 選填：能在野外紮營長休（不是數值效果，effects 可以是空的）
}
```

**紮營**（`camp`）：隊伍裡有一個人的特質有 `camp`，就能在近郊的野外、旅途的道路、旅途中的臨時地圖長休（`rest.ts` 的 `campRest`；城裡有旅店、地下城有安全房，所以不開放）。每人 1 份乾糧、長休 8 小時（存檔規則可改），照那裡的機率可能被襲擊（野外與道路 15%、臨時地圖 20%，帶帳篷減半）：被襲擊就開始戰鬥、這次沒睡成，乾糧不扣；襲擊的怪和短休一樣，洞窟、遺跡這類帶地下城層的臨時地圖用那一層的遭遇，其他用地區的野外遭遇。兩次長休的間隔照舊。強度算 3（`perks.ts` 的 `CAMP_POWER`）。內容編輯器的特質頁籤可以勾「能在野外紮營長休」。
慾望流派的特質（成人向，分類「慾望流派」）另外有 `school`（流派）與 `lust`（慾望效果：慾望上限、受到的慾望、轉換、引爆……），共 16 個（8 個流派各一個入門、一個進階），不進升級的三選一；規則與清單見 [LEWD_STATS](LEWD_STATS.md) 第 6 節。強度把 `lust` 也算進去（有條件的戰鬥修正算一半）。

`check` 的欄位：同一欄位是「或」，不同欄位是「且」；全部不寫＝所有檢定。

**強度**（`perkPower`，比較用）：檢定加值 × 範圍（所有檢定 4、一個屬性 1.5、一個檢定分類 1～2（照它涵蓋的行動與情境加總，夾在 1～2）、一種情境 0.75、一種行動或標籤 0.5，不同欄位取最窄的）；戰鬥修正比照附魔點數再 ×2（仇恨不算）；每 25% 抗性或增傷算 1。壞處算負的（負的加值、弱點），所以缺陷的強度是負數。

### 3.1 種族特質

- **依種族計算，不寫進存檔**（`perksOf` 依角色的 `race` 加上去），主角、隊友、NPC 都一樣；舊存檔不用轉換。
- 不能在建立角色或升級時選、不能受訓、不能從書裡學、不會被 `lose_perk` 拿掉，也不能用 `perk` 效果另外給；NPC 的特質清單、書籍、效果的選項都不列種族特質（`choosablePerks`）。
- 建角畫面和隊伍視窗把它列在特質裡，標「種族」。
- 可以在內容編輯器修改名稱、描述與效果（第 4.4 節）。

### 3.2 缺陷

缺陷（`flaw: true`）是只有壞處的特質：負的檢定加值、負的戰鬥修正、受到的傷害變多（弱點）。強度是負的，大約抵銷一個一般特質（一般特質的強度中位數 2.5，缺陷 −2.5～−3.5，測試檢查每個缺陷都落在一般特質的強度範圍內）。

| 蛇相（`flaw_serpent`） | 化龍族裡偶爾會生出帶著蛇相的人：鱗片細密、舌尖分岔、身子冰涼，常被當成蛇妖轉世。寒冰傷害 ×1.25；說服檢定 -1。 | － |

- **種族限定的缺陷**：寫了 `requires.races` 的缺陷只有那些種族會有（建角時才列出、NPC 才會抽到）；目前只有化龍族的「蛇相」。測試檢查的缺陷數（10～12）不算種族限定的。
- **怎麼得到**：建立角色時自己選（第 4.1 節）、事件與特殊任務的 `perk` 效果（缺陷**直接染上**，不是機會，不能選也不能爭取）、NPC 生成時抽到（第 5 節）。
- **不會出現在**：升級、受訓、書籍、效果給的「學特質的機會」裡（`learnablePerks`、`offerPerks` 都拿掉缺陷）；AI 爭取特質時設計的也不能是缺陷（`sanitizePerk` 拿掉 `flaw` 和負的加值、弱點；正負號不對的數值一律拿掉，不會翻成另一邊）。
- **怎麼克服**：`lose_perk` 效果（日誌寫「克服了缺陷」）；有 `train` 的缺陷可以在那個設施「🎓 受訓」克服（第 4.2 節）。
- **自由行動不會給缺陷**：自由行動、一般判定的大失敗只有當下的後果（受傷、狀態、金錢、好感、聲望……），AI 不能在判定裡給角色永久的缺陷。缺陷一直生效，只由規則（建角、事件、特殊任務、NPC）決定，免得一次擲骰留下永久懲罰，也不會讓 AI 判定的結果難以預期。

## 4. 取得

### 4.1 建立角色
「🌟 特質」最上面是這個種族的種族特質（固定勾選、不能取消）。特質與缺陷依**分類**折疊（社交與交易、探索與潛行、戰鬥、體質、學識與技藝、主從與束縛、慾望流派、其他；`perks.json` 的 `category`，沒寫時依效果推斷，`perks.ts` 的 `perkCategory`；內容編輯器可以改），展開後是表格：圖示、名稱、效果、強度；折疊列上顯示這一類已選的特質。其他不限數量任選（依種族、職業的條件），也可以**自訂**：名稱、描述（沒寫時依效果自動產生）、最多 4 個效果——檢定加值 +1～+3（所有檢定、某個屬性、某種情境、某種主動行動、對某種人）、戰鬥修正 +1～+2、抗性（×0.75 或 ×0.5）。

**缺陷**（「⚠️ 缺陷」）：最多選 2 個（`perks.json` 的 `creation.max_flaws`），自訂的也算；每選一個多 1 個一般特質的名額（`slots_per_flaw`）。一般特質的名額是 `creation.slots`，**預設 0＝不限**（照原本「建角不限數量」的決定），所以預設下缺陷只是角色設定；改成有名額時，換名額的規則就會生效（超過時開新遊戲從後面拿掉）。自訂特質可以勾「缺陷」：效果只能是壞處（檢定 −1～−3、戰鬥修正 −1～−2、傷害 ×1.25 或 ×1.5，`custom.flaw`）。

### 4.2 之後：取得的機會
升級、事件、特殊任務、受訓、物品不直接塞給你特質，而是給一次**機會**（`Character.perkOffers`），在事件視窗「🌟 有機會學會特質」處理：

- **從提供的特質選一個**學會（記一則日誌）。
- **寫一段說法爭取別的**（主動行動 `perk_pitch`，魅力 DC 12，只在開啟 AI 判定時）：AI 依說法和角色的經歷、這次機會的來源判斷合不合理，在 `perk` 欄位設計特質。程式依成功程度夾住強度：大成功最多到「提供的特質最強的 +1」、成功一樣、部分成功 −1；失敗與大失敗不採用，只能從提供的特質選。**每次機會只能試一次**。AI 只在這些場合能設計特質，自由行動等其他判定都不能給特質。
- **放棄**這次機會。

| 來源 | 機會 |
|---|---|
| 升級 | 升到 3、6、9、12、15、18 級時，三選一（`levelup`） |
| 事件、特殊任務 | 效果 `{ "type": "perk", "perk": "<id>", "options": ["<id>"] }`；特殊任務編輯器的「＋ 效果…」選「特質（取得的機會）」，可以多加幾個選項，或勾「直接學會」（`direct`，不給選擇也不能爭取） |
| 受訓 | 站在公會、神殿、酒館、雜貨店、鐵匠鋪、裁縫店、珠寶店、魔法物品店、情報商、娼館（慾望流派）或幾個地標（騎士學院、沙堡……，`train.cells` 寫地標 id）上，「🎓 受訓」列出這裡能學的特質（`trainablePerks`；地標沒開門時不能受訓）。主動行動 `train`：花時間、過檢定。**學費、時數、DC 照特質的強度算**（`perks.json` 的 `training`，`perks.ts` 的 `trainSpec`）：學費 = 強度 × 400 白鸛（取到十位），時數 = 強度 × 8 小時（每天練 8 小時，分幾天練完；中間照常吃睡，日誌寫「分 N 天」），DC = 12 + ⌊強度⌋；克服缺陷用缺陷強度的絕對值，學費與時數打對折、沒有門檻。強的特質有**門檻**：強度 3 以上要角色 Lv.3；強度 4 以上要 Lv.5，而且店主（或老師）的親密度 20 以上（公會、地標這類沒有店主的設施只看等級）；不夠時照樣列出、寫出原因。特質的 `train` 寫了 `price_cc`、`hours`、`dc` 時用寫的（內容編輯器的特質頁可以填，空白照公式）。大成功學費打對折、成功與部分成功照收，然後得到學這個特質的機會；失敗收一半、大失敗照收，沒學會。哪些特質在哪種店或哪個地標受訓也可以在內容編輯器的「🏪 商店」「🏛️ 地標」勾選（改的是同一份 `train.cells`）。身上的缺陷有 `train` 時排在最前面（標「克服缺陷」）：成功就拿掉這個缺陷（`overcomablePerks`），學費照同樣的規則 |
| 書籍 | 讀了（使用，約 4 小時）得到機會：《說話之道》（雜貨店）、《機關圖解》（情報商）、《行旅手札》（雜貨店、酒館）、《戰技精要》（鐵匠鋪）、《聖典抄本》（神殿）、《博物志》（魔法物品店）；物品的 `use.perks`；只給現在學得了的（進階要先有入門、和身上的特質互斥的不給），一個都學不了時讀不了。成人向的流派秘法書見 [LEWD_STATS](LEWD_STATS.md) 第 6.1 節 |
| 老師 | 固定 NPC 的 `mentor`（會教的特質）：老師在身邊時（隊友，或同一格、相鄰），「🎓 受訓」多出他會教的特質；好感要夠（`perks.json` 的 `mentor.affinity`），學費打折、難度降低（`price_mult`、`dc_delta`）。流派的老師見 [LEWD_STATS](LEWD_STATS.md) 第 6.1 節 |

### 4.3 失去
效果 `{ "type": "lose_perk", "perk": "<id>" }`（特殊任務編輯器的「失去特質」；拿掉的是缺陷時寫「克服了缺陷」）。日誌的 `changes.perks` 記下學會與失去。種族特質不會失去。

### 4.4 內容編輯器
內容頁籤的「🌟 特質」可以修改內建的特質（包括種族特質）、新增與複製自建的特質，見 [CONTENT_EDITOR](CONTENT_EDITOR.md)。物品編輯器可以設定消耗品是一本書、讀完教哪些特質（`use.perks`）。

- 數值依 `mods.ts` 的 `perkEditorLimits` 夾住（比建角時自訂的寬）：最多 6 個效果，檢定加值 +1～+5、戰鬥修正 +1～+3、仇恨倍率 −0.5～+0.5、抗性 ×0.25～×1.5（大於 ×1 是弱點，像魔族的神聖 ×1.25，可以用來平衡強項）、增傷 +0～+0.5。
- 勾「缺陷」（`flaw`）的特質才能有負的檢定加值（−5～+5）與戰鬥修正（−3～+3）、負的增傷；不是缺陷時，負的檢定加值與戰鬥修正拿掉（不會翻成正的）。種族特質不能是缺陷。特殊任務編輯器選到缺陷時是「直接染上」，書籍、學特質的機會不列缺陷。
- 被用到的自建特質不能刪除；讀檔與自訂內容改變之後，角色身上、學特質的機會、登場過的人身上已經不存在的特質會拿掉（`state.ts` 的 `prunePerks`），見 [CONTENT_DEPENDENCIES](CONTENT_DEPENDENCIES.md)。

## 5. NPC
- 生成的 NPC 依 `npc.chances`（第一個 45%、第二個 20%）抽 0～2 個特質，權重是 `npc.weight`，NPC 有對應的標籤 ×4、職業 ×3（例如惡人比較常是兇神惡煞、謊話連篇）。
- 另外以 `npc.flaw_chance`（20%）抽一個缺陷，權重一樣看缺陷的 `npc.weight`、標籤與職業（例如商人比較常貪財）。缺陷在一般特質之後才擲，加入缺陷之前抽到的特質不變。身分說明、「這裡的人」標明缺陷。
- **依 NPC 的 id 固定地抽**（不動到遊戲的亂數）：同一個人一直是同樣的特質。固定 NPC 可以在內容頁籤指定（「指定特質」；空的清單＝沒有；「恢復隨機」回到依 id 抽）。
- 娼妓、奴隸另外有機會帶一個慾望流派的入門特質（`lewd.json` 的 `npc_schools`，另外依 id 擲，不影響上面抽到的特質；見 [LEWD_STATS](LEWD_STATS.md)）。
- 入隊時帶進角色資料，戰鬥、派去工作、帶路時都用得上；之後隊友升級也會有自己的機會。認識的人在「這裡的人」看得到特質。
