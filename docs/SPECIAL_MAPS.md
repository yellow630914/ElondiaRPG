# 特殊地圖

> 上層：[GAME_DESIGN](GAME_DESIGN.md)。依賴：[WORLD](WORLD.md)（區域、格子、移動）、[DUNGEON_DESIGN](DUNGEON_DESIGN.md)（遭遇、陷阱、寶箱、光線）。被依賴：[STORY_QUESTS](STORY_QUESTS.md)（任務點、傳送）、[TRADE](TRADE.md)（擺在地圖上的商店）、[NPC_SYSTEM](NPC_SYSTEM.md)（固定 NPC 站的格子）、[CONTENT_EDITOR](CONTENT_EDITOR.md)（特殊地圖頁籤）。
> 資料在 `data/world/special_maps.json`。程式：`src/engine/specialMaps.ts`（進出、通道、刷新、戰敗）、`src/engine/grid.ts` 的 `generateSpecial`（生成）、`src/engine/specialMapMods.ts`（內容編輯器）。

## 1. 特殊地圖是什麼

人工設計的地方，例如萊茵堡的下水道：不是城鎮區塊、不是近郊、也不是地下城的一層，而是自成一張地圖，**屬於某個地點**。

- 區域種類是 `special`，區域 key 是 `sm/<id>`（id 一律 `sm_` 開頭）。
- **所屬地點**（`location`）：遭遇表的地區、商店的物價與貨色、AI 看到的地點、戰敗後被送回的地方。在裡面時 `state.location` 就是所屬地點。
- **給 AI 的描述**（`desc`）：在裡面時每一則日誌的場景（`report.location.scene`）都會帶上地圖名稱與描述（`state.ts` 的 `commitReport`）。地點面板也會顯示。
- **光線**（`lighting`）：一直有光、白天有光或黑暗（預設黑暗），規則同 [DUNGEON_DESIGN](DUNGEON_DESIGN.md) 第 4 節。
- **難度**（`layer`）：陷阱的 DC 與傷害、寶箱的上鎖比照地下城的哪一層；所屬地點是地下城時，沒寫遭遇表就用那一層的遭遇。
- 內建兩張：萊茵堡下水道（會刷新，從下城區的南牆進去）、萊茵堡古蓄水池（不刷新，從下水道深處進去，有安全房）。

## 2. 版面

- **固定地圖**（`grid`）：每個字元依共用的圖例對應格子：`#` 牆、`.` 道路、`~` 水、`E` 出口、`S` 安全房、`M` 遭遇、`X` 強敵、`B` BOSS、`R` 資源、`C` 寶箱、`T` 陷阱。M、X、B、R、C、T 是固定位置，內容在生成時擲（遭遇從遭遇表抽一組，強敵是最強的一組再多一隻，資源從採集物抽，寶箱依遭遇表最高等級）。大小 3～20 格。
- **BOSS 格**（`bosses`，只有固定地圖）：地圖上每一格 `B` 各自指定守在那裡的怪物與名字：`{ x, y, group: [[怪物 id, 數量], ...], name }`（最多 8 格，每組最多 4 種、每種 1～6 隻，名字最多 12 字）。名字顯示在地圖與戰鬥的場景（「萊茵堡下水道・下水道之王」）；沒指定怪物（或怪物被刪了）時照強敵的規則，名字預設「BOSS」。格子種類和地下城的層主一樣（`boss`），戰鬥時怪物比較容易帶特徵，但不給公會的層主功績。沒有畫在 `B` 上的設定在整理時拿掉。
- **隨機地圖**（`size`、`carve_steps`）：從下方中央的出口隨機挖出通道。只能由事件傳送進來，不能設通道、商店或固定 NPC。
- **額外的隨機內容**：`encounters`、`elites`、`traps`、`resources`、`chests` 是另外撒在空地上的數量（兩種版面都可以）；通道的端點、入口、商店的格子不會放。
- **遭遇表**（`table`，選填）：沒寫時，所屬地點是地下城就用 `layer` 那一層，否則用地區的城郊遭遇表。**採集物**（`resource_items`，選填）：沒寫時用地下城的採集表。
- **入口**（`entry`）：被事件傳送進來時站的位置；沒寫時站在出口，再沒有就是第一格空地。
- 生成時記下版本（`specialVersion`：版面與內容的設定）。內容編輯器改了這些設定，存檔裡的地圖會重新生成；主角正站在裡面而那一格不見了或變成牆時，移到入口。名稱、描述、地點、光線、刷新、通道改了不用重新生成。

## 3. 進入與離開

| 方式 | 說明 |
|---|---|
| 事件傳送 | 特殊任務（以及其他用 `StoryOutcome` 的事件）結果的 `special_map`：報告提交之後傳送到那張地圖的入口（`road.ts` 的 `queueMove`、`applyPendingMove`）。在臨時地圖裡時先離開臨時地圖 |
| 通道 | 走上通道格，到另一頭的格子（第 4 節） |
| 從出口離開 | 站在出口，按「離開」：回到從外面進來前的位置與地點（在旅途上被傳送進來的，回到旅途）；沒有記錄時到所屬地點的入口（城門、地下城周邊入口） |
| 從通道走出去 | 走到城鎮那一頭（或任何不是特殊地圖的地方），就算離開了 |
| 被事件帶走 | 結果的 `travel_to`：先離開特殊地圖，再被帶到那個地點 |
| 倒下 | **被送回所屬地點**（城門或地下城入口）；如果是在旅途上被傳送進來的，這趟旅途就此中斷 |

- 從外面進到特殊地圖時記下回程（`state.special.back`）與原本的地點；在特殊地圖之間走來走去不會改回程。
- 裡面**不能直接出發旅行**（只有城門與地下城入口能出發），**長休只能在安全房或旅店格**上（和地下城一樣，安全房要乾糧、每間一次）；短休、被襲擊的機率照 `companions.json` 的 `rest.ambush.special`。
- 特殊地圖不在 `enterLocation` 與出發旅行時清掉（`grid.ts` 的 `clearAreas` 保留 `sm/`）。

## 4. 通道

通道把一張**固定地圖**的一格（`at`）和另一張地圖的一格（`to`）接起來：

- 另一頭可以是**城鎮區塊**（區塊 key，例如 `rhineburg/lower`）的**牆或水**（不能是待售的空地：那一格在遊戲裡會變成空地，整理時拿掉這個通道），或**別張固定特殊地圖**（`sm/<id>`）的任何一格。只能接城鎮區塊與特殊地圖的確切格子；近郊、地下城每次重新生成，不能接。
- 打開時兩頭都變成通道格（`link`），走上去就站到另一頭的通道格上；**一個通道只要在其中一張地圖上寫一次**，另一頭自動接回來（`specialMaps.ts` 的 `endpointsIn`）。
- `requires`（`flags`、`flags_none`）：劇情旗標成立時才打開，例如完成某個任務後城牆的暗門才打得開。關著時城鎮那一頭還是牆，特殊地圖那一頭還原成地圖上畫的格子。
- 套用的時機：城鎮區塊每次組出來時（`getArea`，在空地與房子之後）、特殊地圖每次讀取時（`overlayConnections`），所以旗標一改馬上生效。

## 5. 刷新

`refresh` 為 true 的地圖，主角**離開這片特殊地圖**（從出口、從通道走回城鎮、倒下、被 `travel_to` 帶走）之後作廢，下次進來重新生成：遭遇、資源、寶箱全部重來。沒勾的地圖打過、採過、開過的一直留在存檔裡（`state.areas['sm/<id>']`），旅行也不會清掉。

## 6. 任務點、商店與固定 NPC

- **任務點**：特殊任務的任務點可以指定 `at.where: 'special'` 加 `at.special_map`，任務點（⭐）放在那張地圖的一格空地上（不放在通道端點）；在場的友方站在 ⭐ 旁邊。冒險筆記寫「<地圖名稱>（⭐）」。`at.special_map` 沒寫或寫了不存在的地圖時，任務檢查報錯誤「特殊地圖不存在」（匯入時整條任務不收）。
  - **確切的格子**（只有固定地圖）：再寫 `at.x`、`at.y`，⭐ 就放在那一格。可以指定空地，或畫在地圖上的遭遇、強敵、資源、寶箱、陷阱（⭐ 取代那一格的內容）；入口、通道端點、牆、水、出口、安全房、商店不行（`specialMapMods.ts` 的 `storySpotProblem`）。
  - 超出地圖範圍的格子在整理時拿掉；之後地圖改了、那一格變得不行時，任務檢查會提醒，遊戲裡改成隨機放在一格空地（`story.ts` 的 `ensureStoryMarkers`）。
- **傳送**：任務點結果的 `special_map`（見第 3 節）。
- **商店**（`shops`，只有固定地圖）：`{ shop, x, y }`，shop 是內建店種（`general`、`smithy`……流浪商人除外）或自建商店的 id；格子變成那種店，站上去就能交易，物價與貨色照所屬地點。擺在地圖上的自建商店不能刪。
- **固定 NPC**：固定 NPC 的出現方式選「固定在特殊地圖的一格」（`fixed.area` 是 `sm/<id>`），站在那一格；要是固定地圖上走得到的格子。依劇情旗標改變出沒的各組也可以。

## 7. 內容編輯器

頁籤「🗺️ 特殊地圖」（見 [CONTENT_EDITOR](CONTENT_EDITOR.md) 3.95 節）。內建的地圖每一項都可以改、不能刪；自建的沒有被用到時可以刪（用到的地方：特殊任務的任務點與傳送、其他地圖的通道、待在這裡的固定 NPC）。世界裡拿掉的地圖（刪除、匯入、全部恢復預設）從存檔作廢，主角正在裡面時送回進來前的地方（`pruneSpecialMaps`，讀檔時與改了自訂內容之後）。
