# 特殊任務與劇情旗標

> 上層：[GAME_DESIGN](GAME_DESIGN.md)。依賴：[EFFECTS](EFFECTS.md)（結果與報酬）、[ACTIONS](ACTIONS.md)（判定）、[NPC_SYSTEM](NPC_SYSTEM.md) 與 [CONTENT_EDITOR](CONTENT_EDITOR.md) 第 4 節（固定 NPC）、[TRAVEL_EVENTS](TRAVEL_EVENTS.md)（旅途開頭、臨時地圖、情報商開頭）。被依賴：[GUILD](GUILD.md)（完成任務的功績）、[CONTENT_DEPENDENCIES](CONTENT_DEPENDENCIES.md)。

公會的**一般委託**由系統生成（見 [GUILD](GUILD.md)）。**特殊任務**是人工編寫的任務鏈：有故事線、固定的 NPC、獨特的報酬，要到多個地點、經過多次判定，依結果走向不同的分支。

- 資料：`data/rules/stories.json`（內建）＋「🌍 世界 → ⭐ 特殊任務」的自訂內容（存在目前的「世界」，用同一個世界的存檔共用，可以匯出、匯入；見 [CONTENT_EDITOR](CONTENT_EDITOR.md) 第 0 節）。
- 程式：`src/engine/story.ts`（進行任務）、`src/engine/storyMods.ts`（整理、檢查）、`src/engine/storyFlags.ts`（劇情旗標）。
- 內建的範例：「失竊的聖環徽記」（瑟琳），四個任務點分別示範劇情、判定、戰鬥、選擇，以及任務同行；「翻覆的篷車」示範旅途上的開頭、臨時地圖與改道（見 [`TRAVEL_EVENTS.md`](TRAVEL_EVENTS.md)）；「走私者的帳本」示範情報商的開頭。
- 內建世界的故事線（第一批，規劃見 `worldgen/design/elondia-storylines.md`）：**晨曦王位之爭**（遇襲的樞機馬車 → 老獅子的病 → 晨曦的加冕；推動人類世界的走向，國王在第三個任務死去，登基的一方用階段換上新身分）、**低語墓穴**（風中的低語 → 將軍們的誓約 → 低語皇帝）、**莉莉安**（成人向：魔法少女的繼承人候選 → 星之心的故鄉 → 魔法少女的畢業典禮）。第二批：**萊茵堡的主戰與主和**（南郊的夜襲 → 鐵十字會 → 四將軍的軍議）、**晨霧修道院**（霧中的晨鐘 → 審判的卷宗 → 被抹去名字的聖者）、**伊莎朵拉**（成人向：鞭子大小姐的護衛面試 → 訂婚舞會上的假情人 → 大小姐的私奔）。每條三個任務，Lv.5、8、11 起接；和 NPC 的戰鬥用替身怪物（[`MONSTERS.md`](MONSTERS.md)「特殊任務的替身怪物」）。

## 1. 想法：用劇情旗標串起任務點

自動生成任務鏈很難寫得好看，所以特殊任務改成人工編寫，但格式盡量簡單：

1. 一個任務 = **開頭** + 一串**任務點** + **完成報酬**。
2. 每個任務點只描述「在哪裡、什麼時候出現、發生什麼、結果是什麼」。
3. 任務點之間的順序與分支**不用畫流程圖**，而是用**劇情旗標**表達：
   - 任務點的「解鎖條件」是一組旗標（全部成立才出現），也可以要求某些旗標「不成立」。
   - 任務點的每個結果可以「設定」或「清除」旗標。
   - 例：A 成功設定 🚩`trail_found` → 需要 🚩`trail_found` 的 B 才出現；A 失敗設定 🚩`trail_lost` → C 出現，走另一條路。
4. 同時解鎖的任務點可以任意順序完成（例如「去三個地方收集線索」）；需要的旗標全部到齊才出現的任務點就是匯合點。
5. 編輯器下方有**檢查任務鏈**：列出每個旗標由誰設定、誰需要。問題分成**錯誤**（不存在的 NPC、怪物、物品，沒有完成的結果，地點類型不對……，修正後才能儲存、匯入時不收）與**提醒**（需要卻沒有人設定的旗標——可能來自 AI 或別的任務；沒人開啟的「只由其他事件開啟」任務，可以儲存）。完整清單見 [`CONTENT_DEPENDENCIES.md`](CONTENT_DEPENDENCIES.md) 第 4 節。
6. 目前的存檔正在進行這個任務時，會弄壞進度的修改（改掉完成過的任務點 id、讓所有剩下的任務點都永遠解鎖不了）不能直接儲存：改成「複製成新任務再改」，或「放棄這個存檔的任務進度後儲存」。

### 1.1 條件與劇情計數器

條件（任務的接取、任務點的解鎖、選項、固定 NPC 的出現與階段、旅途與城鎮事件）可以組合：

| 條件 | 說明 |
|---|---|
| `flags` | 全部成立 |
| `flags_none` | 全部不成立 |
| `flags_any` | 至少一個成立（「或」） |
| `counters` | 劇情計數器在範圍內：`{ "human_stance": { "min": 1 } }`（含邊界，min、max 可以只寫一邊） |
| `affinity` | 角色的好感至少多少 |

**劇情計數器**（`data/rules/counters.json`，內容頁籤「⭐ 特殊任務 → 🔢 劇情計數器」新增與修改，跟著世界匯出匯入）：結果的 `counters`（`{ "human_stance": 1 }`）加減數值，條件的 `counters` 要求範圍。計數器有名稱、說明、初始值與上下限；存檔裡存在 `flags` 的 `count:<id>`。內建兩個：`human_stance`（人類世界的走向）、`demon_stance`（魔族世界的走向），政治故事線主和 +1、主戰 -1，史詩線看正負決定走和平或開戰。任務用到不存在的計數器是錯誤；被用到的自建計數器不能刪除。

### 1.2 內容標籤

任務可以標上**內容標籤**（`tags`）：成人向（`adult`）、NTR（`ntr`）、非處女（`non_virgin`）、主角非自願（`pc_unwilling`）。

- 接任務時（公會、NPC 的委託）與冒險筆記顯示成 ⚠ 警示。
- 成人向的任務在設定沒有開啟成人向時不開放；其他標籤玩家可以在「設定 → 內容篩選」關閉，關閉的任務不開放（公會、NPC、旅途、情報商的開頭與「開始特殊任務」的效果都不會開始），進行中的任務不受影響。
- 分支才有的內容（例如阿雅線的 NTR 分支）把標籤加在那個**選項**上：設定關掉時選項不出現。
- `start.pc_body`：只給這些體型的主角（`masc` 男性形象、`fem` 女性形象、`andro` 中性；依建角時選的體態，沒選時依種族與性別），例如做給女性主角的任務。

旗標是全域的：存在存檔的 `flags` 裡（`story:名稱`），其他任務（包括旅途與情報商開頭的任務的接取條件）、固定 NPC 的出現條件都可以讀同一個旗標，所以任務之間也能互相接續（例如完成甲任務設定 🚩`elder_trusts_you`，乙任務的接取條件需要它）。以 `ai:` 開頭的名稱讀 AI 判定寫下的旗標。

## 2. 格式

```jsonc
{
  "id": "lost_relic",
  "title": "失竊的聖環徽記",
  "summary": "冒險筆記上的簡介",
  "rank": "F",                       // 建議的公會階級：接取時檢查（同級或更低，組隊時可以高一級）
  "merit": 5,                        // 完成時的公會功績（不寫＝5，見 GUILD）
  "time_limit": 10,                  // 期限：開始後幾天內要完成（不寫＝不限）；過了就失敗，任務同行的夥伴離隊，冒險筆記寫「⏳ 剩 N 天」
  "start": {
    "kind": "npc",                   // guild 公會、npc 固定 NPC、travel 旅途事件、informant 情報商、manual 只由其他事件開啟
    "npc": "npc_selene",             // npc：這位角色在身邊時可以接
    "location": "soriel",            // guild：哪座城的公會；informant：哪座城的情報商（不寫＝任何一家）
    "chance": 0.2, "regions": [],    // travel：每段旅程遇到的機率、只在前往這些地區時
    "price": 120,                    // informant：情報的價格
    "min_level": 1,
    "min_affinity": 30,              // npc：這位角色的親密度至少多少才會拜託你（沒見過面算 0；不寫＝不限）
    "requires": { "flags": [], "flags_none": [] },
    "text": "開頭的事件描述"
  },
  "start_flags": ["relic_started"],  // 開始時成立的旗標
  "nodes": [ /* 任務點 */ ],
  "rewards": [ /* 完成報酬：效果的清單 */ ]
}
```

### 任務點

| 欄位 | 說明 |
|---|---|
| `id`、`title`、`text` | id（英數）、冒險筆記上的目標、觸發時的事件描述（也交給 AI） |
| `at.where` | `settlement` 在聚落裡、`cell` 站在某種設施、自建的商店或城鎮的特色地標上（`at.cell`，地標見 [LANDMARKS](LANDMARKS.md)）、`npc` 某位固定 NPC 在身邊（`at.npc`）、`outskirts` 近郊的 ⭐、`dungeon` 地下城某一層的 ⭐（`at.layer`）、`road` 旅途上、`side` 臨時地圖裡的 ⭐（`at.side_map`）、`special` 特殊地圖裡的 ⭐（`at.special_map`；固定地圖可以再用 `at.x`、`at.y` 指定確切的格子，見 [SPECIAL_MAPS](SPECIAL_MAPS.md) 第 6 節） |
| `at.location` | 地點 id（`npc` 可以不寫，跟著角色走） |
| `requires` | 解鎖的條件：`flags` 全部成立、`flags_none` 都不成立、`affinity` 每位角色的好感（親密度）都夠，例如 `{ "flags": ["a"], "affinity": { "npc_selene": 20 } }`（沒見過面算 0） |
| `urgent` | 走到任務點時一定要先處理（不能移動、休息），事件視窗另外多一個選擇：不寫（不緊急，預設）多「稍候」，這次先略過、不記日誌，離開這裡之後再來還會觸發；`true`（編輯器的「緊急」）只能處理或「放棄任務」，選了任務線就中斷，適合旅途上、臨時地圖裡這種過了就沒有的場面。判定沒有進展（失敗可以再試、好感不到門檻、戰鬥撤退）之後也不再擋住你，離開再來才會再觸發 |
| `allies` | 在場的友方固定 NPC（id 的清單，任何種類的任務點都可以用）：解鎖之後站在 ⭐ 旁邊，或站在設施上（`cell`；`settlement` 在城門），不管他平常的出沒與出現條件；戰鬥時站在你這邊（由你操作，生命值不留到戰鬥之後）；AI 判定與寫經過時知道他們在場（`report.others`） |
| `kind` | `story` 劇情（直接發生）、`check` 判定（`check: { attr, dc }`，可以參考好感，見下面）、`combat` 戰鬥（`enemies` 怪物、`foes` 固定 NPC）、`choice` 選擇（`options`，每個選項可以有自己的檢定與出現條件 `requires`） |
| `success`、`fail` | 結果（劇情只有 success；判定與戰鬥沒寫 fail 時，失敗可以再試） |

### 參考好感的檢定

判定與選項的檢定可以參考某位固定 NPC 對主角的好感（親密度）：

```jsonc
"check": { "attr": "cha", "dc": 12, "affinity": { "npc": "npc_selene", "per": 10, "max": 5, "min": 20 } }
```

- **加值**：好感每 `per` 點 +1（預設 10；負的好感就扣），最多 ±`max`（預設 5）。放進檢定的情境修正，骰子明細看得到「瑟琳的好感（45）+4」。
- **門檻**（`min`，可以不寫）：好感不到就直接套用失敗的結果，不擲骰（日誌寫「瑟琳的好感 15，不到 20，沒有擲骰」）；沒有寫失敗的結果時，之後可以再試。好感不夠時不想讓玩家白按（每次花 1 小時、寫一篇日誌），就寫一個失敗的結果，或改用任務點的「解鎖需要好感」讓它晚點才出現。
- AI 判定時，場景裡會寫這位角色對主角的好感與看法；日誌的其他人也帶上他，寫經過時有他的關係與記憶。
- 選項另外可以有出現條件：`"requires": { "affinity": { "npc_selene": 10 } }`（也可以用旗標），條件不成立時選項不出現。

例：瑟琳的任務最後邀請她入隊。好感 10 以上才出現這個選項，好感換成魅力檢定的加值，不到 20 直接失敗；成功正式入隊，失敗她給一筆謝禮。

```jsonc
{ "label": "邀請她入隊", "requires": { "affinity": { "npc_selene": 10 } },
  "check": { "attr": "cha", "dc": 12, "affinity": { "npc": "npc_selene", "per": 10, "max": 5, "min": 20 } },
  "success": { "text": "瑟琳答應了。", "effects": [{ "type": "companion", "npc": "npc_selene", "mode": "voluntary" }], "complete": true },
  "fail": { "text": "瑟琳婉拒，塞給你一袋錢當謝禮。", "effects": [{ "type": "money", "amount": 200 }], "complete": true } }
```

編輯器：檢定欄的「參考好感」（角色、每幾點 +1、上限、門檻），任務點的「解鎖需要好感」，選項的「這個選項出現需要」。「檢查任務鏈」會提醒不存在的角色。好感條件也可以用在固定 NPC 的「依劇情旗標改變出沒」等其他用到條件的地方。

近郊與地下城的任務點在進入那一區時放一格 ⭐（解鎖之後才放）。判定與有檢定的選項走主動行動：玩家可以描述做法、搭配能力，交給 AI 判定（大成功、成功、部分成功都算成功）；沒有 AI 時依規則擲骰。

### 結果

```jsonc
{
  "text": "發生的事",
  "set_flags": ["relic_found"], "clear_flags": [],
  "counters": { "human_stance": 1 },   // 劇情計數器的加減（第 1.1 節）
  "deaths": ["npc_alexander"],         // 故事裡的死亡：這些固定 NPC 在這裡死去，之後不再出現
  "effects": [{ "type": "money", "amount": 150 }],  // 金錢、物品、裝備、經驗、聲望、親密度、記憶、能力、正式入隊、生命值、開始特殊任務、主角淪為奴隸
  "join": "npc_selene",      // 固定 NPC 以「任務同行」加入（不佔隊伍名額）
  "leave": "npc_selene",     // 任務同行離開
  "complete": true,          // 完成任務（發完成報酬）；或 "fail_quest": true 任務失敗
  "retry": false,            // true：這個任務點不結束，之後可以再來
  "side_map": "cave",        // 進入臨時地圖（洞窟、遺跡、驛站），出口回到原本的地方
  "special_map": "sm_rhineburg_sewer", // 傳送到特殊地圖的入口（從出口離開回到原本的地方，倒下送回地圖的所屬地點）
  "travel_to": "rivervale"   // 改去別的地點（旅途中直接抵達，不在旅途時被帶過去；在臨時地圖或特殊地圖裡時先離開）
}
```

任務結束（完成、失敗或放棄）時，這個任務帶來的任務同行夥伴都會離隊。

**和固定 NPC 戰鬥、固定 NPC 死去**：要和某位固定 NPC 打一場時，**用一隻代替他的怪物**（`enemies`，在怪物資料裡做一隻同名、數值照任務等級的專用怪物），不要用 `foes`——固定 NPC 的戰鬥資料依等級生成，不好平衡，打倒之後的死亡、制伏也會帶出很多後續問題。故事裡要讓他死去時，在對應任務點的結果寫 `deaths`：他會標記死亡、離開隊伍與名單，需要他的**其他**任務失敗（這個任務照常進行）。

**任務需要的角色**：開頭的固定 NPC、任務同行的夥伴，以及還沒結束的任務點要找的人（`at.npc`）、要加入的人（`join`、正式入隊的效果）死了（處決、戰鬥中被打死），任務直接失敗。戰鬥任務點的敵對角色（`foes`）不算：他們本來就可能被打倒。已經死了或被制伏的角色不會上場（敵對與友方都一樣）；戰鬥任務點的對手全都不在了、又沒有怪物時，直接算勝利。被制伏、等你處置的人不能發任務、不能當任務點要找的人、不能入隊，參考他好感的檢定與選項也不出現；開頭的角色敵對時也不發任務。

**臨時地圖**：結果帶進去的臨時地圖（`side_map`）只屬於這個任務，`side` 任務點只放在這張地圖裡（不會出現在其他事件的洞窟）。任務點還沒完成就離開，等於放棄這個任務（離開時會先問）。

**特質**：`{ "type": "perk", "perk": "veteran", "options": ["diplomat"] }` 給主角一次學特質的機會（從這幾個選一個，或寫說法擲骰交給 AI 爭取別的；來源寫成這個特殊任務），`"direct": true` 直接學會；`{ "type": "lose_perk", "perk": "<id>" }` 失去特質。見 [`PERKS.md`](PERKS.md)。

**刺青**：`{ "type": "tattoo", "template": "lotus" }`（圖樣，可以加 `place`、`by`），或自己描述 `{ "type": "tattoo", "kind": "oath", "name": "…", "text": "…", "attrs": { "str": 2, "int": -2 } }`；`{ "type": "remove_tattoo", "kind": "plain" }` 洗掉。見 [`TATTOOS.md`](TATTOOS.md)。

**非戰鬥狀態**：`{ "type": "condition", "target": "pc", "condition": "blessed", "add": true }`（祝福、放鬆、興致高昂、磨利……，多半到下次長休；奴隸印記、逃亡、暫時離隊不能用）。

**主角淪為奴隸**（只有特殊任務能用）：
- 固定 NPC 當主人：`{ "type": "enslave_player", "master": "npc_selene", "contract": "labor" }`
- 隨機的 NPC 當主人：`{ "type": "enslave_player", "random": { "tag": "noble" }, "contract": "combat" }`（`tag` 是主人的身分標籤，不寫＝依奴隸市場的權重抽；在目前的地點生成，比主角高 1～4 級）

`contract` 是主人打算刻的印記（勞役 labor、戰奴 combat、魔導束縛 arcane、娼妓 brothel），之後照樣有刻印檢定；主角原本的同伴（包括任務同行）會分開；已經是奴隸時改成換主人（印記沿用）。主人會在自己的城市有一棟房子（見 [`COMPANIONS.md`](COMPANIONS.md) 第 3.4 節）。編輯器的「＋ 效果…」選「主角淪為奴隸」，再選「固定 NPC 當主人」或「隨機的 NPC 當主人」；檢查任務鏈會提醒不存在的主人。

**開始特殊任務**（`{ "type": "start_story", "story": "id" }`）：在結果裡接著開啟另一個特殊任務（另外一則日誌）。不看接取條件；已經開始過就略過。開頭是「只由其他事件開啟」（`manual`）的任務要靠它開始，「檢查任務鏈」會提醒沒有任何任務開啟它的情況。

### 例：營救 A，同行一段時間後回公會

```jsonc
{
  "start": { "kind": "guild", "location": "soriel", "text": "公會的委託：A 被盜賊抓走了。" },
  "start_flags": ["rescue_started"],
  "nodes": [
    { "id": "free", "title": "到近郊救出 A", "at": { "where": "outskirts", "location": "soriel" },
      "requires": { "flags": ["rescue_started"] },
      "kind": "combat", "enemies": [["bandit", 2]], "allies": ["npc_a"],          // A 被綁在 ⭐ 旁邊，戰鬥時幫你打
      "success": { "text": "你割斷繩子，A 說要跟你一起回去。", "join": "npc_a", "set_flags": ["a_rescued"] } },
    { "id": "back", "title": "帶 A 回公會", "at": { "where": "cell", "location": "soriel", "cell": "guild" },
      "requires": { "flags": ["a_rescued"] },
      "kind": "story", "success": { "leave": "npc_a", "complete": true } }
  ]
}
```

如果 A 之後要搬家，在固定 NPC 的「依劇情旗標改變出沒」加一組需要 🚩`a_rescued` 的設定（見 [`CONTENT_EDITOR.md`](CONTENT_EDITOR.md) 第 4 節）。

## 3. 編輯器（🌍 世界 → ⭐ 特殊任務）

- **基本與開頭**：名稱、簡介、建議等級（接取時檢查，和公會委託一樣：主角的公會階級同級或更高，組隊 2 人以上時可以低一級；公會、固定 NPC、情報商的開頭不符合時不出現，旅途開頭不符合時不放進旅途）；從哪裡開始、接取條件、開頭的事件描述、開頭的旗標。
- **任務點清單**：每一列顯示種類、地點、需要的旗標（需要 🚩）、會設定的旗標（→ 🚩）、會不會完成（✅）或失敗（❌）任務。點開編輯；可以上下移動、複製、刪除。
- **旗標輸入**：一個一個加入，自動完成內容頁籤裡用過的旗標（任務、固定 NPC 的出現條件與「依劇情旗標改變出沒」的每一組條件）。
- **完成報酬**：效果的清單。
- **檢查任務鏈**：錯誤（擋儲存）與提醒的清單、旗標流向表。
- **複製**：內容清單的「複製」會把開頭旗標換成新任務自己的，其他照抄。
- 內建任務可以修改、恢復預設，不能刪除；自建的可以刪除。固定 NPC 的編輯見 [`CONTENT_EDITOR.md`](CONTENT_EDITOR.md) 第 4 節。

## 4. 遊戲裡

- 公會：站在公會時，這座城的特殊任務列在「⭐ 特殊任務」。固定 NPC：角色在身邊時出現「接下任務」。
- 任務點所在的地方會出現「⭐ 特殊任務」面板：劇情按「繼續」、判定按「嘗試」（可以描述做法）、戰鬥按「開始戰鬥」、選擇按選項。
- 每次推進都產生一份日誌（`report.story`），AI 寫經過時會看到事件描述與結果。
- 進度與經過記在 `state.stories`。

## 5. 冒險筆記（📒 筆記）

左邊的「📒 筆記」按鈕打開冒險筆記，分三頁：

- **一般委託**：進行中的委託（進度、地點、目標怪物、交付地點、線索），可以交付的會標出來，也可以放棄（公會聲望 -1）；下方是完成過的委託。
- **特殊任務**：每個任務的簡介、目前可以進行的目標（解鎖的任務點與地點）、經過；可以放棄進行中的任務。
- **情報**：買到的事件點（地點、事件、有效期限、是否完成或過期）與特殊任務的消息。
