# 刺青

> 上層：[GAME_DESIGN](GAME_DESIGN.md)。依賴：[COMPANIONS](COMPANIONS.md)（奴隸印記的契約條款與功能）、[COMBAT_SYSTEM](COMBAT_SYSTEM.md)（有效屬性）。被依賴：[EFFECTS](EFFECTS.md)（`tattoo`、`remove_tattoo`）、[STORY_QUESTS](STORY_QUESTS.md)。
> 規則在 `data/rules/tattoos.json`（部位、種類、誓約規則、圖樣）與 `data/rules/slavery.json`（奴隸印記的模板）。程式：`src/engine/tattoos.ts`。

## 1. 部位與種類

身上 11 個部位，每個部位一個刺青：頸部、左臂、右臂、胸口、背部、小腹、臀部、左大腿、右大腿、左小腿、右小腿。

| 種類 | 作用 | 怎麼來 |
|---|---|---|
| 奴隸印記 | 奴隸契約（收益歸屬、服從、出城、追蹤……，見 [COMPANIONS](COMPANIONS.md) 第 4 節） | 淪為奴隸、買奴隸時刻上；老鴇改刻 |
| 誓約印記 | 屬性有加有減，加總為 0 | 刻印師、事件、特殊任務 |
| 普通刺青 | 只是外觀 | 刺青店、事件、特殊任務、主人（第 7 節） |
| 詛咒印記 | 淫紋（寄生物）：未馴服時有發作與減值，馴服後變成有屬性加成的印記 | 寄生物（見 [ADULT_EVENTS](ADULT_EVENTS.md) 第 6.4 節） |

- 刺青的名稱、外觀、刺的人（`by`）都寫進給 AI 的主角資料（判定與敘事）；誓約的屬性已經算進有效屬性。
- 隊伍視窗的「🖋️ 刺青」放在「🛡️ 裝備」下面，和裝備欄位一樣列出全部 11 個部位（空的部位顯示「—」）：種類、名稱、誓約的加減、外觀與誰刺的；每位隊員都有。奴隸印記另外有「⛓️」區塊列契約條款。
- 目前只有主角會有普通刺青與誓約印記；隊伍裡的奴隸只有奴隸印記。
- 圖樣、奴隸印記的模板與印記設定都可以在內容編輯器的「🖋️ 刺青」修改（見 [CONTENT_EDITOR](CONTENT_EDITOR.md) 3.7 節）。

## 2. 奴隸印記

- 契約（`ContractRef`）掛在奴隸印記上（`Tattoo.contract`），角色身上沒有另外的契約欄位；程式用 `contractOf`、`setContract`、`clearContract` 存取。
- **刻印時存一份條款**（`ContractRef.terms`）：模板之後改了，已經刻上的印記不變；模板被刪掉也不會壞（`contractKind` 改用預設模板）。
- 刻在條款的部位（模板的 `place`：勞役、戰奴、魔導束縛在頸部，娼妓在小腹；自訂印記可以選部位）。**那個部位原本的刺青會被蓋掉**；換印記（刻印檢定、老鴇改刻）時舊的奴隸印記拿掉，新的刻在它自己的部位。
- 奴隸印記不能用洗刺青的方式去掉，要解除契約（談判、事件、解除印記的服務）。
- 印記模板的用途在 `slavery.json` 的 `roles`：`default`（買奴隸、AI 交易清單、劇情沒指定時）、`madam`（老鴇收下主角、主人是娼妓、自賣給老鴇）。奴隸市場上的印記權重在 `market_contracts`（公開市場、黑市）。

## 3. 誓約印記

- 最多動 3 項屬性，每項 ±1～±3，有加也有減，**加總為 0**（`tattoos.json` 的 `oath`）；每個角色最多 2 個。
- 加減算進有效屬性（`character.ts` 的 `attrsOf`），基礎屬性不變；洗掉後自動回到原本。
- 內建圖樣：

| 圖樣 | 加減 |
|---|---|
| 狂戰之誓 | 力量 +3、智力 −2、魅力 −1 |
| 影行之誓 | 靈巧 +3、魅力 −2、力量 −1 |
| 賢者之誓 | 智力 +3、力量 −2、靈巧 −1 |
| 苦修之誓 | 信仰 +3、魅力 −2、靈巧 −1 |
| 魅惑之誓 | 魅力 +3、信仰 −2、力量 −1 |
| 鐵壁之誓 | 力量 +2、信仰 +1、靈巧 −3 |
| 水銀之誓 | 靈巧 +2、智力 +1、力量 −3 |
| 斷念之誓 | 信仰 +2、力量 +1、魅力 −3 |
| 叛神之誓 | 智力 +2、魅力 +1、信仰 −3 |
| 野性之誓 | 力量 +1、靈巧 +1、智力 −2 |

## 4. 普通刺青

18 種內建圖樣（荊棘藤蔓、展翅之鷹、盤龍、蓮花、蝴蝶、骷髏與玫瑰、月相、狼首、部族環紋、海浪與錨、古文銘句、纏蛇、心與名字、火焰、鳳羽、傭兵團徽、雙魚、花環），各有建議的部位。

## 5. 事件效果

- `{ "type": "tattoo", "template": "<圖樣>", "place": "<部位>", "by": "<誰刺的>" }`：依圖樣刺青；`place` 沒寫時挑圖樣建議的部位裡空著的（都滿了就任何空的部位）。
- 自己描述：`{ "type": "tattoo", "kind": "plain" | "oath", "name": "…", "text": "外觀", "attrs": { "str": 1, "cha": -1 } }`（誓約要 `attrs`，不合規則的寫法在存檔時就被拿掉）。
- 部位已經有刺青、身上沒有空位或誓約已經 2 個時不刺（日誌寫「沒有刺上刺青」）。
- `{ "type": "remove_tattoo", "place": "<部位>" }` 或 `{ "type": "remove_tattoo", "kind": "plain" | "oath" }`：洗掉；奴隸印記不受影響。
- 日誌的 `changes.tattoos` 記下刺上與洗掉。

## 6. 刺青店、刻印師與洗刺青

`tattoos.json` 的 `shops`（價格是白鸛幣）；程式：`tattooShop.ts`，畫面：`TattooPanel`。

| 地方 | 在哪裡 | 刺 | 洗 |
|---|---|---|---|
| 🖋️ 刺青店 | 王都、城市、港口（地圖的 `K`） | 普通刺青 200（自己描述的 +100），2 小時 | 普通刺青 300 |
| 🔏 刻印師 | 王都與有黑市的城市（地圖的 `X`） | 誓約印記：加的總點數 × 1000（自己設計的 +500），4 小時 | 普通刺青 800、誓約印記 4000 |
| ⛪ 神殿 | 神殿（「🧼 洗刺青」） | — | 普通刺青 150、誓約印記 1200；要在這裡的勢力有 10 點聲望，逃亡奴隸不接待 |

- 刺青可以選圖樣或自己描述（名稱、外觀；誓約另外填屬性的加減，要合第 3 節的規則）；部位只能選空著的。
- 洗刺青不用檢定，付錢就好；刺青店只洗普通刺青。
- **詛咒印記**：未馴服的洗不掉，要解咒（神殿、刻印師，見 [ADULT_EVENTS](ADULT_EVENTS.md) 第 6.5 節）；已馴服的刻印師 1000、神殿 600。洗掉或被奴隸印記頂掉的淫紋、刻上淫紋時被蓋掉的刺青，刻印師可以紋回來（「紋回來」）。
- **奴隸印記**不能用洗的：要解除契約（神殿解咒便宜但要聲望、刻印師很貴、法師解構留下紋樣），都有檢定，見 [COMPANIONS](COMPANIONS.md) 第 3.3 節。
- **法師拆誓約**：身邊或隊伍裡的法師可以拆掉誓約的術式（主動行動的「拆掉誓約」）：智力檢定，DC = 誓約強度 − 3（誓約強度 = 10 + 加的總點數 × 2），費用 = 強度 × 120（隊伍裡的法師免費）。成功時屬性的加減消失、紋樣留下來變成普通刺青；大失敗反噬 30% 生命值。

## 7. 主人替主角刺青

主人的事件（`slavery.json` 的 `master_events`，`free_place: true`）：**只在主角身上還有空著的部位時發生，只刺普通刺青，不會蓋掉原本的刺青**（指定的部位已經有刺青時就不刺）。效果裡的 `{master}` 換成主人的名字，`by` 記成主人。

| 事件 | 主人 | 回應 |
|---|---|---|
| 刺上記號（`ink_crest`） | 任何 | 乖乖讓人刺（主人的記號，親密度 +2）；請求刺個好看的圖樣（魅力 13：蝴蝶，失敗照刺記號）；掙扎（力量 15：成功不刺，親密度 −3） |
| 黑巷的刺青攤（`villain_ink`） | 惡人 | 不吭聲（骷髏與玫瑰）；趁醉矇混（靈巧 14：花 20 打點，不刺）；當面拒絕（被打，照刺） |
| 家族徽記（`noble_crest`） | 貴族、王族 | 恭敬接受（徽記，親密度 +2）；請求刺在不顯眼處（魅力 12：左大腿）；以出身為由拒絕（魅力 16：不刺） |

特殊任務與其他事件可以用 `tattoo` 效果給任何刺青（包括誓約印記，見第 5 節）。
