# 模組化像素立繪規格

立繪由多個部件疊成，部件依 NPC 的外貌組合決定。生成路線見 `phase0-report.md` §6.2 的 (B)：先定一個基準頭型，部件都在基準圖上 inpaint 生成再抽出圖層，所以每層天生對齊。

## 1. 外貌從哪裡來

NPC 的外貌已經是「部件」抽出來的：`src/engine/traits.ts` 的 `rollLook` 依 `data/world/npc_traits.json` 從各部位的選項池抽出 `eyes`、`face`、`hair_color`、`hair_style`…，再加上種族或血統的特徵（`features`），最後組成外貌文字。

改版後把這些抽到的部件存進 NPC 的 `look`，立繪用一份對照表（`portrait_parts.json`）把部件對到圖層：

| 部位 | 對照方式 | 範例 |
|---|---|---|
| `hair_style` | 關鍵字 → 髮型（前髮＋後髮兩層） | 「雙馬尾」→ `twintails`、「馬尾」→ `ponytail`、「光頭」→ 無頭髮 |
| `hair_color` | 關鍵字 → 髮色 4 階 | 「烏黑」「栗色」「淡金」「赤紅」「銀白」… |
| `eyes` | 關鍵字 → 眼型＋瞳色 | 「鳳眼」→ 細長眼、「圓溜溜」→ 大圓眼、「翠綠」→ 綠瞳、「眼罩」→ 疊加眼罩 |
| `face` | 關鍵字 → 疊加小部件 | 雀斑、疤、痣、淚痣、短鬚、絡腮鬍、紅暈；沒有對應的（鼻梁挺直）不畫 |
| 種族特徵 | 種族、血統 → 疊加部件 | 精靈尖耳、貓魅族貓耳、魔族角、玉璘族耳鰭 |
| 服裝 | 職業（冒險者）或身分（平民）→ 服裝 | 戰士鎧甲、法師長袍、商人外套、神官袍… |
| 身形 | `body`（masc / fem / andro）→ 基準頭型 | andro 用 fem 的基準 |
| 膚色 | 種族＋外貌關鍵字（「黝黑」「蒼白」）→ 膚色 4 階 | |

用關鍵字而不是逐條對應，是因為各種族、血統、自訂內容都有自己的選項文字，新增選項時不必每條都補對照。

## 2. 畫布與圖層

- 畫布 **64×64**，胸像（頭頂到胸口），**正面**（左右對稱，部分部件可以水平翻轉共用）。
- 疊圖順序（下 → 上）：

| # | 圖層 | 說明 |
|---|---|---|
| 1 | `back_hair` | 頭後方、肩後的頭髮（長髮、馬尾） |
| 2 | `race_back` | 翅膀等在身體後面的種族部件 |
| 3 | `body` | 脖子、肩膀、胸口（膚色） |
| 4 | `outfit` | 服裝 |
| 5 | `head` | 臉與耳朵（膚色），基準頭型 |
| 6 | `race_ears` | 尖耳、耳鰭（蓋住原本的耳朵） |
| 7 | `face_marks` | 雀斑、疤、痣、紅暈、鬍子 |
| 8 | `eyes` | 眼睛（眼白固定色、瞳孔換色） |
| 9 | `brows_mouth` | 眉毛、嘴（第一版只有一種中性表情） |
| 10 | `front_hair` | 瀏海、鬢髮 |
| 11 | `race_top` | 貓耳、角 |
| 12 | `extra` | 眼罩等 |

- 組圖完成後由程式在外圍加 **1px 白色描邊**，不畫在部件裡。

## 3. 換色

- 要換色的部位（膚色、髮色、瞳色、服裝主色）在部件裡用 **4 階索引灰** 畫：`#ffffff` / `#aaaaaa` / `#555555` / `#000000`，和 `tools/pixel/palette.json` 的 `ramp` 相同。
- 一張部件只能有一種可換色的材質，例如頭髮只有髮色。服裝如果有兩種顏色（主色＋飾邊），飾邊用 `fixed` 的固定色。
- 輪廓線用該材質的最暗階（第 4 階），不用純黑，符合參考圖的 selective outline。
- 調色盤：膚色約 6 種、髮色約 12 種、瞳色約 8 種，放在 `palette.json`。

## 4. 生成步驟

### 第 1 步：基準頭型（現在要做的）

1. 生成 **光頭、無表情、正面胸像** 的候選，`masc` 與 `fem` 各 8 張：
   - 提示詞方向：`pixel art, pix_merge, anime style, front view, symmetrical, bust portrait, bald head, neutral expression, closed mouth, looking at viewer, plain grey simple clothes, white background`
   - 要點：正面、左右對稱、頭在畫面上半部置中、肩膀到畫面底部、構圖拉遠到胸口（phase0 提到 `upper body, portrait` 仍然太近）。
2. 縮到 64×64 減色後，跟 1024 原圖一起推上來，讓使用者挑一張 masc、一張 fem 當基準。
3. 基準選定後，畫出各區域的遮罩（頭髮區、臉、服裝區、耳朵區），之後 inpaint 只在遮罩內重畫。

### 第 2 步：試做 3 種髮型（基準確定後）

在基準圖上 inpaint 頭髮區域生成「短髮」「長髮披散」「雙馬尾」，和基準相減抽出 `front_hair` 和 `back_hair`，縮成 64×64、灰階化，疊回基準看對不對得上。這一步確認整條管線可行，才量產其他部件。

### 第 3 步：量產

| 部件 | 數量（約） |
|---|---|
| 髮型（前＋後） | 14 |
| 眼型 | 5 |
| 臉部小部件 | 8 |
| 種族部件 | 6 |
| 服裝 | 15 |

合計約 50 個部件；每個生 4～6 張候選，約 250 張，2 小時左右。
