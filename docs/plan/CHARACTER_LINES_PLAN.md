## 2. 共通規則（照現有的非成人向角色線）

- **一～三**：Lv.5／8／11 起接，階級 D／C／B，**不標成人向**，成人內容關閉時也能玩。寫到告白、在一起為止，和第十八、十九批的戀愛線一樣。
- **四**：成人向（`adult`），和第二十三批的做法一樣。條件是那條線的三結束（任一結局旗標）、好感 40、Lv.11，由對象開頭。先約會（劇情），再是那一晚（選擇；兩個選項都是明確的親密場景，風格不同，結果都寫 `scene`）。格溫德琳是偽娘，**不標** `male_partner`。
- **每個任務都停在可以等的地方**：故事線之間玩家會去練等，所以每個任務收在「敵人退走了」「審判要等巡禮結束」這種懸念上。
- **結局是兩種代價，不是對錯**：聲望給不同的勢力、親密度給不同的人，不讓某個選項明顯賺最多。
- **任務需要的固定 NPC 設成 `no_attack`**：奧菈莉婭、格溫德琳、琥珀目前都沒有設，要補上（塞夫已經有）。和 NPC 打的戰鬥都用替身怪物。
- **報酬**照同階級的角色線（例如伊莎貝拉線）：D 約 300 白鸛、經驗 450；C 經驗 900；B 經驗 1,800～2,000；功績照同階級。
- **和其他故事線呼應**：選項用 `requires` 看別條線的旗標（見各線的「呼應」）。沒走過那條線的玩家照樣能完成。

## 3. 白百合巡禮（奧菈莉婭＆格溫德琳）

### 3.1 核心

- **兩人的魅力**：奧菈莉婭人前清冷寡言、劍術驚人，私底下邋遢又酒品極差。格溫德琳看起來柔弱順從，其實很有心機，一直在照顧她，而且「這個位置不想讓給別人」。
- **主軸**：聖騎士的巡禮要在五處聖地蓋印（聖環主殿 → 舊石橋 → 晨曦聖殿 → 兩人長大的修道院 → 回到聖環主殿受任）。兩人的出沒地點本來就是索里耶爾、晨光城、河谷鎮，剛好就是巡禮路線。主角當他們的「同行證人」（巡禮規定要有一位同行者作證），所以每一段路都有理由一起走。
- **衝突**：格溫德琳是從小被當成女孩子養大的男孩，穿著修女服。審判廷把這件事當成「欺瞞聖職」，矛頭一路從他本人延伸到養大他們的修道院。最後要解決的是**制度**怎麼看他，不是他自己有什麼不對：真理之鏡照的是靈魂，不是衣服。
- **三角變成三人**：格溫德琳一開始把主角當成搶位子的人（綠茶的手段對主角也用），奧菈莉婭喝醉時才說得出真心話。結局三個人在一起，奧菈莉婭的告白是清醒的：「這次我沒喝。」
- **酗酒不當成要治的病**（和卡蜜拉的戒酒線區隔）：喝醉的她闖禍，也說真話。三的告白刻意放在清醒的時候。

## 4. 全城跑最快的精靈（琥珀）

### 4.1 核心

- **魅力**：嘴巴停不下來、愛錢、欠揍，自稱「全城跑最快的精靈」。其實自卑又敏感，最怕被當成「可以賣的精靈」，被戳到痛處就用更多廢話岔開。
- **主軸**：精靈在人類黑市極值錢（世界書：中堅層級的精靈女性 280 白金幣、精英層級 2,500 白金幣），她從小就被追。一條追查「是誰在收購她」的線，順帶找到她的身世。
- **身世**：她母親是**霧谷**的精靈。霧谷就是「森林深處的迷霧」那條線裡，因為與人類通婚被流放了五百年的村子。三十年前，母親懷著她逃出結界，在索里耶爾外環被捕奴隊的「灰狗」殺了。迷霧之幕的塞夫晚了一步，只救下嬰兒，把她留在外環。從那之後，迷霧之幕一直暗中替她清掉靠近的捕奴者。
- **轉折**：「你以為你真的跑得那麼快？」她的驕傲建立在別人沒說出口的保護上。三要讓她第一次**不是一個人跑**，而是和主角並肩跑贏。
- **用詞要小心**：結局不用「你是我的」這類擁有的語言。她要的是「不用再跑」。
