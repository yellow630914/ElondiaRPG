## 0. 目標與原則

**一句話**：所有戰鬥單位多一條「慾望」，多一種抗性「慾望抗性」。不分職業的色情技能主要用來**把傷害轉成慾望、在隊友之間分擔慾望、依慾望給增益，或主動引爆慾望換取爆發**。戰鬥外有五項長期指標（淫亂、敏感、忍耐、順從、曝露名聲），跟服裝、奴隸、娼館、打工線、主題地下城、城鎮和 AI 敘事連動。

**原則**

1. **主力在自己人身上**。敵人的慾望抗性差異很大，骷髏、魔像根本不吃，所以強力技能圍繞友軍增益與承傷。慾望攻擊是對特定敵人的戰術，也用來營造氣氛；引爆類技能（3.4 節）把慾望轉成一般屬性的傷害，對免疫的敵人也有用。
2. **慾望是第二條生命，代價是高潮**。慾望是一個可以分攤到隊友身上的承傷池，滿了就失去一回合、扣三分之一的生命。玩法的張力在於存多少、分給誰、什麼時候引爆。
3. **玩家的自主性**。不強迫玩家帶哪種裝備、修哪個流派。**允許「戲內非自願、戲外自願」**：玩家自己選了一個可能導致非自願結果的選項（例如入住奴房），主角在故事裡可以是非自願的。這類選項標上「主角非自願」，所以「設定 → 內容篩選」照樣管得到（第 13 節）。
4. **數值由引擎算，AI 只描寫**。高潮、技能學會、數值變化都寫進報告；AI 判定只能在上限內動這些數值。
5. **照現有的內容篩選走**。「主角非自願」關掉時，敵人不用慾望攻擊（4.2 節）；`young` 特徵的怪物一律不參與（2.3 節）。
6. **可以整套關掉**。存檔規則「慾望系統」設成 0 時，戰鬥和現在一模一樣（第 14 節）。

## 1. 慾望（戰鬥中的資源）

### 1.1 規則

- 生命條下面多一條粉色的慾望條（隊伍卡、戰鬥畫面、怪物資訊）。
- **增加**：受到慾望攻擊、傷害轉成慾望、隊友分過來、狀態的持續慾望（媚毒）、主動增加慾望的技能（3.4 節）、開戰時的初始慾望。
- **減少**：每回合開始自然消退（上限的 5%，淫亂越高消退越慢，5.2 節；有「發情」類狀態時不消退）、清心類技能、分給別人、引爆。

### 1.2 慾望上限

```
慾望上限 = 30 + 3 × 等級 + 忍耐 / 2 + 裝備、特質、刺青的加成
```

- 1 級約 33，10 級約 60，20 級約 90；忍耐 100 再加 50。
- 慾望受傷的倍率另外看敏感（5.2 節），兩者分開：忍耐決定**能存多少**，敏感決定**漲得多快**。

### 1.3 高潮（我方）

主角、夥伴與我方的召喚、援軍都用這套規則。

- **觸發**：慾望到達上限。
- **效果**：
  - 停止行動一回合（新狀態「高潮」，`control: stun`；被攻擊時迴避照現有的 stun 算 0）。
  - 失去最大生命的 33%，**最多扣到剩 1**，不會因此死亡。
  - 慾望歸零，接著「餘韻」2 回合：受到的慾望 −50%，這段時間不會再高潮，避免被連續鎖住。
- **三次倒下**：一場戰鬥裡高潮第 3 次時倒下（無法戰鬥，但不算死亡、不擲死亡）。我方被這樣倒下的，戰敗成人事件的機率提高（12.1 節）。
- **為什麼不直接扣血**：被集火時，生命可能已經被打到 33% 以下，這時高潮直接扣血會讓慾望玩法太脆弱。「最多扣到剩 1 + 三次倒下」讓慾望的威脅有上限，也可以預期。
- 引爆（3.4 節）**不算**高潮：不扣生命、不計入三次。

### 1.4 高潮（敵方）

敵人**不套**我方的規則，簡化成一次傷害：

- **觸發**：慾望到達上限。
- **效果**：受到**最大生命 33% 的真實傷害**（不看抗性、減傷、護盾，可以致死），慾望歸零。不停止行動、沒有餘韻、不算次數。
- 所以一個滿血的敵人，大約高潮三次會倒下；先用一般攻擊打傷，再用慾望收尾也可以。
- 層主也一樣是 33%（實作時看平衡模擬，太強再給層主另外的比例，第 17 節）。
- 敵人用引爆時照引爆的規則（3.4 節）。

### 1.5 慾望勝利

**最後一擊是高潮傷害**的敵人，叫**慾望勝利**：

- 戰報與日誌另外記一筆（「淫犬 在高潮中屈服」），報告的 `lust_victory` 列出被這樣打倒的敵人。報告帶 `adult_scene`，由「成人場景正文」寫勝利的場面，主角是佔上風的一方。
- 獎勵：被慾望打倒的敵人，戰利品多一份「征服」掉落（淫獸的媚腺、魅魔的香精這類，鍊金與淫器合煉的素材，12.4、12.11 節），經驗照常。
- 淫獸的慾望抗性都偏低（第 2 節），所以主題地下城（第 10 節）是慾望勝利最常出現的地方。

### 1.6 戰前與戰後

- **戰前**：已經「發情」的人開戰時帶 20% 慾望；淫亂高的人也帶一些（5.2 節）；有 `rut` 特徵的怪物開戰時帶慾望。地下城成人事件留下的狀態因此第一次影響戰鬥。
- **戰後**：慾望 ≥ 50% 的人得到「發情」；這場高潮過的人得到「餘韻」或「虛脫」（現有的 `companions.json` 的 `conditions`）。主題地下城裡慾望不清空，跨戰鬥保留（10.4 節）。

### 1.7 接到哪裡

- `Combatant`（`src/engine/combat.ts:56`）加 `lust`、`lustMax`、`climaxes`（只有我方用來算三次倒下）。`fromCharacter`、`fromEnemy` 計算初始值。
- 新狀態（`statuses.json`）：`climax`（stun，只給我方）、`afterglow_combat`（受到慾望 −50%、不會高潮，只給我方）、`lust_dot`（媚毒）、`spent`（引爆後的脫力，3.4 節）。`StatusDef` 加 `lust_dot`、`lust_mult`、`no_climax`。
- 高潮的檢查放在慾望增加的地方（`dealDamage` 等），依 `side` 分成我方（1.3 節）與敵方（1.4 節）兩條路；敵方的真實傷害直接扣 `hp`，不經過 `dealDamage` 的倍率與減傷。
- `startTurn`（combat.ts:1378）：自然消退、持續慾望。
- `finishCombat`（combat.ts:1537）：慾望轉成非戰鬥狀態、慾望勝利的掉落、記下高潮次數給戰敗事件用。
- 有人高潮或慾望勝利的戰鬥報告帶 `adult_scene`，走「成人場景正文」的模型來源（`adultSceneOf`，`src/narrator/prompt.ts:202`）。

## 2. 慾望抗性

### 2.1 做成第 14 種傷害屬性

`data/rules/damage_types.json` 加 `lust`（魅惑），自成一個群組，**不受 `all` 影響**（所以「全屬性抗性」的裝備不會順便擋慾望）。

- 抗性、增傷、免疫／抵抗／弱點標籤全部沿用 `resist`／`offense`（`AffinityMap`）。
- `dealDamage`（combat.ts:939）遇到 `lust` 時改成加慾望、不扣生命；防具減傷與狀態減傷不擋 `lust`。
- 編輯器的抗性欄位、怪物表（`npm run docs:gen`）自動多一欄。

### 2.2 怪物：依種類的預設值，個別覆寫

`kind` 目前只拿來選圖示，改成也決定預設的慾望抗性。`enemies.json` 個別寫了 `resist.lust` 就覆寫。

| 種類（數量） | 預設 | 例外 |
|---|---|---|
| undead 不死（47） | 免疫 | 吸血鬼、夢魘類覆寫成 0 或抵抗，而且有色情技能 |
| construct 構裝（40） | 免疫 | |
| elemental 元素（22） | −0.75 | |
| spirit 精魂（63） | −0.5 | 夢魔類 0 |
| plant 植物（32） | 0 | 淫植 +0.5 弱點 |
| beast 野獸（105） | 0 | 有 `rut` 的 +0.25；淫獸 +0.5 |
| humanoid 人型（129） | 0 | 聖職者 −0.25 |
| demon 惡魔（42） | 0 | 魅魔類 −0.5（擅長也耐） |
| fey 妖精（10） | +0.25 | |

怪物特徵（`monster_traits.json`）：`rut` +0.25 並帶初始慾望；`frenzied` −0.25；`old` −0.25。

### 2.3 安全規則

帶 `young` 特徵的怪物（戰敗事件已經排除它們）**一律免疫，而且不放色情技能**，色情技能也不能以它們為目標。主角、夥伴、NPC 都是成年人（現有的設定）。

### 2.4 角色的慾望抗性

```
慾望抗性 = 種族 + 特質 + 裝備附魔 + 信仰（每點信仰修正 −0.05）
```

- 種族特質：精靈 −0.1、貓魅族 +0.15（也是擅長色情技能的種族）、魔族的魅魔血統 −0.25。`perks.json` 的 `resist` 本來就能寫任何屬性。
- 禁慾派的特質給 −0.25～−0.5（12.2 節）。
- 敏感另外乘在上面（5.2 節），不寫進抗性表，避免和 `all` 的計算混在一起。

## 3. 技能

### 3.1 攜帶上限（整個技能系統）

**所有角色**（主角、夥伴、奴隸）的所有技能都受這條限制，不只色情技能。

- **學會**和**攜帶**分開：角色學會的技能都在「技能庫」，戰鬥中只能用**攜帶中的**技能，最多 12 個。
- **上限**：存檔規則 `skillLoadout`，預設 12，範圍 6～30，0 表示不限（`gameRules.ts` 的 `RULE_DEFS`，和其他存檔規則放在一起，設定的「這個存檔的規則」可以改）。
- **計算範圍**：技能（skill）、法術（spell）、色情技能都算；**戲法不算**，因為戲法本來就有自己的上限（`maxCantrips`）。怪物不受限制。
- **什麼時候可以換**：戰鬥以外隨時可以換（隊伍視窗的能力頁，每個技能一個「攜帶」勾選）。不限制在休息時才能換，避免變成麻煩的操作。
- **學新技能時**：沒滿就自動攜帶；滿了就放進技能庫，日誌提示可以去換。
- **舊存檔**：讀檔時技能超過上限的角色，依「最近學會的優先」自動選 12 個攜帶，其他放進技能庫，日誌提示一次。
- **AI**：判定（`pcDetail`）和隊伍資料只列攜帶中的技能，另外註明「技能庫還有 N 個」。
- 程式：`Character` 加 `loadout: string[]`（沒有這個欄位時等於全部攜帶，方便舊資料）；`fromCharacter` 只帶 `loadout` 裡的技能；升級三選一照舊。
- 這條**在慾望系統關閉時也生效**，因為它是技能系統本身的規則。上限設成 0 就和現在一樣。

### 3.2 色情技能

- `abilities.json` 用假職業 `lewd`（比照怪物技能用 `monster`）。`learnable`、`learnAbility`（`character.ts:311`、`effects.ts:356`）放寬成「自己的職業，或 `lewd`」。
- **不進升級的三選一**，只從這些管道學：奴隸（第 7 節）、娼館（第 8 節）、打工線（第 9 節）、主題地下城的掉落與技能書（第 10 節）、淫鬥場（12.10 節）、事件（`ability`、`ability_pool` 效果）。
- 主要屬性是**魅力**（`attr: "cha"`），施法類用魅力豁免。
- 和職業技能共用攜帶上限（3.1 節），所以要取捨：色情構築會擠掉一部分職業技能。

### 3.3 流派

技能有兩個分類：**種類**說技能做什麼（3.4 節），**流派**說技能屬於哪條修行路線。流派借用 I13 世界書的七流派。

- **入門**：每個流派有一個入門特質（12.2 節），從秘法書、老師或教團學到。學會入門之後，那個流派的技能才會出現在各種學習管道裡。沒有流派限制的通用技能（例如「媚眼」）不需要入門。
- **不限流派數量**。技能數量已經由攜帶上限控制，流派不另外限制。
- **流派和態度無關**：流派只決定戰鬥方式，不決定角色願不願意，所以流派不影響順從。
- **玩家自主**：任何流派都不強迫穿戴特定裝備；雙面效應（6.3 節）是加分，不是條件。

| 流派 | 偏向 | 戰鬥定位 | 招牌機制 |
|---|---|---|---|
| 隸從派 | 奴隸系 | 承傷、護主 | 認主：有主人時全效，沒有時一半效果（7.1 節） |
| 刑罰派 | 奴隸系 | 承傷、反擊 | 越受傷越強；傷害轉慾望的效率最高 |
| 束縛派 | 奴隸系 | 防禦、穩定 | 拘束具的雙面效應最強 |
| 縱欲派 | 淫亂系 | 增益、爆發 | 引爆、慾望越高越強 |
| 肉體派 | 淫亂系 | 續戰 | 敏感與忍耐直接轉成被動加成 |
| 獸蟲派 | 淫亂系 | 召喚、寄生 | 寄生物在戰鬥裡出手（12.3 節） |
| 禁慾派 | 反制 | 抗性、淨化 | 慾望抗性高、清心；不能和縱欲派同修 |

奴隸系與淫亂系沒有硬性區分，流派自由搭配，構築決定偏哪一系。

### 3.4 種類與技能清單

| 種類 | 對象 | 用途 |
|---|---|---|
| **慾望攻擊系** | 敵人 | 對低抗性的敵人控場、加速高潮、慾望勝利 |
| └ **引爆** | 敵人 | 把**自己的**慾望轉成元素或物理傷害；高風險高報酬 |
| └ **自我增慾** | 自己、隊友 | 主動增加慾望，替引爆、依慾望的增益充能 |
| **輔助系** | 友軍、自己 | 依慾望給增益、分擔慾望 |
| **承傷系** | 自己、友軍 | 替友軍承傷、傷害轉慾望、吸收別人的慾望 |

**引爆的共同規則**

- 消耗自己全部的慾望（有的技能要求慾望至少 50%）。
- 傷害 = 消耗的慾望 × 係數 + 魅力修正，屬性看技能（火焰、閃電、神聖、暗影、鈍擊……），**不是** `lust`，所以對慾望免疫的骷髏、魔像也有用。
- 用了**立刻結束回合**，下一回合不能行動（狀態「脫力」，`control: stun`，被攻擊時迴避算 0）。
- 不算高潮：不扣生命、不計入三次。所以在快高潮的時候引爆，是避開高潮的手段，也是傷害最高的時機。
- 敵人也可以有引爆技能（魅魔類），AI 只在慾望 ≥ 70% 時用。

數值都是起始值。「來源」對應學習管道。

### 3.5 需要的新機制

| 欄位（建議） | 放在 | 作用 |
|---|---|---|
| `damage[].type: "lust"` | 能力 | 慾望傷害 |
| `convert: { from: "hp", to: "lust", ratio }` | 狀態 | 受到的生命傷害有一定比例改成慾望 |
| `guard: { ally, ratio }` | 狀態 | 代替指定友軍承受傷害 |
| `lust_transfer: { amount \| ratio, to }` | 能力 | 慾望在自己、友軍、敵人之間移動 |
| `lust_gain` | 能力 | 增加自己或友軍的慾望（自我增慾） |
| `lust_cost` | 能力 | 消耗慾望才能用 |
| `burst: { type, mult, min_ratio, area }` | 能力 | 引爆：消耗全部慾望換傷害；結束回合、附加「脫力」 |
| `lust_scale: { stat, per, max }` | 狀態 | 依目前慾望比例給增益 |
| `on_climax: { heal, ap_gain, apply, to }` | 狀態或特質 | 高潮時觸發 |
| `requires_lust: { min }` | 能力 | 慾望到某個比例才能用 |

大多是 `startTurn`、`dealDamage`、`addStatus` 和行動結算裡的分支。

### 3.6 核心循環

```
敵人打承傷的人 ──→ 痛即是悅：傷害一半變慾望
                         ↓ 獻身／情熱傳染：慾望在隊伍裡移動
淫亂系的人慾望上升 ──→ 渴望之舞：依慾望增傷
                         ↓ 快滿的時候
       ┌─ 引爆（情焰、極樂之光）：慾望變成傷害，下回合脫力
       └─ 解放：慾望變成全隊治療
                         ↓
                    慾望歸零，再累積（自我挑逗加速）
```

平衡的槓桿：轉換比例、慾望上限、引爆係數、脫力的長度。敵人的慾望攻擊會把你的慾望推過頭，打亂節奏。

### 3.7 跟現有職業的配合

- **吟遊詩人**的施法屬性就是魅力，色情技能最順手。
- **聖騎士、牧師**的淨化（`cleanse`）也能清慾望；「清心」是對抗淫獸的反制。
- **武僧**適合禁慾派。
- **野蠻人**狂暴時不消退慾望，依慾望增傷，適合搭配引爆。

## 4. 怪物

### 4.1 誰有色情技能

| 有 | 技能方向 |
|---|---|
| 魅魔、夢魔 | 魅惑之吻、傾國一笑、引爆 |
| 觸手、史萊姆、淫植 | 拘束 + 媚毒、範圍慾望 |
| 有 `rut` 的野獸（45 隻） | 撲倒（慾望 + 倒地） |
| 盜賊、捕奴隊、邪教徒 | 下藥（媚毒投擲物）、羞辱（淫語）、12.12 節的手段 |
| 吸血鬼 | 魅惑凝視、吸血帶慾望 |
| 寧芙、樹精 | 迷魂歌（現有的 `siren_song` 改成帶慾望） |
| 淫獸（第 10 節） | 各自的招牌行為（10.3 節） |

骷髏、殭屍、幽靈、魔像、元素、沒有 `rut` 的一般野獸不給；帶 `young` 特徵的一律不給。

### 4.2 敵人 AI

`chooseAction`（combat.ts:1481）：

- 慾望攻擊的分數乘上目標的慾望受傷倍率（免疫 = 0，不浪費回合）。
- 目標慾望 ≥ 70% 時 +1（收割快高潮的人）。
- `rut` 特徵偏好慾望攻擊（特徵的 `ai.prefer` 加 `lust`）。
- **「主角非自願」關掉時，敵人的慾望攻擊、媚毒、引爆全部從候選裡拿掉**。剩下的技能照常；什麼都沒剩就用武器普通攻擊（沒有武器的怪物用 `weapon` 的預設徒手）。這個判斷用 `content.ts` 現有的 `pc_unwilling`。

### 4.3 淫獸與慾望勝利

- 淫獸的慾望抗性偏低、攻擊偏慾望，雙方在慾望上互相比拼；**不做**「高潮反而回血」的特性。
- 打淫獸時用慾望攻擊系是正解：牠們高潮時受到最大生命 33% 的真實傷害（1.4 節），用高潮收尾就是慾望勝利（1.5 節），有專屬的勝利場面與「征服」掉落。

## 5. 長期指標（五項）

I13 世界書的「開發度」有十幾個維度，挑出和戰鬥有關的，併進原本的淫亂、順從、曝露名聲，合計五項。

| 指標 | 是什麼 | 併進來的開發度維度 |
|---|---|---|
| **淫亂** | 對性的渴求與開放 | 發情度、心態裡的「主動尋求」 |
| **敏感** | 身體對刺激的反應 | 敏感度，以及各部位的開發（只做成一個數字，身體細節交給 AI 的成人場景） |
| **忍耐** | 承受刺激與拘束的能力 | 刺激忍耐、拘束忍耐、脫縛 |
| **順從** | 服從的習慣 | 心態（被迫者的五個階段） |
| **曝露名聲** | 被多少人看過、傳得多開 | 表情控制（在人前的反應）只寫進描述 |

### 5.1 戰鬥效果

| 指標 | 戰鬥 | 取捨 |
|---|---|---|
| 淫亂 | 開戰的初始慾望（每 20 點 +5%）；自然消退變慢；自我增慾的技能 +25%（60 以上） | 引爆、增益構築的好幫手；對承傷的人是負擔 |
| 敏感 | 受到的慾望 × (0.75 + 敏感 / 200)，從 ×0.75 到 ×1.25；依慾望的增益 +（肉體派） | 越敏感越快高潮，但也越快充滿 |
| 忍耐 | 慾望上限 + 忍耐 / 2；雙面效應的負面減輕；脫縛檢定 + | 純粹的好處，所以最難漲（5.3 節） |
| 順從 | 承傷系的轉換率 +（每 20 點 +5%）；隸從派的效果 + | 和主人、調教綁在一起 |
| 曝露名聲 | 在那個地區戰鬥時，慾望攻擊的傷害 +（每 20 點 +1） | 只在有名的地方有用 |

### 5.2 分段

| 數值 | 淫亂 | 敏感 | 忍耐 | 順從（被迫者） | 順從（自願者） | 曝露名聲 |
|---|---|---|---|---|---|---|
| 0～19 | 純情 | 遲鈍 | 初萌 | 恨與反抗 | 生疏 | 沒人知道 |
| 20～39 | 好奇 | 略鈍 | 漸成 | 懲罰與絕望 | 配合 | 有些傳聞 |
| 40～59 | 開放 | 正常 | 精熟 | 麻木與認命 | 習慣 | 小有名氣 |
| 60～79 | 淫蕩 | 敏感 | 入微 | 依賴與習慣 | 忠誠 | 遠近馳名 |
| 80～100 | 淫亂 | 極敏 | 隨心 | 真心臣服 | 奉獻 | 人盡皆知 |

- 順從看角色是被迫還是自願成為奴隸（7.1 節的主動、被迫認主），用不同的分段名稱。被迫者照世界書的原則：逐步、可逆、因人而異；麻木 ≠ 接受。
- 每一段可以像寄生物的階段（`parasites.json` 的 `stage_effects`）一樣，帶被動的檢定修正，或自動給特質（例如淫亂 60 以上得到「食髓知味」）。

### 5.3 怎麼漲、怎麼降

| 指標 | 漲 | 降 |
|---|---|---|
| 淫亂 | 親密場景、娼館工作、高潮、自我增慾的技能、穿成人向服裝（每天少量） | 長時間沒有親密場景時慢慢降；神殿的淨化 |
| 敏感 | 調教（言語、魅惑課程）、寄生物、媚藥、被慾望攻擊高潮 | 很慢；禁慾派修行 |
| 忍耐 | 調教（忍耐、束縛課程）、穿著拘束具的天數、高潮後撐過戰鬥 | 不降（訓練出來的） |
| 順從 | 主人事件選屈服、調教、強制裝備、契約的 `obedience` 上升 | 抵抗、逃跑成功、自由的日子 |
| 曝露名聲 | 在城鎮穿曝露的服裝（6.1 節）、娼館工作、公開的事件、在城鎮附近的戰敗事件 | 每天淡掉 1 |

- 忍耐的漲法刻意慢，因為它全是好處。
- 效果類型加 `lewdness`、`sensitivity`、`endurance`、`submission`、`exposure`（`effects.ts` 的 `EFFECT_TYPES`、`storyMods.ts:71` 的 `STORY_EFFECTS`），事件、任務、主人事件都能用。

### 5.4 曝露名聲

- **依地區、依隊伍成員**：`state.exposure[角色 id][地區]`。只有主角和夥伴有，一般 NPC 沒有。相鄰地區每天傳過去一點（打折），離開那個地區就慢慢淡掉。
- **累積速度看魅氣濃度**（12.6 節）：濃度 1 的地方穿一點就被議論（累積快），濃度 4 的地方見怪不怪（累積慢，但成人城鎮事件多）。
- **效果**：
  - 城鎮的成人事件機率 × (1 + 曝露名聲 / 100)（`townEvents.ts` 的 `chance`）。
  - 新的城鎮事件只在曝露名聲高時出現：被認出來、被跟蹤、粉絲送禮、勒索、私下邀約、被請去當模特兒。
  - 城門盤查（`security.ts`）：搜身事件的機率上升；有的守衛反而放水。
  - 聲望交叉：教廷城鎮扣教廷的聲望，血羽城堡反而加。
- 主角身分標籤可以加一個「放蕩的貴族」：曝露名聲不影響聲望。

### 5.5 順從和契約的 `obedience`

- 契約的 `obedience`（`ContractRef`，`types.ts:288`）是主人加的、暫時的檢定懲罰，最多 8。順從是角色自己的性格，契約解除之後還在。
- 連動：`obedience` 每上升一次，順從 +1；主人事件的「屈服」選項依順從加值，「抵抗」選項依順從減值。

### 5.6 NPC 的預設值

依 `npc_tags`：`prostitute` 淫亂 50～80、敏感 50；`slave` 順從 40～80、忍耐 40；`noble`、`priest`、`bishop` 淫亂 0～20（成人向的固定 NPC 可以表裡反差，個別寫）；`villain` 淫亂 40～70；其他依性格隨機。`NpcDef`（`data.ts:74`）加選填的 `lewd: { lewdness, sensitivity, endurance, submission }`，編輯器的固定 NPC 頁多四格。

### 5.7 給 AI

- 敘事（`protagonistText`，`character.ts:419`）：分段的文字，例如「淫亂：開放；敏感：敏感；忍耐：漸成；順從：配合；在這一帶小有名氣」。**只在成人向的日誌加**（和成人向世界書同一個判斷，`compose.ts:57`）。
- 判定（`pcDetail`，`judge.ts:79`）：數值加分段。
- 隊友與 NPC（`partyLines`、`formatContext`）：同樣的分段。
- AI 判定的效果上限：每項每次 ±3（比照聲望 ±2、親密度 ±8）。
- 主動行動會受影響：淫亂高的主角「獻媚」「誘惑」更容易成功，曝露名聲高時對貴族「唬騙」更難。

## 6. 服裝與裝備

### 6.1 曝露度與加值

- **底材加曝露度 0～3**（`gear.json` 的 `bases`）：常規 0，二次元 0～1（兔女郎裝 2），成人向 2～3，網襪、乳貼 3。曝露度**看最外層**：外衣蓋住內衣時，內衣的不算（可以借刺青被遮住的判斷，`coveredTattoos`）。
- **物品加 `lewd`、`lust` 加值**（和 `attrs` 同一層）：

```jsonc
"gear": { "attrs": { "cha": 2 }, "lewd": { "lewdness": 5, "sensitivity": 0, "endurance": 0, "submission": 0 }, "lust": { "max": 10, "resist": 0.1 } }
```

  - `lewd` 是**穿著時的有效值加成**，脫掉就沒了；上限單件 ±10、全身 ±20（和屬性加值的上限同一套做法，`character.ts:82`）。
  - 曝露名聲**不**用加值，由「穿著在城鎮裡走」實際累積（5.4 節）。
  - `lust` 是慾望上限與慾望抗性。
- **底材的預設**：二次元 → 曝露度 1；成人向 → 淫亂 +5、曝露度 2；束縛 → 順從 +5、忍耐 +3。獨特物品（打工線的結局裝備）個別寫。
- **附魔**：「魅惑」（色情技能 +1、慾望傷害 +10%）、「清心」（慾望抗性）、「餘韻」（高潮後回復）。走現有的附魔點數。
- **主人強制裝備**（`forcedGear.ts`，現有）：強制裝上的物品帶順從加成。

### 6.2 雙面效應

拘束具、調教道具、淫服**平常是負面效果，戰鬥中反轉成增益**，只對修了流派的人有效（3.3 節）；沒修的人只吃負面效果。是否穿戴完全由玩家決定。

- **平常**：非戰鬥的檢定減值（和非戰鬥狀態同一套 `check_penalty`）。
- **戰鬥中**：

| 平常的負面 | 戰鬥中的增益 |
|---|---|
| 限制行走（高跟鞋、腳鍊） | 先攻 +、行動點回復 |
| 束縛雙手（手銬、單手套） | 減傷 +、不會被繳械 |
| 遮住視線（眼罩） | 迴避 +、免疫目盲類 |
| 持續刺激（調教道具） | 法術環或行動點回復 |
| 全身拘束（繩縛、繩衣） | 全屬性小幅 + |

- **負面越大，增益越大**：`restraint` 底材加 `bind: 1～3`（輕、中、重）。忍耐高的人平常的負面減輕，增益不變。
- **流派契合 ×1.2**：拘束具配束縛派或刑罰派、調教道具配肉體派、曝露的淫服配縱欲派、保守的淫服配禁慾派、寄生類配獸蟲派。認主中的隸從派 ×1.4（取代 ×1.2）。
- **鎖**（12.13 節）：鎖上才生效，鎖越好倍率越高（白 ×1、藍 ×1.1、符文 ×1.2、黃 ×1.3）。裝備的 `locked` 擴充成記鎖的等級。

## 7. 奴隸

### 7.1 認主

- 隸從派的技能與被動：**有主人時全效，沒有主人時一半效果**（`ContractRef.master` 有沒有值）。
- 主人在同一隊時再加成（「奴之誓」）。主角當主人時，主角的奴隸夥伴吃到這個加成。
- **主動認主與被迫認主**：自願簽的契約算主動，戰敗、被捕而簽的算被迫。主動認主的事件**不**標「主角非自願」，所以關掉那個篩選的玩家也能玩隸從派。順從的分段名稱依這個區分（5.2 節）。
- **不做契約深化**。

### 7.2 主角當奴隸：主人是工具人

系統上主人只是讓隸從派生效的條件，主角保有主導權；**敘事上主人仍然主導**。

- **親密度高時隨時解約**：和主人的親密度 ≥ 60 時，契約面板（`ContractDialog.vue`）的「談判解約」直接成功，不用擲骰、不用付錢。
- **換主人**：親密度 ≥ 60 時多一個「換主人」：從認識、親密度 ≥ 40、身分允許的 NPC 裡挑一位，契約轉給他（用現有的 `change_master` 效果）。
- **敘事**：報告註明「這是主角的要求，寫成主人准許、主人安排或把主角轉讓出去」，AI 寫成主人做的決定。寫進成人向世界書的常駐條目或敘事規則。
- 親密度不夠時照現有的規則（談判、逃跑、找主人）。

### 7.3 學技能

- **主角或夥伴當奴隸**：主人事件的結果可以給色情技能（`ability`、`ability_pool`，11.3 節）。主人的身分標籤（`master_tags`）決定傾向：商人教侍奉，捕奴隊教忍耐，貴族教禮儀和魅惑。
- **主角當主人**：從調教學（7.4 節）。

### 7.4 調教（主角對自己的奴隸）

奴隸的角色詳情（現在只有「解除契約」）加「⛓️ 調教」：

1. 選一個**課程**。
2. 抽一個這個課程的**調教事件**（格式同主人事件：開場、三個選項、檢定、結果、`adult_scene`）。
3. 主角擲檢定（魅力，依課程換成力量或智力），DC = 課程基礎 − 奴隸順從 / 10，親密度很低時 +2。
4. 結果：五項指標、親密度的變化，有機會學會這個課程的技能。**進度**：同一個課程成功 N 次，保證學會一個還沒學的。
5. 花 2～4 小時；家裡有調教室時加值（12.5 節）。

| 課程 | 主要指標 | 技能方向 |
|---|---|---|
| 侍奉 | 順從 + | 肉盾侍奉、縱慾共鳴 |
| 忍耐 | 忍耐 + | 忍耐、調教的身體 |
| 疼痛 | 順從 +、忍耐 +、親密度 − | 痛即是悅 |
| 言語 | 淫亂 +、敏感 + | 淫語、媚眼 |
| 露出 | 曝露名聲 +（要帶出門） | 寬衣 |
| 束縛 | 忍耐 +、順從 + | 跪伏乞憐 |
| 魅惑 | 淫亂 +、敏感 + | 魅惑之吻、淫念冥想 |

- 不另外加「NPC 非自願」的篩選。
- 親密度太低時調教會反彈（逃跑、怨恨的冒險記憶）。

### 7.5 擴充主人事件

- 現有 37 件；新增性訓練、展示、出借、競賽之類的事件，不一定掛技能。
- 選項的結果可以用五項指標與 `ability_pool` 效果。
- 「屈服」依順從加值、「抵抗」依順從減值（5.5 節）。

### 7.6 奴隸市場

奴隸的身價受順從、淫亂、敏感、忍耐、會的色情技能影響；商品說明列出這些。主角出售自己時同樣依自己的數值定價。

## 8. 娼館

### 8.1 打工事件

- 打工結束時擲一次：機率 = 15% + 淫亂 / 10%（最多 30%）。
- **沒擲到**：照舊領錢。
- **擲到**：從娼館的打工事件庫抽一件。每件事件掛一個或幾個技能（`teaches`），**只抽打工的人還沒學過的技能所掛的事件**；也有不掛技能的事件。結果照常領錢，加上學會技能與指標變化。

### 8.2 受訓

- 娼館多一項「🎓 受訓」，付錢給老鴇，花 4～8 小時。
- **一定**從受訓事件庫抽一件沒學過技能的事件，學會那個技能。
- 全部學過時可以重複：抽到學過的事件，改給淫亂和一點錢（「複習」）。**不做**技能熟練度。
- 費用與 DC 依技能稀有度；頭牌等級高（8.3 節）時便宜。

### 8.3 頭牌等級

- 每個角色在**每一家娼館**各自累積：工作一次 +1，打工事件 +2。
- 等級（例如 0、5、15、30、60 次）：見習 → 熟手 → 紅牌 → 頭牌 → 花魁。
- 效果：時薪提高（每級 +15%）、解鎖貴客事件（打工事件庫的事件可以要求 `rank_min`）、解鎖更稀有的受訓技能。
- 存在 `state`：`brothelRank[角色 id][設施 id]`。

### 8.4 光顧娼婦時學技能

- `patron`（現有）成功時，如果對象是**固定的娼婦 NPC** 且親密度 ≥ 40，額外有機會教主角一個技能。
- 她的淫亂越高，能教的技能稀有度越高（40 以下普通、60 以上稀有、80 以上史詩）。
- 每位娼婦有自己會教的技能清單（`NpcDef` 加 `teaches`），學完就不再教。

### 8.5 提議夥伴去工作

- 現在只有奴隸可以派去（`work.ts:28`）。改成**任何夥伴都能提議**：
  - 奴隸：照舊，直接派。
  - 自由的夥伴：主角擲魅力，DC = 15 − 對方淫亂 / 10 − 親密度 / 25 + 身分修正（貴族、神官 +4；娼婦 −4）。成功就去，收入對分；失敗親密度 −2，大失敗 −6 並記一段冒險記憶。
- 夥伴在娼館工作、受訓時也會觸發事件、學技能，用**他自己的**數值和沒學過的技能清單（「誰擲骰就用誰的」，和現在派奴隸工作一樣）。
- 自由的夥伴是同意了才去，所以只看「男性對象」等現有標籤。

## 10. 魅魔的遊樂園（主題地下城）

### 10.1 概念

魅魔們經營的「遊樂設施」：一座固定地形的入口廣場，通往數個主題園區。每個園區是一座獨立的地下城（3 層），入口統一。

- **位置**：南境，血羽城堡附近（魅魔宮廷所在、魅氣濃度最高的一帶）。名稱草稿：「緋夢樂園」。
- **入口廣場**：固定地圖（特殊地圖，`special_maps.json` 的 `grid`），`peaceful` 的室內，有：
  - 魅魔接待員（固定 NPC）：說明規則、賣通行證、兌換集章獎勵。
  - 小賣店：慾望藥劑、清心茶、成人向服裝（商店擺在地圖上，[TRADE](../TRADE.md)）。
  - 休息處（安全房）：長休清空慾望。
  - 每個園區一條通道，走進去就是那個園區的第一層。
- **集章**：打倒每個園區的最終層主蓋一個章；集滿換獨特獎勵（遊樂園限定的裝備、稀有色情技能書）。

### 10.2 園區

每個園區依**怪物種類**區分，層數與等級固定：第一層 5～7 級、第二層 8～10 級、第三層 11～13 級。

| 園區 | 怪物 | 主題 | 專屬戰敗結果 |
|---|---|---|---|
| 淫獸牧場 | 淫獸（beast） | 圍欄、草原、獸舍 | 被關進獸舍當「展示動物」一晚，早上被放回廣場 |
| 蟲之溫室 | 淫蟲、史萊姆 | 溫室、黏液池 | 被當成溫室的苗床，留下寄生種子（接到現有的寄生物） |
| 觸手水族館 | 觸手、水棲淫獸 | 水道、展示水槽 | 被放進展示水槽給遊客觀賞 |
| 淫植花園 | 淫植（plant） | 迷宮花園、溫泉 | 被花苞吞進去，困上半天，帶著「發情」被吐出來 |
| 夢魔劇場 | 魅魔、夢魔（demon、spirit） | 舞台、後台、觀眾席 | 被拉上舞台當表演的主角，曝露名聲大增 |

- 專屬戰敗結果取代一般的戰敗事件（`defeat.ts`），一樣受「主角非自願」與 `defeatAdult` 設定管。關掉時照一般的戰敗規則（被送回入口廣場）。
- 戰敗後一律回到入口廣場（不是血羽城堡），這趟撿到的東西照存檔規則處理。
- 園區之後可以再加（例如「拘束機關屋」：人型的魅魔玩偶），因為每個園區就是一座地下城加一條通道。

| 吞噬花 | 花園 | 吞入：被吞的人不能行動，打倒花才出來 |
| 菌舌寶箱 | 全部 | 擬態寶箱：打開時變成戰鬥 |
| 魅魔舞者、夢魔 | 劇場 | 魅惑、引爆；劇場的層主是魅魔女王 |

### 10.4 規則

- **魅氣**：在園區裡慾望**跨戰鬥保留**，每走一段路慢慢增加；入口廣場的休息處長休才清空。
- **陷阱**：色情陷阱，觸發現有的地下城成人事件（`maybeDungeonEvent`），或留下媚毒、發情，下一場戰鬥帶著慾望開場。每個園區另外加幾件專屬事件。
- **寶箱**：`gear.json` 的 `chests` 現在只依層，加「依地下城覆寫」。內容：成人向服裝（帶 `lewd`、`lust` 加值）、色情技能書、打工線獨特技能的技能書（稀有）、慾望藥劑。
- **掉落**：怪物的 `loot` 加色情技能書；每個園區的最終層主保證一本。
- **「主角非自願」關掉時**：怪物改用普通攻擊（4.2 節），陷阱的成人事件照現有規則過濾。魅氣照常，因為進園區是玩家自己的選擇。

### 10.5 接到哪裡（要做的技術工作）

- **3 層、沒有周邊的地下城**：現在 `dungeonDepth`（`data.ts:918`）只有 4 或 5 層，而且第 0 層是周邊。要讓園區只有淺、中、深三層，第一層的出口通到入口廣場（特殊地圖），不經過周邊。
- **入口廣場**：`special_maps.json` 一張固定地圖，`location` 設成遊樂園。現在的通道（`connections`）只能接城鎮區塊與固定特殊地圖，**不能接地下城**（地下城每次重新生成，見 [SPECIAL_MAPS](../SPECIAL_MAPS.md) 第 4 節）。要加一種通道的另一頭：「某座地下城的第一層入口」（例如 `to: "dungeon/<園區 id>"`），走上去等於從入口進那座地下城；第一層的出口反過來回到廣場的通道格。
- **地點**：`geography.json` 的 `locations` 加遊樂園（給旅行與地圖用）和各園區（`type: dungeon`）；園區不出現在旅行目的地，只能從廣場進。
- **遭遇**：`enemies.json` 的 `encounters[園區 id]` 的 `shallow`、`middle`、`deep` 與層主。
- **戰敗**：`defeat.ts` 依地下城選專屬的戰敗結果；`specialMaps.ts` 的倒下規則改成回到廣場。
- **公會**：園區要不要發清剿、層主委託，照 W4（依每一層的怪物）自動算，不另外處理。

### 10.6 技能書

新的物品類型 `skill_book`（`items.json`）：用了就學會一個技能，誰都能用（色情技能書要能學 `lewd`；打工線的技能書讓夥伴也學得到）。

## 12. 其他連動的系統

全部要做，除了奴欲心經與殺手奴會。

### 12.1 戰敗事件

- 這場戰鬥裡我方的高潮次數，提高「敵人起意」的機率（`defeat.ts`）。
- 我方有人「三次倒下」（1.3 節），即使隊伍還有人站著，也可以觸發戰敗事件。
- 戰敗事件的結果可以改五項指標。
- 敵人的類型決定事件的走向（12.12 節）。

### 12.2 流派特質

每個流派一個入門特質加一個進階特質（`perks.json`，`category: "lewd"`）：

| 流派 | 入門（範例） | 進階（範例） |
|---|---|---|
| 隸從派 | 可以學隸從派技能 | 痛即是悅的轉換率 +25% |
| 刑罰派 | 可以學刑罰派技能 | 受到暴擊時一半的傷害轉成慾望 |
| 束縛派 | 可以學束縛派技能；拘束具的雙面效應生效 | 穿著拘束具時減傷 +1、慾望上限 +10 |
| 縱欲派 | 可以學縱欲派技能 | 引爆的傷害 +20% |
| 肉體派 | 可以學肉體派技能 | 慾望 ≥ 50% 時每回合回復生命 |
| 獸蟲派 | 可以學獸蟲派技能 | 馴服的寄生物在戰鬥中出手（12.3 節） |
| 禁慾派 | 慾望抗性 −0.25；不能修縱欲派 | 淫亂的增加減半；清心類技能 +50% |
| 露出派 | 可以學露出相關的技能 | 曝露名聲每 20，慾望傷害 +1 |

入門特質可以在教團、修會受訓（`train`），或從秘法書、事件取得。

### 12.3 刺青、寄生物、淫紋

- 刺青店多幾種淫紋圖樣（腹部、腰後），給慾望上限、色情技能加值。
- 寄生物的侵蝕度每 10 點，淫亂 +1、敏感 +1。`succubus_mark` 每個階段給一個色情技能（共生給「魅惑之吻」，支配給「傾國一笑」但會失控）。
- 馴服的寄生物「每次長休觸發一次」變成戰鬥技能（獸蟲派）。
- 奴隸印記的 `functions` 加「順從累積」。

### 12.4 消耗品、鍊金、烹飪

- 媚藥（投擲物：範圍慾望、媚毒）、清心茶（自己的慾望 −30）、冷靜劑（這場戰鬥慾望抗性提高）、精力藥（高潮一次不扣生命）。
- 烹飪：壯陽料理（下一場戰鬥慾望上限 +20%）。
- 鍊金：用淫植、淫蟲的素材和「征服」掉落（1.5 節）。

### 12.5 房子與家具

- 調教室：在家調教時加值；奴隸住在家裡時每天順從 +1。
- 刑架、拘束台：主人事件的「在家」版本（`at_home`）多幾件。

### 12.6 魅氣濃度

每個聚落一個「魅氣濃度」1～4（`geography.json` 的 `locations` 加欄位；I13 的建議：精靈王庭 1、中央平原 2、阿爾貝納與潮汐港的黑市 3、血羽城堡一帶 4）。它決定：

- 曝露名聲的累積速度（5.4 節）。
- 哪裡有淫鬥場、情趣用品店、拍賣會；商店能不能買到色情技能書。
- 近郊遭遇表的淫獸比例。
- **入城規定是選項，不是強制**：濃度 4 的城鎮，城門多一個選項「照規矩戴上拘束具進城」（順便得到雙面效應、入城費全免），也可以付錢、走側門或繞路。玩家選了戴上，戲內就是被要求的，戲外是自己選的。
- 給 AI 的地點描述多一句風氣，同樣的服裝在不同城鎮得到不同反應。

### 12.7 城鎮、商店、旅途

- 裁縫店、魔法物品店：成人向的服裝與帶慾望加成的裝備；新商店類型「情趣用品店」（濃度 3 以上）。
- 城鎮事件：用曝露名聲當條件（5.4 節）。
- 公會委託：娼館、貴族的特殊委託要求曝露名聲或淫亂。
- 旅途事件：路上被認出來（曝露名聲高時）。
- 新的特殊任務可以用 `stats` 條件（11.3 節）：淫亂夠高才接得到的任務線。

### 12.8 場所

世界書的場所拆成地標或城鎮事件（殺手奴會不做）：

| 場所 | 埃隆迪亞 | 用途 |
|---|---|---|
| 淫鬥場 | 新設施 | 12.10 節 |
| 拍賣會 | 地標（濃度 3 以上的大城） | 買賣色情技能書、稀有淫具；被盯上的城鎮事件 |
| 淫市 | 市場的黑市分區 | 情趣用品店、打工抵債 |
| 淫服裁縫鋪 | 裁縫店的特別商品 | 訂做帶 `lewd` 加值的服裝 |
| 青樓 | 娼館（現有） | 第 8 節 |
| 醫館 | 神殿、治療師（現有） | 取出寄生物 |
| 驛站的奴房 | 旅店的選項 | 濃度高的城鎮，旅店多一個便宜的「奴房」：**玩家自己選**入住，戲內是非自願的過夜（標「主角非自願」），省錢、有機會漲順從與學技能 |

### 12.9 主動行動與人際

- 新的主動行動「誘惑」：魅力對（10 + 對方慾望抗性換算 − 對方淫亂 / 10）。成功時親密度上升、對方淫亂 +1，也是提議工作（8.5 節）之前的鋪陳。
- 親密度 ↔ 慾望分擔：慾望分給親密度高的隊友時效率更好（每 25 親密度 +10%）。
- 冒險記憶：「一起經歷的慾望勝利」可以記成記憶（[RELATIONSHIP_MEMORY](../RELATIONSHIP_MEMORY.md)）。

### 12.10 淫鬥場

魅氣濃度 3 以上的城鎮多一個設施，三種擂臺：

| 擂臺 | 規則 | 測的是什麼 |
|---|---|---|
| 淫物場 | 和淫獸、淫蟲、淫植打 | 慾望攻擊系、慾望勝利 |
| 拘束戰鬥場 | 上場前選一件拘束具戴上（玩家選哪一件），打完拿掉 | 雙面效應 |
| 性戰場 | **生命傷害關閉，只算慾望**；雙方都用我方的「三次」規則（擂臺上的例外，對手的高潮不扣真實傷害），先讓對方高潮 3 次的贏 | 純慾望攻防，也是調數字的好工具 |

- 獎勵：錢、色情技能書、戰鬥用的淫具；連勝解鎖更強的對手。
- **賭注賽**（玩家選了才有）：輸了身上加一件鎖著的拘束具，連贏兩場拿掉一件；欠債可能變成鬥場奴隸（契約的 `kind` 多一種「鬥場」）。一般的比賽沒有這些後果。

### 12.11 淫器合煉

- 鐵匠或附魔師把一件武器、防具和一件拘束具或調教道具合成「淫器」：平常是拘束，戰鬥時展開成武器。例：長鞭 + 繩縛、盾牌 + 貞操帶、鎖鏈 + 手銬。
- **加成看穿戴的天數**：最近 10 天裡穿了 ≥ 9 天 → 原武器 ×1.5；≥ 7 天 → ×1.0；≥ 4 天 → ×0.5；更少不能啟動。日常的負面 ×1.5。
- 可以拆回原本的兩件，不損耗。接到 [CRAFTING](../CRAFTING.md) 的委託打造；需要記錄穿著天數（忍耐的成長也用這個，5.3 節）。

### 12.12 敵人的手段

- 人型敵人的色情技能：催情術（不靠道具的範圍慾望）、驅奴術（對身上有奴隸印記的人額外強，短暫控制）、威壓（等級高於目標時，目標慾望抗性下降）。
- 反派的四種類型決定戰敗事件的走向：知識型（契約陷阱、把柄）、武鬥型（拘束、刑罰）、商賈型（賣掉、欠債）、宗教型（以淨化為名）。
- 世界書的「反派首要目標是主角」「每段劇情主動引入反派」不採用（會繞過內容篩選、讓 AI 編出引擎沒有的劇情）。

### 12.13 鎖具與脫縛

- 拘束具的鎖決定雙面效應的倍率（6.2 節）。
- 新的主動行動「嘗試脫縛」：依鎖的等級、雙手有沒有被綁、忍耐決定 DC。
- 鑰匙是一次性的消耗品，可以從擊敗的敵人身上搜到。
- 戰鬥中的拘束（絞縛、蛛絲、膠膜）用同一個脫縛檢定掙脫。

### 12.14 插圖

生成形象圖時，把淫亂、曝露名聲的分段轉成標籤（[PORTRAITS](../PORTRAITS.md)），形象圖隨數值改變。
