# 手機版 UI 計畫

> 上層：[計畫與追蹤](README.md)。狀態：**規劃中**，探索畫面的方向已定，還沒動遊戲程式。

樣稿：`docs/mockups/mobile.html`（可以直接在手機上點）。電腦版維持原樣，只在手機寬度換成這套版面，面板元件共用。

---

## 1. 前提

- **直式**、單手操作。
- 先做**一般探索**畫面；戰鬥畫面之後另外規劃。
- 使用頻率（高 → 低）：地圖移動 → 切換地圖（換區域） → 設施選項 ≈ 這裡的人 ≈ 主動行動 → 隊伍 → 長休／短休 → 其他。
- 行囊目前用得少，但以後可能變多。

## 2. 版面

```
┌────────────────────┐
│ 狀態列：時間 地點 金錢 🔔 │  只看不按（待處理的鈴鐺除外）
├────────────────────┤
│ 地圖（可收成一條）        │
├────────────────────┤
│ 冒險日誌                │
├────────────────────┤
│ [ 進入○○ ] 情境按鈕       │  站在設施上才出現
├────────────────────┤
│ 地圖│隊伍│休息│這裡│更多   │  底部分頁列
└────────────────────┘
```

要按的放下面（拇指好按），上面只放資訊。

### 2.1 主畫面：探索／閱讀兩種狀態

| 狀態 | 地圖 | 日誌 | 什麼時候 |
|---|---|---|---|
| 探索 | 大，好點 | 剩下的空間 | 點地圖那一條、或底部「地圖」 |
| 閱讀 | 縮成一條（地名、所在設施、展開鈕） | 整頁 | AI 寫了一段敘事時自動切過來 |

- 點相鄰格子走一步；**提案**：點遠處的格子自動走過去（樣稿已做，真的遊戲要確認每一步的事件怎麼處理）。
- 切換地圖＝走到出口格（出城、進地下城、下一層），不另外加按鈕；出口格用醒目的顏色和目的地名稱。

### 2.2 設施：情境按鈕

站在設施上時，底部列上方出現「進入○○」，點了滑出設施面板（選項＋這裡的人）。

### 2.3 底部分頁列

| 按鈕 | 內容 | 提醒 |
|---|---|---|
| 地圖 | 切換探索／閱讀狀態 | — |
| 隊伍 | 分頁：隊伍｜行囊 | 有人可以升級 |
| 休息 | 短休、長休、生命骰 | — |
| 這裡 | 這裡的人、主動行動、意圖 | 身邊的人數 |
| 更多 | 次級選單（見 2.4） | 底下項目的提醒加總 |

除了「地圖」，其他按鈕都打開**半屏面板**（從下往上滑出；拉把手可以拉到全螢幕，往下拉或點外面關掉）。

行囊以後用得多，再升格成底部的獨立按鈕。

### 2.4 更多（次級選單）

關係、筆記、工藝、契約（有契約時）、存讀檔、快存、快讀、設定、語言、提示詞、世界、首頁。

## 3. 還沒決定

- 戰鬥畫面。
- 「點遠處自動走」要不要做；走到一半遇到事件時怎麼停。
- 手機版從多寬開始套用（暫定 720px 以下）。
- 角色詳情、交易、設定這些大型對話框在手機上的樣子（目前會照舊用全螢幕對話框）。
