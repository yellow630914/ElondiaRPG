## 1. 來源

| 文件 | 來源 | 寫法 |

| [player-feedback](player-feedback.md) | 玩家的回饋（Discord、心得等）引出的構想 | 寫出玩家遇到的情況與日期；隨時加 |
| [dev-discussion](dev-discussion.md) | 開發討論中提出、還沒做的構想 | 寫出當時在做什麼；隨時加 |
| [early-design](early-design.md) | 早期設計文件裡的構想，以及放比較久、還沒決定的點子 | 註明原本在哪份文件；其他來源的點子放久了也移到這裡 |
