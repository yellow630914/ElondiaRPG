# 點子：早期設計文件

> 上層：[點子庫](README.md)。早期設計文件裡提過、或擱置比較久還沒做的構想：2026-10 從各文件的「待決定」集中過來的，2026-10 盤點時先不做的（原本在 `review-2026-10.md`），以及 UI v2 沒做的部分。原本的編號寫在標題後面。

### I1

**AI 在事件中生成並登錄新 NPC**（原 D2、I7；出處 GAME_DESIGN、QUEST_EVENT_DESIGN）

目前只有兩種：AI 潤飾名單上的人（名字、外貌、性格），以及長休時 AI 用 `meet` 介紹一位旅客。自由行動的 AI 不能憑空生成新角色。

### I2

**敘事輸出檢查**（原 D5、I6；出處 GAME_DESIGN）

比對 AI 正文裡有沒有報告沒有的物品、金額、死亡，不符時重寫或標註。

### I5

**AI 替事件換皮、世界書「引力值」**（原 D7、I9；出處 QUEST_EVENT_DESIGN，已刪除，見 git 歷史）

- AI 替隨機事件換皮（開場描述、台詞）。
- 世界書「引力值」。

「AI 依一段文字生成特殊任務」已經做成世界編輯器的「✨ AI 編排」（[ROADMAP](../ROADMAP.md) R11 E4）；早期提案的「事件導演」做成了城鎮事件（[TRAVEL_EVENTS](../../TRAVEL_EVENTS.md) 第 6 節）。

### I6

**暗殺、背叛的專門機制**（原 D3、I8；出處 QUEST_EVENT_DESIGN）

目前有偷竊、偷襲、蒙混、威嚇與自由行動；暗殺、背叛隊友只能用自由行動描述，AI 的後果受上限限制。

### I7

**地下城探索彙整報告**（原 D4、I5；出處 [DUNGEON_DESIGN](../../DUNGEON_DESIGN.md)）

把「從入口或安全房到下一個安全房」合成一份報告（附剩餘光源與補給）給 AI 寫成一段；目前每個格子事件各自一份報告。

### I8

**遭遇的動態組合**（原 I10；2026-10 盤點）

從同地區的怪物依等級預算自動湊一組（主力＋跟班）；目前是遭遇表裡寫好的組合。

### I9

**S 級內容**（原 I3；2026-10 盤點）

怪物已經有到 20 級（深淵層、史詩頭目），但一般委託的 A／S 級仍然很少（見 [LOGIC_ISSUES](../LOGIC_ISSUES.md) L1）；S 級的冒險主要靠特殊任務的史詩線。

### I12

**世界頁籤補上還不能改的資料**（原 I4；2026-10 盤點）

公會委託模板與材料委託（`town_quests.json`）、地理（地點、路線、地區）、城鎮區塊地圖（可以沿用特殊地圖的畫筆）、臨時地圖（`side_maps`）、工作、交涉、怪物特性、職業與種族、生成 NPC 的名字池與性格。主人與娼館的事件已經可以改（「⛓️ 主奴與娼館」頁籤）。

### I19

**模組化像素立繪**（原 UI v2 的 P6）

依角色的外貌拼出像素立繪：NPC 存 `look`（身形、髮型、髮色、眼型、膚色、臉部小部件、種族部件、服裝），`portrait_parts.json` 對照關鍵字與圖層，canvas 疊圖換色；開新遊戲多一個捏臉面板。顯示順序：玩家的形象圖 → 像素立繪 → 名字首字印章。要大量生成圖層素材，擱置。現在沒有形象圖時顯示名字首字印章；部分固定 NPC 有內建形象圖（[PORTRAITS](../../PORTRAITS.md)）。規格見 `docs/comfy/portrait-spec.md`。

### I20

**地圖格改用生成的 tileset**（原 UI v2 的「需要決定的問題」1）

地圖格現在是程式生成的像素圖塊；可以改用 ComfyUI 生成一套 tileset。生圖量大，擱置。
