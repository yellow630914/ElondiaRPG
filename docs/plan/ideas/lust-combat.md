## 0. 一句話與設計原則

**一句話**：所有戰鬥單位多一條「慾望」，多一種抗性「慾望抗性」。不分職業的色情技能主要用來把**傷害轉成慾望、在隊友之間分擔慾望、依慾望給增益**。戰鬥外有三個長期數值：淫亂值、曝露名聲、順從度，跟服裝、奴隸、娼館、城鎮事件和 AI 敘事連動。

**設計原則**

1. **主力在自己人身上**。敵人的慾望抗性差異很大，骷髏、魔像根本不吃。所以強力技能圍繞友軍增益與承傷；慾望攻擊是對特定敵人的戰術，也用來營造氣氛。
2. **慾望是第二條生命，代價是高潮**。慾望其實是一個可以分攤到隊友身上的承傷池，滿了就失去一回合、扣 33% 生命。玩法的張力就在「存多少、分給誰、什麼時候主動引爆」。
3. **兩種風格，沒有職業門檻**。奴隸系（承傷）和淫亂系（增益）只是技能構築的方向，任何職業都能混著學。
4. **數值由引擎算，AI 只描寫**。高潮、技能學會、數值變化都寫進報告；AI 判定只能在上限內動這些數值（比照親密度 ±8、聲望 ±2）。
5. **照現有的內容篩選走**。關掉「主角非自願」「男性對象」時，該擋的照擋；`young` 特徵的怪物一律不參與（第 2.3 節）。
6. **可以整套關掉**。這套玩法會改變戰鬥平衡，所以做成存檔的遊戲規則（例如「慾望系統：關閉／0.5×／1×／1.5×」），關閉時戰鬥和現在一模一樣。

## 1. 慾望（戰鬥中的資源）

### 1.1 構想

- 生命條下面多一條粉色的慾望條（隊伍卡、戰鬥畫面、怪物資訊）。
- **慾望增加**：受到慾望攻擊、技能把傷害轉成慾望、隊友分過來的慾望、狀態的持續慾望（例如「媚毒」）、開戰時的初始慾望。
- **慾望減少**：每回合開始自然消退（預設上限的 5%，有「發情」類狀態時不消退）、淨化與清心類技能、把慾望分給別人、主動引爆（第 3.4 節）。
- **高潮（慾望滿）**：
  - 強制停止行動一回合（新的狀態「高潮」，`control: stun`，被攻擊時迴避照現有的 stun 算 0）。
  - 失去最大生命的 33%。
  - 慾望歸零，接著「餘韻」2 回合：受到的慾望 −50%，而且這段時間不會再高潮，避免連續被鎖。
  - 層主沿用現有的控制保護（控制最多 1 回合，之後免疫一回合，`combat.json` 的 `boss`）。
- **戰後**：慾望留下的部分轉成現有的非戰鬥狀態。慾望 ≥ 50% 時「發情」；這場戰鬥高潮過就「餘韻」或「虛脫」。這幾個狀態本來就在 `companions.json` 的 `conditions`。
- **戰前**：已經「發情」的人，開戰時帶著 20% 慾望；有 `rut` 特徵的怪物開戰時也帶慾望。這樣地下城成人事件留下的狀態，就第一次對戰鬥有影響（現在只有「虛脫」有 `combat_mods`）。

### 1.2 慾望上限（起點）

```
慾望上限 = (30 + 3 × 等級) × (1 + 淫亂值 / 200) + 順從度 / 5 + 裝備、特質、刺青的加成
```

- 1 級約 33，10 級約 60，20 級約 90。淫亂值 100 再 ×1.5。
- 上限高 = 能存更多慾望才高潮，所以淫亂、順從的角色反而比較耐（但慾望抗性比較差，見 2.2 節）。這正好是兩個系的取捨：淫亂系當「慾望電池」，奴隸系當「慾望海綿」。
- 待決定：上限要不要乾脆跟最大生命掛勾（例如最大生命 × 0.6），這樣現有的傷害骰可以直接拿來當慾望傷害，不用另外調整。

### 1.3 高潮扣的 33% 生命

| 做法 | 好處 | 壞處 |
|---|---|---|
| **A. 最大生命的 33%，最多扣到剩 1**（建議） | 不會被慾望直接打死；主動引爆可以排進戰術 | 慾望攻擊殺不了人，敵方只能拿來控場 |
| B. 最大生命的 33%，可以致死 | 慾望攻擊是真正的威脅 | 色情攻擊直接把人打死，氣氛和戰敗事件都怪 |
| C. 目前生命的 33% | 永遠不會致死 | 殘血的人高潮幾乎沒有代價 |

建議用 A。「被慾望打到無法戰鬥」改成另一條路：一場戰鬥裡**高潮 3 次就倒下**（無法戰鬥，但不算死亡），這會提高戰敗成人事件的機率（第 9.1 節）。

### 1.4 接到哪裡

- `Combatant`（`src/engine/combat.ts:56`）加 `lust`、`lustMax`。`fromCharacter`、`fromEnemy` 計算初始值。
- 新狀態（`data/rules/statuses.json`）：`climax`（stun 1 回合）、`afterglow_combat`（受到慾望 −50%、不能高潮）、`lust_dot`（媚毒，每回合加慾望）。`StatusDef` 加 `lust_dot`、`lust_mult`、`no_climax`。
- `startTurn`（combat.ts:1378）：自然消退、持續慾望、檢查高潮。
- `finishCombat`（combat.ts:1537）：慾望轉成非戰鬥狀態；記下這場的高潮次數給戰敗事件用。
- 戰報與日誌：高潮寫成一行事件（例如「莉雅 高潮，失去 22 生命，下回合不能行動」）。報告加 `climaxes[]`；有人高潮的戰鬥報告帶 `adult_scene`，走「成人場景正文」的模型來源（`adultSceneOf`，`src/narrator/prompt.ts:202`）。

## 2. 慾望抗性

### 2.1 做成第 14 種傷害屬性

最省工的做法：在 `data/rules/damage_types.json` 加一種屬性 `lust`（魅惑，自成一個群組，不受 `all` 影響）。

- 抗性直接用現有的 `resist`／`offense`（`AffinityMap`）：抗性相乘、增傷相加、免疫／抵抗／弱點標籤，全部現成。
- `dealDamage`（combat.ts:939）遇到 `lust` 時改成加慾望，不扣生命；防具減傷（只擋物理）、狀態減傷不擋 `lust`。
- 編輯器的抗性欄位、怪物表（`npm run docs:gen`）自動多一欄。

### 2.2 怪物：依種類的預設值，個別覆寫

`kind` 目前只拿來選圖示（9 種），可以順便讓它決定預設的慾望抗性。`enemies.json` 個別怪物寫了 `resist.lust` 就覆寫。

| 種類（數量） | 預設 | 說明 |
|---|---|---|
| undead 不死（47） | −1 免疫 | 骷髏、殭屍、幽靈。**例外**：吸血鬼、夢魘類覆寫成 0 或抵抗，而且有色情技能 |
| construct 構裝（40） | −1 免疫 | 魔像、機關 |
| elemental 元素（22） | −0.75 | |
| spirit 精魂（63） | −0.5 | 夢魔類覆寫成 0 |
| plant 植物（32） | 0 | 淫植覆寫成 +0.5 弱點 |
| beast 野獸（105） | 0 | 有 `rut` 的 +0.25 |
| humanoid 人型（129） | 0 | 盜賊、捕奴隊沒特別抗性；聖職者 −0.25 |
| demon 惡魔（42） | 0 | 魅魔類 −0.5（擅長也耐），其他照預設 |
| fey 妖精（10） | +0.25 | 寧芙、樹精 |

怪物特徵（`monster_traits.json`）也加一點：`rut` 發情 +0.25 弱點並帶初始慾望；`frenzied` 狂亂 −0.25（顧不上）；`old` −0.25。

### 2.3 安全規則

- 帶 `young` 特徵的怪物（現在戰敗事件已經排除它們）**一律免疫，而且不放色情技能**；色情技能也不能以它們為目標。
- 主角、夥伴、NPC 都是成年人（現有的設定），不需要另外處理。

### 2.4 角色的慾望抗性

```
慾望抗性 = 種族 + 特質 + 裝備附魔 + 信仰調整（每點信仰修正 −0.05）+ 淫亂值分段（60 以上 +0.1、80 以上 +0.25，越淫亂越弱）
```

- 種族：精靈 −0.1（矜持）、貓魅族 +0.15（天性；也是擅長色情技能的種族）、魔族看出身（魅魔血統 −0.25）。都寫成種族特質，`perks.json` 的 `resist` 本來就能寫任何屬性。
- 禁慾、清心類的特質給 −0.25～−0.5（第 10.2 節的流派）。

## 3. 色情技能

### 3.1 不分職業：`classes: ["lewd"]`

- `abilities.json` 用一個假職業 `lewd`（比照怪物技能用 `monster`）。`learnable`、`learnAbility`（`character.ts:311`、`effects.ts:356`）放寬成「自己的職業，或 `lewd`」。
- **不進升級的三選一**，只從新的管道學：奴隸調教、娼館、打工線、地下城掉落、技能書、事件（第 6～8 節）。這樣色情技能是另一條成長線，不會稀釋各職業原本的升級選項。
- 主要屬性是**魅力**（`attr: "cha"`）。施法類用魅力豁免（`save: "cha"`）。
- **待決定：要不要限制數量**。例如「同時能準備的色情技能 = 2 + 魅力修正 + 淫亂值 / 25」，避免後期每個人都背一大堆；或者乾脆不限，靠學習管道本身控制。

### 3.2 三大種類

| 種類 | 對象 | 用途 | 會用到的新機制 |
|---|---|---|---|
| **慾望攻擊系** | 敵人 | 對低抗性的敵人控場、加速高潮、營造氣氛 | `lust` 傷害、媚毒、慾望達門檻時附加控制 |
| **輔助系**（淫亂系的核心） | 友軍、自己 | 依慾望給增益、把慾望轉成資源、主動引爆 | 依慾望比例的增益、消耗慾望、引爆 |
| **承傷系**（奴隸系的核心） | 自己、友軍 | 替友軍承傷、傷害轉慾望、吸收別人的慾望 | 傷害轉換、代受傷害、慾望轉移 |

### 3.3 需要的新機制（能力或狀態的欄位）

| 欄位（建議） | 放在 | 作用 |
|---|---|---|
| `damage[].type: "lust"` | 能力 | 慾望傷害（2.1 節） |
| `convert: { from: "hp", to: "lust", ratio }` | 狀態 | 受到的生命傷害有一定比例改成慾望。核心承傷機制 |
| `guard: { ally, ratio }` | 狀態 | 代替指定友軍承受傷害（沒有這個機制，現在只有嘲諷） |
| `lust_transfer: { amount \| ratio, to }` | 能力 | 把自己的慾望移給友軍或敵人，或從別人身上吸過來 |
| `lust_cost` | 能力 | 消耗自己的慾望才能用（慾望當作 MP） |
| `lust_scale: { stat, per, max }` | 狀態 | 依目前慾望比例給增益，例如每 10% 慾望傷害 +1 |
| `on_climax: { heal, ap_gain, apply, to }` | 狀態或特質 | 高潮時觸發，例如全隊回復 |
| `burst` | 能力 | 主動引爆：自己的回合裡清空慾望換效果，**不扣生命**，下回合仍然停止行動 |
| `requires_lust: { min }` | 能力 | 慾望到某個比例才能用 |

這些大多是 `startTurn`、`dealDamage`、`addStatus` 裡的分支，不用改資料結構的根本。

### 3.3.1 流派：技能的第二個分類（附件的七流派）

三大種類說的是技能**做什麼**，流派說的是技能**屬於哪一條修行路線**。附件的規則直接可以拿來當學習的框架：

- **要先拿到入門才能學**：每個流派有一本入門秘法書（或一位老師、一個教團），學會入門特質之後，那個流派的技能才會出現在各種學習管道裡。
- **深入的流派最多 3 個**：同時修習的流派上限 3（附件：「深入鑽研的流派很少超過 3 個」），想換要「散功」（花錢、花時間、失去那個流派的被動）。這比 3.1 節「限制技能數量」更有味道，可以二選一。
- **奴道是唯一的主修**：修了隸從派就算「奴修」，其他都是輔修。
- **流派和態度無關**：流派只決定戰鬥方式，不決定角色願不願意（附件的強制規則）。所以流派**不**影響順從度，順從度只看經歷（第 5 節）。

| 流派 | 對應的系 | 戰鬥定位 | 招牌機制 |
|---|---|---|---|
| 隸從派（奴道，主修） | 奴隸系 | 承傷、護主 | **認主**：有主人時才有增益（7.0 節） |
| 刑罰派 | 奴隸系 | 承傷、反擊 | 越受傷越強；傷害轉慾望的效率最高 |
| 束縛派 | 奴隸系 | 防禦、穩定 | 拘束具的雙面效應最強（6.3 節） |
| 縱欲派 | 淫亂系 | 增益、爆發 | 主動引爆、慾望越高越強；「戰鬥方式就是性愛本身」→ 慾望攻擊也最強 |
| 肉體派 | 淫亂系 | 續戰 | 開發度（11.13 節）直接轉成被動加成 |
| 獸蟲派 | 淫亂系 | 召喚、寄生 | 寄生物、淫獸夥伴在戰鬥裡出手（11.3 節） |
| 禁慾派 | 反制 | 抗性、淨化 | 慾望抗性高、清心；不能和縱欲派同修 |

使用者說的「奴隸系、淫亂系沒有特定區別，因構築而定」在這裡就是：流派自由搭配，三個流派的組合決定你偏哪一系。

### 3.4 核心循環

```
敵人打奴隸系 ──→ 傷害轉成慾望（痛即是悅）──→ 奴隸系慾望高，自己也有增益（被動）
                                              │
                                              ↓ 慾望分給淫亂系（獻身的反向：奉獻）
淫亂系慾望上升 ──→ 依慾望增傷、給全隊增益（渴望之舞）
                                              │
                                              ↓ 快滿時主動引爆（解放）
全隊回復生命或行動點 ──→ 慾望歸零，重新累積
```

- 奴隸系把**生命傷害**換成**慾望**，等於多了一條可以分攤出去的承傷池。
- 淫亂系把**慾望**換成**輸出與增益**，而且主動引爆可以把「高潮」從懲罰變成爆發。
- 平衡的槓桿：轉換比例、慾望上限、主動引爆的效果。慾望攻擊系的敵人會打亂這個節奏（把你的慾望推過頭），這是對手給的壓力。

### 3.6 跟現有職業的配合

- **吟遊詩人**的施法屬性就是魅力，最順手；色情技能可以算進它的施法加值。
- **聖騎士、牧師**給「清心」類的能力（淨化現在用 `cleanse`，可以加 `lust` 減少），是對抗淫獸的反制手段。
- **武僧**的「禁慾修行」做成特質：慾望抗性高，但學色情技能的檢定變難。
- **野蠻人**狂暴時不消退慾望、改成慾望越高傷害越高（類似 `lust_scale`）。

## 4. 怪物的色情技能

### 4.1 誰有，誰沒有

| 有（依背景） | 技能方向 |
|---|---|
| 魅魔、夢魔（demon、spirit） | 魅惑之吻、傾國一笑、慾望吸取 |
| 觸手、史萊姆（地下城成人事件已經有） | 拘束 + 媚毒、範圍慾望 |
| 淫植（plant） | 花粉（範圍媚毒）、藤蔓拘束 |
| 有 `rut` 的野獸（45 隻，狼、地獄犬……） | 撲倒（慾望 + 倒地），自己帶初始慾望 |
| 盜賊、捕奴隊、邪教徒（humanoid，`villain` 類） | 下藥（媚毒投擲物）、羞辱（淫語） |
| 吸血鬼 | 魅惑凝視、吸血帶慾望 |
| 寧芙、樹精（fey） | 迷魂歌（現有的 `siren_song` 改成帶慾望） |

| 沒有 | 原因 |
|---|---|
| 骷髏、殭屍、幽靈、魔像、元素 | 背景不合；慾望抗性也是免疫 |
| 一般的野獸（沒有 `rut`） | 視背景；可以用特徵 `rut` 擲到時才有 |
| 帶 `young` 特徵的 | 一律不給（2.3 節） |

### 4.2 敵人 AI

`chooseAction`（combat.ts:1481）替慾望攻擊打分數時：

- 乘上目標的慾望受傷倍率（免疫 = 0，不會對骷髏以外的免疫目標浪費回合）。
- 目標慾望 ≥ 70% 時 +1：會「收割」快高潮的人。
- `rut` 特徵的怪物偏好慾望攻擊（特徵的 `ai.prefer` 加一個 `lust`）。
- 我方有人高潮時，有起意的敵人（戰敗事件同一套篩選）仇恨轉向那個人。

### 4.3 怪物高潮

- 敵人高潮一樣停一回合、扣生命，這是慾望攻擊系的價值所在。
- 淫獸類可以反過來：高潮時回復生命（「餵食」），玩家要判斷該不該用慾望打它。資料寫在特徵或怪物的 `on_climax`。

## 5. 長期數值：淫亂值、曝露名聲、順從度

### 5.1 總表

| | 淫亂值 | 曝露名聲 | 順從度 |
|---|---|---|---|
| 是什麼 | 對性的開放與渴求 | 身體和行為被多少人看過、傳得多開 | 對主人或命令的服從習慣 |
| 存在哪 | 角色 | 存檔，依地區（會傳到相鄰地區，打折） | 角色 |
| 主要來源 | 親密場景、娼館、高潮次數、穿成人向服裝 | 在城鎮穿曝露的服裝、娼館工作、公開的事件 | 奴隸事件與調教、主人事件、強制裝備、束縛 |
| 會下降 | 很慢（長時間沒有親密場景）；神殿的淨化 | 每天自然淡掉 1；離開那個地區 | 抵抗、逃跑成功、自由的日子 |
| 戰鬥 | 慾望上限 ×；慾望抗性變差（分段）；色情技能威力 | 慾望攻擊系的傷害 +（在人前的自信）；開戰被認出時士氣 | 承傷系的轉換率 +；慾望上限 + |
| 戰鬥外 | 學色情技能的檢定、娼館收入、說服夥伴去工作的 DC | 城鎮成人事件的機率、新的城鎮事件、城門盤查、店家態度 | 主人事件的選項加減、調教的效果、奴隸身價 |
| 給 AI | 分段描述（例如「開放」） | 這裡的人知不知道你 | 分段描述 |

### 5.2 分段（顯示與條件用）

| 數值 | 淫亂值 | 曝露名聲 | 順從度（附件的心態五階段） |
|---|---|---|---|
| 0～19 | 純情 | 沒人知道 | 恨與反抗 |
| 20～39 | 好奇 | 有些傳聞 | 懲罰與絕望 |
| 40～59 | 開放 | 小有名氣 | 麻木與認命 |
| 60～79 | 淫蕩 | 遠近馳名 | 依賴與習慣 |
| 80～100 | 淫亂 | 人盡皆知 | 真心臣服 |

順從度的分段直接用附件「被迫者的心態演化」：逐步、可逆、因人而異。給 AI 時寫成階段名，正文照階段寫，不一步到位（附件的原則：麻木 ≠ 接受、臣服時痛苦仍在）。自願的奴隸（主動認主，7.0 節）不走這條線，分段改用「配合／忠誠／奉獻」之類的另一組名稱。

分段可以像寄生物的階段（`parasites.json` 的 `stage_effects`）一樣，各自帶被動的檢定修正，也可以自動給特質（例如淫亂值 60 以上自動得到「食髓知味」）。

### 5.3 曝露名聲的細節

- **為什麼依地區**：在潮汐港的黑市出名，不代表精靈王庭也知道。剛好對上點子 I13 的「魅氣濃度」：濃度高的地區，曝露名聲累積得快，城鎮也比較見怪不怪。
- **累積**：每天依身上服裝最外層的「曝露度」（6.2 節），在城鎮裡待著就增加；娼館工作、城鎮的成人事件、在城鎮附近的戰敗事件另外加。
- **效果**：
  - 城鎮的成人事件機率 × (1 + 曝露名聲 / 100)（`townEvents.ts` 的 `chance`）。
  - 新的城鎮事件只在曝露名聲高時出現：被認出來、有人跟蹤、粉絲送禮、勒索、私下邀約、被請去當模特兒。
  - 城門盤查：DC 和「搜身」事件的機率上升（`security.ts`）；有的守衛反而放水。
  - 聲望交叉：在教廷城鎮曝露名聲高會扣教廷的聲望；在血羽城堡反而加。
- 主角的身分標籤 `bypass_reputation` 之類的可以順便擴充一個「放蕩的貴族」：曝露名聲不影響聲望。

### 5.4 順從度和契約的 `obedience`

- 契約的 `obedience`（`ContractRef`，`types.ts:288`）是**主人加的、暫時的檢定懲罰**，最多 8。
- 順從度是**角色自己的性格**，契約解除之後還在。
- 連動：每次 `obedience` 上升時順從度 +1；順從度高時 `obedience` 消得慢；主人事件的「屈服」選項依順從度給加值，「抵抗」選項給減值。
- 順從度很高的奴隸，逃跑、談判解約的 DC 自己就比較高（`escape_dc`、`exit_dc` 加上順從度 / 20）。

### 5.5 NPC 的預設值

依現有的 `npc_tags`：

- `prostitute` 娼婦：淫亂 50～80、曝露 30。
- `slave` 奴隸：順從 40～80。
- `noble` 貴族、`priest` 神官、`bishop` 主教：淫亂 0～20。成人向的固定 NPC 可以表裡反差，在 `NpcDef` 裡個別寫。
- `villain` 反派：淫亂 40～70。
- 其他依性格隨機。

`NpcDef`（`data.ts:74`）加選填的 `lewd: { lewdness, submission }`，編輯器的固定 NPC 頁多三格。

### 5.6 給 AI

- 敘事（`protagonistText`，`character.ts:419`）：分段的文字，例如「淫亂：開放（48）；在這一帶小有名氣；順從：配合」。只在成人向的日誌加（跟成人向世界書同一個開關，`compose.ts:57`），一般日誌不提。
- 判定（`pcDetail`，`judge.ts:79`）：數值加分段，讓 AI 判斷「主動說服別人」之類的結果。
- 隊友與 NPC（`partyLines`、`formatContext`）：同樣的分段。
- AI 判定的效果上限：每次 ±3（比照聲望 ±2、親密度 ±8）。效果類型加 `lewdness`、`exposure`、`submission`（`effects.ts` 的 `EFFECT_TYPES`）。
- 主動行動的結果會受影響：例如淫亂值高的主角「獻媚」更容易成功、曝露名聲高時「唬騙」貴族更難。

## 6. 服裝與裝備

### 6.1 現況

- 底材的 `outfit` 有三種：`regular` 常規、`anime` 二次元、`adult` 成人向（`gear.ts:51`）。另外有束縛用的底材（`restraint: true`，8 種）。
- 底材本身**不給魅力**；魅力來自個別物品的 `gear.attrs`（`items.json`，118 件）。

### 6.2 構想

- **底材加「曝露度」0～3**（`gear.json` 的 `bases`）：常規 0，二次元 0～1（兔女郎裝 2），成人向 2～3，網襪、乳貼這種 3。束縛類另外標「順從」。
- **曝露度看最外層**：外衣蓋住內衣時，內衣的曝露度不算。邏輯可以借刺青被遮住的判斷（`coveredTattoos`）。
- **物品加 `lewd` 加值**（和 `attrs` 同一層）：

```jsonc
"gear": { "attrs": { "cha": 2 }, "lewd": { "lewdness": 5, "exposure": 0, "submission": 0 }, "lust": { "max": 10, "resist": 0.1 } }
```

  - `lewd` 是**穿著時的有效值加成**（脫掉就沒了），跟屬性加值一樣有上限（單件 ±10、全身 ±20）。
  - 曝露名聲**另外**由「穿著在城鎮裡走」實際累積（5.3 節），所以曝露度高的服裝有兩層效果：立即的加成、長期的名聲。
  - `lust` 是戰鬥的慾望上限與慾望抗性。
- **預設值**：不用每件都手寫。底材依 `outfit` 給預設：二次元曝露 +2；成人向淫亂 +5、曝露 +5；束縛順從 +5。獨特物品（打工線的結局裝備）再個別寫。
- **附魔**：新增「魅惑」（色情技能 +1、慾望傷害 +10%）、「清心」（慾望抗性）、「餘韻」（高潮後回復）。走現有的附魔點數。
- **主人強制裝備**（`forcedGear.ts`）：強制裝上的物品本身帶順從加成，穿著越久順從度越高（每天 +1）。

### 6.3 雙面效應（附件的「淫具雙面效應」）

這是把成人向裝備接進戰鬥最漂亮的一條規則：**拘束具、調教道具、淫服平常是負面效果，戰鬥中反轉成增益**。

- **平常**：非戰鬥的檢定減值（用現有的 `check_penalty` 機制，和非戰鬥狀態同一套），例如手銬讓靈巧檢定 −2、眼罩讓察覺陷阱 −3。
- **戰鬥中**：只有**修了流派的人**（3.3.1 節）會反轉成增益；沒修的人只吃負面效果。

| 平常的負面 | 戰鬥中的增益（建議對應） |
|---|---|
| 限制行走（高跟鞋、腳鍊） | 先攻 +、行動點回復 |
| 束縛雙手（手銬、單手套） | 減傷 +、不會被繳械 |
| 遮住視線（眼罩） | 迴避 +、免疫目盲類 |
| 持續刺激（調教道具） | 法術環或行動點回復 |
| 全身拘束（繩縛、繩衣） | 全屬性小幅 + |

- **負面越大，增益越大**：輕度、中度、重度三檔，對應 `restraint` 底材的新欄位 `bind: 1～3`。
- **流派契合 ×1.2**：拘束具配束縛派或刑罰派、調教道具配肉體派、曝露的淫服配縱欲派、保守的淫服配禁慾派、寄生類配獸蟲派。
- **認主中的奴修 ×1.4**（取代 ×1.2）。
- **鎖上才生效、鎖越好倍率越高**（附件的鎖具增幅）：裝備的 `locked`（現在只記主人 id）擴充成鎖的等級，白 ×1、藍 ×1.1、符文 ×1.2、黃 ×1.3。主人強制鎖上的拘束具，戰鬥中反而最強，這是奴隸系的反差。
- 程式：`fromCharacter` 讀裝備時，依角色有沒有流派決定套哪一面；`gearAffinities` 那一層加 `bind` 的換算。

## 7. 奴隸系統擴充

### 7.0 認主（附件的奴道核心機制）

- 隸從派的技能與被動**只在有主人時生效**（`ContractRef.master` 不是空的）。沒有主人時，隸從派的技能可以用但只有一半效果，被動完全失效。
- 這給奴隸系一個強烈的取捨：最強的承傷構築，代價是得有一個主人。主角當奴隸時，這是第一次讓「被主人管著」在戰鬥上有好處。
- **主人在同一隊時更強**（3.5 節的「奴之誓」）；主人是主角時，主角的奴隸夥伴吃到這個加成，正好接上 7.2 節的調教。
- **主動認主與被迫認主**：附件分成兩類，剛好對上現有契約的自願與否。
  - 主動認主（自願簽的契約）：保留「底層權限」，關乎自身利益時可以不聽命令；與主人等級差太多時可以自己解約。
  - 被迫認主（戰敗、被捕）：完全服從，不能自己解除。
  - 內容篩選：主動認主的事件不算「主角非自願」，被迫的算。這讓「主角非自願」關掉的玩家也能玩奴隸系。
- **契約深化**：附件的「基礎 → 深化（強化 2 次）→ 永久（強化 4 次）」可以對上契約的條件（`MarkTerms`）。主人事件累積強化次數，越深主人能做的越多（遠端懲罰、定規矩），隸從派的增益也越大。永久契約要不要做、做了能不能解，待決定。

### 7.1 學技能

- **角色當奴隸**（主角，或別人的奴隸夥伴）：主人事件的結果可以給「學會一個色情技能」。主人的身分標籤（`master_tags`）決定傾向：商人的主人教侍奉，捕奴隊教忍耐，貴族教禮儀和魅惑。
- **主角當主人**：從奴隸面板調教自己的奴隸，奴隸會學到技能（7.2 節）。

### 7.2 主角對奴隸的調教（新）

在奴隸的角色詳情（現在只有「解除契約」）加「⛓️ 調教」：

1. 選一個**課程**：侍奉、忍耐、疼痛、言語、露出、束縛、魅惑。每個課程對應一組技能和一個主要的數值變化。
2. 抽一個這個課程的**調教事件**，格式和主人的突發事件一樣：開場文字、三個選項、檢定、結果、`adult_scene`。
3. 檢定由主角擲（魅力，或依課程換成力量、智力），DC = 課程基礎 − 奴隸順從度 / 10 + 奴隸的意志（目前親密度很低時更難）。
4. 結果：順從度、淫亂值、親密度的變化，有機會學會這個課程的技能。另外有**進度**：同一個課程成功 N 次，保證學會一個還沒學的技能，避免一直抽不到。
5. 花時間（2～4 小時）。在家裡有「調教室」家具時加值（第 10.4 節）。

| 課程 | 主要數值 | 技能方向 |
|---|---|---|
| 侍奉 | 順從度 + | 肉盾侍奉、縱慾共鳴 |
| 忍耐 | 慾望上限（特質） | 忍耐、調教的身體 |
| 疼痛 | 順從度 +、親密度 − | 痛即是悅 |
| 言語 | 淫亂值 + | 淫語、媚眼 |
| 露出 | 曝露名聲 +（要帶出門） | 寬衣 |
| 束縛 | 順從度 + | 跪伏乞憐 |
| 魅惑 | 淫亂值 +、魅力 | 魅惑之吻、魅香 |

- 內容篩選：主角當主人時，調教的對象是 NPC，不算「主角非自願」。但調教本身是非自願的題材，建議**另外開一個篩選標籤**（例如 `npc_unwilling`），或者沿用 `pc_unwilling` 一起擋。待決定。
- 奴隸的親密度太低時調教會反彈（逃跑、怨恨的記憶）；順從度高、親密度高的奴隸可以從調教得到「心甘情願」的特質。

### 7.3 擴充主人事件

- 現有 37 件。新增性訓練、展示、出借、競賽之類的事件，**不一定**要掛技能（使用者的要求）。
- 選項的結果多三種效果：`lewdness`、`submission`、`ability_pool`（從技能庫抽一個沒學過的，第 8.3 節）。
- 主人事件的「屈服」依順從度加值、「抵抗」依順從度減值（5.4 節）。

### 7.4 移到「事件」頁籤維護

現在主人的突發事件在 `slavery.json` 的 `master_events`，**編輯器沒有頁籤**。建議：

- **做法 A（建議）**：和旅途、城鎮、地下城、寄生物事件一樣，併進 `travel_events.json` 的 `templates`，新的 `scope`：
  - `master`：主人對主角的事件（從 `slavery.json` 搬過來）
  - `owner`：主角對奴隸的調教事件（新）
  - `brothel_work`、`brothel_train`：娼館（第 8 節）

  `RoadTemplate`（`road.ts:48`）已經有選項、檢定、結果、`adult_scene`、`tags`、`requires`。只要多幾個欄位：`affinity_min/max`、`at_home`、`cell`、`forced_gear`、`overdue`、`course`（課程）、`teaches`（技能）。
- 做法 B：保留 `slavery.json`，另外做一個編輯器表單。比較快，但兩套事件格式會一直分開。
- 搬家的時候，讀資料的程式先接受兩邊的格式（舊存檔、舊世界包的 `slavery.json` 覆寫照樣能用），之後再拿掉舊的。

## 8. 娼館擴充

### 8.1 打工（現有的 `work`，加上事件）

- 打工結束時，擲一次**打工事件**：機率 = 15% + 淫亂值 / 10%（最多 30%）。
- **沒擲到**：照舊領錢。
- **擲到**：從 `brothel_work` 事件庫抽一件。每件事件掛一個或幾個技能（`teaches`），**只抽主角還沒學過的技能所掛的事件**。結果照常領錢，再加學會技能、淫亂值、曝露名聲的變化。
- 事件庫裡也可以有不掛技能的事件（只是好玩或給錢），讓擲到事件不等於一定學技能。

### 8.2 受訓（新）

- 娼館多一項「🎓 受訓」，付錢給老鴇，花 4～8 小時。
- **一定**從 `brothel_train` 事件庫抽一件沒學過技能的事件，學會那個技能。
- 全部都學過時，照使用者說的可以重複：抽到已經學過的事件，改給淫亂值和一點錢（「複習」），或者讓那個技能的熟練度 +1（如果之後做技能等級）。
- 受訓的費用和 DC 依技能的稀有度。

### 8.3 技能庫怎麼記

事件本身掛技能（`teaches: ["lust_glance"]`），不另外寫一份技能清單。這樣「娼館能學到哪些技能」就是「娼館事件庫掛了哪些技能」，在編輯器裡一眼看得到。新的效果類型：

```jsonc
{ "type": "ability_pool", "scope": "brothel_train", "fallback": [{ "type": "lewdness", "amount": 3 }] }
```

`ability_pool` 從指定的事件庫裡找出主角還沒學的技能，抽一個；全部學過時套用 `fallback`。主人事件、調教事件、地下城寶箱都可以用同一個效果。

### 8.4 提議夥伴去工作

- 現在只有奴隸可以派去工作（`work.ts:28`）。改成**任何夥伴都能提議**：
  - 奴隸：照舊，直接派。
  - 自由的夥伴：主角擲魅力，DC = 15 − 對方淫亂值 / 10 − 親密度 / 25 + 對方身分修正（貴族、神官 +4；娼婦 −4）。
  - 成功：對方去工作，收入對分（比例可以談），對方的淫亂值上升。
  - 失敗：親密度 −2；大失敗時親密度 −6，記成一段冒險記憶。
- 自由的夥伴一定是同意之後才去，所以內容篩選看「男性對象」等標籤就好，不算非自願。
- 夥伴在娼館工作或受訓時也會觸發事件、學技能，用**他自己的**數值和還沒學過的技能清單，「誰擲骰就用誰的」（和現在派奴隸工作的規則一樣）。

### 8.5 其他可以加的

- **頭牌等級**：在同一家娼館工作的次數累積成「頭牌等級」，提高時薪、解鎖貴客事件和更稀有的技能。
- **光顧娼婦**（`patron`）：和固定的娼婦 NPC 親密度高時，她也可以教你一個技能（她的淫亂值越高，教的越進階）。

## 10. 色色主題地下城

### 10.1 構想

- 名稱草稿：**緋夢巢穴**。位置：南境，血羽城堡附近（I13 的對照裡魅氣濃度最高的一帶，魅魔宮廷就在那裡）。也可以把它當作魅魔派系的魅氣源頭，給第 5.3 節的「魅氣濃度」一個故事上的理由。
- 已經有的「地獄溫室」（`hell_greenhouse`，南境，離血羽城堡半天）主題是植物，也可以改成它的一個分支，或在它的深層接進去。待決定。

### 10.2 規則

- **怪物**：攻擊幾乎都是慾望攻擊，但慾望抗性都很低（大多是弱點），所以慾望攻擊系在這裡最好用。這是讓慾望攻擊系有舞台的地方。淫獸「餵食」的特性（4.3 節）讓玩家要想清楚。
- **魅氣**：在這座地下城裡，慾望**跨戰鬥保留**，每走一段路也會慢慢增加；安全房長休才清空。這讓慾望變成探索的資源壓力，類似光源。
- **陷阱**：色情陷阱。走進去沒察覺時，觸發現有的地下城成人事件（`maybeDungeonEvent`），或者留下「媚毒」「發情」，下一場戰鬥開場帶著慾望。新增十件左右這座地下城專屬的事件。
- **寶箱**：`gear.json` 的 `chests` 現在只依層，要加「依地下城覆寫」。內容：成人向服裝（帶 `lewd`、`lust` 加值）、色情技能書、打工線獨特技能的技能書（稀有）、慾望藥劑。
- **掉落**：怪物的 `loot` 加色情技能書；層主保證掉一本。
- **戰敗**：戰敗的成人事件機率很高；可以有專屬的戰敗結果（被帶回巢穴，要逃出來）。照「主角非自願」和 `defeatAdult` 的設定過濾。

## 11. 其他可以連動的系統（發散）

### 11.1 戰敗事件

- 這場戰鬥裡我方的高潮次數，提高「敵人起意」的機率（`defeat.ts`）。
- 戰敗事件的結果多三種變化：淫亂值、順從度、曝露名聲（在城鎮附近被看到）。
- 「被慾望打倒」（一場高潮 3 次，1.3 節）可以單獨當作觸發戰敗事件的條件，即使隊伍還有人站著。

### 11.2 特質：七流派的入門與進階

3.3.1 節的流派，每個做成一個入門特質（學了才能學那個流派的技能）加一個進階特質：

| 流派 | 方向 | 範例 |
|---|---|---|
| 隸從派 | 奴隸系 | 痛即是悅的轉換率 +25%；有主人時更強 |
| 縱欲派 | 淫亂系 | 高潮時全隊回復；慾望上限 +20% |
| 禁慾派 | 反制 | 慾望抗性 −0.5，淫亂值增加減半，不能學淫亂系技能 |
| 束縛派 | 裝備 | 穿著束縛用的底材時，減傷 +1、慾望上限 +10（I13 第 2 節的「雙面效應」） |
| 肉體派 | 承傷 | 慾望 ≥ 50% 時生命回復 |
| 獸蟲派 | 淫獸 | 對淫獸的慾望抗性大幅提升，淫獸不會「餵食」 |
| 刑罰派 | 承傷 | 受到暴擊時把一半的傷害轉成慾望 |
| 露出派（新增） | 曝露名聲 | 曝露名聲每 20，慾望傷害 +1 |

### 11.3 刺青、寄生物、淫紋

- **淫紋刺青**：刺青店多幾種淫紋圖樣（腹部、腰後），給慾望上限、色情技能加值。
- **寄生物的侵蝕度 ↔ 淫亂值**：侵蝕度每 10 點，淫亂值 +1。`succubus_mark` 每個階段給一個色情技能（共生階段給「魅惑之吻」，支配階段給「傾國一笑」但會失控）。馴服的寄生物「每次長休觸發一次」可以變成戰鬥技能。
- **奴隸印記**：印記的 `functions` 加「順從度累積」，主人的印記越深，順從度漲得越快；「奴之誓」只在有印記時有效。

### 11.4 消耗品、鍊金、烹飪

- 媚藥（投擲物：範圍慾望、媚毒）、清心茶（自己的慾望 −30）、冷靜劑（這場戰鬥慾望抗性提高）、精力藥（高潮後不扣生命，一次）。
- 烹飪：壯陽料理（下一場戰鬥慾望上限 +20%）。
- 鍊金配方：用淫植、淫蟲的素材，只能在主題地下城採到。

### 11.5 房子與家具

- 調教室（家具）：在家調教時加值，奴隸住在家裡時每天順從度 +1。
- 刑架、拘束台：可以在家裡觸發主人事件的「在家」版本（`at_home`）。

### 11.6 城鎮、商店、旅途

- **裁縫店、魔法物品店**：成人向的服裝與帶慾望加成的裝備。可以加一種商店類型「情趣用品店」（只在魅氣濃度高的城鎮）。
- **城鎮事件**：用曝露名聲當條件（5.3 節）。`StoryCond` 加一個條件類型：

```jsonc
"requires": { "stats": { "exposure": { "min": 40 }, "lewdness": { "min": 20 } } }
```

  任務、旅途事件、地標場景也都能用，讓「淫亂值夠高才接得到的任務線」成為可能。
- **公會委託**：娼館、貴族的特殊委託要求曝露名聲或淫亂值。
- **旅途事件**：路上被認出來（曝露名聲高時）。

### 11.7 主動行動與人際

- 新的主動行動「誘惑」：魅力對（10 + 對方慾望抗性換算 − 對方淫亂值 / 10）。成功時親密度上升、對方淫亂值 +1，也是「提議工作」（8.4 節）之前的鋪陳。
- 親密度 ↔ 慾望分擔：把慾望分給親密度高的隊友，轉移效率更好（「情熱傳染」每 25 親密度多 10%）。
- 關係記憶：「一起高潮過的戰鬥」可以當成冒險記憶（[RELATIONSHIP_MEMORY](../../RELATIONSHIP_MEMORY.md)）。

### 11.8 插圖

- 生成形象圖時，把淫亂值、曝露名聲的分段轉成標籤（[PORTRAITS](../../PORTRAITS.md)），讓同一個角色的形象圖隨著數值改變。

### 11.9 奴隸市場

- 奴隸的身價受順從度、淫亂值、會的色情技能影響；市場的商品說明列出這三項。
- 主角被賣（出售自己）時，同樣依自己的數值定價。

### 11.10 淫鬥場（附件的場所，最適合當這套玩法的舞台）

在魅氣濃度高的城鎮（11.12 節）多一個設施「淫鬥場」，三種擂臺：

| 擂臺 | 規則 | 測的是什麼 |
|---|---|---|
| 淫物場 | 和淫獸、淫蟲、淫植打 | 慾望攻擊系、禁慾派的反制 |
| 拘束戰鬥場 | 上場前隨機鎖上拘束具再打 | 雙面效應（6.3 節）：有流派的人反而變強 |
| 性戰場 | **生命傷害關閉，只算慾望**；先讓對方高潮 3 次的贏 | 純慾望攻防，色情技能唯一的主場 |

- 獎勵：錢、色情技能書、戰鬥用的淫具；連勝解鎖更強的對手（也是固定 NPC 的露臉機會）。
- 附件的負面事件做成規則：參賽就被打上追蹤印記；輸了身上加一件拘束具，連贏兩場拿掉一件；欠債的話可能變成鬥場奴隸（主角當奴隸的另一個入口，契約的 `kind` 多一種「鬥場」）。
- 性戰場也是測試平衡的好工具：可以單獨拿來調慾望的數字。

### 11.11 淫器合煉（附件的打造方式）

- 鐵匠或附魔師把一件**武器、防具**和一件**拘束具或調教道具**合成「淫器」：平常是拘束，戰鬥時展開成武器。例：長鞭 + 繩縛、盾牌 + 貞操帶、鎖鏈 + 手銬、恢復法器 + 調教道具。
- **加成看穿戴的時間**：記錄最近 10 天裡有幾天穿著。≥ 90% 的天數 → 原武器 ×1.5；≥ 2/3 → ×1.0；≥ 1/3 → ×0.5；更少就不能啟動。日常的負面效果也 ×1.5。
- 可以拆回原本的兩件，不損耗。
- 接到 [CRAFTING](../../CRAFTING.md) 的委託打造；需要記錄「穿著天數」，可以順便給 6.2 節的「穿越久順從越高」用。

### 11.12 魅氣濃度（附件的淫氣強度）

I13 已經建議每個聚落有一個「魅氣濃度」1～4。放進這套玩法後，它決定：

- 曝露名聲的累積速度（濃度 4 的地方見怪不怪，累積慢但城鎮事件多；濃度 1 的地方穿一點就被罵，累積快）。
- 哪裡有淫鬥場、情趣用品店、拍賣會；商店能不能買到色情技能書。
- 近郊的遭遇表多加淫獸的比例。
- 入城規定（城門盤查，`security.ts`）：濃度 4 的城鎮要求戴某種拘束具才能進城，戴了就有雙面效應。
- 給 AI 的地點描述多一句風氣，這樣同樣的服裝在不同城鎮得到不同反應。

### 11.13 開發度（附件的「女修開發度」，抽象成戰鬥數值）

附件的開發度有十幾個維度，很多是身體描寫，不適合當數值。挑出**對戰鬥有意義的五個**，每個五級（初萌、漸成、精熟、入微、隨心），不分體型：

| 維度 | 戰鬥效果 | 怎麼練 |
|---|---|---|
| 敏感度 | 慾望受傷倍率 + （越敏感越容易高潮，但肉體派的增益也越大） | 調教、娼館 |
| 刺激忍耐 | 慾望上限 + | 忍耐課程、刑罰派 |
| 拘束忍耐 | 雙面效應的負面 −（平常不那麼不便） | 長時間穿戴拘束具 |
| 脫縛 | 從拘束、絞縛、蛛絲、膠膜中掙脫的檢定 + | 束縛課程、自己嘗試脫縛 |
| 發情度 | 慾望自然消退 −、開戰的初始慾望 + | 縱欲派、寄生物 |

- 其他的身體維度不做成數值，留給 AI 的成人場景描寫（可以存成角色設定的文字）。
- 附件的觀察：**開發度不均勻是角色的特色**（例如禁慾派敏感度高但發情度低）。五個維度分開練，正好讓每個角色的慾望戰鬥風格不同。
- 開發度和淫亂值要不要合併，待決定：開發度比較細，淫亂值比較好懂。可以讓淫亂值等於五個維度的平均（自動算出），不另外存。

### 11.14 鎖具與脫縛

I13 第 2 節已經提過，在這套玩法裡多了戰鬥上的意義：

- 拘束具的鎖決定雙面效應的倍率（6.3 節）。
- 新的主動行動「嘗試脫縛」：依鎖的等級、雙手有沒有被綁、開發度的「脫縛」決定 DC。
- 鑰匙是一次性的消耗品，可以從擊敗的敵人身上搜到（淫道的對手更常有）。
- 戰鬥中的拘束（絞縛、蛛絲、膠膜）也用同一個「脫縛」檢定掙脫。

### 11.15 奴欲心經（附件的主角專屬功法）

做成**主角專屬的特質**（建角時可選，或特殊任務的獎勵），讓主角在奴隸系統裡多幾條路：

- **暗中消解**：被迫簽下的契約，可以花一個月與一級的經驗，在體內慢慢解除。
- **多主**：可以同時有好幾個主人，命令衝突時自己選要聽誰的，違反的那邊受罰（契約系統目前只能有一個主人，要擴充）。
- **鎖具交換**：沒有鑰匙也能解開一件鎖著的拘束具，但要換上一件同等級以上的。
- 戰鬥上：雙面效應也吃鎖具倍率（附件的規則）。

### 11.16 敵人的手段（附件的男修手段與反派準則）

- **人型敵人的色情技能**：催情術（不靠道具的範圍慾望）、驅奴術（對身上有奴隸印記的人額外強，可以短暫控制）、威壓（等級高於目標時，目標慾望抗性下降）。
- **反派的四種類型**對應戰敗事件的走向：知識型（契約陷阱、把柄）、武鬥型（拘束、刑罰）、商賈型（賣掉、欠債）、宗教型（以淨化為名）。戰敗事件的「敵人起意」之後依敵人的類型選事件。
- 附件的「反派首要目標是主角」「每段劇情主動引入反派」**不採用**（I13 第 4 節的理由：會繞過內容篩選、讓 AI 編出引擎沒有的劇情）。

### 11.17 場所

附件的場所可以拆成地標或城鎮事件，接到現有的設施：

| 附件的場所 | 埃隆迪亞 | 和這套玩法的關係 |
|---|---|---|
| 淫鬥場 | 新設施 | 11.10 節 |
| 拍賣會 | 地標（濃度 3 以上的大城） | 買賣色情技能書、稀有淫具；被盯上的城鎮事件 |
| 淫市 | 市場的黑市分區 | 情趣用品店、打工抵債 |
| 淫服裁縫鋪 | 裁縫店的特別商品 | 訂做帶 `lewd` 加值的服裝 |
| 青樓 | 娼館（現有） | 第 8 節；附件的「新人檢查與訓練期」就是 8.2 節的受訓 |
| 醫館 | 神殿或治療師（現有） | 取出寄生物 |
| 驛站的奴房 | 旅店（現有）的城鎮事件 | 濃度高的城鎮，女性旅客只有奴房可住 |
| 殺手奴會 | 勢力 | 可以接到點子 I6（暗殺、背叛）；被盯上時派出的刺客是有色情技能的強敵 |
