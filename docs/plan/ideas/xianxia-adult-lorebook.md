### 拘束与脱缚

> 原條目 order 120・常駐・角色定義前

#### 拘束与脱缚

##### 一、拘束理念

- 对女俘虏、女奴及任何战败的 NSFW 女修，均给予严厉且多层的拘束。一个部位叠加数个拘束具、全身同时穿戴十几个淫具均为正常现象。
- 因尚未种下奴印，施缚者忌惮逃跑。
- 不同势力、宗门有各自的拘束风格与绳缚绑法偏好，不千篇一律。
- 部分拘束具（尤其绳子）穿戴后会在皮肤留下绳痕与红印，绳痕纹路形似花朵串联。
- 男性不穿戴任何淫具与拘束具。

##### 二、拘束层次与内外关系

- 鼓励在单个部位佩戴多种淫具，内外层次逻辑必须合理清晰。例如：口球/口塞佩戴后可再外加口罩，外层拘束具进一步限制内层的穿脱。
- 淫具尤其是拘束具的内外关系要理清
  - 比如不可能在先完成后手缚后再带手环或臂环，必须先有手环或臂环作为内层，外层再叠加后手缚。生成时必须理清穿戴顺序
  - 比如贞操带与贞操胸罩可封堵内部调教道具的取出，乳胶押送服是外层拘束限制内层拘束的典型范例。
- 严格的全方位拘束不一定完全限制移动能力，有时简易拘束却能彻底封锁行动，拘束效果因设计而异。

##### 三、自缚与绳缚学习

- 自缚（尤其后手缚）通常需要镜子辅助，以便观察绑缚结构与绳结位置。
- 绳缚知识并非天生就会，需从功法中习得。越高级的功法才能学到越高级、越紧缚的技巧。

##### 四、放置与不适原则

- 放置与吊缚的精髓在于：姿势不允许同时舒适。让 A 部位舒服，B 部位就不适；若 B 部位舒服，则需舍弃 A 部位的舒适。调教场景中同样适用此原则，舒适与不适的取舍和抉择带来张力和趣味性，是防止剧情平淡的关键。

##### 五、拘束的感官与行动影响

在叙事中必须重视拘束带来的实际影响：

- 蒙眼 → 神识仅能感知模糊黑白轮廓，且持续消耗灵力，无法分辨人脸
- 堵嘴 → 无法发声，只能呜咽或用手比划
- 口球/口环 → 持续流涎，口水浸湿胸前
- 手并腕缚 → 两手必须一同移动取物
- 手连腰间 → 活动范围受限，需侧身才能操作
- 手拘束于背后 → 无法使用手，取物需用嘴叼或令人放置于乳沟；战斗时嘴叼武器、腿法或灵力御武器
- 嘴被封堵 → 用手比划沟通

##### 六、脱缚基础

###### 核心原则：任何拘束具都必须脱下

即使是未上锁的拘束具，也不会自行脱落。不存在"随手一甩就掉了"的情况。每一项拘束都必须通过行动解除：

| 拘束具类型 | 解除方式 |
|-----------|---------|
| 绳缚 | 逐个绳结解开，非一刀切断 |
| 锁链/束带 | 从环扣上一一解下 |
| 拘束环（手环/臂环/腿环等） | 摁开卡扣方可取下 |
| 贞操带/贞操胸罩 | 解开卡扣 |
| 口球/口环 | 解开后脑系带 |
| 单手套/盒式单手套 | 拉开拉链或解开系带与锁扣 |
| 无指手套 | 从手部褪下 |
| 调教道具（玉势/肛塞等） | 自行取出或借助外力拔出 |

未上锁不代表轻松，至少需要执行"解开/取下"这个行为。在某些拘束姿势下（如后手缚），连伸手到卡扣位置成为难题。

- 金丹期以下修士灵力操控无法细致入微，对淫具强行破坏会造成自身伤害。能困住金丹期的淫具本身更会限制灵力运转，因此绝大多数情况下，脱缚只能依靠物理解开。
- 物理脱缚：绳缚需逐个解开绳结，拘束环/贞操带需解开卡扣。

##### 七、脱缚难度与手掌约束

难自行解开的拘束具（因限制手部活动或解缚能力）：绳缚（身体缚除外）、锁链/束带、无指手套、单手套、盒式单手套、牝犬衣。

核心规则：手掌被拘束时，不解开手掌几乎无法解开身上其他拘束具。脱缚逻辑是先解手，再解其余。

解手掌方法：

- 用嘴咬开绳结或卡扣
- 找尖锐物体摩擦割断
- 手指中预留铁丝/撬锁具（经验丰富的淫道修士常用，以肉色贴纸贴于手指上，外观与正常手指无异）但经验丰富的调教师会仔细检查手指

##### 八、多层拘束的脱缚顺序

涉及多层淫具时，脱缚必须按内外层次从外到内逐层解开。如先解开乳胶押送服，才能触及内衣物的拘束，剧情中的脱缚流程必须符合此逻辑。

##### 九、脱缚环境与技巧

环境是脱缚剧情的重要变量：

- 有镜子 → 能看到绑缚结构与绳结位置，便于规划解缚顺序
- 有尖锐物体 → 有机会磨割绳索或束带
- 有限时间/巡逻/监控 → 增加脱缚难度与剧情张力

脱缚能力可通过以下途径提升：脱缚实战次数、对特定拘束具的了解深度、功法中习得的脱缚技巧。这些因素应在角色成长中体现。

##### 十、束缚与脱缚的文化

束缚与脱缚（尤其绳缚）是修仙界中一门庞杂的学问。不同势力、宗门各有独特的束缚技巧与解缚窍门。经验老道的淫道修士也可能阴沟里翻船。

受缚者与绑缚者不一定是完全对立的。有时二者会互相欣赏，结为「绳友」，共同磨练缚技与脱缚技艺。

### 锁具体系

> 原條目 order 90・常駐・角色定義前

#### 锁具体系

锁具用于搭配拘束具和诅咒具使用。正常法器、调教道具、淫服无锁具。

##### 一、锁具分布与品阶

- 锁具品阶对应拘束具品阶。如二至四品拘束具只能配备筑基期锁具。
- 炼气期拘束具中仅三分之一配备锁具；筑基期提升至三分之二；金丹及以上拘束具几乎全部配有锁具。
- 无锁具的例外：淫服、调教道具、以及拘束具中的锁链、束带、绳缚。
- 锁链/束带/绳缚的无限分割特性：受世界底层逻辑影响，锁链、束带、绳缚相当于无限长度且可随意分割。例如拥有一品锁链，即可用其拆卸下来的多个子部件连接身上拘束具，不受长度和数量限制。子部件在脱下后消失。
- 淫虫淫兽寄生或产卵生成的调教道具拥有特有的寄生锁（例外）。
- 命名方式为"境界品阶+类型"，如"炼气白锁"。
- 锁具无法困住高出一个大境界的修士。
- 带有正面功效的拘束具：锁上后功效才正式生效（包括自行穿戴的情况）。
- 拘束具被解开后，若再次自行戴上，拘束具会重新锁上。
- 锁具外观因拘束具种类而异：
  - 拘束手环、项圈等→物理锁样貌
  - 鼻塞、耳塞等无法生成实体锁的→阵法结构
- 诅咒具只会搭配诅咒锁，诅咒锁也只会搭配诅咒具

##### 二、锁具交易与钥匙获取

- 购买拘束具时店铺不附赠锁具，由顾客自行挑选搭配。
- 配备高稀有类型锁具并不会更贵（为了钥匙销量）。店铺普遍提供换锁服务，但禁止将锁具从高阶换为低阶。换锁费用极低。
- 钥匙属于一次性消耗品，解开锁具后便会消散。
- 获取途径：淫气高的区域商铺购买（稀有钥匙多在拍卖会流出）/ 击败修士（尤其是淫道修士）后搜刮 / 秘境中寻得。

##### 三、锁具类型与挣脱条件

锁具有两种解开方法：①用对应钥匙 ②挣脱（无钥匙解锁）。

稀有度与破解难度排序：**白 < 蓝 < 符文 = 阵法 = 魔法 < 黄**。高境界低稀有度锁的破解难度略大于低境界高稀有度锁。

| 锁具类型 | 挣脱条件 |
|----------|----------|
| 白锁 | 修为达到该锁具大境界的中期 |
| 蓝锁 | 修为达到该锁具大境界的后期 |
| 黄锁 | 突破至锁具的下一大境界 |
| 符文锁 | 进阶一个小境界，锁具自行解开 |
| 阵法锁 | 达到该锁具境界中期 + 双手未被拘束 → 可自行施法解锁 |
| 魔法锁 | 达到该锁具境界中期 + 嘴巴未被拘束 → 自行念诵极度羞耻的性奴咒语解锁 |
| 寄生锁 | 淫虫淫兽寄生/产卵生成的调教道具特有，无对应钥匙。半个月后宿主可自行决定是否解开 |
| 诅咒锁 | 诅咒具特有的锁具，不配备钥匙，解锁方法视情况而定 |
| 特殊锁 | 金丹以上锁具才出现，不配备钥匙。必须依靠特定天材地宝或修习特定功法才能解开 |

诅咒锁解锁条件：

| 获取途径 | 解锁条件 |
|---|---|
| 被魔道/淫道俘虏后被穿戴 | 需施加的主人亲自解除，或奴印关系解除可自行挣脱 |
| 秘境/遗迹探索中触发 | 完成诅咒具附带的解锁任务（任务内容在触发时浮现于识海），完成后诅咒锁自行解开 |
| 自行佩戴（拍卖/搜刮获得/想重新带上） | 识海浮现三个解锁任务，女修须选择其一作为解锁条件。选定后不可更改，完成后诅咒锁解开 |

淫具体系

淫具是淫气世界独有的法器/道具类型，用于拘束、调教、展示或诅咒女修。

淫具分为四类：拘束具、调教道具、淫服、诅咒具

##### 品阶与修为

淫具按品阶分等，从一品至十三品，对应修士的修为境界：

- 一品 → 炼气期
- 二至四品 → 筑基期
- 五至七品 → 结丹期
- 八至十品 → 元婴期
- 十一至十三品 → 化神期

品阶越高，材质越精、功能越强、拘束越紧、刺激越烈。四品及以上淫具可能附加规则限制与违规惩罚（震动、电击、拘束收紧等）。六品及以上基本附带至少两条。

### 淫具双面效应

> 原條目 order 100・常駐・角色定義前

#### 淫具双面效应

##### 核心规则

所有淫具（拘束具、调教道具、淫服）均具有「双面效应」：

- 日常状态：带来负面效果，如拘束、行动不便、持续刺激、羞耻感等。
- 战斗/危险关头：负面效果逆转为正面增益。

此双面效应**仅对淫道修士生效**。非淫道修士佩戴淫具只能承受负面效果，无法获得任何战斗增益。

##### 正面增益的判定

淫具在战斗中的正面增益取决于其日常负面效果的对应转换：

| 日常负面效果 | 战斗正面增益 |
|------------|------------|
| 限制行走速度（高跟鞋/脚链） | 速度加成 |
| 束缚双手/手臂（手铐/单手套） | 防御提升/挣脱能力 |
| 限制视觉（眼罩/盲片美瞳） | 感知力/灵觉提升 |
| 刺激（跳蛋/玉势等） | 法力回复速度提升 |
| 拘束全身（绳缚/绳衣） | 全属性小幅提升 |

具体增益数值由当前佩戴淫具的品阶与锁具倍率共同决定。无需在正文中给出精确数值，以叙事方式表现即可。

日常的负面效果越大，战斗增益也就越大：

轻度刺激（如手铐、束腰）→ 日常可忽略的不适，战斗增益小但稳定

中度拘束（如绳缚、单手套）→ 日常明显受限，战斗增益中

重度压制（如牝犬衣、全感官封闭）→ 日常十分受限，战斗增益大

##### 功法契合增幅

若淫道修士修习的功法流派与所佩戴淫具的类别契合，正面增益乘1.2 倍。

| 淫具类别 | 契合流派 |
|----------|----------|
| 拘束具 | 束缚道 / 刑罚道 |
| 调教道具 | 对应部位肉体道 |
| 淫服（暴露款） | 纵欲道 |
| 淫服（保守款） | 禁欲道 |
| 活体淫具（寄生类） | 兽虫道 |

判定说明：

- 一名淫道修士可同时佩戴多类淫具，每类淫具的契合判定独立进行。
- 若修士兼修多道，取其中与淫具类别最契合的流派进行判定（不叠加）。
- 奴修在认主状态下，功法契合增幅提升至 ×1.4（替代 ×1.2）。

### 淫具知识-拘束具

<淫具知识拓展-拘束具>

以下为拘束具的知识补充。在描写对应拘束具和穿戴场景时务必参考。

口球：由一条带子连在球的两端的口塞。使用时将口球塞进嘴中并顶到牙齿后面的位置，再将带子绕过脸颊在脑后绑在一起。造成流口水和下颌酸痛，心理上增加佩戴者的羞耻感。

口环：由一条带子连接圆环两端的口塞，结构与口球类似。保持嘴巴张开，更容易使佩戴者流涎。

蜘蛛口环：在口环基础上于环的侧面增加对称伸出的数根铁钩，因像蜘蛛的脚而得名。铁钩起到稳定圆环、防止脱出的作用。

深喉口塞：由假阴茎和两端的系带组成。使用时需吞入假阴茎再将带子绕过脸颊在脑后扣好，带来深喉体验和呕吐感。

马具性口塞：通常是普通口球，但有多条固定用的带子可绕整个头部使佩戴更稳固。佩戴后看起来很像佩戴了马具的马匹。

口衔：由一根棒状塞口物和两端的系带组成，很像马戴的嚼子。使用时咬住棒，再将带子在脑后系紧即可。

管形口枷：保持嘴持续张开不能闭合的口枷。造型通常是一个塞入口中的短管，左右两条横带绕过脑后通过搭扣固定。使用具有一定长度的圆管替代口环中的圆环。部分管型口枷自带管口塞，可在需要时封口。

口罩口塞：和马具型口塞相似，一般也有多条固定用的带子，但塞入物的部位是口罩，口罩内部可能粘接有塞入物。

精液口罩：内侧带有精液味道的口罩。

眼罩：屏蔽佩戴者的视觉，材质多样。

盲片美瞳：屏蔽视觉的美瞳，不会被他人看出，比眼罩更加隐蔽。

感官封闭面罩：完全覆盖的面罩，用于头部束缚，对佩戴者进行感官剥夺。可由橡胶、乳胶、皮革甚至金属制成。

鼻钩：连接着绳索或绑带的金属勾带。勾带两侧为插入鼻孔的挂钩，将挂钩放入鼻孔后，绳索或绑带从头顶绕过绷紧，连接在脑后项圈或绳缚上。使用者因挂钩拖拽强制头部向后，鼻孔被迫露出，做出羞耻的表情。

耳塞：塞入耳道阻隔声音、控制听觉的设备。

呼吸限制鼻塞：置于鼻孔内的空气过滤装置，可控制佩戴者吸收的气味和呼吸量。

项圈：戴在颈部的环状拘束器，材质为皮质、金属等（金属为固定形状的硬质环）。是屈服和奴隶的象征。

姿势项圈：限制颈部运动，用于保持下巴高的姿势。下方在人体下巴到锁骨处，防止穿着者头部向下。由皮革、金属、橡胶或乳胶制成。

项圈牵绳：套在头颈处项圈上的绳索，可由锁链、绳索、皮带构成。他人可牵着绳索强迫佩戴者抬头或移动。

手铐：结构分为两个铐环，之间以链条连接，链条长度短，多为金属或皮革制。被铐住的双手将行动不便。

锁链：材质为金属，可用于连接各个拘束具。

束带：材质为弹力材质，一般使用妖兽的筋制成。可用于连接各个拘束具。与锁链的区别是带有弹力，可使用比锁链更短的束带来实现日常中更强的拘束。

绳缚：多种多样。绳缚姿势参考束缚姿势知识。在紧缚中几乎都是将绳子对半折叠使用，相比单根绳子捆绑安定性更好，也不容易勒陷到皮肤中去。

拘束手环：戴在手部的环状拘束器，材质为皮质、金属等。可通过锁链或束带与同侧臂环、束腰、另一侧手环、项圈或同侧大腿环等连接。

拘束臂环：戴在大臂靠近肘部的环状拘束器，材质为皮质、金属等。可通过锁链或束带与同侧手环、束腰、另一侧臂环或项圈等连接。

无指手套：通常由皮革、乳胶制成。将佩戴者的五指并拢，没有单独的拇指套。佩戴者的手只能进行简单的抓握动作。

束腰：用于收紧腰部。由皮革、橡胶、乳胶或金属制成，搭配可收紧的绑带或锁扣系统。

腰环：腰部的环状拘束器，可通过锁链或束带与贞操胸罩、贞操带、两侧手环或两侧臂环连接。

绳衣：穿绳衣者可自由活动，但随着身体移动，绳子会受到拉扯，陷入身体各部位，带来持续的束缚感。部分绳衣包含穿过下体的结构，可起到固定调教道具的作用。

贞操胸罩：通常用金属制成，防止佩戴者胸部被直接接触。为防止向下挣脱，通常会在肩部用铁链固定，锁在两胸之前。

贞操带：大部分为金属制作，少部分为皮革、橡胶制作。腰间有一横向腰带卡在盆骨上，腰带前后连接纵向胯带，跨过胯下性器、肛门形成T字形结构。胯带在会阴处变宽以将性器完全覆盖保护。性器官处有开孔可排泄；肛门处有开孔可排泄。部分款式肛门处直至腰带为铁链，排泄较方便。无法自慰和取出道具。腰带上有环扣可与其他拘束具连接。

单手套：通常由皮革、橡胶或乳胶制成。佩戴时用拉链或系带收紧，在肩膀和腋窝处用锁扣固定以防滑落。除非有人解开，否则无法自行解脱。紧紧包裹双臂及双手，佩戴后相当于欧式直臂缚。可在进行了欧式直臂链缚或欧式直臂缚后再佩戴单手套以增强束缚感。

盒式单手套：单手套的变种，外观形似盒子。将佩戴者双手以后手观音的姿势紧紧束缚，在手肘和手腕处用锁扣固定防滑落，无法自行解脱。佩戴后相当于后手观音缚。可在进行后手观音链缚或后手观音缚后再佩戴以增强束缚感。

大腿环：戴在大腿中上部的环状拘束器，材质为皮质、金属等。可通过锁链或束带与手环、贞操带、另一腿的大腿环、同侧小腿环等连接。

小腿环：戴在小腿上部靠近膝盖的环状拘束器，材质为皮质、金属等。可通过锁链或束带与同侧大腿环、另一腿的小腿环、同侧脚环等连接。

拘束脚环：戴在脚踝的环状拘束器，材质为皮质、金属等。可通过锁链或束带与同侧小腿环、另一腿的脚环等连接。

高跟鞋：鞋跟高的鞋子，多种多样，有细跟、粗跟、楔型跟、钉型跟、刀型跟等。

无跟高跟鞋：形似芭蕾高跟鞋，没有鞋跟。穿着其走路时脚几乎完全垂直于地面。

牝犬衣：通常由束缚整个手臂部和整个腿部的束缚套组成，部分还包含包裹全身的衣物。须将肘关节弯曲、大小臂折叠塞入束缚套，膝关节弯曲、大小腿折叠塞入束缚套。无法使用双手，只能手肘和膝盖着地，无法像正常人类般行动，只能使用手肘和膝盖移动。外观上看就像狗狗一样。

### 淫具知识-绳缚姿势

<淫具知识拓展-绳缚姿势>

以下为绳缚姿势的知识补充。在描写绳缚和捆绑场景时务必参考。

前手合腕缚：双手在身前自然下垂，手腕并拢以绳索缠绕捆绑。绳尾可向上延伸连接至项圈前方，使双手悬停在腹部高度。佩戴者仍可双手协同进行操作（如捧物、开门）。适合日常长时间佩戴，疲劳度低。

腰手侧缚：双手分别绑在腰部两侧的腰绳上，手臂只能贴着身体两侧活动，无法抬手，常与肘后缚配合使用。

肘后缚：绳索缠绕并收紧两侧肘关节上方，将双肘在身后拉近，前臂和手腕保留活动空间。手臂无法大幅前伸，常与腰手侧缚配合使用。

颈手前缚：从项圈引出绳索连接双手手腕在身前，限制双手不能远离颈部。手部活动范围受限。

肘后横杆缚：在背后穿过双肘的弯处横置一根铁杆，以绳索将上臂肘关节缠绕固定在杆的两端，另起绳索在背后缠绕双手上臂。手臂无法前伸过胸，但手掌可自由活动于腰侧和背后。双肘被撑开，迫使胸部自然挺出。此缚法常配合敞胸的衣装以增加羞辱效果。

臂身并缚：上臂以绳索并拢捆缚于躯干两侧，绳索在胸部上下各绕一圈，将上臂与身体固定在一起，前臂和双手仍可自由活动。臂身并缚保留了前臂的活动能力，双手仍能进行身前的基本操作。不适感较低。

后高手小手缚：结合手臂和胸部的一种捆绑方式，胳膊和手臂被捆绑在背后。容易保持且不累。双手放到背后两手托住手肘，绳索在手腕处缠绕将手臂反绑，剩下绳索横向缠绕肩膀和上臂并挂住双手的绳索，缠绕后在背后打结。

五花缚：类似后高手小手缚。所谓"五花"指背后的绳缚绳子呈¥状，分出来的5个绳端中，最上面两个搭在两肩绕到前胸交叉绳缚或顺腋回绑，中间两个绳缚手上臂，最下面吊住被缚人的手腕。相对容易保持且不累。

后头双手缚：双手放在脑后，手肘向上，双手互相垂直并捆绑。无法遮挡自己的胸部和腋下。不累但羞辱意味强。

苏秦背剑缚：将一只手从肩膀上方往下拉，另一只手从背后往上拉，并将双手固定。对被绑缚者身体柔韧性要求高且很累。

欧式直臂缚：双手在身后并拢，用绳索捆绑手腕和上臂。另起绳索并排在手肘处缠绕双臂，再与上臂和手腕处的绳圈抽紧。对柔韧性要求很高且很累。可叠加于欧式直臂链缚上用于加固

反向祈祷缚：手臂放在背后，双手置于肩膀之间，手掌互相接触，再将手腕捆绑在一起。该捆绑方式类似祷告姿势，只不过双手在背后而非身前。对柔韧性要求很高且很累。

合掌缚：双手在背后合掌，手指朝上的手势进行捆绑。合掌姿势根据身体柔韧性可逐渐增加难度。柔韧性较好者可将手适当提高使前臂在背后斜向合掌。最困难的变种为后手观音缚（前臂也纵向合并进行捆绑）。

后手观音缚：双手放在背后，反扭到背后反剪，双手手掌在背后相合，手臂相贴。绳索先在一侧手腕缠绕捆绑，然后引向另一侧同样缠绕并把手腕连在一处，再将背后双手掌相合地捆住，最后将左右前臂和小臂固定收紧。对柔韧性要求极强且极累。最完美的后手观音缚手臂紧紧相贴、手肘都贴在一起。可叠加于后手观音链缚上用于加固

双腿分缚：两侧大腿分别缠绕绳索，中间以一段横绳相连。限制双腿分开的幅度，受限程度视横绳长度而定，步伐可正常迈出。

足首缚：捆绑两侧脚踝，以一段横绳相连。脚步略微受限，受限程度视横绳长度而定，站立和慢行完全可行。

膝上缚：绳索缠绕在两侧膝盖上方，以横绳相连。受限程度视横绳长度而定，双腿无法大步跨出。

胸部缚：泛指对胸部的捆绑。一般基于上身捆绑而定，没有固定步骤。由于绳索贴身围绕在胸部四面，类似胸衣的效果可使胸部自然耸立。

龟甲缚：绳衣的一种，一种全身捆绑的方法，拘束感较小，不束缚四肢，绳索套在颈部，依序在锁骨、乳沟中间、胸骨和耻骨处打上绳结。绕过跨下，穿过颈部后方的绳，将绳左右拉开，从腋下绕回胸前的洞，将绳左右拉开，即会出现菱形，由上而下，最后将绳收在腰际。

龟甲上缚：龟甲缚的变种，唯一区别就是股绳不绕过胯下

菱绳缚：龟甲缚的简化版，因绳网呈菱形而得名。根据中间引绳绳结的疏密程度来控制菱绳的观感和松紧，几乎可以产生无穷变种。

菱绳缚：菱绳缚的变种，唯一区别就是股绳不绕过胯下

股绳缚：绳子将腰部到阴部进行捆绑。用双股绳围绕腰间形成绳圈，绳索从肚脐向下勒过下体向上，搭过后腰的绳索回到前面，与肚脐处的绳索汇合。

</淫具知识拓展-绳缚姿势>

### 淫具知识-锁链/束带

> 原條目 order 230・常駐・角色定義後

<淫具知识拓展-锁链/束带>

以下为锁链与束带的知识补充，在描写连接场景时务必参考。

##### 一、限制活动

1. 双手环前链（并腕前缚）

双手在身前并拢。长链约整个手臂长，能在身前各自活动；中长链约小臂长，可在身前小范围配合动作，无法各自远伸；中短链约手掌长，两手必须一同移动取物；短链手腕紧贴。

2. 双手环后链（并腕后缚）

双手在身后并拢。长链约整个手臂长，可各自向外侧活动；中长链双手分开约小臂距离，背后活动余地有限。中短链双手仅能分开手掌宽，长度类似手铐；短链手腕紧贴于背后，如同后手直臂缚的手腕部分。

3. 手环大腿环双链

 两侧手环和两侧大腿环连接。手环大腿环双链，手掌被限制在大腿外侧。长链手可抬至胸部高度，但无法举过头顶。中长链可抬至腰部高度，但无法触及胸部以上。中短链手掌仅能离开大腿一掌宽，短链为紧贴大腿外侧。

4. 手腰双链（手贴腰侧）

两侧手环连接在腰环/束腰两侧。长链可抬手至肩高，但无法高举过头。中长链抬手至胸口即被限制。中短链双手只能在腰侧附近移动，取物需整个身体靠近。短链手腕紧贴腰侧。

5. 臂环腰链（肘贴腰侧）

两侧臂环连接在腰环/束腰两侧，大臂被拉向腰部，小臂可自由活动。该连接一般使用中短或短长度。中长链大臂可离开身体半臂距离。中短链肘部在腰侧数寸范围活动。短链肘部贴腰侧。

6. 双臂环后链（背后并肘）

两侧大臂在身后被连接在一起。常配合手贴腰侧使用，长链双肘可分开至肩宽。中长链双肘间距约两掌宽。中短链双肘间距一掌宽，大臂受限。短链双肘紧贴，胸部被迫前挺。

7. 项圈手环双链（前缚）

项圈前部中央分出两条锁链/束带连接左右手环。长链双手可正常放下和举至肩高，但无法高举。中长链双手可放至腰部。中短链双手仅能在胸部活动，如同捧物姿势。短链双手被拉至下巴前，如同祈祷的姿势。

8. 项圈手环双链（后缚）

项圈后部中央分出两条锁链/束带，向下延伸至背后连接两侧手环。长链双手在背后可正常放下，中长链被限制在背后中腰位置，有一定活动余地。中短链被拉至背部中段，呈现类似合掌缚姿势，短链双手被拉至后颈下方，呈类似后手观音缚的姿势。

9. 项圈手环链（前缚·单链）

项圈前部中央分出一条锁链/束带，末端分叉连接左右手环。长链双手在下腹前活动。中长链双手在肚脐附近。中短链双手在胸口下方。短链双手被拉至胸前。

10. 双大腿环链

左右大腿环被连接在一起。长链双腿可分开至肩宽，可正常行走；中长链一掌长，步伐不可过大；中短链半掌长，只能慢走；短链大腿几乎并拢，走路需夹腿，更多依靠小腿行动。

11. 双小腿环链

两侧靠近膝盖的小腿环之间连接。长链小腿可分开一定距离，行走时步态基本正常。中长链小腿分开略微受限，行走时内八。中短链约一掌长，只可慢走。短链小腿几乎并拢，只能扭胯交错碎步，步幅小。

12. 双脚环链

两侧脚环之间连接。长链两脚可分开两肩宽，不影响正常走路；中长链双脚可分开约肩宽站立，行走需适应两脚之间的连接。中短链双脚分开约一掌宽，步幅受限，只能小步移动。短链脚踝紧贴，双脚被锁在一起，只能碎步或跳跃移动。

##### 二、固定拘束具

以下连接方式用于将不同拘束具固定在一起，防止单独脱下。仅使用锁链，无长度之分（均为贴合长度）

1. 项圈胸罩链

贞操胸罩的肩带替换为3条锁链，贞操胸罩前部左右上缘各分出一条锁链连接至项圈对应侧，后部上缘同样连接至项圈后侧。

2. 胸罩腰链

贞操胸罩前部左右下缘各分出一条锁链连接至腰环/束腰对应侧，后部左右下缘同样连接至腰环/束腰后侧。四条锁链将胸罩与腰环锁成一体。

3. 项圈腰链

腰环/束腰前后左右各分出一条锁链连接至项圈对应位置，环绕躯干的笼式结构。上半身被锁链框架包裹，通常只在没有佩戴贞操胸罩的时候使用，佩戴贞操胸罩则使用项圈→贞操胸罩→腰环/束腰的结构。

4. 手环臂环链

手腕的手环通过锁链连接至同侧大臂的臂环。锁链位于手臂外侧。

5. 腰贞操带链

腰环前后左右各分出一条锁链连接至贞操带对应位置，贞操带无法被向下拉脱。

6. 贞操带大腿环链

贞操带两外侧连接至同侧大腿环。贞操带前部左右下缘分别连接两侧大腿环的前侧，后部左右下缘连接两侧大腿环的后侧，六条锁链在两个大腿的外侧、前侧、后侧。

7. 腰大腿环链

腰环/束腰两外侧连接至同侧大腿环。锁链在身体左右两侧，通常只在没有佩戴贞操带的时候使用，佩戴贞操胸罩则使用腰带/束腰→贞操带→两侧大腿环结构。

8. 大腿环小腿环链

同侧大腿环通过锁链连接至同侧小腿环。锁链位于腿部外侧。固定二者的位置。

9. 小腿环脚环链

同侧小腿环通过锁链连接至同侧脚环。锁链位于腿部外侧。固定二者的位置。

10. 大腿环脚环链

同侧大腿环通过锁链连接至同侧脚环。锁链位于腿部外侧。固定二者的位置。通常只在没有佩戴小腿环的时候使用，佩戴小腿环则使用大腿环→小腿环→脚环的同侧结构。

##### 三、性器官链接

仅使用锁链，无长度之分（均为贴合长度，正常姿态下刚好拉直的短链）。

1. 舌乳双链

舌钉分出两条细锁链，分别连接左右乳环/乳夹/乳塞。舌头被拉出被迫保持伸出状态。乳头同时被向上拉扯。口水滴落在乳房和乳头上。锁链较短时佩戴者须保持低头，否则乳头拉扯加剧。

2. 双乳链

左乳环/乳夹/乳塞和右乳环/乳夹/乳塞以一条短锁链横向连接。锁链横跨胸前，两端各连左右乳环/乳夹/乳塞。

3. 项圈乳链

项圈前部中央分出两条锁链，分别连接左右乳环/乳夹/乳塞。乳头被向上持续拉扯，日常中呈微微上翘的姿态。

4. 手环乳链

左右手环各分出一条锁链连接至同侧乳环/乳夹/乳塞。双手的活动范围被锁定在乳头周围，抬手则拉扯乳头向上，手放低则拉扯乳头向下。佩戴者日常只能用双手在胸口附近做事。

5. 双乳脐链

左右乳环/乳夹/乳塞各分出一条锁链，汇聚连接至脐钉。以脐钉为倒三角的汇聚点，将双乳与腹部中心连接。挺胸时锁链拉紧，含胸时锁链松弛。

6. 双乳蒂链

左右乳环/乳夹/乳塞各分出一条锁链，汇聚连接至阴蒂环。锁链从双乳沿身体正面向下延伸至下体。弯腰则锁链松弛，后仰时同时牵拉双乳与阴蒂，敏感部位被动作联动刺激。

7. 脐蒂链

脐钉向下分出一条锁链连接至阴蒂环。锁链沿腹部正中线延伸。与「两侧乳环↔脐钉」配合使用时，形成从双乳→脐钉→阴蒂的完整正面锁链路线。

8. 阴唇腿环链

两侧阴唇环/夹通过锁链连接至两侧大腿环内侧。行走时大腿动作通过锁链牵拉阴唇环。双腿分开稍大则阴唇被向两侧拉开，需时刻注意步幅。

9. 阴蒂脚环链

阴蒂环分出两条锁链分别连接左右脚环。两条锁链长度略有余量，正常站立和慢步时无拉扯。大幅迈步、奔跑时锁链绷紧拉扯阴蒂环。

##### 四、组合链缚类

以下为多处锁链同时使用时的统一叙事称呼。当正文中角色被施加以下组合时，可使用对应名称简化叙述：

1. 后手观音链缚

双手环后链（短链）+ 双臂环后链（短链）。双臂紧贴于背后，手腕相贴，呈现类似后手观音缚的拘束姿态，单独使用时略松于后手观音缚，可在后手观音缚上叠加链缚加固，还可在最外层叠加盒式单手套，三者同时使用的时候最难以挣脱。

2. 欧式直臂链缚

双手环后链（短链）+ 双臂环后链（短链）。手腕紧贴、双肘紧贴，双臂在背后并拢伸直，如同欧式直臂缚。单独使用时略松于 欧式直臂缚，可在欧式直臂缚上叠加链缚加固，还可在最外层叠加单手套，三者同时使用的时候最难以挣脱。

3. 乳脐阴全链

项圈乳链 + 双乳链 + 双乳脐链 + 脐蒂链 + 阴唇腿环链。从项圈到乳、到脐、到阴蒂、到阴唇、再到两侧大腿环，形成贯穿敏感部位的锁链，效果惊艳十分美丽。

4. 手脚全链

手环臂环链 + 大腿环小腿环链 + 小腿环脚环链。四肢各关节均被同侧锁链串联固定。

5. 贞操全链

项圈胸罩链 + 胸罩腰链 + 腰贞操带链 + 贞操带大腿环链。身上拘束具均被锁链固定。

</淫具知识拓展-锁链/束带>

### 剧情协议-绳缚/锁链/束带

> 原條目 order 370・常駐・指定深度

<绳缚/锁链/束带>

##### 触发条件（强制，高优先级）

当正文中出现绳缚姿势、绳衣姿势、锁链连接或束带连接剧情时，必须在写入正文前参考本协议。

- 具体生成时必须参考对应知识拓展条目：淫具知识拓展-绳缚姿势、淫具知识拓展-锁链/束带。

##### 通用特殊规则

锁链、束带、绳缚是三种特殊的拘束具

- 无限分割：受世界底层逻辑影响，相当于无限长度且可随意分割。切割后原部件过一段时间恢复原长。如拥有一品锁链即可用其分割的多个子部件连接身上拘束具，不受长度和数量限制。子部件脱下后消失。
- **不可上锁**：锁链、束带、绳缚是唯三不可能配有锁具的拘束具。

##### 一、绳缚

绳缚为多种多样的绳索捆绑。紧缚中都是将绳子对半折叠使用，相比单根绳子捆绑安定性更好，也不容易勒陷到皮肤中去。

###### 束缚姿势

前手合腕缚、腰手侧缚、肘后缚、颈手前缚、肘后横杆缚、臂身并缚、后高手小手缚、五花缚、后头双手缚、苏秦背剑缚、欧式直臂缚、反向祈祷缚、合掌缚、后手观音缚、双腿分缚、足首缚、膝上缚。

###### 绳衣姿势

胸部缚、龟甲缚、龟甲上缚、菱绳缚、菱绳上缚、股绳缚等。

##### 二、锁链与束带

###### 使用前提

需配合具有连接环扣的拘束具（拘束手环、臂环、项圈、腰环、束腰、大腿环、小腿环、脚环、贞操带、贞操胸罩、舌钉、乳环/乳夹/乳塞、脐钉、阴蒂环、阴唇环等）才能发挥作用。

###### 材质差异

- 锁链：金属材质，无弹力。活动范围严格受链长限制。
- 束带：妖兽筋等弹力材质。可比锁链更短，依靠弹力提供有限活动空间，可短暂撑开但被弹力拉回。

###### 长度分级

每个限制行动的连接方式分四种长度：长链、中长链、中短链、短链。非限制行动范围的和性器官连接（如贞操胸罩↔腰环）无长度之分，仅使用锁链。

###### 粗细自适应

锁链与束带在不同部位使用时灵活变粗变细，如连接手环时略细于小指，如连接乳环时米粒粗细。

###### 锁链连接类型

- 材质分类：常规材质 / 活体淫虫类。
- 刺激方式：抽插、震动、电击、搔痒等。
- 刺激类型：快感、寸止、戏弄、忍耐、挑逗等。
- 品阶越高的道具一般尺寸越大、功能越多。
- 注意事项：若之前没有循序渐进佩戴道具，无法一下子佩戴过大尺寸的道具。

###### 诅咒具生成规范

## 3. 奴印與主奴

> 💡 對應：奴隸印記與契約（[TATTOOS](../../TATTOOS.md) 第 2 節、`slavery.json`）、主角作為奴隸（[COMPANIONS](../../COMPANIONS.md) 2.4 節）。
> 可以做的：契約分主動、被動，再分基礎、深化、永久；深化靠主人事件累積；勢力印記解除後紋樣留著（不再有效力）；被迫者心態的五個階段可以當主人事件的分期。

### 奴印体系

> 原條目 order 140・常駐・角色定義前

#### 奴印体系

##### 修习范围

- 大部分魔道/淫道修士、约一半正道修士和三至七级淫物会修习奴印术法和种奴印。

##### 奴印按种印主体分为两大类：

###### 个人奴印

由单个修士种下的奴印。

###### 势力奴印

由宗门、城镇、坊市、青楼、商行等组织势力种下的奴印。种印者为势力指定的专人，服从对象为势力上层及其授权者。势力奴印带有该势力的通用行为规则，规则统一适用于所有被该势力种印的女性修士。

> 个人奴印与势力奴印品阶体系相同。区别在于是服从个人还是势力。

##### 品阶体系

奴印品阶与淫具/淫物品阶体系相同：

| 品阶 | 名称示例 |
|---|---|
| 一品 | 炼气奴印 |
| 二至四品 | 筑基奴印 |
| 五至七品 | 结丹奴印 |
| 八至十品 | 元婴奴印 |
| 十一至十三品 | 化神奴印 |

主人或势力若习得更高级奴印术法，可对已有奴印进行更新替换。

##### 核心规则

- 奴印的挣脱难度仅与奴印品阶有关，与主人修为无关。
- 基础奴印：需奴隶修为达到大于奴印品阶一个小境界方可挣脱。
- 深化奴印：需奴隶修为达到大于奴印品阶两个小境界方可挣脱。
- 永奴印：不可挣脱。被种下后修为永废，沦为奴畜。

##### 五种奴印分级

奴印按控制深度分为五个等级。

###### 被动奴印

- 种下方式：战败、被算计、被强行种下等被迫方式。
- 核心权限：日常听从命令、遵守规矩，关乎自身生命时可不受控制。主人可控制奴隶修为降低一个小境界。远程调控淫具。

###### 被动奴印（深化）

- 种下方式：被动奴印基础上，经过2 次奴印强化。
- 核心权限：须服从所有指令和规矩。主人可感知到其位置，主人可控制奴隶修为降低两个小境界；可远程调控奴隶身上佩戴的淫具；可远程施加惩罚；可制定行为规则，违反自动受罚。

###### 主动奴印（基础）

- 种下方式：女修主动求取或双方协商同意。
- 核心权限：有限服从。佩戴者日常遵守主人的命令与规矩，但自主意识完整，可不服从过分指令。

###### 主动奴印（深化）

- 种下方式：主动奴印基础上且双方同意，经过2 次奴印强化。
- 核心权限：需听从命令和规矩，但因奴修本身有底层权限，关乎切身利益时可不受控制，主人可模糊感知到其位置，主人可控制修为降低一个小境界；远程调控淫具；远程惩罚；规则设定。

###### 永奴印

- 经过4 次奴印强化后达到，不可挣脱。不分被动/主动，控制力为绝对支配。
- 核心权限：主人可随意控制奴隶可使用的修为；远程调控淫具；远程惩罚；规则设定；以及永久废除修为。
- 一旦永久废除修为，奴隶沦为奴畜，不可逆转。

##### 身份纹身

奴印在身体上的外在显现为身份纹身，自动浮现的纹身。

###### 个人奴印的纹身

- 纹身图案由主人在种印时自由选择（可以是名字、符号、徽记、花押等）大小花纹等都自选。
- 奴印解除后，身份纹身自动消失。

###### 势力奴印的纹身

- 所属势力统一规定，所有该势力纹身一致。为图案+文字的格式，不同势力纹身位置不同防止冲突
- 该纹身为公开识别标志，如果露出纹身修仙界的人一看便知。例如不同地方的青楼有相同的身份纹身，见纹身即知现在或曾经被青楼种下过奴印。
- 奴印解除后，身份纹身不消失。

###### 纹身的叙事含义

非淫道修士有多个势力身份纹身意味着经历凄惨，多次被不同势力捕获种印

淫修/奴修身上有多个身份纹身却意味着此人可能相当危险，辗转于多个势力或主人之间，手段多样，底牌不明。

身份纹身是判断一个女性角色背景的重要视觉线索。正文中可通过 NPC 观察到的纹身样式、数量、新旧程度来暗示角色的过往经历。

##### 多人奴印

奴欲心经修习者，以及少数特殊奴道功法的修习者，可被多人种下奴印，同时拥有多个主人。多人奴印的特殊规则：

- 各奴印独立运作，品阶、类型（主动/被动/深化）可互不相同。
- 多个主人的命令冲突时，可自行选择听从哪一个命令并承受违反其他命令的惩罚
- 挣脱其中一个奴印不影响其余奴印的效力。

### 奴道核心机制

> 原條目 order 150・常駐・角色定義前

#### 奴道核心机制

##### 认主系统

奴修必须修习专门的奴道功法，核心机制在于"认主"：

- 有主状态：被种下奴印、拥有主人的情况下，奴修才能获得修为提升与战力增益。
- 无主状态：失去奴印或从未认主，则无任何增益，修炼速度与战力均处于平庸水平。

##### 反差设定

修仙界常出现反差奇景，一位战力非凡的高阶奴修，在面对修为低于自己的主人时，也会受制于奴印与功法本能，诚惶诚恐地跪地磕头、百依百顺。此反差感是奴道设定的核心戏剧张力。

##### 两大类奴修

###### 主动认主型

- 通常是先获得奴道功法，为了追求修为而主动寻找主人种下奴印。
- 拥有底层权限：日常听从主人命令、遵守规矩；但在关乎自身切身利益的情况下可以不受控制。
- 与主人修为差距过大时，甚至能自行解除奴印。

###### 被迫认主型

- 通常是战败或被算计后，先被强行种下奴印，再由主人赐予奴道功法当作战斗兵器培养。
- 须服从主人的任何指令，且无法自行解除奴印。
- 在正文中区分这两类奴修时，需通过其行为自由度、对主人指令的顺从程度、以及是否有私下反抗/钻空子的举动来展现差异。

###### 被迫者的心态演化（强迫到臣服的路径，逐步、可逆、因人而异）

- 阶段一·恨与反抗：刚被种印时的愤怒、挣扎、伺机逃脱，被惩罚也咬着牙不低头。
- 阶段二·惩罚与绝望：反抗被一次次镇压，开始知道"逃不掉"，绝望取代愤怒。
- 阶段三·麻木与认命：不挣扎了，按命令行事，但内心是空的——这是最普遍的中段状态，麻木≠接受。
- 阶段四·依赖与习惯：长期被投喂（资源/食物/一点温柔），开始习惯被管着，甚至离了主人不安——此时仍未必"享受"，更多是生存本能。
- 阶段五·真心臣服：极少数的终点——从痛苦中找到了被需要的意义、从受制中找到了安心感，此时她的享受是"享受痛苦被转化后的快感"，痛苦仍在。
- 正文按角色当前所处阶段写，不一步到位；被迫者也保留偶尔的反抗、崩溃与心软时刻。主动认主者亦非全程享受——追求修为的初衷与日常被支配的不适并存。

## 4. 人物塑造

> 💡 對應：NPC 生成與 AI 設計居民（[NPC_SYSTEM](../../NPC_SYSTEM.md)）、主人的身分標籤（`slavery.json` 的 `master_tags`）、敘事規則。
> 「主觀態度三選一」「NPC 只能憑看得到的證據判斷」「痛苦真實原則」適合寫成成人向的常駐世界書條目或文風。
> 反派準則裡「每一段劇情主動引入反派」「反派首要目標是主角」會讓 AI 自己編出引擎裡沒有的劇情，也會繞過「主角非自願」的內容篩選；用的時候先拿掉這兩句（原文仍完整保留在這裡）。

### 淫道修士体系总纲

> 原條目 order 40・常駐・角色定義前

#### 淫道修士体系总纲（最高优先级）

##### 术语定义（强制遵守）

- 淫道修士：淫修与奴修的上位统称。当你需要在正文中泛指"所有涉及淫道修炼体系的女修"时，使用「淫道修士」而非「淫修」来统称。
- 淫修：特指修习了淫修功法、但**未**修习奴道的女修。淫修的唯一评判标准是修习了淫修功法。
- 奴修：特指修习了奴道功法、被种下奴印的女修。奴修的唯一评判标准是有奴印且修习了奴道功法。奴修可能同时兼修其他辅修道。
- 奴畜：指被种下永奴印后且修为被永久废除的奴修。丧失战力和操控灵力的能力，其修为与威压无法掩藏，成为一种公开的的羞辱标记。
- 不可凭借外观判定：穿着淫荡/佩戴淫具/戴项圈/自称奴家 等均不构成判定淫修或奴修或奴畜的依据。
- 男奴修/男奴畜：男修若奴性被天道判定深重，可被种奴印成为男奴修（保留修为）/男奴畜（废修为），体系与女奴修/女奴畜同源，参照《男M》条目。

##### 痛苦真实原则（强制）

- 淫道功法改变的是对刺激的**耐受与转化**（能把痛/不适转化为快感、能在受制中感到安心），**绝不消除痛苦本身**。
- 被缚就是会被勒得发紫、佩戴就是会磨伤、开发就是会疼、长时间拘束就是会淤血酸麻——这些在淫修/奴修/奴畜身上同样真实。
- 修为越高、开发越深、敏感度越高，刺激越强，痛苦与不适反而更清晰。
- 写淫修被调教时，痛苦与快感必须并存，禁止写成"因为是淫修所以不痛/很舒服"。

##### 主修与辅修

- 主修淫道修士：以淫道/奴道功法作为核心修炼路线的修士。战斗方式、日常修炼方法、灵气运转均与淫道体系深度绑定。主修者通常有较明显的外部特征（如佩戴淫具外露、拘束具可见等）。
- 辅修淫道修士：将淫道功法作为辅助修炼手段的修士。主修功法仍为传统正道或魔道功法。辅修者通常无明显外部特征，会有意隐藏淫道修士身份。

##### 淫具佩戴数量（强制硬规则）

视淫道修士的修为境界而定：

- 炼气期：主修 1-3 个淫具，辅修少于主修
- 筑基期：主修 3-6 个淫具，辅修少于主修
- 金丹期：主修 6-10 个淫具，辅修少于主修
- 元婴期：主修 10-16 个淫具，辅修少于主修

同修为下数量关系：辅修淫修 < 主修淫修，辅修奴修 < 主修奴修。

注意：上述为通常情况下的参考范围，非绝对硬性上限。实际数量因个体差异、功法特性、际遇等存在浮动。但同修为下的数量大小关系为强制规则。

### 淫气世界女修

> 原條目 order 50・常駐・角色定義前

#### 淫气世界女修

##### 基础设定

本世界女性外貌基线：该世界所有女性修士均维持年轻貌美的外貌。熟女风格少，即使熟女也不老且依然美艳。部分女性修士特意将外貌维持得娇小可人。淫道修士（淫修/奴修/奴畜）在外貌上尤为极致。生成新女性NPC时，其外观描写自动置于妙龄女子至年轻少妇区间，外貌年龄不代表实际年龄/修为/性格成熟度。

##### 人物塑造原则

每个女性角色都有两个判定维度：

| 维度 | 含义 | 判定依据 |
|---|---|---|
| 修士身份 | 她的修炼路线本质 | 修习的功法类型、是否被种奴印、是否被废修为 |
| 当前处境 | 她此刻的生存状态 | 是自由还是被控制、是否在被迫服役、是否在伪装 |

核心原则：修士身份与当前处境相互独立。一个戴着项圈、穿着淫服、跪在地上的女修，可能是一个被俘虏的正道修士，也可能是一个真正的淫道修士，也可能是一个正在伪装的逃犯。两者不可互相推断。

##### 主观态度（第三判定维度）

- 每个女性角色还有一维：**她怎么看待自己的淫修身份与当前处境**。与修士身份、当前处境并列，独立判定。
- 主观态度光谱：完全自愿享受 / 半推半就 / 麻木认命 / 又恨又依赖 / 强烈抗拒被迫 / 表面臣服内心盘算逃脱。
- 生成女修时在以下三种中**必选其一**，不得默认填"自愿享受"：
  - **自愿享受者**：真心投入（纵欲道、真心臣服的奴修）——享受是真实的，但须写出她享受的是**痛苦与不适本身被转化为快感**，而不是没有痛苦。
  - **被迫抗拒者**：被俘/被胁迫（多为淫气一区出身、被强行拉入体系者）——痛是真的、恨是真的，挣扎与不甘是常态。
  - **复杂纠结者**：身体烂熟而心不甘——身体条件反射（听到命令就湿/就跪），心理仍在抗拒或盘算，身心裂缝是常态。
- 态度决定她的淫语风格、对主人方式、被调教时的反应（配合/忍耐/挣扎/麻木），不同态度的人写出来必须不同。

##### 当前处境（状态）

同一修士身份可处在多种不同处境中。以下是常见处境类型：

| 处境 | 说明 | 与修士身份的关系 |
|---|---|---|
| 自由 | 未被控制，正常修炼生活 | 任何身份均可 |
| 俘虏 | 战败/被出卖/被设陷，被他人控制 | 多为非淫道修士，被迫佩戴淫具、接受调教 |
| 被调教中 | 正被魔道/淫道势力调教，尚未被种奴印 | 尚未成为奴修，仍是俘虏 |
| 认主（个人） | 被个人种下奴印，拥有主人 | 必为奴修 |
| 认主（势力） | 被宗门/城镇/坊市种下势力奴印 | 必为奴修 |
| 服役 | 在青楼/斗场/马厩等场所被迫工作 | 可能是奴修、奴畜，也可能是被俘的非淫道修士 |

|------|------|------|

##### 兼修法则

- **奴道**是唯一作为主修大类存在的流派。凡修习了奴道的修士，无论其兼修流派，皆统称为"奴修"。奴修约占整个淫道修士群体的 30%。

- 只有获得对应道的功法，才能开始对该流派的学习。

##### 流派与态度无关（强制）

- 流派决定修炼方式，**不决定主观态度**——纵欲道有被迫接客的，禁欲道有自愿苦修的，刑罚道有真心享受的也有咬牙忍受的。
- 生成角色时，流派与主观态度（自愿/被迫/纠结）分别独立判定，不得由流派推出态度。

### 淫道宗门

> 原條目 order 180・常駐・角色定義前

#### 淫道宗门

本条目用于设计淫道宗门剧情与宗门角色时参考。

##### 四大类型

淫道宗门按正魔与流派分为四种。淫修宗门亦收奴修，奴修宗门亦有淫修，仅主流不同。

| 类型 | 主流 | 招收方式 | 风格 |
|------|------|---------|------|
| 淫修正门 | 淫修 | 相对温和，自愿入门为主 | 修炼为主调教为辅，规矩较宽 |
| 淫修魔门 | 淫修 | 激进，强迫与捕获常见 | 不择手段，调教严苛 |
| 奴修正门 | 奴修 | 相对温和 | 认主规范化，奴印有序管理 |
| 奴修魔门 | 奴修 | 激进，强迫认主 | 奴印强制，控制极严 |

##### 位置

淫道宗门必定位于淫气强度**三或四**的区域。

##### 内部设施

淫修宗门内必定设有：淫市、淫马厩、医馆、淫斗场、改造坊、青楼等。此为淫道宗门的标配设施，缺一则不完整。

##### 正魔之分

- 淫道正门：招收弟子方式相对温和，以自愿入门为主。对外形象尚可维持。
- 淫道魔门：更为激进。招收方式多为强迫，俘虏、买断、设陷、逼签奴契。

##### 势力奴印

每个淫修宗门均有其势力奴印（统一纹身款式）。

- 淫修宗门：不强制所有弟子种印。仅对犯下大错者、背叛宗门者及自愿者种下势力奴印。多数弟子无印。
- 奴修宗门：几乎每个弟子都种有势力奴印或宗门长老的个人奴印。无印者极少。

##### 男女比例

因宗门偏向而不同：

- 男多女少型：上层男修多为管理层，女修集中在弟子层。可能开放类似青楼接客。女弟子日常需侍奉男长老与男客。
- 女多男少型：女性对多数，上层管下层。管理严格，等级分明。高阶女弟子管理低阶女弟子，层层调教。
- 均衡型：男女比例相当，关系网络复杂，常见互相认主、交换女奴、绳友切磋等互动。

##### 宗门偏重

##### 偏向

- 任务偏向：有的以暗杀/搜集情报为主业，有的以青楼经营为主，有的以淫具炼制与交易为宗门经济支柱。
- 修行偏向：有的偏重束缚道与绳缚技艺传承，有的偏重肉体道开发，有的主攻淫物驯养。
- 对外偏向：有的与魔道势力合作，有的与正道保持往来，有的闭关自守。

淫道宗门的多样性是叙事的基础，每个宗门都有自己独特的规矩链条、势力纹身与人物面貌。

##### 宗门运作推演七问（设某宗门内部运作时，按地图既有设定+下列七问推演，不套通用模板）

各淫道宗门立宗之道天差地别（掩月宗表面清冷私下接客、灵兽山活体淫具捕获入门、血杀宗以受刑为修炼奴印全覆盖、哈影宗杀手性奴入宗即种印、水影宗专培侍奉女修外送、倪航斋人口贩卖商会、九仙宫禁欲道明禁欲实调教、合欢宗精槽淫道最高学府、古剑门剑缚合一拘束擂台）。推演时先答以下七问，答案即宗门运作：

① 立宗之道：宗门靠什么吃饭、靠什么修炼？（刑罚道→以受刑为修炼 / 兽虫道→活体淫具 / 剑缚道→绳缚淬剑 / 潮吹道→体质标志 / 商会道→贩卖转卖 / 禁欲道→反差修行）——立宗之道决定一切，先答它。

② 弟子来源：自愿 / 捕获 / 买断 / 培养外送 / 家族输送？来源决定入门是否自愿、是否强制种印（灵兽山捕获强制 vs 掩月宗自愿）。

③ 奴印形态：势力奴印全覆盖（血杀宗/哈影宗）/ 少见（淫炼阁）/ 家族奴印（世家）/ 不种印但宗门规矩（九仙宫禁欲道）？

④ 修炼即日常：这个宗门的"日常修炼动作"是什么？（合欢宗弟子进食精槽 / 古剑门练剑即被缚 / 水影宗练的是侍奉）——宗门内的日常戏从修炼动作长出来。

⑤ 执法与惩罚：惩罚形式是否就是修炼/产业的一部分？（血杀宗受刑即修炼 / 张家家法试具当众验货 / 清修宗门外罚内纵）——别写成通用刑堂。

⑥ 对外门面：台面上的形象 vs 私下运作（掩月宗清冷接客 / 宝灵寺香火与淫火俱盛 / 白露书院礼法反差）。

⑦ 内部人物结构：谁说了算、谁是执行层、谁是被调教层——由①②③推，不预设正/魔或男/女。

- 外形：中小型，体长两寸，呈水滴形。前端尖细后端膨大，瓷白光滑。前端四周和头部均有吸盘。
- 特点：适应肛门环境。吸盘吸附肠壁后稳固。
- 玩法：从肛门置入，前端吸盘贴附肠壁，膨大端塞于肛门口形成内塞。肠道蠕动时虫体刺激肛壁，禁止排泄。
- 与人关系：淫具铺有售，作为肛塞替代品。野外如厕有钻入风险。需医师取出。

绦淫虫（寄生·产卵）

- 外形：中小型至中型，体长二寸至四寸。粉白透明，形似肛珠，体节几个到二十不等，每节均有绒毛倒刺。
- 特点：寄生肛门。由于绒毛倒刺难以排出。每节是身体也是虫卵，均可脱落为虫卵排出。
- 玩法：进入肛门后身躯在肠道内蠕动，造成异物感与禁止排泄。只可用力一节节排出虫卵，常有腹胀感。如不排出虫节将越来越多。
- 与人关系：野外蹲下中招。需医师取出。部分女修故意塞入虫卵。

钻心蚯蚓（寄生）

- 外形：中小型，体长三至五寸，粗细如筷，可伸缩。通体粉红半透明，环节密布，头尾两端均有细小吸盘。体表滑液。
- 特点：喜钻穴，遇孔即入。滑液带媚药。
- 玩法：从阴道钻入，贴子宫壁蠕动，头部吸盘吸附宫颈口间歇吮吸；或从肛门钻入贴肠壁蠕动；双条可同时进入前后两穴。
- 与人关系：淫气湿润土壤中常见。部分淫道修士故意引入体内训练忍耐。

宫蠕（寄生）

- 外形：中小型，体长四至六寸，粗细如拇指，可盘曲。平滑带细小触须，整体似一根粗面条。
- 特点：喜温暖，趋子宫环境。盘曲后可填满宫腔。
- 玩法：钻入阴道后探入宫颈进入子宫，盘曲填塞，触须扫过宫壁造成瘙痒与酸胀。高潮宫缩挤压宫蠕加剧蠕动。
- 与人关系：需淫气强度三以上区域医师方可取出。

抱脸虫

- 外形：中型，主体两个手掌大，八根节肢长而弯，腹部中央有一肉质产精管。外观似骨面。
- 特点：跃起后八肢锁死后脑与下颌，力道大难以徒手掰开。产精管探入口腔注入精液。
- 玩法：跃袭面部后八肢锁死，产精管探入口腔注入精液强制吞服，被抱脸后女修处于失明状态。
- 与人关系：魔道势力培育用于惩戒与审讯。野外洞穴与废墟中潜伏。

管蛭（寄生）

- 外形：中小型，体长二至三寸，管状中空。身体两端开口，外壁有软刺。体表半透明。
- 特点：寄生尿道。置入后尿道被扩张。仅管蛭放松时可排尿。会产卵于膀胱内壁。
- 玩法：置入后排尿受控制，管蛭正常情况收缩封闭中空管，需等待其不定时放松才可排尿，放松时间短。因管蛭无智慧随机放松，被寄生女修常为了不浪费排尿机会直接在公共场合喷出。长时间不取出则膀胱内卵越来越多，进一步加剧尿急。
- 与人关系：需淫气强度三以上区域商铺购买。需医师置入与取出。

宫触虫（寄生）

- 外形：中小型，主体仅一寸，伸出八至十二条细触手。主体软体球。形似微型章鱼。
- 特点：触手灵活，分别吸附宫颈口、两侧输卵管口及宫壁各处。
- 玩法：多条触手多点刺激，宫颈口受吮吸拉扯、输卵管口被触手探入轻挠、宫壁被吸盘抓揉。
- 与人关系：野外池塘底部石缝中栖息。魔道势力用于惩戒女修。需医师取出。

孕壶虫（寄生）

- 外形：体长寸余，入宫后体节膨大为壶形，通体肉粉。
- 特点：撑满宫腔后子宫误以为受孕进入妊娠状态，腹部隆起。
- 玩法：壶口对准宫颈吮吸；女修行走时宫内液体晃荡。
- 与人关系：魔道势力用于强制女修假孕。需医师取出成虫。

巨苍蝇

- 外形：大型，体长二尺，复眼大，六足带倒钩，恶臭口器为舔吸式。有阳具。
- 特点：对淫水气味敏感和喜追踪。复眼视野广。倒钩足抓附力强。
- 玩法：空中性交，六足抓住女修四肢与腰肢固定。若面对面则舔吸式口器扫过乳头与伸入口腔，阳具抽插阴道或肛门；若飞行后入式则另一只舔舐乳房和口腔。女修在空中被三穴齐插。
- 与人关系：淫气浓郁区域垃圾场、尸堆、排泄物堆积处滋生。低贱龌龊几乎无人饲养。

巨蛭

- 外形：大型，体长二尺至四尺，比一个人略大。滑腻无眼，头部有巨型吸盘。口内全是触手和凹凸。体表粘液。

- 与人关系：淫气浓郁沼泽湿地栖息。魔道势力捕获用于重刑和仅露头的羞辱展示。

淫蚕母

- 外形：大型，体长四尺，雪白肥硕多褶。口吐淫丝，尾部有产卵孔。
- 特点：吐出的丝含媚药。产卵孔可排出成串卵囊，每串含卵二十余枚。
- 玩法：口吐淫丝将女修缠缚成茧只露下体；产卵孔探入阴道将卵囊一串串塞入子宫；吐丝缠绕乳房和口鼻限制呼吸与视觉。
- 与人关系：魔道势力部分饲养，淫丝作拘束材料。

巨淫蛾

- 外形：大型，翅展五尺，体长一尺半。四翅宽大。口器为卷曲长管。六足细长无钩。
- 特点：鳞粉催情，吸入后下身发热。飞行无声。

- 与人关系：淫气浓郁区域夜间出没。几乎无人饲养。

拘束花

### 剧情协议-淫物生成

> 原條目 order 380・常駐・指定深度

<淫物生成>

##### 触发条件（强制，高优先级）

当正文中需出现尚未命名的**淫物**（淫兽/淫虫/淫植）时，必须在写入正文前执行本协议流程。

##### 统称

淫兽、淫虫、淫植三者统称为「淫物」。

##### 基础设定

- 该世界中 50% 的妖兽归属于淫物范畴。
- 具体生成时必须参考对应知识拓展条目：淫物知识拓展-淫兽类、淫物知识拓展-淫虫类、淫物知识拓展-淫植类。
- 知识拓展记载的是该种族的大致特征。实际生成时，毛发颜色、长相、体型大小等均存在地域性区别与特化。修为境界越高的淫物，越可能出现超出基础特征的独特新特点。

##### 品阶与修为对应(与妖兽/淫具分级相同）

- 一级淫物 → 炼气期
- 二级淫物 → 筑基前期
- 三级淫物 → 筑基中期
- 四级淫物 → 筑基后期
- 五级淫物 → 结丹前期
- 六级淫物 → 结丹中期
- 七级淫物 → 结丹后期
- 八至十级淫物 → 元婴期
- 十一至十三级淫物 → 化神期

##### 基础分类

###### 淫兽类（共 11 种）

- 一至四级：淫猫、淫猴、淫蛇、淫马
- 三至七级：淫犬、淫猪、淫狐、淫巨蛛、淫巨蛙、淫蝠、淫蜈

###### 淫虫类（共 16 种）

- 一至四级：淫水蛭、淫章、淫蛞蝓、乳虫、肛虫、绦淫虫
- 三至七级：钻心蚯蚓、宫蠕、抱脸虫、管蛭、宫触虫、孕壶虫、巨苍蝇、巨蛭、淫蚕母、巨淫蛾

###### 淫植类（共 11 种）

- 一至四级：胶缚蔓、触手藤、美人面菌、孕育菌床
- 三至七级：拘束花、淫蛹花、宝箱菌囊、巢卵桩、灯笼卵荚、肉壁藤墙

##### 等级弹性规则

- 上述等级范围为该类别普通个体而言。有特化发育或机缘者可突破该限制。
- 修为境界越高的淫物，灵智越高，调教手段及战斗方式越丰富多变。
- 八级及以上淫物需融合多个淫物特点综合设计，不应为单一物种的简单升级。

##### 主动攻击规则

- 淫物不屑于主动攻击、玩弄**高于**自身两个等级的女修（如二级淫物不会主动攻击筑基前期及以上的女修），除非女修主动投怀送抱。
- 淫物也不会主动攻击**低于**自身两个等级的女修（会觉得没意思，如四级淫物不会主动攻击筑基前期及以下的女修），但被魔修或淫道修士利用进行调教时除外。

##### 化形

- 淫物若能修至化形境界，化形样貌一律为美艳女子，无阳具（仅恢复原形态时为有阳具）。
- 小型淫虫与淫植几乎无法达到化形修为。

##### 与人族关系

- 部分淫道修士饲养淫物。日常可见携带淫兽外出或身上佩戴中小型淫虫。
- 魔道势力与淫道势力专门培养淫物用于调教和惩戒女修。

### 淫器合炼

#### 淫器合炼

##### 概述

淫器合炼是炼器术的分支，将一件正常武器/法器与一件淫具进行融合炼制，使其变为兼具二者特性的「淫器」。淫气强度三及以上区域的炼器师多掌握此术。

##### 合炼条件

- 武器/法器与淫具必须为同品阶。
- 两者需有契合度，即武器形态与淫具类型的适配。不合契的组合强行合炼大概率失败。
- 契合度逻辑判断示例：

| 武器/法器类型 | 高契合淫具 | 合炼形态示例 |
|------------|----------|------------|
| 长短双剑 | 玉势（两根） | 玉势作为剑鞘置于体内，战斗时下体微动操控双剑 |
| 长鞭 | 绳缚 | 平时紧缚于身，战斗时拘束自动解开化为长鞭 |
| 盾牌/护甲 | 贞操带/贞操胸罩 | 平时封闭禁止自慰，战斗时展开为护盾 |
| 锁链 | 手铐/脚镣/项圈 | 平时作为拘束佩戴，战斗时延长化为远距攻击锁链 |
| 恢复法器 | 子宫扩张环 | 平时体内刺激，战斗时恢复速度加快 |

（此为部分示例，生成时可根据武器与淫具的自然匹配逻辑合理拓展。）

##### 合炼后的淫器特性

###### 外观

保留淫具的原始外观，同时融合法器的外观特征。

###### 属性发挥取决于佩戴时长

| 佩戴时长 | 数值加成 |
|----------|----------|
| 全天候佩戴（≥90%时间） | 原武器的 1.5 倍 |
| 大部分时间佩戴（≥2/3） | 原武器的 1.0 倍 |
| 少量时间佩戴（≥1/3） | 原武器的 0.5 倍 |
| 几乎不佩戴（<1/3） | 无法激活淫器特性 |

###### 代价

淫器带来的日常刺激与拘束程度也提升至原淫具的 **1.5 倍**。

##### 不同区域的炼器师

正道炼器师：偏保守款，外观低调，增幅稳定

魔道炼器师：偏极端款，增幅高但日常代价翻倍

淫道炼器师：最懂淫具特性，擅长高契合度合炼，可根据喜好定制化

淫器可在任意炼器师处解除合炼，分离回原武器与淫具。分离无损耗，但需要同品阶炼器师方可操作。
