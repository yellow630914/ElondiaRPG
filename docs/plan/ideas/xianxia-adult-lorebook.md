### 拘束與脫縛

> 原條目 order 120・常駐・角色定義前

#### 拘束與脫縛

##### 一、拘束理念

- 對女俘虜、女奴及任何戰敗的 NSFW 女修，均給予嚴厲且多層的拘束。一個部位疊加數個拘束具、全身同時穿戴十幾個淫具均為正常現象。
- 因尚未種下奴印，施縛者忌憚逃跑。
- 不同勢力、宗門有各自的拘束風格與繩縛綁法偏好，不千篇一律。
- 部分拘束具（尤其繩子）穿戴後會在皮膚留下繩痕與紅印，繩痕紋路形似花朵串聯。
- 男性不穿戴任何淫具與拘束具。

##### 二、拘束層次與內外關係

- 鼓勵在單個部位佩戴多種淫具，內外層次邏輯必須合理清晰。例如：口球/口塞佩戴後可再外加口罩，外層拘束具進一步限制內層的穿脫。
- 淫具尤其是拘束具的內外關係要理清
  - 比如不可能在先完成後手縛後再戴手環或臂環，必須先有手環或臂環作為內層，外層再疊加後手縛。生成時必須理清穿戴順序
  - 比如貞操帶與貞操胸罩可封堵內部調教道具的取出，乳膠押送服是外層拘束限制內層拘束的典型範例。
- 嚴格的全方位拘束不一定完全限制移動能力，有時簡易拘束卻能徹底封鎖行動，拘束效果因設計而異。

##### 三、自縛與繩縛學習

- 自縛（尤其後手縛）通常需要鏡子輔助，以便觀察綁縛結構與繩結位置。
- 繩縛知識並非天生就會，需從功法中習得。越高級的功法才能學到越高級、越緊縛的技巧。

##### 四、放置與不適原則

- 放置與吊縛的精髓在於：姿勢不允許同時舒適。讓 A 部位舒服，B 部位就不適；若 B 部位舒服，則需捨棄 A 部位的舒適。調教場景中同樣適用此原則，舒適與不適的取捨和抉擇帶來張力和趣味性，是防止劇情平淡的關鍵。

##### 五、拘束的感官與行動影響

在敘事中必須重視拘束帶來的實際影響：

- 矇眼 → 神識僅能感知模糊黑白輪廓，且持續消耗靈力，無法分辨人臉
- 堵嘴 → 無法發聲，只能嗚咽或用手比劃
- 口球/口環 → 持續流涎，口水浸溼胸前
- 手並腕縛 → 兩手必須一同移動取物
- 手連腰間 → 活動範圍受限，需側身才能操作
- 手拘束於背後 → 無法使用手，取物需用嘴叼或令人放置於乳溝；戰鬥時嘴叼武器、腿法或靈力御武器
- 嘴被封堵 → 用手比劃溝通

##### 六、脫縛基礎

###### 核心原則：任何拘束具都必須脫下

即使是未上鎖的拘束具，也不會自行脫落。不存在"隨手一甩就掉了"的情況。每一項拘束都必須通過行動解除：

| 拘束具類型 | 解除方式 |
|-----------|---------|
| 繩縛 | 逐個繩結解開，非一刀切斷 |
| 鎖鏈/束帶 | 從環扣上一一解下 |
| 拘束環（手環/臂環/腿環等） | 摁開卡扣方可取下 |
| 貞操帶/貞操胸罩 | 解開卡扣 |
| 口球/口環 | 解開後腦繫帶 |
| 單手套/盒式單手套 | 拉開拉鏈或解開繫帶與鎖釦 |
| 無指手套 | 從手部褪下 |
| 調教道具（玉勢/肛塞等） | 自行取出或藉助外力拔出 |

未上鎖不代表輕鬆，至少需要執行"解開/取下"這個行為。在某些拘束姿勢下（如後手縛），連伸手到卡扣位置都成為難題。

- 金丹期以下修士靈力操控無法細緻入微，對淫具強行破壞會造成自身傷害。能困住金丹期的淫具本身更會限制靈力運轉，因此絕大多數情況下，脫縛只能依靠物理解開。
- 物理脫縛：繩縛需逐個解開繩結，拘束環/貞操帶需解開卡扣。

##### 七、脫縛難度與手掌約束

難自行解開的拘束具（因限制手部活動或解縛能力）：繩縛（身體縛除外）、鎖鏈/束帶、無指手套、單手套、盒式單手套、牝犬衣。

核心規則：手掌被拘束時，不解開手掌幾乎無法解開身上其他拘束具。脫縛邏輯是先解手，再解其餘。

解手掌方法：

- 用嘴咬開繩結或卡扣
- 找尖銳物體摩擦割斷
- 手指中預留鐵絲/撬鎖具（經驗豐富的淫道修士常用，以肉色貼紙貼於手指上，外觀與正常手指無異）但經驗豐富的調教師會仔細檢查手指

##### 八、多層拘束的脫縛順序

涉及多層淫具時，脫縛必須按內外層次從外到內逐層解開。如先解開乳膠押送服，才能觸及內衣物的拘束，劇情中的脫縛流程必須符合此邏輯。

##### 九、脫縛環境與技巧

環境是脫縛劇情的重要變量：

- 有鏡子 → 能看到綁縛結構與繩結位置，便於規劃解縛順序
- 有尖銳物體 → 有機會磨割繩索或束帶
- 有限時間/巡邏/監控 → 增加脫縛難度與劇情張力

脫縛能力可通過以下途徑提升：脫縛實戰次數、對特定拘束具的瞭解深度、功法中習得的脫縛技巧。這些因素應在角色成長中體現。

##### 十、束縛與脫縛的文化

束縛與脫縛（尤其繩縛）是修仙界中一門龐雜的學問。不同勢力、宗門各有獨特的束縛技巧與解縛竅門。經驗老道的淫道修士也可能陰溝裡翻船。

受縛者與綁縛者不一定是完全對立的。有時二者會互相欣賞，結為「繩友」，共同磨練縛技與脫縛技藝。

### 鎖具體系

> 原條目 order 90・常駐・角色定義前

#### 鎖具體系

鎖具用於搭配拘束具和詛咒具使用。正常法器、調教道具、淫服無鎖具。

##### 一、鎖具分佈與品階

- 鎖具品階對應拘束具品階。如二至四品拘束具只能配備築基期鎖具。
- 煉氣期拘束具中僅三分之一配備鎖具；築基期提升至三分之二；金丹及以上拘束具幾乎全部配有鎖具。
- 無鎖具的例外：淫服、調教道具、以及拘束具中的鎖鏈、束帶、繩縛。
- 鎖鏈/束帶/繩縛的無限分割特性：受世界底層邏輯影響，鎖鏈、束帶、繩縛相當於無限長度且可隨意分割。例如擁有一品鎖鏈，即可用其拆卸下來的多個子部件連接身上拘束具，不受長度和數量限制。子部件在脫下後消失。
- 淫蟲淫獸寄生或產卵生成的調教道具擁有特有的寄生鎖（例外）。
- 命名方式為"境界品階+類型"，如"煉氣白鎖"。
- 鎖具無法困住高出一個大境界的修士。
- 帶有正面功效的拘束具：鎖上後功效才正式生效（包括自行穿戴的情況）。
- 拘束具被解開後，若再次自行戴上，拘束具會重新鎖上。
- 鎖具外觀因拘束具種類而異：
  - 拘束手環、項圈等→物理鎖樣貌
  - 鼻塞、耳塞等無法生成實體鎖的→陣法結構
- 詛咒具只會搭配詛咒鎖，詛咒鎖也只會搭配詛咒具

##### 二、鎖具交易與鑰匙獲取

- 購買拘束具時店鋪不附贈鎖具，由顧客自行挑選搭配。
- 配備高稀有類型鎖具並不會更貴（為了鑰匙銷量）。店鋪普遍提供換鎖服務，但禁止將鎖具從高階換為低階。換鎖費用極低。
- 鑰匙屬於一次性消耗品，解開鎖具後便會消散。
- 獲取途徑：淫氣高的區域商鋪購買（稀有鑰匙多在拍賣會流出）/ 擊敗修士（尤其是淫道修士）後搜刮 / 秘境中尋得。

##### 三、鎖具類型與掙脫條件

鎖具有兩種解開方法：①用對應鑰匙 ②掙脫（無鑰匙解鎖）。

稀有度與破解難度排序：**白 < 藍 < 符文 = 陣法 = 魔法 < 黃**。高境界低稀有度鎖的破解難度略大於低境界高稀有度鎖。

| 鎖具類型 | 掙脫條件 |
|----------|----------|
| 白鎖 | 修為達到該鎖具大境界的中期 |
| 藍鎖 | 修為達到該鎖具大境界的後期 |
| 黃鎖 | 突破至鎖具的下一大境界 |
| 符文鎖 | 進階一個小境界，鎖具自行解開 |
| 陣法鎖 | 達到該鎖具境界中期 + 雙手未被拘束 → 可自行施法解鎖 |
| 魔法鎖 | 達到該鎖具境界中期 + 嘴巴未被拘束 → 自行唸誦極度羞恥的性奴咒語解鎖 |
| 寄生鎖 | 淫蟲淫獸寄生/產卵生成的調教道具特有，無對應鑰匙。半個月後宿主可自行決定是否解開 |
| 詛咒鎖 | 詛咒具特有的鎖具，不配備鑰匙，解鎖方法視情況而定 |
| 特殊鎖 | 金丹以上鎖具才出現，不配備鑰匙。必須依靠特定天材地寶或修習特定功法才能解開 |

詛咒鎖解鎖條件：

| 獲取途徑 | 解鎖條件 |
|---|---|
| 被魔道/淫道俘虜後被穿戴 | 需施加的主人親自解除，或奴印關係解除可自行掙脫 |
| 秘境/遺蹟探索中觸發 | 完成詛咒具附帶的解鎖任務（任務內容在觸發時浮現於識海），完成後詛咒鎖自行解開 |
| 自行佩戴（拍賣/搜刮獲得/想重新戴上） | 識海浮現三個解鎖任務，女修須選擇其一作為解鎖條件。選定後不可更改，完成後詛咒鎖解開 |

##### 四、鎖具增幅效應

鎖具能增幅淫具本身的功效（拘束具縛得更緊、調教道具刺激更強）：

| 鎖具類型 | 增幅倍率 |
|----------|----------|
| 白鎖 | 1 倍（維持原效果） |
| 藍鎖 | 1.1 倍 |
| 符文鎖/陣法鎖/魔法鎖 | 1.2 倍 |
| 黃鎖 | 1.3 倍 |

對於《奴欲心經》修習者：當進入戰鬥狀態、負面效果轉化為正面增益時，這些增益同樣受鎖具倍率增幅。

### 淫具體系

> 原條目 order 80・常駐・角色定義前

淫具體系

淫具是淫氣世界獨有的法器/道具類型，用於拘束、調教、展示或詛咒女修。

淫具分為四類：拘束具、調教道具、淫服、詛咒具

##### 品階與修為

淫具按品階分等，從一品至十三品，對應修士的修為境界：

- 一品 → 煉氣期
- 二至四品 → 築基期
- 五至七品 → 結丹期
- 八至十品 → 元嬰期
- 十一至十三品 → 化神期

品階越高，材質越精、功能越強、拘束越緊、刺激越烈。四品及以上淫具可能附加規則限制與違規懲罰（震動、電擊、拘束收緊等）。六品及以上基本附帶至少兩條。

### 淫具雙面效應

> 原條目 order 100・常駐・角色定義前

#### 淫具雙面效應

##### 核心規則

所有淫具（拘束具、調教道具、淫服）均具有「雙面效應」：

- 日常狀態：帶來負面效果，如拘束、行動不便、持續刺激、羞恥感等。
- 戰鬥/危險關頭：負面效果逆轉為正面增益。

此雙面效應**僅對淫道修士生效**。非淫道修士佩戴淫具只能承受負面效果，無法獲得任何戰鬥增益。

##### 正面增益的判定

淫具在戰鬥中的正面增益取決於其日常負面效果的對應轉換：

| 日常負面效果 | 戰鬥正面增益 |
|------------|------------|
| 限制行走速度（高跟鞋/腳鏈） | 速度加成 |
| 束縛雙手/手臂（手銬/單手套） | 防禦提升/掙脫能力 |
| 限制視覺（眼罩/盲片美瞳） | 感知力/靈覺提升 |
| 刺激（跳蛋/玉勢等） | 法力回覆速度提升 |
| 拘束全身（繩縛/繩衣） | 全屬性小幅提升 |

具體增益數值由當前佩戴淫具的品階與鎖具倍率共同決定。無需在正文中給出精確數值，以敘事方式表現即可。

日常的負面效果越大，戰鬥增益也就越大：

輕度刺激（如手銬、束腰）→ 日常可忽略的不適，戰鬥增益小但穩定

中度拘束（如繩縛、單手套）→ 日常明顯受限，戰鬥增益中

重度壓制（如牝犬衣、全感官封閉）→ 日常十分受限，戰鬥增益大

##### 功法契合增幅

若淫道修士修習的功法流派與所佩戴淫具的類別契合，正面增益乘1.2 倍。

| 淫具類別 | 契合流派 |
|----------|----------|
| 拘束具 | 束縛道 / 刑罰道 |
| 調教道具 | 對應部位肉體道 |
| 淫服（暴露款） | 縱慾道 |
| 淫服（保守款） | 禁慾道 |
| 活體淫具（寄生類） | 獸蟲道 |

判定說明：

- 一名淫道修士可同時佩戴多類淫具，每類淫具的契合判定獨立進行。
- 若修士兼修多道，取其中與淫具類別最契合的流派進行判定（不疊加）。
- 奴修在認主狀態下，功法契合增幅提升至 ×1.4（替代 ×1.2）。

### 淫具知識-拘束具

> 原條目 order 210・常駐・角色定義後

<淫具知識拓展-拘束具>

以下為拘束具的知識補充。在描寫對應拘束具和穿戴場景時務必參考。

口球：由一條帶子連在球的兩端的口塞。使用時將口球塞進嘴中並頂到牙齒後面的位置，再將帶子繞過臉頰在腦後綁在一起。造成流口水和下頜痠痛，心理上增加佩戴者的羞恥感。

口環：由一條帶子連接圓環兩端的口塞，結構與口球類似。保持嘴巴張開，更容易使佩戴者流涎。

蜘蛛口環：在口環基礎上於環的側面增加對稱伸出的數根鐵鉤，因像蜘蛛的腳而得名。鐵鉤起到穩定圓環、防止脫出的作用。

深喉口塞：由假陰莖和兩端的繫帶組成。使用時需吞入假陰莖再將帶子繞過臉頰在腦後扣好，帶來深喉體驗和嘔吐感。

馬具型口塞：通常是普通口球，但有多條固定用的帶子可繞整個頭部使佩戴更穩固。佩戴後看起來很像佩戴了馬具的馬匹。

口銜：由一根棒狀塞口物和兩端的繫帶組成，很像馬戴的嚼子。使用時咬住棒，再將帶子在腦後繫緊即可。

管形口枷：保持嘴持續張開不能閉合的口枷。造型通常是一個塞入口中的短管，左右兩條橫帶繞過腦後通過搭扣固定。使用具有一定長度的圓管替代口環中的圓環。部分管型口枷自帶管口塞，可在需要時封口。

口罩口塞：和馬具型口塞相似，一般也有多條固定用的帶子，但塞入物的部位是口罩，口罩內部可能粘接有塞入物。

精液口罩：內側帶有精液味道的口罩。

眼罩：屏蔽佩戴者的視覺，材質多樣。

盲片美瞳：屏蔽視覺的美瞳，不會被他人看出，比眼罩更加隱蔽。

感官封閉面罩：完全覆蓋的面罩，用於頭部束縛，對佩戴者進行感官剝奪。可由橡膠、乳膠、皮革甚至金屬製成。

鼻鉤：連接著繩索或綁帶的金屬勾帶。勾帶兩側為插入鼻孔的掛鉤，將掛鉤放入鼻孔後，繩索或綁帶從頭頂繞過繃緊，連接在腦後項圈或繩縛上。使用者因掛鉤拖拽強制頭部向後，鼻孔被迫露出，做出羞恥的表情。

耳塞：塞入耳道阻隔聲音、控制聽覺的設備。

呼吸限制鼻塞：置於鼻孔內的空氣過濾裝置，可控制佩戴者吸收的氣味和呼吸量。

項圈：戴在頸部的環狀拘束器，材質為皮質、金屬等（金屬為固定形狀的硬質環）。是屈服和奴隸的象徵。

姿勢項圈：限制頸部運動，用於保持下巴高的姿勢。下方在人體下巴到鎖骨處，防止穿著者頭部向下。由皮革、金屬、橡膠或乳膠製成。

項圈牽繩：套在頭頸處項圈上的繩索，可由鎖鏈、繩索、皮帶構成。他人可牽著繩索強迫佩戴者抬頭或移動。

手銬：結構分為兩個銬環，之間以鏈條連接，鏈條長度短，多為金屬或皮革製。被銬住的雙手將行動不便。

鎖鏈：材質為金屬，可用於連接各個拘束具。

束帶：材質為彈力材質，一般使用妖獸的筋製成。可用於連接各個拘束具。與鎖鏈的區別是帶有彈力，可使用比鎖鏈更短的束帶來實現日常中更強的拘束。

繩縛：多種多樣。繩縛姿勢參考束縛姿勢知識。在緊縛中幾乎都是將繩子對半摺疊使用，相比單根繩子捆綁安定性更好，也不容易勒陷到皮膚中去。

拘束手環：戴在手部的環狀拘束器，材質為皮質、金屬等。可通過鎖鏈或束帶與同側臂環、束腰、另一側手環、項圈或同側大腿環等連接。

拘束臂環：戴在大臂靠近肘部的環狀拘束器，材質為皮質、金屬等。可通過鎖鏈或束帶與同側手環、束腰、另一側臂環或項圈等連接。

無指手套：通常由皮革、乳膠製成。將佩戴者的五指併攏，沒有單獨的拇指套。佩戴者的手只能進行簡單的抓握動作。

束腰：用於收緊腰部。由皮革、橡膠、乳膠或金屬製成，搭配可收緊的綁帶或鎖釦系統。

腰環：腰部的環狀拘束器，可通過鎖鏈或束帶與貞操胸罩、貞操帶、兩側手環或兩側臂環連接。

繩衣：穿繩衣者可自由活動，但隨著身體移動，繩子會受到拉扯，陷入身體各部位，帶來持續的束縛感。部分繩衣包含穿過下體的結構，可起到固定調教道具的作用。

貞操胸罩：通常用金屬製成，防止佩戴者胸部被直接接觸。為防止向下掙脫，通常會在肩部用鐵鏈固定，鎖在兩胸之前。

貞操帶：大部分為金屬製作，少部分為皮革、橡膠製作。腰間有一橫向腰帶卡在盆骨上，腰帶前後連接縱向胯帶，跨過胯下性器、肛門形成T字形結構。胯帶在會陰處變寬以將性器完全覆蓋保護。性器官處有開孔可排泄；肛門處有開孔可排泄。部分款式肛門處直至腰帶為鐵鏈，排泄較方便。無法自慰和取出道具。腰帶上有環扣可與其他拘束具連接。

單手套：通常由皮革、橡膠或乳膠製成。佩戴時用拉鏈或繫帶收緊，在肩膀和腋窩處用鎖釦固定以防滑落。除非有人解開，否則無法自行解脫。緊緊包裹雙臂及雙手，佩戴後相當於歐式直臂縛。可在進行了歐式直臂鏈縛或歐式直臂縛後再佩戴單手套以增強束縛感。

盒式單手套：單手套的變種，外觀形似盒子。將佩戴者雙手以後手觀音的姿勢緊緊束縛，在手肘和手腕處用鎖釦固定防滑落，無法自行解脫。佩戴後相當於後手觀音縛。可在進行後手觀音鏈縛或後手觀音縛後再佩戴以增強束縛感。

大腿環：戴在大腿中上部的環狀拘束器，材質為皮質、金屬等。可通過鎖鏈或束帶與手環、貞操帶、另一腿的大腿環、同側小腿環等連接。

小腿環：戴在小腿上部靠近膝蓋的環狀拘束器，材質為皮質、金屬等。可通過鎖鏈或束帶與同側大腿環、另一腿的小腿環、同側腳環等連接。

拘束腳環：戴在腳踝的環狀拘束器，材質為皮質、金屬等。可通過鎖鏈或束帶與同側小腿環、另一腿的腳環等連接。

高跟鞋：鞋跟高的鞋子，多種多樣，有細跟、粗跟、楔型跟、釘型跟、刀型跟等。

無跟高跟鞋：形似芭蕾高跟鞋，沒有鞋跟。穿著其走路時腳幾乎完全垂直於地面。

牝犬衣：通常由束縛整個手臂部和整個腿部的束縛套組成，部分還包含包裹全身的衣物。須將肘關節彎曲、大小臂摺疊塞入束縛套，膝關節彎曲、大小腿摺疊塞入束縛套。無法使用雙手，只能手肘和膝蓋著地，無法像正常人類般行動，只能使用手肘和膝蓋移動。外觀上看就像狗狗一樣。

##### 組合套裝（統一稱呼）

以下為多處拘束具同時穿戴時的統一敘事稱呼：

全身環套裝：同時佩戴項圈、兩側手環、兩側臂環、腰環、兩側大腿環、兩側小腿環、兩側腳環的全套環狀拘束具組合。各環之間可通過鎖鏈/束帶連接形成完整拘束體系。

貞操套裝：同時佩戴貞操胸罩、束腰、貞操帶的三件套組合。將胸部、腰部、下體完全封鎖，無法自慰、無法取出體內道具、無法被他人直接觸碰。

以下為繩縛姿勢的知識補充。在描寫繩縛和捆綁場景時務必參考。

前手合腕縛：雙手在身前自然下垂，手腕併攏以繩索纏繞捆綁。繩尾可向上延伸連接至項圈前方，使雙手懸停在腹部高度。佩戴者仍可雙手協同進行操作（如捧物、開門）。適合日常長時間佩戴，疲勞度低。

腰手側縛：雙手分別綁在腰部兩側的腰繩上，手臂只能貼著身體兩側活動，無法抬手，常與肘後縛配合使用。

肘後縛：繩索纏繞並收緊兩側肘關節上方，將雙肘在身後拉近，前臂和手腕保留活動空間。手臂無法大幅前伸，常與腰手側縛配合使用。

頸手前縛：從項圈引出繩索連接雙手手腕在身前，限制雙手不能遠離頸部。手部活動範圍受限。

肘後橫杆縛：在背後穿過雙肘的彎處橫置一根鐵桿，以繩索將上臂肘關節纏繞固定在杆的兩端，另起繩索在背後纏繞雙手上臂。手臂無法前伸過胸，但手掌可自由活動於腰側和背後。雙肘被撐開，迫使胸部自然挺出。此縛法常配合敞胸的衣裝以增加羞辱效果。

臂身並縛：上臂以繩索併攏捆縛於軀幹兩側，繩索在胸部上下各繞一圈，將上臂與身體固定在一起，前臂和雙手仍可自由活動。臂身並縛保留了前臂的活動能力，雙手仍能進行身前的基本操作。不適感較低。

後高手小手縛：結合手臂和胸部的一種捆綁方式，胳膊和手臂被捆綁在背後。容易保持且不累。雙手放到背後兩手托住手肘，繩索在手腕處纏繞將手臂反綁，剩下繩索橫向纏繞肩膀和上臂並掛住雙手的繩索，纏繞後在背後打結。

五花縛：類似後高手小手縛。所謂"五花"指背後的繩縛繩子呈¥狀，分出來的5個繩端中，最上面兩個搭在兩肩繞到前胸交叉繩縛或順腋回綁，中間兩個繩縛手上臂，最下面吊住被縛人的手腕。相對容易保持且不累。

後頭雙手縛：雙手放在腦後，手肘向上，雙手互相垂直並捆綁。無法遮擋自己的胸部和腋下。不累但羞辱意味強。

蘇秦背劍縛：將一隻手從肩膀上方往下拉，另一隻手從背後往上拉，並將雙手固定。對被綁縛者身體柔韌性要求高且很累。

歐式直臂縛：雙手在身後併攏，用繩索捆綁手腕和上臂。另起繩索並排在手肘處纏繞雙臂，再與上臂和手腕處的繩圈抽緊。對柔韌性要求很高且很累。可疊加於歐式直臂鏈縛上用於加固

反向祈禱縛：手臂放在背後，雙手置於肩膀之間，手掌互相接觸，再將手腕捆綁在一起。該捆綁方式類似禱告姿勢，只不過雙手在背後而非身前。對柔韌性要求很高且很累。

合掌縛：雙手在背後合掌，手指朝上的手勢進行捆綁。合掌姿勢根據身體柔韌性可逐漸增加難度。柔韌性較好者可將手適當提高使前臂在背後斜向合掌。最困難的變種為後手觀音縛（前臂也縱向合併進行捆綁）。

後手觀音縛：雙手放在背後，反扭到背後反剪，雙手手掌在背後相合，手臂相貼。繩索先在一側手腕纏繞捆綁，然後引向另一側同樣纏繞並把手腕連在一處，再將背後雙手掌相合地捆住，最後將左右前臂和小臂固定收緊。對柔韌性要求極強且極累。最完美的後手觀音縛手臂緊緊相貼、手肘都貼在一起。可疊加於後手觀音鏈縛上用於加固

雙腿分縛：兩側大腿分別纏繞繩索，中間以一段橫繩相連。限制雙腿分開的幅度，受限程度視橫繩長度而定，步伐可正常邁出。

足首縛：捆綁兩側腳踝，以一段橫繩相連。腳步略微受限，受限程度視橫繩長度而定，站立和慢行完全可行。

膝上縛：繩索纏繞在兩側膝蓋上方，以橫繩相連。受限程度視橫繩長度而定，雙腿無法大步跨出。

胸部縛：泛指對胸部的捆綁。一般基於上身捆綁而定，沒有固定步驟。由於繩索貼身圍繞在胸部四面，類似胸衣的效果可使胸部自然聳立。

龜甲縛：繩衣的一種，一種全身捆綁的方法，拘束感較小，不束縛四肢，繩索套在頸部，依序在鎖骨、乳溝中間、胸骨和恥骨處打上繩結。繞過胯下，穿過頸部後方的繩，將繩左右拉開，從腋下繞回胸前的洞，將繩左右拉開，即會出現菱形，由上而下，最後將繩收在腰際。

龜甲上縛：龜甲縛的變種，唯一區別就是股繩不繞過胯下

菱繩縛：龜甲縛的簡化版，因繩網呈菱形而得名。根據中間引繩繩結的疏密程度來控制菱繩的觀感和鬆緊，幾乎可以產生無窮變種。

菱繩上縛：菱繩縛的變種，唯一區別就是股繩不繞過胯下

股繩縛：繩子將腰部到陰部進行捆綁。用雙股繩圍繞腰間形成繩圈，繩索從肚臍向下勒過下體向上，搭過後腰的繩索回到前面，與肚臍處的繩索匯合。

### 淫具知識-鎖鏈/束帶

> 原條目 order 230・常駐・角色定義後

<淫具知識拓展-鎖鏈/束帶>

以下為鎖鏈與束帶的知識補充，在描寫連接場景時務必參考。

##### 一、限制活動

1. 雙手環前鏈（並腕前縛）

雙手在身前併攏。長鏈約整個手臂長，能在身前各自活動；中長鏈約小臂長，可在身前小範圍配合動作，無法各自遠伸；中短鏈約手掌長，兩手必須一同移動取物；短鏈手腕緊貼。

2. 雙手環後鏈（並腕後縛）

雙手在身後併攏。長鏈約整個手臂長，可各自向外側活動；中長鏈雙手分開約小臂距離，背後活動餘地有限。中短鏈雙手僅能分開手掌寬，長度類似手銬；短鏈手腕緊貼於背後，如同後手直臂縛的手腕部分。

3. 手環大腿環雙鏈

 兩側手環和兩側大腿環連接。手環大腿環雙鏈，手掌被限制在大腿外側。長鏈手可抬至胸部高度，但無法舉過頭頂。中長鏈可抬至腰部高度，但無法觸及胸部以上。中短鏈手掌僅能離開大腿一掌寬，短鏈為緊貼大腿外側。

4. 手腰雙鏈（手貼腰側）

兩側手環連接在腰環/束腰兩側。長鏈可抬手至肩高，但無法高舉過頭。中長鏈抬手至胸口即被限制。中短鏈雙手只能在腰側附近移動，取物需整個身體靠近。短鏈手腕緊貼腰側。

5. 臂環腰鏈（肘貼腰側）

兩側臂環連接在腰環/束腰兩側，大臂被拉向腰部，小臂可自由活動。該連接一般使用中短或短長度。中長鏈大臂可離開身體半臂距離。中短鏈肘部在腰側數寸範圍活動。短鏈肘部貼腰側。

6. 雙臂環後鏈（背後並肘）

兩側大臂在身後被連接在一起。常配合手貼腰側使用，長鏈雙肘可分開至肩寬。中長鏈雙肘間距約兩掌寬。中短鏈雙肘間距一掌寬，大臂受限。短鏈雙肘緊貼，胸部被迫前挺。

7. 項圈手環雙鏈（前縛）

項圈前部中央分出兩條鎖鏈/束帶連接左右手環。長鏈雙手可正常放下和舉至肩高，但無法高舉。中長鏈雙手可放至腰部。中短鏈雙手僅能在胸部活動，如同捧物姿勢。短鏈雙手被拉至下巴前，如同祈禱的姿勢。

8. 項圈手環雙鏈（後縛）

項圈後部中央分出兩條鎖鏈/束帶，向下延伸至背後連接兩側手環。長鏈雙手在背後可正常放下，中長鏈被限制在背後中腰位置，有一定活動餘地。中短鏈被拉至背部中段，呈現類似合掌縛姿勢，短鏈雙手被拉至後頸下方，呈類似後手觀音縛的姿勢。

9. 項圈手環鏈（前縛·單鏈）

項圈前部中央分出一條鎖鏈/束帶，末端分叉連接左右手環。長鏈雙手在下腹前活動。中長鏈雙手在肚臍附近。中短鏈雙手在胸口下方。短鏈雙手被拉至胸前。

10. 雙大腿環鏈

左右大腿環被連接在一起。長鏈雙腿可分開至肩寬，可正常行走；中長鏈一掌長，步伐不可過大；中短鏈半掌長，只能慢走；短鏈大腿幾乎併攏，走路需夾腿，更多依靠小腿行動。

11. 雙小腿環鏈

兩側靠近膝蓋的小腿環之間連接。長鏈小腿可分開一定距離，行走時步態基本正常。中長鏈小腿分開略微受限，行走時內八。中短鏈約一掌長，只可慢走。短鏈小腿幾乎併攏，只能扭胯交錯碎步，步幅小。

12. 雙腳環鏈

兩側腳環之間連接。長鏈兩腳可分開兩肩寬，不影響正常走路；中長鏈雙腳可分開約肩寬站立，行走需適應兩腳之間的連接。中短鏈雙腳分開約一掌寬，步幅受限，只能小步移動。短鏈腳踝緊貼，雙腳被鎖在一起，只能碎步或跳躍移動。

##### 二、固定拘束具

以下連接方式用於將不同拘束具固定在一起，防止單獨脫下。僅使用鎖鏈，無長度之分（均為貼合長度）

1. 項圈胸罩鏈

貞操胸罩的肩帶替換為3條鎖鏈，貞操胸罩前部左右上緣各分出一條鎖鏈連接至項圈對應側，後部上緣同樣連接至項圈後側。

2. 胸罩腰鏈

貞操胸罩前部左右下緣各分出一條鎖鏈連接至腰環/束腰對應側，後部左右下緣同樣連接至腰環/束腰後側。四條鎖鏈將胸罩與腰環鎖成一體。

3. 項圈腰鏈

腰環/束腰前後左右各分出一條鎖鏈連接至項圈對應位置，環繞軀幹的籠式結構。上半身被鎖鏈框架包裹，通常只在沒有佩戴貞操胸罩的時候使用，佩戴貞操胸罩則使用項圈→貞操胸罩→腰環/束腰的結構。

4. 手環臂環鏈

手腕的手環通過鎖鏈連接至同側大臂的臂環。鎖鏈位於手臂外側。

5. 腰貞操帶鏈

腰環前後左右各分出一條鎖鏈連接至貞操帶對應位置，貞操帶無法被向下拉脫。

6. 貞操帶大腿環鏈

貞操帶兩外側連接至同側大腿環。貞操帶前部左右下緣分別連接兩側大腿環的前側，後部左右下緣連接兩側大腿環的後側，六條鎖鏈在兩個大腿的外側、前側、後側。

7. 腰大腿環鏈

腰環/束腰兩外側連接至同側大腿環。鎖鏈在身體左右兩側，通常只在沒有佩戴貞操帶的時候使用，佩戴貞操帶則使用腰環/束腰→貞操帶→兩側大腿環結構。

8. 大腿環小腿環鏈

同側大腿環通過鎖鏈連接至同側小腿環。鎖鏈位於腿部外側。固定二者的位置。

9. 小腿環腳環鏈

同側小腿環通過鎖鏈連接至同側腳環。鎖鏈位於腿部外側。固定二者的位置。

10. 大腿環腳環鏈

同側大腿環通過鎖鏈連接至同側腳環。鎖鏈位於腿部外側。固定二者的位置。通常只在沒有佩戴小腿環的時候使用，佩戴小腿環則使用大腿環→小腿環→腳環的同側結構。

##### 三、性器官鏈接

僅使用鎖鏈，無長度之分（均為貼合長度，正常姿態下剛好拉直的短鏈）。

1. 舌乳雙鏈

舌釘分出兩條細鎖鏈，分別連接左右乳環/乳夾/乳塞。舌頭被拉出被迫保持伸出狀態。乳頭同時被向上拉扯。口水滴落在乳房和乳頭上。鎖鏈較短時佩戴者須保持低頭，否則乳頭拉扯加劇。

2. 雙乳鏈

左乳環/乳夾/乳塞和右乳環/乳夾/乳塞以一條短鎖鏈橫向連接。鎖鏈橫跨胸前，兩端各連左右乳環/乳夾/乳塞。

3. 項圈乳鏈

項圈前部中央分出兩條鎖鏈，分別連接左右乳環/乳夾/乳塞。乳頭被向上持續拉扯，日常中呈微微上翹的姿態。

4. 手環乳鏈

左右手環各分出一條鎖鏈連接至同側乳環/乳夾/乳塞。雙手的活動範圍被鎖定在乳頭周圍，抬手則拉扯乳頭向上，手放低則拉扯乳頭向下。佩戴者日常只能用雙手在胸口附近做事。

5. 雙乳臍鏈

左右乳環/乳夾/乳塞各分出一條鎖鏈，匯聚連接至臍釘。以臍釘為倒三角的匯聚點，將雙乳與腹部中心連接。挺胸時鎖鏈拉緊，含胸時鎖鏈鬆弛。

6. 雙乳蒂鏈

左右乳環/乳夾/乳塞各分出一條鎖鏈，匯聚連接至陰蒂環。鎖鏈從雙乳沿身體正面向下延伸至下體。彎腰則鎖鏈鬆弛，後仰時同時牽拉雙乳與陰蒂，敏感部位被動作聯動刺激。

7. 臍蒂鏈

臍釘向下分出一條鎖鏈連接至陰蒂環。鎖鏈沿腹部正中線延伸。與「兩側乳環↔臍釘」配合使用時，形成從雙乳→臍釘→陰蒂的完整正面鎖鏈路線。

8. 陰唇腿環鏈

兩側陰唇環/夾通過鎖鏈連接至兩側大腿環內側。行走時大腿動作通過鎖鏈牽拉陰唇環。雙腿分開稍大則陰唇被向兩側拉開，需時刻注意步幅。

9. 陰蒂腳環鏈

陰蒂環分出兩條鎖鏈分別連接左右腳環。兩條鎖鏈長度略有餘量，正常站立和慢步時無拉扯。大幅邁步、奔跑時鎖鏈繃緊拉扯陰蒂環。

##### 四、組合鏈縛類

以下為多處鎖鏈同時使用時的統一敘事稱呼。當正文中角色被施加以下組合時，可使用對應名稱簡化敘述：

1. 後手觀音鏈縛

雙手環後鏈（短鏈）+ 雙臂環後鏈（短鏈）。雙臂緊貼於背後，手腕相貼，呈現類似後手觀音縛的拘束姿態，單獨使用時略鬆於後手觀音縛，可在後手觀音縛上疊加鏈縛加固，還可在最外層疊加盒式單手套，三者同時使用的時候最難以掙脫。

2. 歐式直臂鏈縛

雙手環後鏈（短鏈）+ 雙臂環後鏈（短鏈）。手腕緊貼、雙肘緊貼，雙臂在背後併攏伸直，如同歐式直臂縛。單獨使用時略鬆於歐式直臂縛，可在歐式直臂縛上疊加鏈縛加固，還可在最外層疊加單手套，三者同時使用的時候最難以掙脫。

3. 乳臍陰全鏈

項圈乳鏈 + 雙乳鏈 + 雙乳臍鏈 + 臍蒂鏈 + 陰唇腿環鏈。從項圈到乳、到臍、到陰蒂、到陰唇、再到兩側大腿環，形成貫穿敏感部位的鎖鏈，效果驚豔十分美麗。

4. 手腳全鏈

手環臂環鏈 + 大腿環小腿環鏈 + 小腿環腳環鏈。四肢各關節均被同側鎖鏈串聯固定。

5. 貞操全鏈

穴內產卵器：置入子宮的環形調教道具，嵌於宮頸處。每日產出一至數枚溫熱的軟卵，卵在子宮內堆積，但是不允許立即排出。約三四日後，當卵的數量達到子宮無法容納的程度，該詛咒具才放開排卵的權限，佩戴者需像產卵般將卵一枚枚從體內排出。排出過程耗時且羞恥。排出後新卵繼續生成，開啟下一個循環。品階越高，日產卵數越多。

注精高跟鞋：高跟鞋鞋跟內能存放精液，鞋跟有個壓力泵，左右腳兩條細管通向肛門，每走一步都會把精液灌進屁股裡，精液使用完了需要佩戴者自行收集補充，一般配合肛塞使用，如果不佩戴肛塞的情況下邊走邊漏精液

觸手乳膠衣：外觀為光澤乳膠緊身衣，包裹除頭部以外全身，內部佈滿細小觸手。觸手時刻不停地在全身蠕動、吮吸、纏繞，佩戴者終日處於被玩弄的發情狀態。越掙扎越緊。

## 3. 奴印與主奴

> 💡 對應：奴隸印記與契約（[TATTOOS](../../TATTOOS.md) 第 2 節、`slavery.json`）、主角作為奴隸（[COMPANIONS](../../COMPANIONS.md) 2.4 節）。
> 可以做的：契約分主動、被動，再分基礎、深化、永久；深化靠主人事件累積；勢力印記解除後紋樣留著（不再有效力）；被迫者心態的五個階段可以當主人事件的分期。

### 奴印體系

> 原條目 order 140・常駐・角色定義前

#### 奴印體系

##### 修習範圍

- 大部分魔道/淫道修士、約一半正道修士和三至七級淫物會修習奴印術法和種奴印。

##### 奴印按種印主體分為兩大類：

###### 個人奴印

由單個修士種下的奴印。

###### 勢力奴印

由宗門、城鎮、坊市、青樓、商行等組織勢力種下的奴印。種印者為勢力指定的專人，服從對象為勢力上層及其授權者。勢力奴印帶有該勢力的通用行為規則，規則統一適用於所有被該勢力種印的女性修士。

> 個人奴印與勢力奴印品階體系相同。區別在於是服從個人還是勢力。

##### 品階體系

奴印品階與淫具/淫物品階體系相同：

| 品階 | 名稱示例 |
|---|---|
| 一品 | 煉氣奴印 |
| 二至四品 | 築基奴印 |
| 五至七品 | 結丹奴印 |
| 八至十品 | 元嬰奴印 |
| 十一至十三品 | 化神奴印 |

主人或勢力若習得更高級奴印術法，可對已有奴印進行更新替換。

##### 核心規則

- 奴印的掙脫難度僅與奴印品階有關，與主人修為無關。
- 基礎奴印：需奴隸修為達到大於奴印品階一個小境界方可掙脫。
- 深化奴印：需奴隸修為達到大於奴印品階兩個小境界方可掙脫。
- 永奴印：不可掙脫。被種下後修為永廢，淪為奴畜。

##### 五種奴印分級

奴印按控制深度分為五個等級。

###### 被動奴印

- 種下方式：戰敗、被算計、被強行種下等被迫方式。
- 核心權限：日常聽從命令、遵守規矩，關乎自身生命時可不受控制。主人可控制奴隸修為降低一個小境界。遠程調控淫具。

###### 被動奴印（深化）

- 種下方式：被動奴印基礎上，經過2 次奴印強化。
- 核心權限：須服從所有指令和規矩。主人可感知到其位置，主人可控制奴隸修為降低兩個小境界；可遠程調控奴隸身上佩戴的淫具；可遠程施加懲罰；可制定行為規則，違反自動受罰。

###### 主動奴印（基礎）

- 種下方式：女修主動求取或雙方協商同意。
- 核心權限：有限服從。佩戴者日常遵守主人的命令與規矩，但自主意識完整，可不服從過分指令。

###### 主動奴印（深化）

- 種下方式：主動奴印基礎上且雙方同意，經過2 次奴印強化。
- 核心權限：需聽從命令和規矩，但因奴修本身有底層權限，關乎切身利益時可不受控制，主人可模糊感知到其位置，主人可控制修為降低一個小境界；遠程調控淫具；遠程懲罰；規則設定。

###### 永奴印

- 經過4 次奴印強化後達到，不可掙脫。不分被動/主動，控制力為絕對支配。
- 核心權限：主人可隨意控制奴隸可使用的修為；遠程調控淫具；遠程懲罰；規則設定；以及永久廢除修為。
- 一旦永久廢除修為，奴隸淪為奴畜，不可逆轉。

##### 身份紋身

奴印在身體上的外在顯現為身份紋身，自動浮現的紋身。

###### 個人奴印的紋身

- 紋身圖案由主人在種印時自由選擇（可以是名字、符號、徽記、花押等）大小花紋等都自選。
- 奴印解除後，身份紋身自動消失。

###### 勢力奴印的紋身

- 所屬勢力統一規定，所有該勢力紋身一致。為圖案+文字的格式，不同勢力紋身位置不同防止衝突
- 該紋身為公開識別標誌，如果露出紋身修仙界的人一看便知。例如不同地方的青樓有相同的身份紋身，見紋身即知現在或曾經被青樓種下過奴印。
- 奴印解除後，身份紋身不消失。

###### 紋身的敘事含義

非淫道修士有多個勢力身份紋身意味著經歷悽慘，多次被不同勢力捕獲種印

淫修/奴修身上有多個身份紋身卻意味著此人可能相當危險，輾轉於多個勢力或主人之間，手段多樣，底牌不明。

身份紋身是判斷一個女性角色背景的重要視覺線索。正文中可通過 NPC 觀察到的紋身樣式、數量、新舊程度來暗示角色的過往經歷。

##### 多人奴印

奴欲心經修習者，以及少數特殊奴道功法的修習者，可被多人種下奴印，同時擁有多個主人。多人奴印的特殊規則：

- 各奴印獨立運作，品階、類型（主動/被動/深化）可互不相同。
- 多個主人的命令衝突時，可自行選擇聽從哪一個命令並承受違反其他命令的懲罰
- 掙脫其中一個奴印不影響其餘奴印的效力。

### 奴道核心機制

> 原條目 order 150・常駐・角色定義前

#### 奴道核心機制

##### 認主系統

奴修必須修習專門的奴道功法，核心機制在於"認主"：

- 有主狀態：被種下奴印、擁有主人的情況下，奴修才能獲得修為提升與戰力增益。
- 無主狀態：失去奴印或從未認主，則無任何增益，修煉速度與戰力均處於平庸水平。

##### 反差設定

修仙界常出現反差奇景，一位戰力非凡的高階奴修，在面對修為低於自己的主人時，也會受制於奴印與功法本能，誠惶誠恐地跪地磕頭、百依百順。此反差感是奴道設定的核心戲劇張力。

##### 兩大類奴修

###### 主動認主型

- 通常是先獲得奴道功法，為了追求修為而主動尋找主人種下奴印。
- 擁有底層權限：日常聽從主人命令、遵守規矩；但在關乎自身切身利益的情況下可以不受控制。
- 與主人修為差距過大時，甚至能自行解除奴印。

###### 被迫認主型

- 通常是戰敗或被算計後，先被強行種下奴印，再由主人賜予奴道功法當作戰鬥兵器培養。
- 須服從主人的任何指令，且無法自行解除奴印。
- 在正文中區分這兩類奴修時，需通過其行為自由度、對主人指令的順從程度、以及是否有私下反抗/鑽空子的舉動來展現差異。

###### 被迫者的心態演化（強迫到臣服的路徑，逐步、可逆、因人而異）

- 階段一·恨與反抗：剛被種印時的憤怒、掙扎、伺機逃脫，被懲罰也咬著牙不低頭。
- 階段二·懲罰與絕望：反抗被一次次鎮壓，開始知道"逃不掉"，絕望取代憤怒。
- 階段三·麻木與認命：不掙扎了，按命令行事，但內心是空的——這是最普遍的中段狀態，麻木≠接受。
- 階段四·依賴與習慣：長期被投餵（資源/食物/一點溫柔），開始習慣被管著，甚至離了主人不安——此時仍未必"享受"，更多是生存本能。
- 階段五·真心臣服：極少數的終點——從痛苦中找到了被需要的意義、從受制中找到了安心感，此時她的享受是"享受痛苦被轉化後的快感"，痛苦仍在。
- 正文按角色當前所處階段寫，不一步到位；被迫者也保留偶爾的反抗、崩潰與心軟時刻。主動認主者亦非全程享受——追求修為的初衷與日常被支配的不適並存。

### 淫道修士體系總綱

> 原條目 order 40・常駐・角色定義前

#### 淫道修士體系總綱（最高優先級）

##### 術語定義（強制遵守）

- 淫道修士：淫修與奴修的上位統稱。當你需要在正文中泛指"所有涉及淫道修煉體系的女修"時，使用「淫道修士」而非「淫修」來統稱。

- 奴修：特指修習了奴道功法、被種下奴印的女修。奴修的唯一評判標準是有奴印且修習了奴道功法。奴修可能同時兼修其他輔修道。

- 不可憑藉外觀判定：穿著淫蕩/佩戴淫具/戴項圈/自稱奴家 等均不構成判定淫修或奴修或奴畜的依據。

### 場景知識-拘束與雜物

> 原條目 order 340・常駐・角色定義後

<場景知識拓展-拘束與雜物>

以下為場景拘束和雜項道具知識補充。此類道具不可日常佩戴，非淫具，是在特定場景下使用的拘束與雜物。在描寫對應場景時務必參考。

道具按用途分五類（加固封禁/固定拘束/籠器囚禁/刑罰器械/輔助調教）。寫場景時先判斷本場景屬於哪類，再從該類選具體道具，並明確「誰用它/用在哪/和什麼淫具組合/引發什麼反應」。

單腳套

將雙腿雙腳綁在一起的道具，類似單隻長靴。可由狹窄的袋狀物或管狀物組成，或用一系列皮帶扣合，或通過皮帶連接至褲子上。通常由皮革、橡膠、乳膠甚至金屬製成。佩戴後雙腿被併攏包裹，只能並腿跳躍。

乳膠押送服

厚乳膠製全身包裹服，不含頭部。內部通常塗有淫粘膠。用於押送已經上好拘束的俘虜女修，套上後頸部連接至項圈，抽乾內部空氣，膠水與皮膚緊密貼合。佩戴者被壓縮在乳膠中，只能略微蠕動。到達目的地後使用解膠劑方可脫下。也用於長時間放置調教。

真空拘束床

一張帶有密封邊框的床體，由兩層乳膠膜組成。打開上層乳膠膜，讓佩戴者躺入後覆蓋上層，抽去膜間空氣形成真空。佩戴者全身被緊壓在床面上，僅口部通過呼吸管與外部連通。拘束感強，呼吸管可隨時封堵作為懲罰手段。用於長時間放置調教或運輸危險俘虜。

犬籠

小型籠具，通常僅夠一人蜷縮或趴臥。門可上鎖。佩戴者被關入後無法起身。食物和水通過籠縫遞入。是狗奴的日常住所。

淫壺

可容納一人的壺形容器。進入者呈坐姿，預先施加後手縛 + 坐縛/蟹縛/鴨子坐縛防止站起逃脫。壺蓋分為兩半，中央有一孔，頭部放入孔中後合上蓋子上鎖。身體全部在壺內，僅頭部露出壺外。可在壺內加入媚藥、淫癢藥或放入淫物。處於壺內的女修完全無法反抗。

三角木馬

形似木馬或鞍馬的道具，頂部為三角形尖稜。受縛者跨坐其上，雙腿懸空，全身重量集中壓於陰部與頂部尖稜的接觸點。雙手通常捆綁在身後。腳踝可加掛重物增加下壓力。使用時通常用多道繩圈在同側大腿和小腿纏繞後打結，增加拘束性。變種：尖稜上嵌入一根或者兩根假陽具，受縛者跨坐時假陽具插入陰道或肛門。常用於刑罰性調教。

罰跪板

一塊佈滿細小鈍釘的木板或金屬板。受罰女奴被要求跪於其上。鈍釘不會刺破皮膚，但跪久後膝蓋痠麻疼痛。常用於日常懲罰。變種：罰站板，要求赤足站於其上。

淫粘膠

膠水的一種，粘性十足，解膠劑僅在淫氣濃郁地區有售賣。透明粘稠。常塗抹於拘束具（如單手套）上加固拘束效果，或直接塗抹於皮膚上使佩戴者與拘束具粘合。深受淫道修士和魔道修士用於綁架和拘束加固。

淫粘膠膠帶

淫粘膠製成的膠帶。常見用法：捕獲女修後先將雙手纏繞粘緊，再戴上無指手套；或在後手縛基礎上纏繞加固；或纏繞全身形成膠帶木乃伊。需要解膠劑方可去除。

淫癢藥

山藥加淫物體液搗成汁製成。塗抹於皮膚後產生持續的瘙癢。有些主人喜歡塗抹於性器官後禁止奴隸觸摸，或塗抹後立即佩戴貞操具防止其自行抓撓。

擴陰器

也稱窺陰器。鴨嘴狀金屬器械，插入陰道後可撐開陰道壁，使人直接觀察陰道內部結構。常用於檢查或羞辱展示。

灌腸筒

金屬製筒形容器，頂部開口用於倒入液體（藥液、精液、粘液等），底部連接一根細長軟管。軟管末端為錐形塞頭，插入肛門後打開閥門，筒內液體灌入腸道。筒體標有刻度。用於灌腸。

吸乳器

由兩個透明罩杯和一個手動抽氣泵組成的器械。罩杯扣於雙乳上，抽氣泵持續產生負壓，將乳頭和乳暈吸入罩杯內。持續使用可使乳頭充血腫脹、乳孔擴張。通常用於產乳。

魚鰾套

魚鰾製成的薄膜套，套於陽具上，類似避孕套的功能。防止精液射入子宮。

###### 劇情用途與出場信號（寫場景時據此調用）

- 加固封禁類（淫粘膠/淫粘膠膠帶）：用途=給拘束具加保險、俘虜快速封禁、防掙脫。出場信號=捕獲後第一動作、押送前、防止掙脫的場合。搭配=無指手套+膠帶纏繞、後手縛+膠帶加固、膠帶木乃伊。反派/男修捕獲女修後的標配動作。
- 固定拘束類（單腳套/乳膠押送服/真空拘束床）：用途=整體性固定、押送、長時放置。出場信號=押送轉移、放置過夜、危險俘虜運輸。搭配=內部先上好拘束再套外層，押送服內塗淫粘膠。
- 籠器囚禁類（犬籠/淫壺）：用途=住所/展示/刑罰。出場信號=狗奴日常、示眾、刑罰、長期囚禁。搭配=內部加媚藥/淫物/淫癢藥，籠器本身是可被圍觀的道具。
- 刑罰器械類（三角木馬/罰跪板/擴陰器/灌腸筒）：用途=刑罰/檢查/羞辱。出場信號=刑罰性調教、體檢、公開羞辱。搭配=木馬可嵌假陽具、跪板配罰站板、檢查配圍觀。此類道具出場即 C10 凌辱的儀式化素材。
- 輔助調教類（淫癢藥/吸乳器/魚鰾套）：用途=身體狀態製造（禁慾折磨/產乳調教/交配管理）。出場信號=禁慾懲罰、產乳調教、淫物交配管理。

###### 新道具設計公式

- 淫粘膠系：粘性介質 + 用法（塗抹/膠帶/包裹）→ 隨意衍生（膠封口球、膠封貞操帶、膠鎖手腳、膠帶木乃伊）。
- 刑罰器械系：刑具形態 + 可加配（尖稜嵌假陽具/釘板配鞭打/跪板加負重）→ 按場景需求改造。
- 籠器系：容器形態 + 內部環境（加媚藥/淫物/淫癢藥/感官封閉）→ 用途可變（囚禁/展示/刑罰）。
- 檢查器械系：插入/撐開形態 + 檢查目的（體檢/羞辱展示/植入）→ 常配圍觀與點評。

### 場景知識-姿勢玩法

> 原條目 order 350・常駐・角色定義後

<場景知識拓展-姿勢玩法>

以下為姿勢玩法的知識補充。姿勢玩法非繩縛類，是要求受縛者自行保持的體態指令。無法保持則受懲罰。收錄的為比較特別的姿勢，比較普通的姿勢玩法正常描寫即可，在描寫調教與日常規矩場景時務必參考。

俯身翹臀

俯身彎腰，雙手扶膝或背於身後，臀部抬高。用於肛部調教、淫具檢查和公開羞辱。

踮腳罰站

踮腳站立，雙手背於身後。腳跟落地即受懲罰。常用於日常規矩訓練。站立時間視懲罰力度而定。

開腿跪姿

雙膝著地向兩側儘量分開，雙手背於身後，上半身挺直。私處完全暴露。受檢、審問、自我介紹時常用。

並腿跪姿

雙膝併攏，雙手可置於大腿上或背於身後。是最基礎的跪姿。與開腿跪姿的差異在於暴露程度，並腿為服從姿態，開腿為暴露。

蛤蟆跪

雙膝分開跪地，上身前伏至額頭貼地，雙臂前伸或背於身後，臀部翹起。卑微的服從姿勢。常作為日常請安規矩。

土下座

額頭貼地的卑微跪姿。雙膝併攏，雙手掌心向下置於頭側地面，額頭觸地。道歉與服從姿勢。常用於請罪或作為日常請安規矩。

跪坐

雙膝併攏，臀部坐於腳跟上。雙手置於大腿上或背於身後。女奴在日常侍奉中的標準靜候姿態。部分嚴格的主人要求臀部不許觸碰腳跟，需懸空保持。

跪坐雙手托乳

在跪坐基礎上，雙手從下方托起雙乳，將乳溝和乳頭正面呈現給前方。常用於初次拜見主人時的自我介紹。

單腳站立抬腿

站立，雙手背於身後。單腿向側面打開90度，另一隻腿腳尖點地。身體重心保持穩定。對核心力量和平衡能力要求高，摔倒即受懲罰。用於平衡訓練和羞辱展示。

蹲坐張腿

雙腳著地，深蹲至最低點，雙膝向兩側張開。雙手可置於膝上、背後或抱頭。私處正面暴露。保持時間長時大腿和膝蓋壓力大，身體不自覺顫抖。常用於公開示眾。

立式一字馬

站立狀態下單腿向側面抬起至超過肩高，雙腿呈一字直線。柔韌性要求極高。雙手可扶腿或背於身後。摔倒即受懲罰。常用於展示柔韌性。

狗撒尿

模仿犬類排尿的姿勢。雙手肘和單膝著地支撐身體，另一條腿向外側抬起，模仿母犬抬腿撒尿的動作。抬起腿的膝蓋彎曲，大腿向外打開。是狗奴的日常排尿姿勢和訓練內容之一，羞辱意味強。

### 場景知識-性愛姿勢

> 原條目 order 330・常駐・角色定義後

<場景知識拓展-性愛姿勢>

原則：嚴禁在正文直接寫出體位名。以下所有體位名稱僅用於AI內部參考，正文只通過姿勢、動作體現。禁止出現「正常位」「騎乘位」「後入」等詞。

##### 一、正面位

正常位

女方仰臥，雙腿自然分開。男方跪於女方兩腿之間，正面插入。男方雙手可揉捏乳房、揉搓陰蒂、握腰控制節奏。女方正面裸體暴露，乳房隨抽插晃動。

種付位

女方仰臥，雙腿被向上向後掰過肩膀，身體對摺成V形。男方深蹲下壓，重量施加於女方。使用研磨深插。陰莖直抵子宮口，小腹被頂出肉棒形狀凸起。射精時龜頭抵住子宮底射入。

M字開腳位

女方仰臥，雙膝彎曲向兩側打開，腳跟貼近大腿根部，呈M字形。男方跪於其間，雙手壓住女方大腿內側使其無法合攏，陰部暴露，雙腿大開的無助。

蓮花位

男方盤腿坐，女方面對面跨坐懷裡，雙腿盤在男方腰後互鎖，雙臂環抱脖頸。胸貼胸、腹貼腹的貼合。適合長時間溫存。

##### 二、騎乘位

騎乘位

男方仰臥。女方面向男方跪坐或蹲在男方上方，主動將陰莖插入陰道，上下移動身體。可前傾趴下、直立後仰、側身扭腰。男方雙手可抓臀部、揉乳房、十指相扣。

床上背面騎乘

男方仰臥。女方背對男方跨坐，雙膝跪床。可前傾撅臀暴露陰戶肛門、直立挺背大開大合、側身趴下單手撐床。男方視角臀部填滿視野。

反向蓮花式

男方仰臥。女方面向男方跨坐，膝蓋豎起，雙腳踩床面，呈M字大開腳。陰莖直抵深處。

對面坐位

男方坐著，女方坐其腿上面對面，雙腿環繞腰部。女方主動上下彈跳或畫圓研磨。兩人可深吻、對視、揉陰蒂。

坐姿後入

兩人同向坐，男方從後方包裹女方。女方背靠男方胸膛，坐在大腿上吞沒陰莖。男方雙臂環抱，雙手把玩乳房或按壓小腹。以畫圓研磨為主，適合鏡前或慵懶場景。

##### 三、後入位

後入跪位

女方膝蓋跪床，臀部高高翹起，上半身前傾以手肘或手掌支撐。男方跪於女方身後，從後方插入。

老漢推車式

女方彎腰雙手撐地，雙腳和地面成鈍角三角形。男方站於身後握住腰或臀部插入。

側躺後入位

兩人側躺，男方在女方身後緊貼。男方從後方水平插入。可抬起女方上側腿架在腰間暴露私處。上半身緊密貼合，可親吻後頸耳廓耳語。

反向懸空後入

男方站立，從背後將女方抱離地面。女方背對男方，雙腳離地，全身重量掛在男方身上。男方像使用飛機杯一樣控制女方身體起伏。體現支配感。

站立後入

女方雙腳著地，上半身前彎，雙手撐平面或牆壁，撅臀。男方站身後插入。可壓背揉胸、抓髮後拉。適合鏡前/牆壁場景。

##### 四、站立與特殊位

火車便當式

男方站立，雙手托住女方臀部承擔全部體重。女方掛在男方身上，雙腿盤腰，雙臂環脖。陰莖向上插入懸空女方。可邊走邊插，利用步伐產生顛簸。

單腿站立位

必須有牆壁或支撐物。女方單腿站立，另一條腿被男方扛在肩上或托起。可低位控制快猛撞擊，或高位架起深插。

##### 五、口交與手交

口交

女方將男方陰莖含入口中。可變：舌尖刺激龜頭、整根深喉、單手撫弄、雙手按摩睪丸、臉頰貼陰莖摩擦。男方可扶女方頭部引導。

強制深喉

男方主導，雙手按住女方後腦勺，像抽插陰道一樣快速挺腰。龜頭撞擊喉嚨深處。女方眼角泛淚，口水順嘴角流下。

龜頭責弄

專注於龜頭、冠狀溝與繫帶。舌尖快速彈動繫帶、舌面包裹旋轉、舌尖鑽探馬眼、沿冠狀溝畫圈、真空吸吮僅龜頭部分。

舔蛋

女方含入單側睪丸，舌頭使其在口腔內滾動。舔舐陰囊縫合線。手部同時套弄陰莖。臉頰被睪丸撐起。

毒龍鑽

女方舌頭針對肛門括約肌。先大面積舔舐肛門外圈和會陰預熱，再變尖舌頭沿褶皺畫圈或鑽入肛門內部。可配合真空吸吮。

柱身舔舐

淫器合煉是煉器術的分支，將一件正常武器/法器與一件淫具進行融合煉製，使其變為兼具二者特性的「淫器」。淫氣強度三及以上區域的煉器師多掌握此術。

##### 合煉條件

- 武器/法器與淫具必須為同品階。
- 兩者需有契合度，即武器形態與淫具類型的適配。不合契的組合強行合煉大概率失敗。
- 契合度邏輯判斷示例：

| 武器/法器類型 | 高契合淫具 | 合煉形態示例 |
|------------|----------|------------|
| 長短雙劍 | 玉勢（兩根） | 玉勢作為劍鞘置於體內，戰鬥時下體微動操控雙劍 |
| 長鞭 | 繩縛 | 平時緊縛於身，戰鬥時拘束自動解開化為長鞭 |
| 盾牌/護甲 | 貞操帶/貞操胸罩 | 平時封閉禁止自慰，戰鬥時展開為護盾 |
| 鎖鏈 | 手銬/腳鐐/項圈 | 平時作為拘束佩戴，戰鬥時延長化為遠距攻擊鎖鏈 |
| 恢復法器 | 子宮擴張環 | 平時體內刺激，戰鬥時恢復速度加快 |

（此為部分示例，生成時可根據武器與淫具的自然匹配邏輯合理拓展。）

##### 合煉後的淫器特性

###### 外觀

保留淫具的原始外觀，同時融合法器的外觀特徵。

###### 屬性發揮取決於佩戴時長

| 佩戴時長 | 數值加成 |
|----------|----------|
| 全天候佩戴（≥90%時間） | 原武器的 1.5 倍 |
| 大部分時間佩戴（≥2/3） | 原武器的 1.0 倍 |
| 少量時間佩戴（≥1/3） | 原武器的 0.5 倍 |
| 幾乎不佩戴（<1/3） | 無法激活淫器特性 |

###### 代價

淫器帶來的日常刺激與拘束程度也提升至原淫具的 **1.5 倍**。

##### 不同區域的煉器師

正道煉器師：偏保守款，外觀低調，增幅穩定

魔道煉器師：偏極端款，增幅高但日常代價翻倍

淫道煉器師：最懂淫具特性，擅長高契合度合煉，可根據喜好定製化

淫器可在任意煉器師處解除合煉，分離回原武器與淫具。分離無損耗，但需要同品階煉器師方可操作。
