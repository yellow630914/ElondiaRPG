# 工藝計畫：介面、技能門檻、學費、圖紙與檢定

> 上層：[ROADMAP](../ROADMAP.md) R18（第 2 節，介面）、R21（第 3 節，規則）。
> 2026-11-05 依玩家回饋（Discord 的 Tirpitz、[issue #62](https://github.com/yellow630914/ElondiaRPG/issues/62) 第 14～17 條）決定要做。這份計畫只寫還沒做的部分；做完的階段寫進 [CRAFTING](../../CRAFTING.md)，從這裡刪掉，最後整份刪掉並在[已完成](COMPLETED.md)記一段。

## 1. 現況（2026-11-05 盤點）

- **七種工藝**（`data/rules/crafts.json`）：
  - 鍛造（力量）、木工（靈巧）、製革（靈巧）、裁縫（靈巧）、珠寶（智力）。
  - 煉金（智力）、烹飪（靈巧），這兩種只能依配方製作。
- **等級**：存在角色的 `crafts`（`src/engine/types.ts`）。沒有資料時當作 **Lv.1**（`src/engine/crafting.ts` 的 `skillOf`），最高 7。只能靠製作升級，沒有任何地方能花錢學。
- **門檻**：工藝等級 ≥ 材料或配方的等級就能做，所以第 1 級的東西人人都能做。
- **檢定**：d20 + 屬性調整值 + 熟練加值（看角色等級）+ 工藝等級 ×1 + 特質（巧手 +2）。
  - 打造裝備的 DC 是 10、12……22（`data/rules/gear.json` 的 `craft.dc`）；配方的 DC 是 10～18，自創配方再 +2。
  - 委託店家打造時一律用智力，自己打造用工藝自己的屬性（兩者不一致）。
- **配方與圖紙**：沒有圖紙，配方人人都看得到（`src/engine/recipes.ts`）。
- **三種製作方式**（`src/components/CraftDialog.vue`）：
  - 依配方製作。
  - 自創配方：只能做消耗品與家具，製革只有家具（`crafts.json` 的 `invention.categories`）。
  - 打造裝備：底材加材料。
- **打造裝備的介面**（`src/components/CraftPanel.vue`）：
  - 底材是一整條長清單，照 `gear.json` 的順序排，標籤是「部位・名稱」，一般裝備和成人向服裝混在一起。
  - 材料清單也照資料的順序排。
  - 玩家找不到「皮頭盔」，實際上它叫「皮帽」，埋在清單裡。
- **成品預覽**：「成品」欄會寫出武器的傷害骰、防具的迴避與減傷、材料加成（`gear.ts` 的 `gearSummary`）。
  - 但普通皮革做的皮靴，迴避加成剛好是 +0，所以那一欄只寫「普通・鞋子」，看起來像沒有預覽。
  - 結果表只寫出各種結果的稀有度與附魔點數，沒有寫數值。
- **背景**：創角的背景是自由文字，沒有任何東西會給工藝等級。

## 2. 介面與材料（R18）

樣稿：[`docs/mockups/craft.html`](../../mockups/craft.html)（用 vite 開，直接讀遊戲的資料與計算）。

### 2.1 連動選單

- 打造裝備的底材改成依序選：**部位 → 類型 → 底材 → 材料**，部位、類型、底材都是按鈕列（帶數量）。例如：頭部 → 皮革衣物 → 皮帽 → 魔獸皮。
  - **部位**照裝備欄的順序：主手、副手、頭部、上身、手腕、腰帶、下身、鞋子、首飾、戒指、穿孔飾品、腿部飾品、內衣、內褲。
  - **類型**：`gear.json` 的底材加一個欄位（世界編輯器可以改）。主手：刀劍、鎚斧、長柄、弓弩、法杖、鞭；副手：盾、副手武器、法器；其他部位：金屬／皮革／布護甲、各材質的衣物、飾品、成人向服裝（🔞，內容篩選關掉時不顯示）。
  - **底材**：同一類型照價格排，卡片上寫出主要數值（例如「1d8 斬擊」）。
  - **搜尋**：輸入「帽」「靴」直接跳到底材（玩家找不到「皮頭盔」，實際叫「皮帽」）。
- 委託店家打造用同一套，只列這間店會做的。
- 上次選的部位與類型記在瀏覽器裡。

### 2.2 材料比較表（取代原本的「各結果的數值」）

- 做樣稿時確認：**稀有度不改變數值，只決定附魔點數；數值完全由材料決定**（例如普通皮革的皮靴大成功、成功都是迴避 +0，硬化皮革才 +1；皮帽的加成只有一半，第 1、2 級皮革都沒有加成）。
- 所以材料改成一張表：這個底材用每種材料做出來的數值、材料等級、建議等級、持有幾份。工藝等級不夠的灰掉加 🔒。
- 成品區寫出數值，以及大成功、成功、部分成功的稀有度與附魔點數（隨機）；材料沒有加成時寫出換哪種材料才有。

### 2.3 第 1 級材料改成物品、材料來源可以選（擁有者 2026-11-05 決定）

玩家回饋：「一級材料為啥非要自己買？直接把材料標注是多少級不就好了。」現在第 1 級材料（鐵、皮革、亞麻、橡木、銅）不是物品，自己打造時直接扣一筆材料費；第 2 級以上一定要用行囊裡的打造材料，同一種材料有好幾種物品時自動先用最便宜的，也不能在店裡當場買。

- **第 1 級改成物品**：新增鐵錠、皮革、亞麻布、橡木料、銅錠（`items.json` 的 `forge`），在雜貨店、鐵匠鋪、裁縫店、珠寶店賣，價格約等於現在的材料費。自己打造一律用行囊裡的打造材料，拿掉「第一級材料自己買」的材料費（`crafts.json` 的 `self.tier1_cost_ratio`）。
- **選用哪一份**：材料表每一列寫「持有幾份／需要幾份」；同一種材料有好幾種物品時可以選要用哪一種（預設最便宜的）。
- **當場補買**：份數不夠、這間店有賣時顯示「缺的 N 份在這裡買（多少錢）」，打造時一起付。
- **委託店家**：第 1 級照舊由工匠提供、含在工錢裡。
- **輔料保留**（擁有者確認）：照舊最多 3 種、每種最多 5 個，不論結果都用掉；價值越高越可能稀有度再高一級（部分成功時照成功做），名稱與描述決定附魔偏向的屬性。當作打造材料用掉的份數不算進輔料（現在就是這樣）。第 1 級材料變成物品後也能當輔料，但價值低、效果很小。
- 舊存檔不用轉換：以後自己打造第 1 級要先買（或當場補買）。
- 說明文字改成一句：「每件裝備要用幾份材料；行囊裡沒有的，店裡有賣就能當場補買。」

## 3. 規則（R21）

### 3.1 工藝 0 級與學費

- **新角色**的工藝從 **0** 開始，0 級什麼都不能做。
- 在對應的店（鍛造在鐵匠鋪、木工在鐵匠鋪、皮革與裁縫在裁縫店、珠寶在珠寶店、煉金在魔法店、烹飪在酒館）付學費學工藝，**店裡最多教到 Lv.2**。Lv.3 以上只能靠製作升級。
  - 學費與時間：0→1、1→2 兩段各一個價格（數值待定）。
  - 學會的那一段直接給等級，經驗值從 0 起算。
- **舊存檔**：沒有工藝資料的角色**算 Lv.1**，不收走已經有的能力。要分辨新舊，在存檔記一個版本旗標，新開的遊戲才用 0 級規則。
- **同伴與 NPC 也套用 0 級規則**：新產生的同伴沒有工藝資料時是 0 級。職業對得上的（例如鐵匠）照職業給等級（和 [CHECKS_PERKS_PLAN](CHECKS_PERKS_PLAN.md) 第 5 節的工匠身分一起）。店主的等級照聚落大小算，不受影響。
- **工匠身分**：創角選了工匠類的身分標籤，對應的工藝開局 Lv.2（見 [CHECKS_PERKS_PLAN](CHECKS_PERKS_PLAN.md) 第 5 節）。

### 3.2 檢定公式

- 改成：**d20 + 工藝等級 × 2 + 屬性調整值 ÷ 3（向零捨去）+ 特質、圖紙等修正**。拿掉熟練加值，工藝等級成為主要的加成，屬性的影響變小（issue #62 第 8 條也提到敏捷太強）。
- DC 表跟著重算，讓「剛好達到等級」時的成功率和現在差不多，「高出兩級以上」時明顯比較穩。
- 委託店家打造的檢定一起整理：改用工藝自己的屬性，和自己打造一致。
- 用 [worldgen/balance](../../../worldgen/balance/README.md) 算各等級、各 DC 的成功率表，寫進 [CRAFTING](../../CRAFTING.md)。

### 3.3 圖紙

- **每個底材一張**圖紙（例如「皮靴圖紙」「長劍圖紙」），是一種物品，不會用掉。
- 打造裝備時：**沒有圖紙 DC +5**，有圖紙照常。打造畫面寫出有沒有圖紙。
- **取得**：
  - 對應的店會賣（價格大約是底材價的幾倍，數值待定）。
  - 戰利品、寶箱會出。
  - 老師可以教，等於送一張。
- 世界編輯器新增底材時自動有對應的圖紙，不用另外建。
- 存檔裡的圖紙只記底材 id，不用為每張圖紙建一筆物品資料。

### 3.4 合併製革與裁縫

- 製革、裁縫合併成一種工藝（名稱待定，例如「皮革與裁縫」），屬性靈巧，在裁縫店學。
- **存檔遷移**：兩者取等級較高的那一個；經驗值取那一個的。
- 一起改的地方：
  - `crafts.json`。
  - 物品配方的 `craft` 欄位。
  - 底材對應的工藝。
  - 自創配方的類別（合併後有消耗品與家具）。
  - 特質判斷工藝的清單（`perks.ts` 的 `CRAFT_KINDS`）。
  - 世界包裡寫舊 id 的配方：讀取時自動換成新的 id。
