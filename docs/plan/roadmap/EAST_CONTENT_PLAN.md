## 1. 世界觀（世界書）

### 1.1 大陸與地區

- **炎華之地**：東海群島再往東、遠洋十天的大陸。化龍族稱它「炎華」：大陸南部終年溫暖，地底有熱泉與硝石，傳說是「熱量之龍」行經之地（1.2 節）。
- **炎華南域**：大河與運河交織的水鄉、丘陵上的窯場、熱鬧的海港；西北是山林與白樺，冬天下雪。大燁的統治中心。
  - 龍安府：王都，御街、瓦舍勾欄、太學與貢院，政治、經濟與文化的中心。
  - 萍江府：運河上的手工業城市，絲織、刺繡、瓷器；園林、道觀、竹湖。
  - 瑔州港：海外貿易的大港，蕃坊、市舶司、造船廠與火藥坊；商業地盤被靈狐族的胡記商幫與金黃鱗的海商瓜分。
  - **青丘屯**：大燁西北的山林村子，靈狐族的發源地，還保有自己的文化（1.4 節）。
- **炎華北原**：北方的草原，人馬族的汗國**媞丹**（第 11 節）。大燁每年付「歲幣」換和平，兩國在鷹河榷場做茶馬互市。政治線的下半在這裡交會（11.10 節）。

### 1.2 化龍族

- **外觀**：龍人。頭上一對龍角、頸側與手背與小腿覆鱗、豎瞳、一條長尾；鱗色就是社會階級（1.3 節）。兩性都有。
- **天性**：重禮、重文、愛美；講究器物與儀節，說話含蓄。怕冷（寒冰 ×1.25）、不怕火（火焰 ×0.5）。
- **名字**：宋式的姓加一、二字名；皇族姓燁。
- **蛇相**：化龍族裡偶爾會生出帶著蛇的樣子的特殊個體：鱗片細密、舌尖分岔、身子冰涼，常被當成「蛇妖轉世」而避諱。做成化龍族才能選的**缺陷**「蛇相」（寒冰傷害再 ×1.25；初見面的交涉 −1，被當成蛇妖），玩家建角時也能選；成人向角色青蘿就是這樣的人（5.2 節）。
- **起源的傳說**：古時候「熱量之龍・熾寂兩極」卡格尼的熱浪掃過這片大陸，活下來的人在熱浪裡「化」成了龍的樣子；熱浪退去後的死寂寒冷，是他們怕冷的原因。只是傳說：化龍族祭祀「祖龍」這個想像，巨龍本身不可名狀。
- **和玉璘族**：同源的兩支，一支在陸、一支在海；都記得「從同一片熱浪裡出來」的古歌謠，玉璘族的版本裡熱浪後來被海水冷卻。往來：珍珠與螺鈿換瓷器與絲綢。

### 1.3 鱗色與階級（美學與科舉）

| 鱗色 | 象徵 | 階級 | 比例 |
|---|---|---|---|
| **天青鱗**（汝窯色） | 極致的素雅與文化品味 | 最高階：文官、皇族、進士 | 10（龍安府多一點） |
| **朱砂鱗** | 武 | 軍人、皇室親軍（禁軍） | 20（龍安府多一點） |
| **墨鐵鱗** | 技藝 | 庶民、工匠、農民、火藥與造船的技師 | 50（萍江府、瑔州港多一點） |
| **金黃鱗** | 財富 | 商人 | 20（瑔州港多一點） |

- 生成的化龍族 NPC：鱗色約 90% 決定職業與身分，約 10% 例外。
- **點青**：鱗色天生，但殿試及第的人在「點青禮」上用汝窯釉藥封鱗，從此算是天青鱗。天生的天青鱗看不起「點出來的青」；這是階級能往上爬的唯一窄路。

### 1.4 靈狐族（新種族）

- **發源**：大燁西北的山林（青丘屯一帶）。三百年前大燁開國時歸附，之後大部分的靈狐族搬進城裡、改用化龍族的姓名與禮儀，**已經大致融入大燁文化**；在龍安府與瑔州港，他們是精明的商人、樂師、郎中。**只有青丘屯還保有靈狐族的文化**。
- **外觀**：狐耳與蓬鬆的狐尾；尾巴的數目隨年紀與修行增加（年輕人一條，屯裡的長者三、四條，九尾只在傳說裡）。眼瞳在暗處會發光。兩性都有。
- **天性**：機敏、好面子、記恩也記仇；講「討封」與「還願」。
- **青丘屯的文化：出馬**（參考東北的出馬仙，只保留狐仙一家）：
  - 屯裡供奉**胡家的仙**：靈狐族的祖靈。靈狐族相信自己是胡家的後代，死後也會回到胡家的仙堂。
  - **出馬**：「弟馬」（通常是女性）讓胡家的老仙附身，替人看事、治病、解冤；「二神」（香童）敲文王鼓、唱神調幫她請仙、送仙。
  - **堂口**：每位弟馬有自己的堂口（供桌與胡家仙的牌位）。
  - **討封**：山裡的黃皮子（野外的妖精，不是仙家）會攔路問人「你看我像人還是像仙」，答錯的人要倒霉（城鎮事件，9.2 節）。屯裡的人很討厭被城裡人把黃皮子和胡家仙混為一談。
- **和朝廷**：朝廷的祀典裡沒有仙家；龍安府的禮部認為出馬是「淫祀」，想把堂口改成祭祖龍的祠（青丘屯的故事線，8.4 節）。
- **胡記商幫**：城裡的靈狐族最大的一支，世代拿朝廷的**皇商特許**（茶引、鹽引、香料的專賣），所以向著朝廷。

### 1.5 歷史

| 時代 | 事件 |
|---|---|
| 古時 | 熱浪的傳說（1.2 節）；靈狐族在西北山林，化龍族在南方水鄉 |
| 前朝（燭龍朝） | 朱砂鱗的武人立國，窮兵黷武 |
| 大燁開國，約 300 年前 | 天青鱗的文臣擁立燁氏「以文制武」：**真相是文臣在永昭陵的祭典上毒殺了末代燭龍君，讓他的朱砂鱗將軍們陪葬**（永昭陵線，8.5 節）。靈狐族在這時歸附 |
| 現在 | 海貿與火藥讓金黃、墨鐵鱗富了起來，但朝中的位子還是天青鱗的；北原的歲幣、花石綱都落在他們身上。女帝登基五年（1.7 節） |

### 1.6 信仰

- 朝廷**祭天、祭祖龍**，太廟供奉燁氏歷代皇帝與祖龍。
- 墨鐵鱗的工匠拜「匠藝之神」赫斐斯托斯；瑔州港的水手同時拜玉璘族的「潮澤之母」凤母。
- 瑔州港的蕃坊有一座艾爾隆（光明之主）的教堂，給外國商人。
- 萍江府的**靈虛觀**是修道的女冠住的道觀（成人向角色玄霜，8.9 節）。
- 青丘屯的**仙家**與出馬（1.4 節）。仙家是靈，不是神祇。

### 1.7 政治格局

- **女帝燁昭華**：登基五年，強勢、勤政、手腕俐落。在太平盛世她有望清除積弊、成為明君；可是她遇上了劇烈的社會變革（海貿與火藥讓中產崛起、行會要權、北原的歲幣越來越重），賢明如她也焦頭爛額。
- **三地的角力**（各地故事線的主軸，8.4 節）：

| 地方 | 角力的兩邊 | 幫哪一邊 |
|---|---|---|
| 龍安府 | 朝廷的保守派（宰相溫世衡、天青鱗世家）與改革的聲音（太學生、欠餉的禁軍） | 保守派 → 君主制；改革 → 共和制 |
| 萍江府 | **官府**（女知府蘇懷瑾）與**農工階級**（織工行會的陸青禾） | 官府 → 君主制；農工 → 共和制 |
| 瑔州港 | **胡記商幫**（靈狐族，皇商特許）與**金黃鱗的海商**（金墨盟的金玉棠） | 胡記 → 君主制；金黃鱗 → 共和制 |
| 青丘屯 | 朝廷的改祀與屯裡的自治 | 改祀 → 君主制；自治 → 共和制 |

- **每條故事線的結局都有第三個「平衡」的選項**：讓兩邊各退一步、立下規矩（工約、分地盤、新制）。平衡的選項多了，大燁就走向**君主立憲**。
- **三種政體**（政治線上半的終章，8.7 節）：
  - **君主制**：女帝親政，掃除舊弊但收緊權力；朝廷與胡記得勢。
  - **共和制**：女帝退位，公議會治國；金墨盟與行會得勢，朝廷通緝死忠的保守派。
  - **君主立憲制**：女帝與議會共治，憲章限制皇權也保障各方；觸發多人任務「五席的夜宴」（8.10 節）。

### 11.12 燁婉寧的線與北原的多人任務

#### 燁婉寧：和親的公主（成人向，像中央平原的阿雅）

- **她的魅力**：端莊的天青鱗宗室女，嫁到草原當南院大王的可敦；她自己都不敢承認，她癡迷的是雄性人馬族的身體。
- **走向**：
  - **主角是人馬族**：可以走純愛線（不標 NTR）：她迷的身體就是主角的。
  - **主角不是人馬族**：一律是 **NTR 線**（標 `ntr`）：主角陪著她、看著她，一步步走向雄性的人馬族。
  - 設定裡關掉 NTR 時：非人馬族的主角看不到這條線；人馬族的主角照樣能走純愛線。
- **任務**（全部標成人向）：

| 任務 | 階級 | 說明 |
|---|---|---|
| ① 可敦的秘密 | D | 主角撞見她偷看那達慕的人馬族摔跤手；她紅著臉求主角保密，之後一次次找主角「陪她去看」 |
| ② 那達慕之後的夜 | C | 她想去摔跤手們的營帳「只是看看」。**分岔**：人馬族的主角「讓她看著我」（純愛）；其他主角「去吧，我在帳外等妳」（NTR，旗標 `ywn_ntr`） |
| ③ 純愛・可敦的選擇 | B | 只有人馬族的主角：她不再偷看別人，向主角坦白；結局成為戀人 |
| ③ NTR・野馬帳 | B | 她帶主角去草原上只收熟客的成人帳「野馬帳」，讓主角看她在那裡的樣子，然後問主角還要不要她 |

- **完成 NTR 線之後開放特殊場所「野馬帳」**（人馬風格的成人場所；地標、場景每三天一次，照中央平原的「黑檀之夜」）：鷹河榷場外的一頂大帳，雄性的人馬族在這裡挑選、享用來客。可以看燁婉寧在這裡和人馬族交歡；陰柔、中性體型的主角可以一起侍奉。
- 純愛線走完**不開放**野馬帳（和阿雅「被矯正」的走向一樣；2026-11-04 確認）。
- **程式工項**：劇情條件多一項「**主角的種族**」（現在只能判斷主角的身分標籤），讓分岔看主角是不是人馬族。

#### 金帳的三人（成人向）

- **對象**：天可汗烏蘭圖雅、少主察蘭（她的女兒）、國師其其格。
- **開放條件**：三人的角色線都走到第四個任務之後。
- **內容**：冬獵之後的金帳，其其格的骨紋占到「天可汗與少主要爭同一樣東西」，天可汗大笑，把三人與主角都留在金帳裡過夜（多人的成人向場景）。結局：察蘭得到母親的認可，或母女的較勁換一個戰場。
- **內容警示**：母女同時和主角親密，接任務前與冒險手冊顯示警示（和太妃宮的兩代同堂一樣）。
