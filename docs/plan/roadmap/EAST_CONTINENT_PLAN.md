## 1. 範圍

- 東海群島再往東的一塊新大陸：**炎華之地**（化龍族對故鄉大陸的稱呼；外地人叫它「東大陸」）。**分成南北兩個地區**：南部是化龍族的地方，這一版做；北部之後留給人馬族，這一版只保留地區 id 與名稱，不放地點。
- 新種族**化龍族**：龍人系，是南部的主要居民。文化和玉璘族接近，但更偏中國古風，參考**宋朝**：文治、科舉、市井繁華、瓦舍勾欄、茶坊、書院、市舶司。北邊的人馬族對應遼、金的草原民族。
- 南部約**三座城市**，規模是半個中央平原（看聚落數），內容密度做到東海群島的 1.5～2 倍。
- **等級帶和中央平原一樣，從 Lv.1 開始**：化龍族的主角可以直接在南部出生、從頭玩起，所以南部要有完整的新手內容（第 3 節）。

## 3. 從 Lv.1 開始帶來的工項

中央平原以外的地區都是從 Lv.2 以上起跳，所以南部要另外補上這些新手內容：

- **低等怪物**：野外與四座地下城周邊、淺層要有 Lv.1～2 的怪（中央平原有史萊姆、野狼、哥布林這一類）。這一層要做宋式的低等怪，例如山賊、野狗、水鬼、狐魅。
- **公會委託**：一般委託依附近的地下城生成，地下城的等級對了就會有 F、E 級委託，不用另外寫。
- **低階特殊任務**：中央平原 D 級（Lv.5～6）以下的任務有 46 條，其中 F、E 級只有 3 條。南部至少要有一條**入門委託**（像索里耶爾瑟琳的「失竊的聖環徽記」），再加上 D 級 8～12 條。
- **出生地**：`src/engine/state.ts` 的 `DEFAULT_BIRTHPLACE` 加上 `化龍族 → 龍安府`。建角畫面的出生地依地區分組，會自動列出。
- **旅途**：從瑔州港渡海到潮汐港，中間是東海群島（Lv.2～7）。要確認遠洋航線的旅途遭遇用哪一張表，避免 Lv.1 的主角在船上撞到 Lv.5 的怪。
- **物價與店**：南部的店照地點類型決定等級與物價，不用改；但新手常買的東西（藥劑、乾糧、基本裝備）要確定南部的店都有。

## 5. 工項

### 5.1 程式（量小）

- `src/engine/npcs.ts` 的 `raceWeights`：各地區 NPC 的種族比例寫死在程式裡，要加南北兩個地區與化龍族，或者順手搬進資料檔。
- `src/engine/state.ts`：`DEFAULT_BIRTHPLACE`。
- `src/components/MapPanel.vue`：世界地圖是固定的一張圖（`assets/map/elondia-map.webp`，1536×1024），東大陸在畫面外。要重畫或擴大地圖，或另外做一張東大陸的地圖（美術）。
- 確認沒有地點的北部地區不會在旅行面板、出生地、編輯器的地區選單裡出現空的一組。
- **鱗色決定職業**（約 90%）：現在生成居民時先挑標籤與職業（`population.ts` 的 `generateResident`），之後才挑種族與血統（`traits.ts`）。要改成化龍族先擲血統（鱗色），再從血統指定的標籤／職業挑，約 10% 照一般規則。血統多一個欄位，例如 `jobs: { tags: [...], occupations: [...], chance: 0.9 }`；固定 NPC 不受影響（手寫的）。
- 測試要更新：`shopNames.spec.ts`、`fixtures/race_combat.json`、建角與編輯器的快照。

### 5.3 地區與聚落資料

- **`data/world/geography.json`**
  - 南北兩個地區（炎華南域、炎華北原）、勢力（朝廷、中產力量）。
  - 3 座聚落與 2～3 座地下城，每個地點寫種族比例。
  - 路線：潮汐港 ↔ 瑔州港的遠洋航線（10 天、船資 150，沿海渡口不直航），加上龍安府、萍江府、瑔州港之間的官道。
- **`data/world/maps.json`**：每個區塊是 9×7 的 ASCII 地圖，合計約 10～12 塊，另外要取王城區的名稱。
  - 王都 4～5 塊，例如御街、市坊、瓦舍、貴族坊、皇城。
  - 城市 3 塊。
  - 港市 2 塊。
- **`data/rules/shops.json`**：地區的店名用字（`naming.regions`），例如酒樓分正店／腳店，還有茶坊、邸店、解庫、書坊。
- **`data/rules/lewd.json`**：魅氣濃度。
- **`data/rules/npc_population.json`**：各聚落的人口組成和街上的路人職業。
- **`data/rules/slavery.json`**：要不要設市場或黑市。
- **`data/rules/enemies.json`**：南部的野外遭遇，以及每座地下城的遭遇表（周邊、淺、中、深、底層，加上層主）。等級照第 2 節。
- **`data/rules/travel_events.json`**：遠洋航程專屬的旅途事件。
- **背景圖**：地區 1 張、聚落 3 張、地下城 2～3 張（`src/assets/backgrounds/`）。

### 5.4 內容

- **怪物**：新做 25～35 種，包括層主。照 R14 魔物娘的分類規則，再跑 [worldgen/balance](../../../worldgen/balance/README.md) 的平衡模擬。

- **固定 NPC**：25～40 位，立繪之後再補。
- **地標**：10～15 個，例如瓦舍勾欄、書院、市舶司、虹橋、貢院。
- **特殊地圖**：2～4 張，例如皇城地宮、城底下的水道。
- **特殊任務**：40～70 條。
  - 必做：入門委託、渡海往來的引導線、化龍族的種族線，以及地區的**政治史詩**：朝廷（天青、朱砂）對金黃、墨鐵的中產力量，三個結局（君主制、共和制、君主立憲制）。結局要決定會不會改變世界：例如兩個勢力的聲望、龍安府王城區的主人、固定 NPC 的階段（依旗標改變出沒與身分）、地標的場景。可以參考中央平原政治史詩用旗標累積走向的做法（`worldgen/design/elondia-storylines.md`）。
  - 題材可以用：科舉舞弊、水泊盜寇、審案、花石綱、火藥坊的工潮、市舶司的稅。
- **其他事件**：地下城事件、城鎮事件。
- **世界書**：新增地區、種族、人物條目；改寫「大陸概述」和「區域地理地標相對位置」，加入東大陸的方位與路程。
- **文件和產生的頁面**：`docs/WORLD.md` 的幾張表、README 的數量、CHANGELOG，以及重跑 `worldgen/tools/guide/guide.py`（攻略）和 `worldgen/tools/flowdoc/flowdoc.py`（任務流程圖）。
