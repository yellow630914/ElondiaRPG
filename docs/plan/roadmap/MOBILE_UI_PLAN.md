## 1. 實機測試

模擬器（Pixel 7、iPhone 13、iPhone SE、360／320 寬）都測過，觸控手感、鍵盤彈出、返回鍵要在真的手機上再走一輪。下面這些要特定的遊戲狀態才看得到，外框已經是全螢幕頁面或半屏面板，裡面的排版還沒看過：

- 事件視窗：升級選能力、學特質、入隊、刻印、旅途事件、提議、對峙、主人的事件、戰敗事件、俘虜的處置、特殊任務的節點。
- 奴隸契約、形象圖工作室、騰出隊伍空位、房屋管理、地下城、淫鬥場、拍賣會、緋夢樂園等特殊地圖。
- 多人對多人的戰鬥、戰鬥的「色情」分頁。
