## 1. 開關與存檔規則

| 項目 | 在哪裡 | 預設 | 說明 |
|---|---|---|---|
| 內容篩選「懷孕」 | 設定 → 成人內容的內容篩選（`content.ts` 的 `FILTER_TAGS` 加 `pregnancy`） | **關** | 關掉時不擲受孕、不出現察覺事件；已經懷孕的照常進行到生產（不會憑空消失），已經生下的小孩照常在 |
| 內容篩選「泌乳」 | 同上（`lactation`） | **關** | 關掉時泌乳道具不能用、懷孕後期與胎生的苗床不會進入泌乳、已經有的泌乳狀態不生效 |
| 存檔規則「受孕機率」 | 成人內容頁的存檔規則（`gameRules.ts` 的 `RULE_DEFS`） | 1 倍（0～3） | 0 = 不會受孕（篩選打開但想暫停時用） |
| 存檔規則「孕期天數」 | 同上 | 40（10～120） | 階段照比例縮放（第 4 節） |
| 內容篩選「怪物的苗床」 | 同上（`monster_brood`） | **關** | 見第 12 節 |
| 存檔規則「苗床的機率」 | 同上 | 1 倍（0～3） | 0 = 怪物不會讓人變成苗床 |

懷孕整個屬於成人向：成人內容沒開的存檔不擲、不顯示。篩選的預設值寫在 `settings.ts` 的 `contentFilters`；讀舊設定時 `{ ...base, ...saved }` 會自動補上新的鍵，不用轉換。

## 2. 誰能受孕、誰能讓人受孕

照 `npc_pool.json` 的性別（主角是自由輸入的文字，照 `genderDef` 對應）：

| 性別 | 能懷孕 | 能讓人懷孕 |
|---|---|---|
| 女性 | ✓ | |
| 扶她 | ✓ | ✓ |
| TS | | ✓ |
| 偽娘、男性 | | ✓ |
| 未知、主角對應不到的文字 | 體型陰柔、中性 ✓；陽剛不行 | 體型陽剛 ✓ |

- **範圍**：主角（`pc`）、隊伍裡的人、留守或寄放的夥伴、有 NPC 登錄的人（人際關係裡的人）。這正好就是 `sexCandidates` 收的人（怪物本來就不收），不用另外篩。
- **已經懷孕的人不會再受孕**；產後虛弱期間也不會（第 6 節）；身上有胎生的苗床時也不會（第 12.4 節）。
- **歡愉的惡作劇**（改性別）：懷孕期間不會擲到改性別的結果。生產之後照常。
- **怪物**：對象沒有 id、而這份報告裡有怪物（`report.others` 有 `monster`）時不擲，交給寄生物。

## 3. 受孕判定

### 3.1 在哪裡擲

在 `sexRecord.ts` 的 `applySexUpdates` 裡，每一位 `sex > 0` 的人呼叫 `addEncounter` 之後擲。**不要擲在 `addEncounter`**：`npcLife.ts` 的私生活也呼叫它（決定 8）。

- AI 記錄失敗、手動按「♥ 記下性經歷」的也是走 `applySexUpdates`，一樣會擲。
- 同一則日誌只擲一次：沿用 `sexLogged`。回退掉的日誌不會留下懷孕，因為懷孕和性經歷寫在同一個存檔狀態裡，回退時一起回去。
- 亂數用「日誌 id ＋ 母親 id」的固定種子，重讀同一個檔結果一樣（和 NPC 私生活的做法相同）。

### 3.2 父親是誰

從這個人的 `with` 裡挑「`sex` 不是 false、而且能讓人懷孕」的對象：

| 情況 | 記成 |
|---|---|
| 只有一位，有 id | 那個人（id 與名字） |
| 只有一位，只有名字 | 那個名字，沒有 id |
| 兩位以上 | **父親不明** |
| 沒寫對象、只寫「幾位客人」這類 | **父親不明** |
| 對象全部都不能讓人懷孕（例如兩位女性） | 不擲 |

對象的性別：有 id 的照他的角色或 NPC 登錄；只有名字的當成可以，除非內容篩選關了男性對象。

### 3.3 機率

```
受孕機率 = 基礎 × 次數 × 種族 × 加減 × 存檔規則「受孕機率」，最多 60%
```

數值放在新的 `data/rules/family.json` 的 `conception`（暫定，屬於 R1 數值平衡）：

| 項目 | 暫定值 |
|---|---|
| 基礎 | 15% |
| 次數 | 這次性交 1 次 ×1、2 次 ×1.3、3 次以上 ×1.5 |
| 種族 | 同種族 ×1、不同種族 ×0.6；父母任一方是精靈 ×0.6、魔族或化龍族 ×0.5（可以疊乘）；父親不明照母親的種族、當成同種族 |
| 淫紋・子宮 | ×1.5（刺青圖樣多一個 `fertility`） |
| 魅魔的契紋（共生、支配） | ×1.5（寄生物多一個 `stage_fertility`） |
| 避子湯 | ×0（第 3.4 節） |
| 娼館接客（`narration.adult_actor`，主角自己去打工也算） | ×0：老鴇讓接客的人喝避子湯 |

### 3.4 避子湯

新的消耗品：喝了之後 24 小時內不會受孕（狀態 `contraceptive`，記到期的時間）。雜貨店、神殿販售，暫定 30 白鸛；配方是煉金 2、藥草 ×2。內容篩選「懷孕」關閉時不上架。

## 4. 懷孕的狀態

### 4.1 存在哪裡

存在 `state.pregnancies`（角色 id → 記錄，主角是 `pc`），不放在 `Character` 上，因為人際關係裡的 NPC 不一定有角色資料：

```ts
interface PregnancyState {
  conceived: number            // 受孕的日子
  due: number                  // 預產日 = 受孕日 + 孕期天數（受孕當下算好，之後改存檔規則不影響已經懷上的）
  father?: { id?: string; name: string }   // 沒有 = 父親不明
  report?: string              // 哪一則日誌
  known: boolean               // 察覺了沒
  knownDay?: number
}
```

### 4.2 階段

依「已經懷了幾天 ÷ 孕期」算，不另外存：

| 階段 | 40 天時 | 比例 | 平常的減值 | 慾望指標 |
|---|---|---|---|---|
| 未察覺 | 0～7 天 | 0～20% | 沒有；擲察覺事件（第 5 節） | — |
| 初期 | 8～15 天 | 20～40% | 長休後 30% 有「孕吐」：下次長休前力量檢定 −1 | — |
| 中期 | 16～30 天 | 40～75% | 靈巧、潛行 −1 | 敏感每 5 天 +1 |
| 後期 | 31～39 天 | 75～100% | 靈巧、潛行 −2；開始泌乳（第 8 節） | 敏感每 5 天 +1 |
| 臨盆 | 40 天 | 100% | 觸發生產（第 6 節） | — |

- **未察覺時沒有減值**，角色詳情不顯示，避免玩家從數字看出來。
- 中期一到就**自動察覺**（肚子看得出來了），不管察覺事件擲到沒有。
- 減值只對有角色資料的人（主角、隊伍、留守的夥伴）有意義，接在 `party.ts` 的非戰鬥狀態減值旁邊，事件視窗的情境修正寫「懷孕・中期 −1」。

### 4.3 戰鬥（慾望戰鬥開著時）

照拘束具、寄生物的雙面效應：**平常是上面的減值，戰鬥中修了任何流派的人反轉成增益**。沒修流派的人只吃平常的減值。

| 階段 | 戰鬥中 |
|---|---|
| 初期 | 豁免 +1 |
| 中期 | 豁免 +1、減傷 +1 |
| 後期 | 豁免 +2、減傷 +1；有隊友倒下時傷害 +2 |

數值放在 `family.json` 的 `two_face`；程式照 `parasites.ts` 的 `parasiteTwoFace`。

### 4.4 顯示

- **角色詳情**：察覺之後，「慾望」頁多一行「懷孕：中期（第 18 天，預產第 52 天）・父親：某某／父親不明」。
- **人際關係**：不在隊上的人，卡片上寫「懷孕中」（察覺之後）。
- **形象圖**：中期以後生圖的描述加上懷孕（`pregnant`）；後期加上泌乳的描述照第 8 節。
- **日誌**：受孕當下**不寫**（未察覺）；察覺、生產寫一筆。

## 5. 察覺劇情

只做察覺；不做告知父親與父親的反應（決定 7）。

### 5.1 主角

- **什麼時候**：未察覺期間（第 3 天以後），長休之後 30%、旅途每天 20%，用 `scope: pregnancy` 的事件，在事件視窗回應（和寄生物的發作一樣）。內容標 `adult`、`pregnancy`。
- **做法**：每件事件都有「確認」的選項，選了就察覺：
  - 自己想到（智力檢定），成功察覺，失敗當成吃壞肚子
  - 去神殿或找草藥師（到了聚落才算，要付診察費）
  - 先不管（下次再擲）
- **內建 6 件**：早上的孕吐、月事遲了、聞到酒味就反胃、胸口脹痛、突然很想吃酸的、旅店老闆娘看出來。
- 第 8 天以後都沒察覺，中期一到就自動察覺：「肚子已經藏不住了」，寫一筆日誌。

### 5.2 夥伴（在隊上、留守、寄放）

- 在隊上的夥伴：主角看出異樣的事件，內建 3 件：「某某最近吃不下」「某某在路邊吐了」「某某摸著肚子發呆」。選「關心」的察覺並親密度 +2；「帶去神殿」的察覺；「沒注意」的下次再擲。
- 留守、寄放的人：主角回去見到時，中期以後直接察覺。

### 5.3 人際關係裡的人（不在隊上）

主角見到他（在「這裡的人」列出來）時，中期以後察覺，人際關係多一筆近況「看起來懷孕了」（規則寫的短句，不交給 AI）。

### 5.4 神殿的診察

神殿的新服務「診察」，暫定 20 白鸛：看出隊伍裡誰懷孕了（包括未察覺的）。通緝中、逃亡奴隸照神殿現有的規則不接待。

## 6. 生產

### 6.1 預產日到了

| 人在哪裡 | 怎麼生 |
|---|---|
| 主角、在隊上的夥伴，人在聚落裡或自己的房子裡 | 跳生產事件（第 6.2 節） |
| 主角、在隊上的夥伴，人在野外或地下城 | 先進入「陣痛」，給一天回到聚落；過了一天就在原地生，生產檢定的 DC +4 |
| 留守在房子的夥伴 | 在房子裡自動生下，嬰兒留在那棟房子；日誌補一筆 |
| 寄放在酒館的夥伴 | 在那座城自動生下，嬰兒照第 7.4.1 節自動安排；日誌補一筆 |
| 人際關係裡的人（不在隊上） | 在他的城裡自動生下，人際關係寫一筆近況；嬰兒自動送到主角那裡（第 7.4 節） |

### 6.2 生產事件

- **地點**：
  - 這座城有神殿：可以選「去神殿生」（付費，暫定 200 白鸛，一定順利）
  - 自己的房子、旅店：生產檢定（信仰），DC 12；隊伍裡有牧師、聖騎士或會治療法術的人 −2
  - 野外：DC 16
- **結果**：成功是「產後虛弱」3 天；失敗是 6 天，不會死、嬰兒也不會有事（決定 3）。產後虛弱的效果是所有檢定 −1，戰鬥中生命上限 −20%，記在 `state.pregnancies` 拿掉之後的 `postpartum`（到期的日子）。
- **嬰兒**：
  - 玩家取名字（預設從種族的名字庫抽）
  - 性別照 `npc_pool.json` 的權重擲
  - 種族：父母各一半；父親不明照母親的種族
  - 生產之後馬上選放在哪裡（第 7 節）
- **日誌**：`kind: "social"`，標籤「生產」，交給 AI 描寫，屬於一般的日誌，**不是成人場景**。
- **雙胞胎**這一版不做（第 13 節）。

## 7. 嬰兒

### 7.1 存在哪裡：和 NPC 完全分開

嬰兒**不進 NPC 登錄**，存在 `state.children`：

```ts
interface ChildRecord {
  id: string                // c<編號>
  name: string
  gender: string
  race: string
  born: number              // 出生的日子
  mother: { id: string; name: string }
  father?: { id?: string; name: string }    // 沒有 = 父親不明
  where: { kind: 'temple'; location: string; since: number; paidUntil: number }
       | { kind: 'home'; home: string; at: { area: string; x: number; y: number } }
}
```

**這是刻意的設計**：嬰兒不是 NPC，所以從結構上就不會出現在「這裡的人」、人際關係的互動、性經歷、NPC 私生活、誘惑、娼館、奴隸市場、拍賣會、調教、主人事件、戰鬥裡，不必每個系統各自記得排除。測試要檢查這一點（第 11 節）。

### 7.2 神殿的育幼院

- 有神殿的聚落都收。神殿面板多一個「育幼院」區塊：寄養、探望、繳費、接走。
- **寄養費**：暫定每天 10 白鸛，從寄養那天起算。到神殿時一次繳清欠的，也可以預繳幾天（`paidUntil`）。
- **欠費**：嬰兒照樣有人照顧，不會被趕出去，也不會被賣掉。只是**這座神殿的其他服務**（治療、解咒、診察、祝福）要先繳清才能用。
- **通緝中、逃亡奴隸**：其他服務照現有規則不接待，但**育幼院一定收嬰兒**，也可以探望、繳費。
- **探望**：寫一筆日誌（標籤「探望」，一般日誌）。探望的人得到「家人的笑容」（非戰鬥狀態，下次長休前豁免 +1，`clears: long_rest`）。

### 7.3 自己的房子

- 嬰兒在房子裡**不用錢**，也**不一定要有搖籃**（自動送來的嬰兒不能因為沒有搖籃就被擋掉，決定 12）。
- 新家具「**搖籃**」（可有可無）：雜貨店，暫定 60 白鸛，室內，`function: "crib"`，舒適 1。有空的搖籃時嬰兒放在搖籃上，沒有時放在一樓靠床的地板格（和留守的夥伴一樣找一格站）。搖籃上有嬰兒時不能收起。
- 房屋區塊多一行「孩子」：列出名字，可以「抱抱」（得到家人的笑容）、「送去育幼院」。
- 房子沒了（以後如果能賣房、或內容被刪掉）：嬰兒送到這座城的神殿，沒有神殿時送到最近有神殿的聚落。

### 7.4 搬來搬去

| 從 | 到 | 怎麼做 |
|---|---|---|
| 育幼院 | 同一座城自己的房子 | 在育幼院按「接回家」；欠費先繳清 |
| 自己的房子 | 同一座城的育幼院 | 在房屋區塊按「送去育幼院」 |
| 任何地方 | 別的城 | 神殿派人護送：費用照路程（暫定每天路程 30 白鸛），照路程的時間抵達 |

主角不能把嬰兒帶在身上（決定 6）。

### 7.4.1 自動送來的嬰兒

不在隊上的人生下的嬰兒（人際關係裡的 NPC、寄放在酒館的夥伴，第 6.1 節）照下面自動安排，玩家不用做什麼（決定 12）：

1. 主角**有房子**：送到房子。有好幾棟時，先挑母親那座城的；沒有時挑離母親那座城最近（照路程）的一棟。
2. 主角**沒有房子**：送到**母親那座城的神殿**；那座城沒有神殿時，送到最近有神殿的聚落。寄養費從送到那天起算在主角身上。
3. 日誌補一筆（規則寫的短句，不交給 AI）：「某某生下了孩子某某，送到了……」。名字照種族的名字庫抽，之後可以在「家人」改。

不管父親是不是主角都這樣安排：只要母親是人際關係裡的人，嬰兒就算主角照顧。主角生產、隊上的夥伴生產時照舊由玩家選（第 6.2 節）。主角是奴隸時也一樣，主人的家不算（決定 14）。

### 7.5 顯示

- 「隊伍」視窗最下面「不在隊上的夥伴」底下，多一段「**家人**」：每個孩子的名字、幾天大、父母、在哪裡、欠多少寄養費。
- 父親或母親的人際關係卡片：寫「孩子：某某（在某某神殿）」。

## 8. 泌乳

和懷孕是兩個獨立的狀態；懷孕後期只是其中一個來源。

### 8.1 誰能泌乳

女性、扶她、TS（有乳房的性別）；主角對應不到的性別看體型（陰柔、中性）。**陽剛體型的主角不能用泌乳道具**（決定 13）：道具、裝備、刺青都擋掉，事件效果也不生效。

### 8.2 存在哪裡

`state.lactation`（角色 id → 記錄）：

```ts
interface LactationState {
  sources: { kind: 'pregnancy' | 'brood' | 'item' | 'gear' | 'tattoo' | 'event'; until?: number; ref?: string }[]
}
```

有任何一個還沒到期的來源就算泌乳。裝備、刺青的來源跟著穿戴：卸下、洗掉就拿掉。

### 8.3 來源

| 來源 | 持續 | 哪裡拿 |
|---|---|---|
| 懷孕後期 | 從後期開始，到生產後 30 天 | 自動（篩選「泌乳」要開） |
| 胎生的苗床（共生以上） | 到產下後 15 天 | 自動（篩選「泌乳」要開；第 12.4 節） |
| **催乳茶**（消耗品） | 3 天 | 雜貨店（城市以上）；煉金 2：乳香草 ×2 |
| **魔乳果**（料理類） | 5 天 | 菜圃種「魔乳果苗」，7 天成熟；苗在雜貨店、魔法物品店 |
| **催乳藥劑**（消耗品） | 14 天 | 魔法物品店（魅氣 3 以上）；煉金 4：淫獸的媚腺、乳香草 ×2 |
| **泌乳之環**（穿孔飾品） | 戴著的時候 | 珠寶店（魅氣 3 以上）、拍賣會；敏感 +5 |
| **淫紋・乳泉**（胸口的淫紋） | 紋著的時候 | 刺青店（魅氣 3 以上）；慾望上限 +10% |
| **斷乳藥**（消耗品） | 拿掉道具、事件造成的泌乳（懷孕的不行） | 神殿、雜貨店 |
| 事件、任務的效果 | 照效果寫的天數 | 內容編輯器 |

新材料**乳香草**：菜圃種「乳香草種子」，4 天成熟，收成 2～3。

**給別人用**：奴隸照舊直接給。自由的夥伴要先答應，和「提議夥伴去接客」同一條公式（[LEWD_STATS](../../LEWD_STATS.md) 第 10 節）：魅力檢定，DC = 15 − 淫亂 / 10 − 親密度 / 25；失敗親密度 −2。

### 8.4 效果

- **平常**：
  - 敏感的有效值 +5
  - 胸部那一側真空或曝露時，每天的曝露名聲多 +1
  - 交給 AI 的角色資料寫「正在泌乳」（只在成人向的敘事與判定送）
- **戰鬥中**（修了流派、慾望戰鬥開著）：慾望上限 +10%，受到的慾望 +10%；肉體派契合 ×1.2。
- **形象圖**：生圖的描述加上泌乳（`lactation`），只在成人向生圖。
- **嬰兒的餵養不連到泌乳**：育幼院和房子裡的嬰兒怎麼吃，一律抽象處理，不寫進這個狀態。泌乳的描寫屬於成人內容，**提示詞裡不會同時出現嬰兒**（第 9 節）。

## 10. 內容編輯器（P5）

### 10.1 懷孕的事件：察覺事件與孕期事件

察覺事件從 `family.json` 搬進 `travel_events.json`，標 `scope: "pregnancy"`，用「🎲 事件」的編輯器（種類「🍼 懷孕」）。同一個 scope 分兩種：

| 欄位 | 說明 |
|---|---|
| `known` | `false`（或不寫）= 察覺事件：還沒察覺的人、受孕滿 `min_days`、未察覺或初期；`true` = 孕期事件：已經察覺的人 |
| `stages` | 哪些階段（`hidden`、`early`、`mid`、`late`；不寫不限） |
| `subject` | `pc` 主角、`companion` 隊上懷孕的夥伴（文字 `{a}`、效果 `$a`） |
| `moments` | `rest` 長休之後、`travel` 旅途每天、`step` 走動（城鎮、地下城、近郊、臨時地圖） |
| `in_settlement` | 只在聚落裡 |
| `father` | `unknown` 父親不明、`known` 知道是誰、`in_party` 父親在隊上、`not_in_party`；不寫不限 |
| `father_races` | 父親是這些種族（父親不明時不成立） |
| `mixed` | 混血（父親的種族和母親不同） |
| `forced` | `true` 只有非自願懷上的、`false` 只有不是非自願的 |
| `requires`、`hours`、`pc_body`、`tags` | 和其他事件一樣（這一期補上檢查；P2 時沒有檢查） |
| 選項的 `reveal` | `always`／`success`：察覺（只對察覺事件有意義） |

- 受孕時多記父親的種族（`father.race`）、這次經歷是不是非自願（`forced`，看性經歷的 AI 記錄）。
- **頻率**（`family.json` 的 `event_rules`）：察覺事件照舊（長休 30%、旅途 20%）；孕期事件另外一組（長休 15%、旅途 10%、走動 1%），兩種共用 12 小時的冷卻。
- **內建**：察覺事件照舊 9 件；孕期事件主角 12 件、夥伴 6 件，**不分父親的種族、非自願**（決定 20），只分階段，少數看「父親在隊上」。部分成人向（決定 21）。

| 階段 | 主角（12） | 夥伴（6） |
|---|---|---|
| 初期 | 乾嘔得厲害、突然很想吃某樣東西、聞到血腥味就反胃 | 夥伴吐得臉色發白 |
| 中期 | 第一次胎動、衣服變緊了、路人的祝福、父親把手放在肚子上（父親在隊上）、孕期變敏感（成人向） | 夥伴讓你摸胎動、夥伴的衣服撐不下了 |
| 後期 | 腰痠背痛、夜裡腿抽筋、產婆主動來打招呼、和伴侶的親密時光（成人向） | 夥伴走不動了、夥伴夜裡睡不著 |

新的非戰鬥狀態：「胎動的喜悅」（下次長休前魅力 +1）、「腰痠背痛」（下次長休前力量 −1）、「抽筋」（下次長休前靈巧 −1）；產婆的事件給「產婆的叮囑」（這一次生產的 DC −1，記在懷孕記錄的 `birth_dc`）。

### 10.2 條件

特殊任務、事件、地標的「更多條件」多三種（`StoryCond`）：

| 條件 | 寫法 |
|---|---|
| 懷孕 | `pregnancy: { who: 'pc' \| 'party', stage_min, stage_max, known }` |
| 泌乳 | `lactating: true / false`（主角） |
| 孩子 | `children: { min, max }`（主角有幾個孩子） |

### 10.3 效果

| 效果 | 寫法 | 說明 |
|---|---|---|
| 懷孕 | `{ type: 'pregnancy', op: 'conceive' \| 'reveal', target, father?, father_name? }` | 受孕一定成立（決定 23）；篩選關掉、身體不行、已經懷孕、產後虛弱時不做，日誌寫原因。`target` 是主角、某位 NPC 或 `$a`；`father` 是 `pc`、NPC id，或空著＝父親不明 |
| 泌乳 | `{ type: 'lactation', op: 'add' \| 'remove', target, days? }` | 來源記成 `event`；拿掉只拿事件與道具的 |

- 特殊任務與事件都能用；主人事件格式（主人事件、調教、娼館）只能用「泌乳」。
- 用了這兩種效果、卻沒有標「懷孕」或「泌乳」內容標籤的任務與事件，編輯器提醒。

### 10.4 物品、刺青、寄生物

| 地方 | 新增 |
|---|---|
| 物品 | 消耗品的「泌乳幾天」「斷乳」；裝備的「戴著時泌乳」；所有物品的「內容標籤」（關掉時商店不賣）；家具功能「搖籃」 |
| 刺青 | 圖樣的「紋著時泌乳」「受孕倍率」「內容標籤」 |
| 寄生物 | 「受孕倍率」（侵蝕度從多少開始、倍率） |

淫紋・子宮與魅魔的契紋的受孕倍率從 `family.json` 的 `conception` 搬到圖樣與寄生物自己的資料（`fertility`），數值不變。

### 10.5 ⚙️ 懷孕與泌乳設定

「🐛 寄生物」頁籤旁邊的固定按鈕，照「⚙️ 事件設定」的做法：`family.json` 的數值（受孕、階段與減值、孕吐、察覺、事件頻率、生產、產後虛弱、育幼院、泌乳、雙面效應）都能改、可以恢復預設。存在 `ContentMods.family`，跟著世界匯出匯入。

### 10.6 引用與保護

- 用量檢查：刪物品時列出種子作物；刪固定 NPC 時列出效果「懷孕」裡指定的對象與父親。
- 自建的懷孕事件刪掉時，等待中的作廢（`prunePregnancyEvent`）。

### 11.1 P1 實作時和計畫不同的地方（2026-11-10）

- **避子湯**：效果是「下次長休前不會受孕」（非戰鬥狀態「避孕」，和其他喝的東西一樣長休時解除），不是 24 小時。
- **搬到別的城**：神殿派人護送，費用照路程，但**馬上送到**（不另外記抵達的日子）。
- **嬰兒的名字**：生產時可以自己取；自動生下的照名字庫抽，**這一版不能改名**。
- **不在隊上的人察覺**：主角人在他那座城時（中期以後）察覺，不另外看「這裡的人」。
- **生產的治療加值**：隊伍裡母親以外有牧師、聖騎士或德魯伊時 −2（看職業，不看法術）。
- **產後虛弱**：只有所有檢定 −1；戰鬥中生命上限 −20% 和懷孕的雙面效應一起放到 P4。
- **通知**：察覺、陣痛、自動生下的孩子在事件視窗的「🍼 家人的消息」（不擋行動），按「知道了」寫成一筆日誌。

### 11.2 P2 實作時和計畫不同的地方（2026-11-10）

- **事件放在 `family.json` 的 `events`**，不放 `travel_events.json`：格式一樣（事件模板），多了 `subject`（主角或夥伴）、`in_settlement` 與選項的 `reveal`。內容編輯器的支援放在 P5。
- **察覺不是新的效果種類**，是選項的 `reveal`（always／success）。
- **「帶去神殿」的選項沒有做**：夥伴的事件改成「關心」（察覺、親密度 +2）、「仔細觀察」（智力檢定）或「沒注意」；要確認可以到神殿診察。
- **人際關係的近況**：不在隊上的人被察覺、生下孩子時各記一則（規則寫的短句，不交給 AI）。

### 11.3 P3 實作時和計畫不同的地方（2026-11-10）

- **泌乳之環給陽剛主角**：可以戴（它也是一件敏感 +5 的乳環），只是不會泌乳；道具與淫紋・乳泉才擋掉。
- **乳香草不在商店賣**，只能種（乳香草種子）；催乳茶要城市以上的雜貨店。
- **同一樣道具再用一次**取比較晚的到期日，不疊加天數。
- **給夥伴用的檢定**是主角的魅力調整值＋熟練（和提議接客一樣的 DC 公式），不吃情境修正。
- **泌乳的事件效果**（任務、事件讓人泌乳）和內容編輯器一起放在 P5；這一版的效果種類還沒有「泌乳」。

### 11.4 P4 實作時和計畫不同的地方（2026-11-10）

- **懷孕的雙面效應要先察覺**：還沒察覺時戰鬥中也沒有加成（和平常的減值一樣）。
- **「有隊友倒下」在每個角色的回合開始時更新**，不是倒下的那一刻；倒下的人被救起來之後，下一個回合開始就不算。
- **產後的生命上限 ×0.8 一律生效**，不看有沒有修流派、慾望戰鬥有沒有開（它不是雙面效應）。
- **靈巧的減值也算在先攻上**：先攻本來就是靈巧的檢定，計畫沒有特別寫。
- **形象圖**：懷孕與泌乳寫在外貌後面（中文加上英文的 pregnant、lactating），沒有另外的模板代號。

### 11.5 P5a 實作時和計畫不同的地方（2026-11-10）

- **懷孕的階段欄位叫 `preg_stages`**（寄生物的 `stages` 是數字的階段，兩個不能共用）。
- **察覺事件的 DC 照寫的**，不像地下城、寄生物的事件依層或等級調整（P2 的文件寫錯了，這次一起改）。
- **察覺事件不在走動時擲**，只有孕期事件會。
- **察覺事件與孕期事件共用冷卻**（12 小時）；最近出現過的避開 6 件。
- 夥伴的孕期事件裡，主角幫忙揹行李會得到「腰痠背痛」（狀態是給主角的）。

P6 和 P1～P5 互不依賴（只共用「產後虛弱」與泌乳的來源），可以在 P1 之後任何時候做。

**存檔**：`pregnancies`、`children`、`lactation` 都是選填，讀舊存檔時補成空的，不用升存檔格式。苗床存在原本的 `Character.parasites`，多的欄位也是選填。

**測試**（`src/__tests__/pregnancy.spec.ts`、`children.spec.ts`、`lactation.spec.ts`、`brood.spec.ts`）：
- 篩選關掉、存檔規則 0 時不受孕
- `npcLife` 的私生活不會受孕
- 只收 `sexCandidates` 裡的人
- 報告有怪物、對象沒有 id 時不擲
- 兩位以上可能的父親時記「父親不明」
- 同一則日誌只擲一次，固定種子、重讀結果一樣
- 階段照比例縮放
- `advanceTime` 一次跳很多天也會觸發生產
- 娼館接客不受孕
- 嬰兒不出現在 `sexCandidates`、NPC 登錄、「這裡的人」、奴隸市場
- 自動送來的嬰兒：有房子送房子（母親那座城優先）、沒有送神殿、沒有搖籃也放得進去
- 寄養費的累積與欠費擋服務
- 搖籃有嬰兒時不能收起
- 泌乳的來源到期、卸下裝備時拿掉
- 陽剛主角不能用泌乳道具
- 苗床：篩選關掉不會發生；非自願的來源要「主角非自願」打開；一般怪物只在色情戰敗事件擲、戰鬥中不會被植入；幼體怪物不會造成苗床；胎生和懷孕互斥；懷孕中不會變成任何苗床；侵蝕度到支配時產下；魔物幼體帶 `young`、不進任何成人系統

## 12. 怪物的苗床

怪物不會讓人懷孕（決定 4）；怪物造成的一律做成**寄生物**的一類「**苗床**」（`parasites.json` 的 `category: "brood"`），沿用寄生物的侵蝕度、階段、被動效果、發作事件、解咒與內容編輯器（[ADULT_EVENTS](../../ADULT_EVENTS.md) 第 6 節）。分三種：

| 種類 | `brood.kind` | 是什麼 | 要有子宮 | 多快（侵蝕度每天） | 到「支配」時 |
|---|---|---|---|---|---|
| **卵生** | `egg` | 怪物把卵產在體內，卵慢慢長大 | 不用 | +25（約 4 天） | 產卵：排出魔物卵（物品） |
| **胎生** | `live` | 怪物的種在子宮裡長成幼體 | **要** | +5（約 18 天） | 產仔：生下魔物幼體 |
| **寄生** | `parasite` | 幼蟲、孢子在體內寄生、吸取養分 | 不用 | +10（約 9 天） | 破繭：排出，或修了獸蟲派的人可以讓它共生 |

**寄生植物的種子**（現有的）歸到寄生這一種，規則、數值都不變，只是在寄生物頁籤裡顯示在「苗床」底下。

### 12.1 開關與誰會變成苗床

- 內容篩選「**怪物的苗床**」（`monster_brood`，**預設關**）與存檔規則「苗床的機率」（0～3 倍）。篩選關掉時不會變成新的苗床；已經有的照常長到產下（和懷孕一樣不會憑空消失）。
- 非自願的來源（戰敗、戰鬥中被植入）還要「主角非自願」打開；自己屈服的事件選項只看苗床的篩選。
- **只有主角**：寄生物本來就只放在主角身上。夥伴的苗床放在第 13 節。
- **身體**：卵生、寄生誰都可以，陽剛主角也行（敘事照現有的 `mascBodyNote`）；胎生要有子宮，條件和懷孕一樣（第 2 節）。
- **互斥**：
  - 懷孕中不會變成任何苗床（不做流產，避免兩件事打架）
  - 有胎生的苗床時不會受孕（第 2 節），也不會再有第二個胎生
  - 卵生、寄生可以同時存在，每一種最多一個（同一種寄生物最多一個是現有的規則）

### 12.2 怎麼變成苗床

| 來源 | 規則 |
|---|---|
| **色情戰敗事件** | 圍住主角的怪物有 `brood`（`enemies.json` 新欄位，寫苗床的寄生物 id）時：沒能擺脫 30%、吃了大虧 60%，再乘上「苗床的機率」（`defeat.ts`）。看第一隻有 `brood` 的怪物。**成人向的怪物與一般怪物都算**（決定 16）；只有走成人向的戰敗事件才擲（設定裡戰敗的成人向關掉時不會） |
| **戰鬥中被植入**（只有成人向的怪物） | 能力的新欄位 `brood: { parasite, chance }`（例如「產卵管」）：命中時主角多一層戰鬥狀態「被植入」；戰鬥結束時每一層擲 `chance`（暫定 15%），中了就變成苗床。打贏也一樣，因為卵已經在體內了 |
| **地下城事件、寄生物發作、任務** | 現有的效果「寄生物」直接寫苗床的 id（屈服的選項） |
| **園區的專屬戰敗** | 蟲之溫室現在給寄生植物的種子；苗床的蟲后、觸手母體這類頭目改成給各自的苗床 |

- 變成苗床當下就**知道**（不像懷孕有「未察覺」），寄生物分頁直接顯示。日誌寫一筆。
- **侵蝕度照長**：現有規則是「發作被擋掉的日子侵蝕度不長」，苗床例外，每天照 `grow_per_day` 長，不然「主角非自願」關掉時會永遠產不下來。

### 12.3 卵生

| 階段 | 平常 | 戰鬥中（修了流派） |
|---|---|---|
| 潛伏、發作 | 靈巧 −1 | 減傷 +1 |
| 共生 | 靈巧 −1，腹部脹滿：旅途時間 ×1.1 | 減傷 +1、豁免 +1 |
| 支配 | 觸發產卵 | — |

- **產卵事件**（事件視窗）：自己用力（力量檢定，失敗多一天「產後虛弱」）、請隊友幫忙（親密度最高的那位，親密度 +1）、屈服（進入親密場景）。
- **產出**：魔物卵 1～6 顆（照苗床寫的 `yields`）：
  - **蜂卵**：煉金材料（媚液類）
  - **蛛卵**：煉金材料（拘束用的絲）
  - **蛇卵**：料理材料，做滋補的燉品；也是蛇溪洞窟「產卵室」任務線裡的那種卵
  - 都可以賣給魔法物品店，第一版**不會孵化**。

### 12.4 胎生

| 階段 | 平常 | 戰鬥中（修了流派） |
|---|---|---|
| 潛伏 | 沒有 | — |
| 發作 | 靈巧、潛行 −1 | 豁免 +1 |
| 共生 | 靈巧、潛行 −1；開始泌乳（篩選「泌乳」要開） | 豁免 +1、減傷 +1 |
| 支配 | 靈巧、潛行 −2；觸發產仔 | 豁免 +2、減傷 +1 |

- **產仔事件**：和人的生產一樣看地點（神殿、房子或旅店、野外），失敗只會讓產後虛弱變長，不會死。之後得到 1～3 隻**魔物幼體**，當場選怎麼處理：
  - **放回巢穴**：沒有任何後果，只是敘事（決定 17）
  - **交給魔物學者**：魔法物品店、情報商收，給錢，照怪物的等級算
  - **交給神殿淨化**：免費，所在地的神殿聲望 +1
- **魔物幼體不是嬰兒**：
  - 不進 `state.children`，也不取名字
  - 一律帶 `young` 特徵：慾望戰鬥本來就排除 `young`（`combat.ts`），也不會出現在任何成人向的描寫
  - 交給 AI 時只寫「生下了幾隻某某的幼體」
- **計數與稱號**：記下產過幾次（`state.counters` 或寄生物的紀錄），新稱號「魔物的苗床」（產仔 3 次以上），只顯示、和現有稱號一樣不影響數值。
- 產下之後泌乳再持續 15 天（第 8 節）。

### 12.5 寄生

| 階段 | 平常 | 戰鬥中（修了流派） |
|---|---|---|
| 潛伏、發作 | 每天長休回復的生命 −10%（被吸走養分） | 毒傷害 ×0.9 |
| 共生 | 同上，再加智力 −1 | 毒傷害 ×0.8、豁免 +1 |
| 支配 | 觸發破繭 | — |

- **破繭事件**：排出（得到蟲蛻、孢子囊這類材料），或者**修了獸蟲派入門**的人可以選**共生**：寄生物變成已馴服，不再發作，給一個被動效果（例如毒傷害 ×0.85），和魅魔的契紋馴服之後一樣留著。
- 寄生植物的種子照現有的規則（開花產下），不加共生的選項。

### 12.6 拿掉

照現有的解咒（神殿、刻印師，[ADULT_EVENTS](../../ADULT_EVENTS.md) 第 6.5 節）。另外加一個比較便宜的「**取出**」，只對卵生、寄生：在魔法物品店或煉金術士付錢、擲智力檢定，暫定 DC 12、200 白鸛。胎生只能解咒。

### 12.7 內建的苗床（建議）

| 種類 | 苗床 | 哪些怪物 |
|---|---|---|
| 卵生 | 蜂卵 | 產卵寄生蜂、苗床的蟲后 |
| 卵生 | 蛛卵 | 淫巨蛛、石心魔蛛 |
| 卵生 | 蛇卵 | 淫蛇、霧鱗蛇魔、溪蛇魔母、絞纏的大海蛇 |
| 胎生 | 觸手之種 | 深淵觸手、深水觸手、觸手母體、觸手藤、巨妖觸手 |
| 胎生 | 史萊姆的核 | 媚藥史萊姆、粉紅史萊姆母體、失控的魔力史萊姆 |
| 寄生 | 蛞蝓的幼體 | 淫蛞蝓、溫室的蛞蝓王 |
| 寄生 | 水蛭的幼體 | 媚液水蛭、血岩水蛭 |
| 寄生 | 孢子 | 異界孢子母體、孢子寄生的走獸 |
| 寄生 | 寄生植物的種子 | （現有的，不改） |

上面是成人向的怪物：戰敗事件與戰鬥中被植入都會。

**一般怪物**（決定 16）：**只在色情戰敗事件**造成苗床，能力不加 `brood`。用到的苗床一樣是寄生物，資料照種類補上：

| 種類 | 苗床 | 哪些怪物 |
|---|---|---|
| 胎生 | 哥布林的種 | 哥布林與各種哥布林 |
| 胎生 | 獸種 | 灰狼、雪原狼、白狼、霜鬃狼、草原狼群、蒼狼這類狼 |

- 名單是建議，做資料時照 `enemies.json` 的實際內容整理；內容編輯器可以自己加。

### 12.8 內容編輯器

- 寄生物頁籤：新的類別「苗床」，加上種類（卵生、胎生、寄生）、要不要子宮、產出（物品與數量）、幼體（哪一種怪物、幾隻）
- 怪物頁籤：「苗床」（選一個苗床的寄生物）
