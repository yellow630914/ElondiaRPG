埃隆迪亞大陸（ElondiaRPG）本機版

遊戲是網頁做的，要經由本機的小伺服器開啟（直接雙擊 game\index.html 打不開）。

【Windows】
  雙擊「Start-Windows.bat」。會出現一個黑色視窗並自動打開瀏覽器。
  遊玩時不要關掉黑色視窗；關掉它就停止遊戲。
  若 Windows 跳出「Windows 已保護您的電腦」，按「其他資訊」→「仍要執行」。

【macOS】
  第一次：在「Start-macOS.command」上按右鍵 →「打開」→ 再按「打開」（之後雙擊即可）。
  需要 Python 3；沒有的話終端機會提示安裝方法。

【Linux】
  在這個資料夾執行 ./start.sh（需要 python3）。

遊戲網址固定是 http://localhost:8473/ 。
存檔、世界與設定存在瀏覽器裡，並且跟這個網址綁在一起：
  ・換瀏覽器、清除網站資料，或改玩線上版，都看不到原本的存檔。
  ・要搬移或備份，請在遊戲右上角「存讀檔」匯出，再到新的地方匯入。
  ・更新到新版本時，解壓到任何地方再用同樣方式開啟，存檔還在（同一個瀏覽器）。

不想安裝也可以直接玩線上版：https://yellow630914.github.io/ElondiaRPG/
