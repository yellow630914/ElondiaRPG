# 平衡性自檢流程

> 生成的內容要能玩：怪物打得過、但不無聊；物品與報酬不會讓錢暴增；技能與特質不會強過內建的。這個資料夾說明怎麼用**世界檢查**自檢，以及工具沒有涵蓋、要自己對照的地方。
> 工具：`src/__tests__/worldCheck.ts`（檢查的內容）、`src/__tests__/balanceSim.ts`（戰鬥模擬）。目標數字來自系統文件 [MONSTERS](../../docs/MONSTERS.md)、[GUILD](../../docs/GUILD.md)、[ITEMS](../../docs/ITEMS.md)、[PERKS](../../docs/PERKS.md)。

## 1. 迴圈

```
寫一批內容 → 跑世界檢查 → 讀 check-report.md → 修 → 再跑，直到沒有錯誤
```

```
WORLD=worldgen/worlds/<代號>/world.json WORLD_TRIALS=6 npx vitest run src/__tests__/worldCheck.spec.ts
```

- **一批一批來**：每寫完一種內容（例如一個地區的怪物）就跑一次，不要整個世界寫完才第一次跑。
- 邊寫邊查用 `WORLD_TRIALS=6`（快、但有誤差）；交付前用預設的場數再跑一次，以那一次為準。預設是每種戰鬥 20 場；層主戰的雜訊大，不論設定多少都至少跑 40 場，而且場數少於 20 時層主勝率超出範圍只列成提醒。
- 模擬隊伍的技能只從內建的能力裡學（改過的內建能力照改過的算）：世界包新增的玩家技能不會讓基準跟著動。
- 測試失敗＝報告裡有錯誤。報告開頭是錯誤、提醒、說明的數量。

## 2. 報告的三種等級

| 等級 | 意思 | 要怎麼做 |
|---|---|---|
| ❌ 錯誤 | 匯入時會被丟掉（特殊任務、條目），套用時出錯（包括地標、商店擺不上去的格子），或數值超出目標 | **一定要修到 0** |
| ⚠️ 提醒 | 「整理時改了」＝你寫的欄位被修正或拿掉（寫錯了；寫成 `false`、0、空的這類預設值被拿掉的不算）；不支援的效果（附替代的寫法）；不存在的掉落與配方材料、店主顧的店不在他的所在地；名稱重複；遊戲裡遇不到的怪物；價格、報酬偏離 | 「整理時改了」一定要處理；其他的逐條判斷，有理由保留時寫進世界資料夾的說明 |
| ℹ️ 說明 | 數量統計、只有認識才找得到的 NPC、整理時補上 `combat_only` 的道具…… | 看過就好 |

## 3. 各種內容檢查什麼

| 內容 | 工具會檢查 | 要自己對照 | 文件 |
|---|---|---|---|
| 怪物 | 耐打度（小怪 3～4.5 下、層主 4～5 回合）、小怪兩隻一組的戰鬥（依區域的掉血與勝率）、層主戰的勝率、有沒有出現地點、同名 | 等級對地區、經驗值、掉落、技能組合理不理 | [monsters](monsters.md) |
| 技能 | 每行動點的傷害不超過內建同級最強的 1.25 倍 | 控制、治療、增益的強度；行動點與次數限制 | [abilities](abilities.md) |
| 物品 | 裝備價格對照組成的估價；其他物品對照同種類的價格範圍 | 使用效果的強度、取得的難易、會不會被拿來套利 | [items](items.md) |
| 狀態、特質、刺青 | 特質強度不超過內建最強；誓約刺青加總為 0（整理時檢查） | 狀態的數值、持續回合；特質的取得條件 | [statuses-perks-tattoos](statuses-perks-tattoos.md) |
| 經濟 | 特殊任務的完成報酬對照階級 | 事件的金錢與物品、商店的價格與交易 | [economy](economy.md) |
| 特殊任務 | 有錯誤的任務（匯入時不收）與提醒（旗標沒有地方設定……） | 難度對階級、節奏、報酬 | [stories](stories.md) |

## 4. 工具沒有測到的

- **組合效果**：一件裝備、一個特質、一個技能各自都合格，疊在一起可能太強。設計時想一下最壞的組合（同一個角色全部拿到）。
- **AI 判定**：自由行動與事件的結果由 AI 判定，數值上限在系統裡（`caps`），內容只要不在描述裡暗示過大的報酬即可。
- **故事上的平衡**：主線太長、支線太多同一種、某個地區什麼都沒有……用規劃清單（`npcs.md`、`stories.md`）自己看。
