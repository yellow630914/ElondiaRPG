# 技能的平衡

> 欄位與寫法見 [guides/abilities](../guides/abilities.md)；規則見 [COMBAT_SYSTEM](../../docs/COMBAT_SYSTEM.md)。

## 1. 傷害：工具的檢查

工具用「每行動點的期望傷害」比較（不含屬性調整值，武器骰算 1d8，全體技能算 2 個目標、隨機多目標最多算 3 個；行動點用遊戲裡實際的消耗：沒寫 `ap` 時技能 2、法術依環數、戲法算 1），**不能超過內建同級最強的 1.25 倍**。內建的參考值（2026-10）：

| 等級帶 | 中位數 | 最強 |
|---|---|---|
| 戲法 | 4.5 | 7.0 |
| 技能 1～2 級 | 3.4 | 4.5 |
| 技能 3～4 級 | 4.0 | 4.5 |
| 技能 5～6 級 | 3.0 | 9.0 |
| 技能 7～8 級 | 6.8 | 14.0 |
| 技能 9～10 級 | 5.6 | 9.9 |
| 技能 11～12 級 | 5.8 | 7.3 |
| 技能 13～14 級 | 6.8 | 7.0 |
| 技能 17～18 級 | 7.5 | 9.7 |
| 1 環法術 | 6.8 | 10.5 |
| 2 環 | 13.5 | 13.5 |
| 3 環 | 18.7 | 18.7 |
| 4 環 | 16.7 | 16.7 |
| 5 環 | 18.7 | 24.0 |
| 6 環 | 18.8 | 33.8 |
| 7～8 環 | 20.1 | 21.0 |
| 9 環 | 22.4 | 28.0 |

**設計時對準中位數**，不要對準最強：最強的那幾個通常有代價（次數限制、要專注、只打一個）。

## 2. 自己對照的

| 種類 | 怎麼比 |
|---|---|
| 治療 | 和同環（同級）的內建治療比骰子與加值；全體治療約是單體的一半 |
| 控制（暈眩、恐懼、束縛……） | 一定要有豁免（`resolve: save`）；持續 1～2 回合；群體控制只給 3 環以上的法術 |
| 增益、減益 | 數值照狀態的平衡（[statuses-perks-tattoos](statuses-perks-tattoos.md)）；一個技能不要同時給多種強增益 |
| 次數限制 | 強的效果用 `uses`（每場、每次休息）限制，不要靠高行動點 |
| 怪物的技能 | 不受上表限制（怪物的強度由怪物的模擬檢查），但低血大招要用 `ability_hp_below` 限制時機 |
