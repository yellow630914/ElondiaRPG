## 2. 特殊任務的報酬（工具會檢查）

- 完成報酬的金錢建議是任務階級一般委託的 **1～3 倍**（多個任務點、有劇情、有風險）；超過 3 倍會被提醒。比同階一般委託還少也會提醒（除非報酬是物品、特質或人情）。
- 中途的任務點也可以給錢，但加總不要超過完成報酬。
- 物品與裝備報酬：價格（或估價）算進總額；獨特物品另外考量（見 [items](items.md)）。

## 3. 事件與商店（自己對照）

- **旅途與城鎮事件**：金錢的得失多半在 20～250 白鸛（內建的旅途與城鎮事件是 −150～+400）；會反覆發生，報酬要小。
- **商店的交易（deals）與收購**：不要讓「買進→賣出」或「便宜材料→打造→賣出」有明顯的利潤。
- **新物品的目錄價**：對照 [基本價格依據表](prices.md)：同一類裡做工、材料越多的越貴，武器、防具大約是中世紀普通貨的 1～3 倍。
- **跑商**：城鎮標籤與狀態讓同一類東西在各地價格不同，改了 `market.json` 的倍率、狀態或收購遞減之後，跑一次 `TRADE_SIM=1 npx vitest run src/__tests__/tradeSim.spec.ts`，對照 [trade-sim](trade-sim.md)：平常每天的利潤要遠低於同階委託，最好的一趟也不要超過 B 級委託太多（[TRADE](../../docs/TRADE.md) 3.4 節）。
- **固定 NPC 的雇用費**：照同等級、同職業的內建角色。
