# 特殊任務的平衡

> 欄位與寫法見 [guides/stories](../guides/stories.md)；設計見 [design/story-design](../design/story-design.md)；規則見 [STORY_QUESTS](../../docs/STORY_QUESTS.md)。

## 1. 工具的檢查

- **錯誤**（匯入時整條不收）：沒有結果會完成任務、任務點沒有地點、引用不存在的 NPC／怪物／物品／特殊地圖、選擇沒有選項、戰鬥沒有敵人……（`storyMods.ts` 的 `storyCheck`）。
- **提醒**：需要的旗標沒有地方設定、只由其他事件開啟卻沒人開啟、指定的格子走不到……
- **報酬**：見 [economy](economy.md) 第 2 節。

## 2. 自己對照的

| 項目 | 參考 |
|---|---|
| 階級 | `rank` 是建議的公會階級（接取時檢查）。戰鬥任務點的怪物等級要對得上階級（公會階級的等級帶，`progression.json` 的 `guild_ranks`：F 1～2 級、E 3～4、D 5～6、C 7～8、B 9～10、A 11～12、S 13～20） |
| 判定的 DC | 一般 10～14，困難 15～18，極難 19 以上；同一條任務不要連續三個高 DC 的判定 |
| 長度 | 支線 2～4 個任務點，主線一章 4～8 個；超過的拆成幾條（用「開始特殊任務」效果接起來） |
| 期限 | 有時間壓力的才設 `time_limit`；天數要夠來回路程（見 [GUILD](../../docs/GUILD.md) 第 0 節的委託期限） |
| 失敗 | 失敗的結果不要直接讓主角死亡或失去大量財物；淪為奴隸這類重大後果只放在明確選擇的分支 |
