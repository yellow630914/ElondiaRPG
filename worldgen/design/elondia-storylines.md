# 內建世界的故事線規劃（艾隆迪亞）

> 這份是內建世界擴充的故事線藍圖（2026-10 和作者討論定下的方向）。已經做成特殊任務的見第 5 節。
> 角色先做（見 `data/world/npcs.json`），故事線之後照這份逐條設計；做法見 [story-design](story-design.md)。

## 1. 總體結構

### 1.1 一條故事線

- 每條故事線由 **2～3 個特殊任務**組成，等級大致是：
  - 第一個任務：Lv.5～7 接
  - 第二個任務：Lv.8～10 接
  - 第三個任務：Lv.11～13 接
- **開頭**可以用看起來普通的任務慢慢引入（例：教義重新解釋的故事線，從一名牧師的一本筆記開始），也可以直接切入正題（例：安納塔西亞從教國回王國時，馬車遇襲）。
- 任務和任務之間是相對空閒的時間，讓玩家去練等。

### 1.2 主戰與主和

許多故事線的結局會把世界推向**主戰**或**主和**（下表標「⚔／🕊」）。每條會記錄一個劇情旗標，最後由人類方、魔族方各自的多數決定史詩線的走向。

| 勢力 | 主戰派 | 主和派 |
|---|---|---|
| 萊茵帝國 | 四軍團中的主戰將軍 | 皇帝（停戰是他一手促成）、主和將軍 |
| 聖環教廷 | 教廷（整體主戰） | — |
| 晨曦王國 | 皇子阿列克謝 | 公主安納塔西亞 |
| 魔族 | 瓦爾卡斯（若反叛）、血角氏族 | 莉莎爾的律法體制 |

在河谷鎮、沿海渡口這類各國角力的故事線裡，**帝國主和、教廷主戰**，其他勢力照各自的立場。

### 1.3 兩條史詩級故事線（Lv.14～18，切成多個特殊任務）

1. **政治鬥爭的匯流**：人類世界與魔族世界的政治鬥爭，最後匯集成一條史詩線。
   - 人類方、魔族方的**主戰派佔多數** → **開戰路線**：玩家一開始要選陣營，經歷開戰路線的任務。
   - 人類方、魔族方的**主和派佔多數** → **清剿主戰派路線**：去多個城鎮協助清剿主戰派。
   - 兩條路線最後都會引發**龍災**（歷史之龍「回響編年」阿契隆的注視）。
2. **巨龍史詩**：依照之前的選擇，正式解決各地的龍災。

## 3. 成人向角色與戀愛線（第二部分）

### 3.1 大方向

- **男性向**：戀愛與成人向的對象是女性、偽娘、扶她、TS；**不寫傳統男性與傳統男性**的戀愛或性愛。
- **全部是成年人**：每個角色都在背景寫明二十歲以上（長壽種族寫明「以族人來說已成年」）。嬌小的角色不寫成孩子的樣子。
- **每個人有一種魅力**：強勢的千金大小姐、寂寞的少婦、純情的魅魔、病嬌的賣花姑娘……先想好「這個人迷人在哪裡」，再寫外貌與性格。參考的屬性：大小姐、人妻、熟女、母性、無口、傲嬌、病嬌、天然、女僕、雙胞胎、女忍者、女醫、魔法少女、魅魔、偽娘、扶她、人外娘（史萊姆、幽靈、機偶）、精靈姊姊、女王。
- **個人故事線**：每人一條，大致輕鬆、帶有成人氛圍，最後通向兩人的結合（成為戀人、伴侶、入隊或住進主角的家）。等級照第 1.1 節的帶法，可以比主線短。
- **資料**：這些角色標成「成人向角色」（`adult: true`），成人向內容關閉時完全不出現；私密部位的描述放在「成人向外貌」。一般角色的關係不寫到成人向角色。
- 第一部分的角色之後也會有戀愛線，放在他們自己的特殊任務裡。

特定角色的任務線要在接任務前（以及冒險手冊裡）顯示警示，讓玩家自己決定要不要接：

- **NTR**：例如阿雅線的 NTR 分支（媚黑俱樂部）。
- **非處女**：角色在任務開始前就有性經驗，例如人妻（艾蜜莉亞、瑪格麗特、莉澤洛特、克拉拉）、伊蓮娜、卡蜜拉、花魁瑟蕾娜、貝爾維婭（曾被盜賊抓去當玩物）、卡珊卓。

做法（已經做好，見 docs/STORY_QUESTS.md 第 1.2 節）：任務的內容標籤（成人向、NTR、非處女、主角非自願），接任務時與冒險筆記顯示成警示；分支型的（只有某個選項會進入 NTR）標在那個選項上。玩家可以在設定裡關掉 NTR、非處女、主角非自願（關掉的任務不開放、選項不出現）。

- **做給女性主角的任務**（遭到灌醉、色情寶箱怪……）打上「主角非自願」，開頭用「只給這些主角」限定女性形象。
- **戰敗色情事件**本身也算主角非自願：關掉「主角非自願」就不會發生；另外可以設成「男性形象的主角不發生」或關閉。

## 4. 其他種類的特殊任務（之後再談）

- **獨特物品任務**：傳說之劍、英雄的遺物、聖物、遠古的造物……數值超越同等級裝備、有獨特屬性（也可能是沒什麼用的成人向裝備）。
- **短篇任務**：某個村的小故事、神秘的寶圖、小型色情事件（豔遇、遭到迷姦、色情寶箱怪……）。
- 任務可以標記成**成人向**。
