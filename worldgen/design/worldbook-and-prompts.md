# 世界書與提示詞

> 目標：世界生成完之後，把新的人、事、地寫回世界書，產出一組新的提示詞，和內容一起打包成世界包。玩家匯入世界時，這組提示詞會一起建立並綁定（切換世界時自動切換）。
> 格式見 [guides/content-file](../guides/content-file.md) 第 5 節；範例見 [worlds/elondia-plus/parts/prompts.json](../worlds/elondia-plus/parts/prompts.json)（由 [scripts/gen_prompts.py](../worlds/elondia-plus/scripts/gen_prompts.py) 產生）。系統規則見 [PROMPTS](../../docs/PROMPTS.md)。

## 1. 世界書在遊戲裡怎麼用

每次請 AI 寫正文時，遊戲從世界書挑條目注入：

| 注入方式（`mode`） | 什麼時候注入 | 放在哪裡 |
|---|---|---|
| `constant` 常駐 | 每次 | system 前段（可以被快取） |
| `keyword` 關鍵字 | 報告的文字命中任一個 `keys` | user 後段 |
| `travel` 旅行 | 只有旅行報告 | user 後段 |
| `off` 停用 | 不注入 | |

- **拿來比對關鍵字的文字**：所在地點與地區的名稱、場景描述、這次結果的摘要、**在場人物的名字**、遇到的人的種族、委託的目標地點（`src/narrator/lore.ts` 的 `reportLoreText`）。所以「人物條目用名字當關鍵字」在那個人出現時一定會觸發；用「教皇」這類稱號當關鍵字，則是在場景或摘要提到時觸發。
- **繁簡都比**：比對前會把文字轉成簡體再比一次。關鍵字用繁體或簡體都可以；內建世界書是簡體，新條目用哪一種都行。
- **字數上限**：預設 12,000 字（設定裡可以調）。常駐的先放，觸發的依 `order` 往後排，超過就丟掉。**常駐條目要短**，長的內容一律用關鍵字。
- **內建條目的預設**：世界觀（uid 0）、勢力概述（28）、神祇（44）常駐；區域、種族、價格參考依關鍵字；地標相對位置（46）只在旅行時；規則類條目停用（由遊戲引擎實作）。

## 2. 生成完之後要寫回什麼

| 新增的內容 | 寫到哪裡 | 怎麼寫 |
|---|---|---|
| 勢力的現任統治者、首領 | 改寫 **uid 28「区域地理与势力划分概述」**（常駐） | 在原文後面加「各势力现任首领」，每個勢力一行，只寫名字與一句話 |
| 一個地區的重要人物（A、B 層與 ⭐） | 改寫那個地區的「区域-…」條目（uid 6、7、27、32、33、41） | 原文後面加「重要人物（当代）」，依地點分組，每人一行：名字（出現的地方）：身分與性格 |
| 地區故事線、地下城傳說的開頭 | 同上，加「近来的传闻」 | 每條任務一句，寫成傳聞（任務的 `summary` 通常可以直接用），**不寫結局** |
| A 層人物（統治者、勢力首領） | 新增 `customLore`「人物-<名字>」 | 關鍵字：全名、去掉稱號的名字、名字的第一段、獨有的稱號；內容：身分、所在、性格、外貌、背景、人際關係 |
| 主線 | 新增 `customLore`「主线-<名稱>」 | 關鍵字：主線獨有的名詞（道具、現象、委託人的名字）；內容：核心設定、各章摘要、已知的線索。開頭寫明「尚未經歷的部分不要提前揭露」 |
| 新的地標、特殊地圖 | 那個地區的「区域-…」條目，加在該城的「特色建筑」下；或新增 `customLore`「地点-<名稱>」，用地標名稱當關鍵字 | 地標與特殊地圖本身已有說明會送給 AI，世界書只補「傳說、誰在那裡、和什麼事有關」 |
| 新的組織、派系 | 新增 `customLore`「势力-<名稱>」 | 關鍵字：組織名稱與成員常用的稱呼 |
| 獨特物品的傳說 | 新增 `customLore`「传说-<物品>」 | 關鍵字：物品名稱 |
| 改寫原本的設定（例如換了時代、某國已經滅亡） | 改寫對應的內建條目（`lore`） | 整段改寫，前後要一致：同一件事出現在幾個條目，每一個都要改 |

怪物、技能、狀態不用寫進世界書：戰鬥與報告會直接帶上它們的資料。

## 3. 寫法守則

1. **`uid`**：新增的條目從 100000 開始、不重複（不合的整條會被丟掉）。同一個世界的條目連號，方便查。
2. **`order`**（越小越前面）：內建的大致是核心 1～3、規則 100～160、種族 400～405、地理 499～506、神祇與巨龍 600～602、價格 800～813。建議主線 610、勢力 620、地點 630、人物 650、傳說 660。
3. **關鍵字**：
   - 要**夠獨特**：不要用「王」「門」「龍」「村」這種一定會撞到的單字；兩個字以上，最好三個字以上。
   - 人物：全名＋去掉「」稱號的名字＋名字的第一段（「瓦倫汀・克雷」→「瓦倫汀」）＋獨有的稱號（「教皇」「矮人王」「潮主」）。兩個勢力都有的稱號（「女王」）要加限定詞（「晨曦女王」「精靈女王」）。
   - 主線：用玩家在任務文字裡一定會看到的名詞。
4. **改寫內建條目**時，`content` 是**整段取代**：從 `data/worldbook/elondia.worldbook.json` 讀出原文，在後面加你的段落，不要手抄（抄錯會讓原本的設定不見）。用腳本產生，內建世界書更新時重新產生一次就好。
5. **格式**跟著世界書：縮排的「欄位: '內容'」。一個條目不超過 1,500 字；常駐條目加的段落不超過 500 字。
6. **不矛盾**：世界書已經有名字的人物，用那個名字；地點、勢力的名稱照 `geography.json` 與世界書。
7. **不劇透**：傳聞與主線只寫「現在大家知道的」；結局、真相寫在條目裡時，要明寫「玩家沒經歷前不要揭露」。
8. **成人內容**：只和成人場景有關的條目設 `"adult": true`，玩家沒開成人內容時不會注入。

## 4. 文風與其他提示詞

- `styles`（文風）與 `custom`（其他提示詞）**省略時用遊戲的預設**。生成世界通常只寫世界書。
- 玩家想要不同的文風：在遊戲的「提示詞」頁按「匯出設定」，拿那份檔案的 `styles` 修改後放進 `prompts.json`。寫了 `styles` 就整份取代預設的文風，所以要從匯出的檔案改，不要只寫一條。

## 5. 步驟

1. 列出這個世界新增的：統治者、各地區的重要人物、主線、地區故事線與傳說、新的地點、組織、獨特物品。
2. 照第 2 節決定每一項寫到哪個條目。
3. 寫產生腳本（`worlds/<代號>/scripts/gen_prompts.py`，可以照艾隆迪亞擴充的改）：從 `parts/` 的 NPC 與任務、規劃清單讀資料，從內建世界書讀原文，產出 `parts/prompts.json`。
4. `node worldgen/tools/build-world.mjs <代號>`，跑世界檢查：「說明」會列出修改內建幾條、新增幾條；uid 不合或重複是錯誤。
5. 在遊戲裡匯入世界包，到「提示詞」頁的世界書清單確認新條目都在（標著「自訂」）、改寫的條目標著「已修改」；走到那個地區、遇到那個人之後，用「👁️ 預覽」看條目有沒有觸發、字數有沒有超過上限。
