# 世界生成模板

> 玩家填這份，Agent 照 [WORLD_GUIDE](../WORLD_GUIDE.md) 依序生成。**複製一份到 `worldgen/worlds/<代號>/setting.md` 再填**，不要改這份模板。
> **空著的格子 = 交給 AI 依世界書決定。** 只填你在意的就好；什麼都不填，AI 會照原版世界書做出一個像 [艾隆迪亞擴充](../worlds/elondia-plus/) 的世界。
> 地圖是固定的：地點、路線、地區不能新增或改名（地點清單見 `data/world/geography.json`、世界書的「區域-…」條目），所有東西都放在現有的地點上。

## 1. 基本

| 項目 | 填寫 | 說明 |
|---|---|---|
| 世界的代號 | | 英文小寫與連字號，例如 `dark-age`；資料夾名稱 |
| 世界的名稱 | | 遊戲裡顯示的名字，例如「艾隆迪亞・黑暗時代」 |
| 一句話簡介 | | 匯入時顯示的說明 |
| 基調 | 史詩奇幻／黑暗／輕鬆冒險／宮廷權謀／其他： | 決定 NPC 的性格、任務的結局與世界書的語氣 |
| 成人內容 | 有／沒有 | 有的話可以有成人向的 NPC 標籤與世界書條目（`adult`） |
| 規模 | 小／中／大 | 見下表 |

| 規模 | 固定 NPC | 特殊任務 | 新怪物 | 地標、特殊地圖、商店 |
|---|---|---|---|---|
| 小 | 每個地區 5～8 位（約 40） | 主線 3 章＋每地區 1 條（約 10） | 0～10 | 只用內建的 |
| 中 | 每個聚落與地標都有人（約 80） | 主線 5 章＋每地區 2 條＋角色任務線（約 35） | 10～30 | 每地區 1～2 個 |
| 大 | 中的全部＋每個地標 2 位以上（約 120） | 中的全部＋每個 ⭐ NPC 一條（約 60） | 30 以上 | 每地區 3 個以上 |
